Relative luminance

3.67.12
L = 0.2126 × linear red + 0.7152 × linear green + 0.0722 × linear blue

Contrast ratio

3.77.67.12
ratio = (lighter L + 0.05) ÷ (darker L + 0.05)
choose black or white: the larger ratio wins
verdict = pass if ratio ≥ 4.5 ← policy step, checked separately
Example background L = 0.187 (card on the left)
black text0.187 + 0.05 = 0.237 0 + 0.05 = 0.05 0.237 ÷ 0.05 = 4.74
white text1 + 0.05 = 1.05 1.05 ÷ 0.237 = 4.430
choice4.74 > 4.430 → black
Range: 1 : 1 (same colors) to 21 : 1 (black on white: 1.05 ÷ 0.05 = 21). A background L below 0.50 does not automatically mean white text.

Dither: signed noise before the 8-bit store

7.107.10 companion
raw = ((column + 3) × 7 + (row + 5) × 13) remainder 16
unit = raw ÷ 15 ← 0 … 1
signed = 2 × unit − 1 ← −1 … +1
offset = signed × amount ← amount = 0.02, a channel number
stored8 = round(clamp(true channel + offset) × 255)
Why: many neighboring true values round to the same integer, which shows as a stripe (banding). The offset breaks the stripe. The pattern repeats every 16 × 16 pixels; it is a tile, not a dice roll.
Example column 200, row 80, true red 0.401
raw200 + 3 = 203 203 × 7 = 1421 80 + 5 = 85 85 × 13 = 1105 1421 + 1105 = 2526 2526 remainder 16 = 14
signed14 ÷ 15 = 0.933 2 × 0.933 = 1.866 1.866 − 1 = 0.866
offset0.866 × 0.02 = 0.017
store0.401 + 0.017 = 0.418 0.418 × 255 = 106.59 → round → 107
no noise0.401 × 255 = 102.255 → round → 102
