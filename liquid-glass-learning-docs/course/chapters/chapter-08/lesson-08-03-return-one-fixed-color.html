1 · THE NEW OBJECTS

Name half4, the 0..1 range, and the proof

half4

half4 in this lesson is four numbers packed together, in order: red, green, blue, alpha. The word half names a storage size. Lesson 8.7 explains half versus float. Here you only need “four numbers.”

0..1 channel

Each Metal color channel uses 0 for none of that channel and 1 for the full amount. Lesson 8.1 stored 8-bit integers 0..255. Lesson 7.10 stored round(clamped × 255). This return uses the 0..1 side of that pair.

Return is the store

Lesson 8.1’s store wrote a color into one cell. Here, return half4(...) is the store for the current output pixel. Because the body does not read position or color, every pixel of the rectangle stores the same four numbers.

Proof pair

Orange function versus navy function. Selecting navy applies labNavy, which Xcode compiled beside labOrange. A SwiftUI Color drawn in a separate rectangle, and never passed to colorEffect, does not change the fill. That unused color is the trap.

8-bit orange red = 224 224 / 255 = 0.878... teaching half4 red = 0.88 return half4(0.88, 0.48, 0.18, 1.0) → every pixel of the draw rectangle stores that color

0.88 is a teaching rounding of 224/255, matching Lesson 8.1’s orange. It is not a claim that 224/255 equals 0.88 exactly. Alpha 1.0 means the fill is opaque, so no lower layer shows through this rectangle.

Navy uses the same path. 8-bit (26, 64, 102). 26/255 = 0.10196... → 0.10. 64/255 = 0.25098... → 0.25. 102/255 = 0.40000 → 0.40. Teaching tuple half4(0.10, 0.25, 0.40, 1.0).

9 · EXERCISES
Answer before opening each hidden solution

    
What is half4 in this lesson?
Four numbers packed together, in order: red, green, blue, alpha. Each color channel is 0..1. Alpha 1.0 makes this fill opaque. Lesson 8.7 will explain half versus float.

    
Diagnostic: why not return half4(224, 122, 46, 1)?
Metal color channels here are 0..1. 224 is an 8-bit integer. 224/255 is about 0.878, teaching value 0.88. Returning 224 treats 224 as already 0..1, which is far above 1.

    
You switch the unused SwiftUI box from red to green. The shader still returns orange. What color is the shader rectangle?
Orange. The unused box is a separate view. It is never passed to colorEffect.

    
Why is every pixel of the rectangle the same color?
The body returns one half4 and does not read position or color. Lesson 8.4 will use the pixel coordinate so pixels can differ.
