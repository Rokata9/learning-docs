Chapter 8 · Hand the function to Android

Create a RuntimeShader

Question: Lesson 8.1 wrote a pixel function named colorAt(column, row) and a CPU loop that called it once per cell of an 8×4 grid. Android drawing does not ask you to write that loop. How do you hand a pixel function to Android so the GPU runs it?

An AGSL string is the pixel-function text. RuntimeShader compiles that string into a GPU program. ShaderBrush plus drawRect asks Android to fill a rectangle using that program.

1 · THE NEW OBJECTS

Name the string, the compile, and the draw

AGSL string

AGSL means Android Graphics Shading Language. It is the language this pixel-function text is written in. An AGSL string is that text stored in Kotlin as a String. It is not yet a running program.

Compile

Compile here means Android reads the AGSL string and builds a GPU program from it. The RuntimeShader constructor does that work. If the string is not valid AGSL, construction fails. Lesson 8.12 teaches those errors.

RuntimeShader

A RuntimeShader is the compiled GPU program object. It holds the pixel function the GPU will run. Creating it does not yet draw a rectangle. Added in Android 13, API 33. This project’s minimum SDK is 33, so the class is always present.

ShaderBrush and drawRect

A ShaderBrush is a Compose brush that paints using that program. drawRect(brush = brush) fills a rectangle. Every output pixel of that rectangle is then colored by the shader. You do not write a Kotlin for-loop over those pixels.

Entry function main

The entry function is the function the GPU starts. AGSL names it main. The signature is half4 main(float2 fragCoord). half4 is four numbers packed together; Lesson 8.3 names them. fragCoord is the GPU’s name for the current pixel’s position. The parameter must be present. This body does not read it. Lesson 8.4 will.

What stays from Lesson 8.1

A shader is still a pixel function the GPU runs. Same function body, once per output pixel. The new work is the handoff: string → compile → brush → draw. The CPU loop is no longer the runner.

AGSL string → RuntimeShader(string) compiles it → ShaderBrush(shader) → drawRect(brush) → GPU calls main once per output pixel of that rectangle

6 · ANDROID ROUTE
The real constructor lives in the explorer

    

      
private const val OrangeAgsl = """
half4 main(float2 fragCoord) {
    return half4(0.88, 0.48, 0.18, 1.0);
}
"""

val shader = remember { RuntimeShader(OrangeAgsl) }
val brush = remember(shader) { ShaderBrush(shader) }

Canvas(Modifier.fillMaxWidth().height(PanelHeightDp.dp)) {
    drawRect(brush = brush)
}

      

        
What each part changes

        
OrangeAgsl is the AGSL string. RuntimeShader(OrangeAgsl) compiles it. ShaderBrush(shader) is the Compose paint recipe. drawRect fills the Canvas using that recipe.

        
PanelHeightDp is 140. A short solid fill is enough to prove the program is attached. This is not glass geometry. The Canvas width is the explorer card width so the GPU program covers that rectangle.

        
remember keeps one RuntimeShader across recompositions. Creating a new one on every frame is not this lesson’s production path.

9 · EXERCISES
Answer before opening each hidden solution

    
What does the RuntimeShader constructor do to the AGSL string?
It compiles the string: Android reads the text and builds a GPU program. The result is a RuntimeShader object. Construction does not draw a rectangle.

    
Diagnostic: ShaderBrush(shader) exists and you have not called drawRect. Is the rectangle filled?
No. The brush is a paint recipe. Pixels are stored when drawRect(brush = brush) runs. Stage 3 of the lab shows that empty target.

    
Is this page’s orange rectangle a real RuntimeShader?
No. This page cannot compile AGSL. The orange is a JavaScript stand-in of the GPU output. The Android explorer runs RuntimeShader(OrangeAgsl).

    
Why must fragCoord appear in main if this body does not read it?
AGSL requires that entry-function signature. The GPU will pass the current pixel’s position. This lesson leaves the parameter unread. Lesson 8.4 teaches that value.
