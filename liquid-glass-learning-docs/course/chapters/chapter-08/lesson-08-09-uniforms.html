Chapter 8 · Pass Swift values that are not size

Uniforms

Question: Lesson 8.3 selected another stitchable function to change color. Lesson 8.5 passed only the rectangle size. How do you send a slider value and a color from Swift into the same compiled function?

A uniform is still a named extra argument. This lesson adds two arguments besides resolution: splitU, one fraction from 0.0 through 1.0, and leftColor, four channels each from 0.0 through 1.0. Swift passes them as .float and .float4. The .metal file is not rewritten. The GPU reads the same argument values for every pixel of this draw.
Time is Lesson 8.10. This page is a JavaScript stand-in. The iPhone 16 Pro explorer passes the real arguments. This lesson passes four floats. It does not pass .color, which can convert color spaces. A missing argument still lets the Swift file compile. SwiftUI refuses that draw. To show a zero slot, pass 0.

1 · THE NEW SLOTS

Resolution stays. Two more names join it.

8.3 leftover

Changing orange to navy meant selecting labNavy instead of labOrange. That path still works. It is the wrong path for a slider that moves every frame of a drag.

8.5 leftover

Resolution is already an argument. This lesson does not re-teach size. It keeps passing resolution so UV can be computed, then passes two more arguments.

splitU

float splitU is one fraction from 0.0 through 1.0. Swift passes the current slider value with .float. if (uv.x < splitU) uses that same number at every pixel. 0.5 is halfway. 0.25 is a quarter from the left.

leftColor

float4 leftColor is four channels, each from 0.0 through 1.0. Swift passes them with .float4. The function returns half4(leftColor). The else branch still returns teaching navy from the function, so only the left store is an argument.

Swift, once per draw: .float2(pixelWidth, pixelHeight) .float(splitU) .float4(r, g, b, a) ← three arguments, one compiled function ← pixel size is points × displayScale
Metal, once per pixel: float2 fragCoord = position * scale; float2 uv = fragCoord / resolution; if (uv.x < splitU) return half4(leftColor); return navy ← splitU and leftColor are the same for every pixel ← uv is not

ShaderLibrary looks uniformSplit up by name. A call that omits .float(splitU) still compiles. SwiftUI then refuses that draw, so the function does not run. There is no silent 0. To show the vanished band, pass 0. If splitU is 0, uv.x < 0 is false for pixels inside the rectangle, so every pixel stores navy. Lesson 8.12 is the Metal compile log. This lesson only needs that visible zero, and the fact that a missing argument does not fill the slot.

6 · iOS ROUTE
Three arguments, one compiled function

    

      
// shader/Uniforms.metal
[[ stitchable ]] half4 uniformSplit(
    float2 position, half4 color, float scale, float2 resolution,
    float splitU, float4 leftColor) {
    float2 fragCoord = position * scale;
    float2 uv = fragCoord / resolution;
    if (uv.x < splitU) {
        return half4(leftColor);
    }
    return half4(0.10, 0.25, 0.40, 1.0);
}

let pixelWidth = pointWidth * displayScale
let pixelHeight = pointHeight * displayScale
ShaderLibrary.uniformSplit(
    .float(Float(displayScale)),
    .float2(Float(pixelWidth), Float(pixelHeight)),
    .float(splitU),
    .float4(leftR, leftG, leftB, 1))

      

        
What each part changes

        
Xcode compiles uniformSplit when it builds the app. Slider and color changes do not compile a new function. Swift passes new arguments into the same function.

        
.float4 writes the four channels. This lesson does not pass .color, which can convert into the shader’s working color space. The teaching numbers match Lesson 8.3’s 0..1 channels.

        
Pass 0 is a button on this page and on the explorer. The default call passes the slider. Omitting .float(splitU) still compiles, and SwiftUI refuses that draw, so the missing-argument path is not a device toggle.

9 · EXERCISES
Answer before opening each hidden solution

    
What new arguments does this lesson add?
float splitU and float4 leftColor. Resolution is still passed, as in Lesson 8.5. Time is not an argument yet. The return packs leftColor into a half4.

    
Diagnostic: you change leftColor from orange to green. Does Xcode compile a new function?
No. Swift passes four new floats into the existing leftColor argument. Lesson 8.3 selected a different stitchable function. This path does not rewrite the .metal file.

    
You omit .float(splitU). What happens, and how do you show a zero split?
The Swift file still compiles, because ShaderLibrary looks the function up by name. SwiftUI refuses that draw. The function does not run, and the slot is not filled with 0. Pass 0 on purpose. Then uv.x < 0 is false inside the rectangle, the fill is navy, and the orange band vanishes.

    
Why not .color in this lesson?
That argument can convert the color into the shader’s working color space. .float4 passes the same 0..1 numbers Lesson 8.3 used. The conversion path is not measured here.
