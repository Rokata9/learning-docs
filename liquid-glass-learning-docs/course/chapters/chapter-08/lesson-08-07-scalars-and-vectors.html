Chapter 8 · Name the packs and the one-number type

Scalars and vectors

Question: Lesson 8.6 stored a float2 named uv. Lesson 8.3 stored a half4 color. What is one number, what is a packed group, and why do the words float and half differ?

A scalar in this lesson is one number, stored as float or half. A vector in this lesson is a packed group of those numbers. The digit in the type name is the count: float2 is two floats. half4 is four half numbers. A member is one named number inside the pack, such as uv.x.

1 · THE NEW NAMES

One number, a pack, a member, and two storage sizes

Scalar

Lesson 3.6 already used scalar for one luminance number. Here it is one Metal number: float t = uv.x. t is not a pair. It is not a color. The next consumer can copy it into red, green, and blue to paint a gray ramp.

Vector

A vector here is a packed group, not a physics velocity and not an arrow on a graph. float2 uv is two floats in order: x then y. half4 is four halfs in order: red, green, blue, alpha.

Member

A member is one named number inside the pack. uv.x is the first. uv.y is the second. Splitting on uv.y paints a horizontal cut. That is a different picture from Lesson 8.6’s vertical cut on uv.x.

half versus float

float is a 32-bit storage size. half is a 16-bit storage size. This course’s usual contract is: positions and resolution use float; the returned color uses half4. This lesson does not claim a frame-time difference.

float t = uv.x ← one number pulled out of the pair return half4(t, t, t, 1.0) ← that one number copied into three color slots
half4 color .x .y .z .w same four slots as .r .g .b .a ← r is x, g is y, b is z, a is w

Lesson 8.3 needed “four numbers” to return a color. This lesson names the pack, the count, the member, and the storage word. It does not remap which pixel is 0. That is Lesson 8.8.

6 · iOS ROUTE
Extract one member, then store a half4

    

      
// shader/ScalarVector.metal
[[ stitchable ]] half4 scalarGrayFromX(
    float2 position, half4 color, float scale, float2 resolution) {
    float2 fragCoord = position * scale;
    float2 uv = fragCoord / resolution;
    float t = uv.x;
    return half4(t, t, t, 1.0);
}

let pixelWidth = pointWidth * displayScale

9 · EXERCISES
Answer before opening each hidden solution

    
What is a scalar in this lesson?
One number. Example: float t = uv.x. Lesson 3.6 used the same word for one luminance value. Here the number lives in the stitchable function as float or half.

    
Diagnostic: is a vector an arrow?
Not in this lesson. A vector is a packed group of numbers. float2 is two floats. half4 is four halfs. An arrow picture would be a later use of those numbers, not the type itself.

    
What does color.r read compared with color.x?
The same first slot of the half4. .r .g .b .a are the color names for .x .y .z .w.

    
Why does this lesson not claim half is faster than float?
Storage size is a format. Frame time is a device measurement. This lesson has no iPhone 16 Pro timing. Lesson 6.10 already required a release-like measurement for that class of claim.
