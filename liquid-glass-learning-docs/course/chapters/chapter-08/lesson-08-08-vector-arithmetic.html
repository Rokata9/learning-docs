Chapter 8 · Move the origin, then scale distances

Vector arithmetic

Question: Lesson 8.6’s UV pair is 0 at the top-left. A later lens sits in the middle. How do you move and scale that pair so the middle becomes 0?

1 · THE NEW OPERATIONS

Subtract to move. Multiply to scale.

UV origin

UV is 0 at the top-left. The visual center is about (0.5, 0.5), not (0, 0). A later circle that asks “how far from 0?” would sit in the corner unless you move the origin first.

Subtract a pair

p = uv - float2(0.5, 0.5) subtracts 0.5 from each member. The visual center becomes (0, 0). Left is negative x. Top is negative y, because y increases downward.

Multiply by one number

p * 2.0 multiplies both members by 2. The origin stays put. Distances from that origin double. The left edge goes from about −0.5 to about −1.0.

Sign

A sign in this lesson is whether a number is below zero, zero, or above zero. p.x < 0 is left of the current origin. p.y < 0 is above it.

float2 p = uv - float2(0.5, 0.5) ← moves the origin to the visual center p = p * 2.0 ← origin stays; members double
Center pixel uv = (0.5, 0.5) p after subtract = (0.0, 0.0) p after × 2 = (0.0, 0.0) Left-edge uv = (0, 0.5) p after subtract = (−0.5, 0.0) p after × 2 = (−1.0, 0.0)

AGSL subtracts matching members: first minus first, second minus second. Multiplying a pair by one number multiplies each member by that number. This lesson does not multiply x by one scale and y by a different scale.

6 · ANDROID ROUTE
Subtract the center, then scale

    

      
private const val CenteredAgsl = """
uniform float2 resolution;

half4 main(float2 fragCoord) {
    float2 uv = fragCoord / resolution;
    float2 p = uv - float2(0.5, 0.5);
    if (p.x < 0.0 && p.y < 0.0) {
        return half4(0.88, 0.48, 0.18, 1.0);
    }
    if (p.y < 0.0) {
        return half4(0.10, 0.25, 0.40, 1.0);
    }
    if (p.x < 0.0) {
        return half4(0.05, 0.59, 0.41, 1.0);
    }
    return half4(0.85, 0.47, 0.02, 1.0);
}
"""

      

        
What each part changes

        
float2(0.5, 0.5) builds a pair from two scalars. Subtracting it moves the origin. The four if tests read signs, not UV 0.5 tests. The pictures can look similar. The numbers at the center are now 0, 0.

        
The scaled-band program multiplies p by 2.0 before the −0.25..0.25 test. The cross stays at the visual center. The band gets narrower.

9 · EXERCISES
Answer before opening each hidden solution

    
What is the origin of a pair in this lesson?
The position where both numbers of that pair are 0. For UV that position is the top-left. After uv - float2(0.5, 0.5) that position is the visual center.

    
Diagnostic: does multiplying by 2.0 move the origin?
No. Multiply scales distances from the current origin. The origin stays. The pixel at UV 0.25 has centered x = −0.25 and scaled x = −0.50. The zero did not slide. The pixel moved farther from zero in the pair’s numbers, so it can leave a fixed numeric band.

    
Why is negative p.y the top half?
Canvas y increases downward. A pixel above the center has smaller y, so uv.y - 0.5 is negative. Subtracting 0.5 does not flip the axis.

    
Is the band a circle?
No. The band is the strip where p.x is between −0.25 and 0.25. Distance from the origin, and a circle, are Chapter 9.
