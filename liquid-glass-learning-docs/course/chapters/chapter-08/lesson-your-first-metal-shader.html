3 · VOCABULARY

Words this chapter uses for the pixel function

Pixel function

One function body, once per output pixel. Lesson 8.1 names it colorAt and calls it from a CPU loop over an 8 by 4 grid so each call is visible. Paint returns orange. Stripe uses column remainder 2.

Stitchable function

A [[ stitchable ]] function in a .metal file. Xcode compiles that file when it builds the app. SwiftUI requires float2 position and half4 color first. Later lessons add extra arguments after those two.

ShaderLibrary

The name lookup that finds a compiled stitchable function. ShaderRect fills its bounds with colorEffect. A missing argument still lets the Swift file compile. SwiftUI refuses that draw. Pass 0 to show a zero slot.

fragCoord

position is in points. fragCoord is position × displayScale, in pixels. Lesson 8.4 compares x with 80. That 80 stays pixels. The indigo line sits at 80 / displayScale points.

Resolution and UV

Resolution is the rectangle width and height in pixels, passed as .float2. UV divides pixel fragCoord by that pixel resolution. The visual center is (0.5, 0.5). Lesson 8.8 then builds p = uv − (0.5, 0.5).

Shader argument

An extra parameter after position and color. Swift passes .float or .float4. The .metal file stays compiled. Lesson 8.9 sends a split and a color. Lesson 8.10 sends a trip count. Do not pass .color.

mix and smoothstep

Lesson 8.11 stores mix(navy, orange, smoothstep(edge0, edge1, uv.x)). Default edges are 0.40 and 0.60. At uv.x = 0.45, the linear fraction is 0.25, the curved fraction is 0.15625, and the stored red is 0.221875.

Metal compile error

Xcode prints the .metal file, a 1-based line, a column, and the complaint, and the build stops. There is no Swift try. gl_FragCoord in the Lesson 8.11 function produces use of undeclared identifier 'gl_FragCoord'. A float return is a different output type.

FragCoordExplorer.swift

UvShaderExplorer.swift

ScalarVectorExplorer.swift

Lesson 8.7. shader/ScalarVector.metal copies float t = uv.x into three color slots. The y-split is a horizontal cut. Orange is the top half. This lesson does not measure GPU time.

VectorArithmeticExplorer.swift

Lesson 8.8. shader/VectorArithmetic.metal builds p = uv − (0.5, 0.5). The centered band tests −0.25 < p.x < 0.25. Multiplying by 2 maps the edges near ±1. Negative p.y is the top half.

UniformsExplorer.swift

TimeUniformExplorer.swift

ClampMixSmoothstepExplorer.swift

ShaderErrorExplorer.swift
