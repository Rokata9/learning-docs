Chapter 7 · Break stripes without dirty specks

Fine noise or dither

Question: Lesson 7.6 left a quieted frosted fill whose interiors still change slowly from pixel to pixel. A slow change can look like a set of stripes instead of a smooth ramp. How do we break those stripes without covering the glass with colored specks?

Banding is a visible stripe of neighboring pixels that all stored the same 8-bit RGB. Fine noise is a small signed offset added to a pixel before that store. Dither is the use of that offset so neighboring pixels can round to different integers and the eye averages the field.

1 · THE NEW OBJECTS

A stripe is a store collision. Noise is an offset.

True ramp

Each column of the teaching panel has a normalized RGB that changes slowly from left to right. This ramp stands in for the slow interiors left by blur and tint. It is not a new blur.

8-bit store

Lesson 3.1: each channel is stored as an integer from 0 through 255. channel8 = round(normalized × 255). Many neighboring true values round to the same integer. That run is a stripe.

Signed offset

A number in −1 .. +1 taken from the pixel’s column and row with a fixed recipe. offset = signed × amount is added to the true channel, then the sum is stored. Amount 0 is no noise.

unit = ((column + 3) × 7 + (row + 5) × 13) remainder 16 ÷ 15 signed = 2 × unit − 1 offset = signed × amount stored8 = round(clamp(true channel + offset) × 255)
Luminance noise uses one signed value for red, green, and blue. Chroma noise uses a different signed value per channel. Production uses luminance noise at a small amount.

4 · THE PRODUCTION RULE

After you have seen stripes and dirt

add one signed offset to red, green, and blue
then store each channel as an 8-bit integer
keep the amount small
do not give each channel its own offset

Inputs

Amount — the slider. Normalized channel units. Teaching default: 0.02. Android default: the same 0.02.

Column and row — integer pixel coordinates in the bitmap. They are not dp.

True channel — the slow ramp at that column, still normalized 0..1.

Outputs, and who consumes them

Signed is consumed by the offset multiply.

Offset is consumed by the add, then by Lesson 3.1 rounding.

Stored 8-bit RGB is consumed by the panel bitmap. Rim, band, shadow, and label do not read it.

6 · NOT A PHOTOGRAPH

The recipe is arithmetic, not a grain scan

What the recipe does

Column and row are integers. The remainder recipe always returns the same unit value for the same pair. That is why the grain does not crawl from frame to frame.

The numbers 7, 13, 3, and 5 are chosen so the 16-slot table is easy to compute by hand. They are not a claim about camera sensors or film.

What this noise is not

It is not a second photograph of sand. It is not a custom GPU program. It is not Apple’s private grain. A large amount, or a different offset per channel, makes the panel look dirty. The label stays outside this store so the letters do not get speckled.

Write the stored integers into a bitmap, then draw it

red += offset
green += offset

What each part changes

unitNoise is the remainder recipe. Salt 0 is luminance noise. Chroma noise would pass a different salt per channel. Production does not.

store8 is Lesson 3.1 rounding. The bitmap then holds those integers. Canvas.drawImage shows the bitmap. Rim and label are later siblings, still sharp.

10 · EXERCISES

Answer before opening each hidden solution

What is banding in this lesson?

A visible stripe of neighboring pixels that all stored the same 8-bit RGB because their true normalized values rounded to one integer.

Why add the offset before store8, not after?

The store is what creates the stripe. Adding an offset to an already-stored integer cannot split a run of identical stored values into different integers unless you also re-store. The lesson adds, then rounds, so two neighbors can land on different integers.

A panel looks speckled with tiny red and green dots. Which choice went wrong?

Chroma noise: a different signed value per channel. Production uses one signed value for red, green, and blue, at a small amount. A large luminance amount can also look dirty, but the specks stay gray.

How is this different from Lesson 7.11?

This lesson only adds a signed offset before the 8-bit store. Lesson 7.11 will put blur, tint, saturation, rim, band, shadow, and noise in one deliberate order. That order is not this lesson’s new operation.
