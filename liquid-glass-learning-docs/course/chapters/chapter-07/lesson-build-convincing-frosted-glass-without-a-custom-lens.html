3 · VOCABULARY

Words this chapter uses for the frost panel

Neighborhood average

The Lesson 7.1 teaching model: one output position receives color from a 3 × 3 block of nearby source positions, each with equal weight. .blur() on the test image is SwiftUI blur at a fixed 12 pt. The model leaves the GPU weights unnamed.

Point radius

The single argument to .blur(radius:opaque:), in points. pt × displayScale is the device-pixel readout printed beside it. That readout stays out of the blur call.

Edge wrap

Clamp, Decal, Mirror, or Repeated. SwiftUI .blur() has no edge-treatment argument, so Lesson 7.3 extends the bitmap with the closest Core Image wrap, runs CIGaussianBlur at sigma = 18 pt × displayScale, then crops back.

Recording pivot

Lesson 7.4 shrinks the artwork into a smaller bitmap, blurs that bitmap, then enlarges the stored result. The recording pivot and the placement pivot are separate. Production uses top-left for both.

Tint amount

The opacity of a rectangle drawn after the 18 pt blur. Default is 0.25. The sharp label is a later sibling, so the blur leaves it alone.

setToSaturation

Weights 0.213 / 0.715 / 0.072 applied to the glass group. Lesson 7.6 flattens blur plus tint, then runs stitchable saturationOnGlassGroup through colorEffect. The label stays outside that filter. Default saturation is 0.40.

Slot

Three facts for one ingredient: clip membership, effect owner, and sibling order. Lesson 7.11 assigns one slot to the shadow, the fill, the grain, the band, the rim, and the label.

Frozen frost stack

Blur 18 pt, tint 0.25, saturation 0.40, rim 3 pt, inner band 12 pt with band blur 6 pt, shadow blur 12 pt offset 4 pt. Later lessons reuse these numbers.

Chapter07Screen.swift

Owns the chapter title, the scroll container, every Chapter 7 explorer, and the light and dark previews.

BlurNeighborhoodAveragingExplorer.swift

Lesson 7.1. A 3 × 3 equal-weight average is the teaching model. .blur() on the test image uses a fixed 12 pt. The model leaves the GPU weights unnamed.

BlurRadiusExplorer.swift

Lesson 7.2. The slider is in points and is the .blur(radius:opaque:) argument. Default is 12 pt. The pixel line is pt × displayScale.

BlurEdgeTreatmentExplorer.swift

Lesson 7.3. Radius stays 18 pt. Clamp, Decal, Mirror, and Repeated are Core Image wraps around CIGaussianBlur. Sigma is 18 pt × displayScale.

DownsampledBlurExplorer.swift

Lesson 7.4. Shrink the artwork into a smaller bitmap, blur that bitmap, then enlarge it. Production uses top-left for the recording pivot and the placement pivot. The four countable cases stay in lesson-07-04-scaling-cases-companion.html.

TintLayerExplorer.swift

Lesson 7.5. .blur(radius: 18, opaque: false) runs first. A later rectangle uses the tint amount as its opacity. Default amount is 0.25. The sharp label is drawn after both.

SaturationContrastExplorer.swift

Lesson 7.6. Blur stays 18 pt and the white veil stays at 0.25. SaturationGlass.metal supplies stitchable saturationOnGlassGroup with weights 0.213 / 0.715 / 0.072. Default saturation is 0.40. The label stays outside colorEffect.

StaticRimExplorer.swift

Lesson 7.7. A later stroke follows the panel path. The stroke is centered, so the clip keeps the inner half. Production insets by width / 2. Default rim is 3 pt, range 0...8.

InnerHighlightExplorer.swift

Lesson 7.8. A wider inset stroke is blurred on its own layer with .blur(radius: 6, opaque: false). The parent clip discards the outward fade. Default band width is 12 pt. The 3 pt rim stays unblurred on top.

OuterShadowExplorer.swift

Lesson 7.9. A darker copy of the panel shape is blurred behind the clipped glass. Default shadow blur is 12 pt. Offset down is 4 pt. The stage has room for the halo. A same-size layer inside the clip has no surround pixels.

FineNoiseExplorer.swift

Lesson 7.10. A CPU bitmap adds one signed offset to red, green, and blue, then stores each channel as an 8-bit integer. Default amount is 0.02. unitNoise uses salt 0. The remainder proof stays in lesson-07-10-companion-why-7-gives-unique-remainders.html.

CombineLayersExplorer.swift

Lesson 7.11. Assigns clip membership, effect owner, and sibling order. The shadow stays outside clipShape. The label stays outside the fill colorEffect. The page title is “Combine the layers.”

CompareBackgroundsExplorer.swift

Lesson 7.12. Freezes the Lesson 7.11 tree. Only the destination class changes: photo-like, text, gradient, dark, or light. Pass means white contrast of at least 4.5:1.
