Chapter 7 · A bright outline that is not yet lighting

Static rim

Question: Lesson 7.6 left a blurred, tinted, quieter glass fill. Against a busy backdrop that fill can still melt into the scene. How do we mark the panel’s geometric edge — the rounded rectangle that owns the glass — without pretending a lamp is shining on it?

A static rim is a bright stroke of one width and one color that follows the panel path. The same paint runs along the top, bottom, left, and right. It does not get brighter on the side that faces an imagined lamp.
Already taught: Lesson 4.5 drew a Stroke along a path. Lesson 4.7 discarded paint outside a clip. Lesson 4.4 shrank a corner radius by a uniform inward padding. This lesson places one stroke on the frosted card and shows the one new fact those three pieces create together: a centered stroke on a clipped path loses its outer half.

1 · THE NEW OBJECT

A rim is a later stroke on the same panel path

Panel path

The rounded rectangle that already clips the frosted fill. Its corner radius is the radius of that rectangle. On Android this lesson uses the same 14.dp card corners as Lessons 7.5 and 7.6.

Static rim

A later draw: one bright color, one width, following that path. It sits beside the glass group, like the sharp label, so it is neither blurred nor moved toward gray.

Not lighting

A lit edge would change if a lamp moved. This stroke does not. Lesson 7.8 will add a soft inner band. Later lighting lessons will use a direction. Do not call this rim a highlight.

4 · THE PRODUCTION RULE

After you have seen both cases

inset = rim width ÷ 2
inner path = panel path moved inward by that inset
inner corner radius = panel corner radius − inset

Inputs

Rim width — the slider. Teaching unit: CSS pixels. Android unit: dp converted to px.

Panel corner radius — inherited. Teaching canvas: 36 px so the rounded corners stay obvious. Android: 14.dp, same as the 7.5 / 7.6 card.

Outputs, and who consumes them

Inset becomes the top-left offset of drawRoundRect.

Inner corner radius is Lesson 4.4 with padding = inset. It keeps the inner stroke concentric with the clipped corner. drawRoundRect consumes both.

7 · ANDROID ROUTE

Inset, then drawRoundRect with Stroke

val inset = rimWidthPx / 2f
val innerRadius = (cornerRadiusPx - inset).coerceAtLeast(0f)

drawRoundRect(
    color = rimColor,
    topLeft = Offset(inset, inset),
    size = Size(
        size.width - rimWidthPx,
        size.height - rimWidthPx,
    ),
    cornerRadius = CornerRadius(innerRadius),
    style = Stroke(width = rimWidthPx),
)

What each part changes

The frosted group from Lesson 7.6 stays underneath. This canvas is a sibling, still inside Modifier.clip. That clip discards paint outside the rounded rectangle — the same idea as Lesson 4.7 clipPath.

inset moves the path inward so a centered stroke does not lose its outer half to the clip.

The inner corner radius shrinks by the same inset so the stroke still follows the rounded rectangle. That is Lesson 4.4, with padding equal to the inset.

Blur, tint amount, and saturation stay fixed. This lesson changes only the rim.

10 · EXERCISES

Answer before opening each hidden solution

What is a static rim in this lesson?

A bright stroke of one width and one color following the panel path. It does not change if we imagine a lamp moving.

Why inset by width ÷ 2?

A Canvas stroke is centered on the path. Half the paint sits outside the path. If that path is also the clip, the outer half is discarded. Moving the path inward by half the width puts the full band inside the clip.

Why shrink the corner radius by the same inset?

The inner path is a smaller rounded rectangle. Lesson 4.4: inner radius = outer radius − uniform padding. Here the padding is the inset. If the radius were left unchanged, the inner corner centers would shift and the stroke would not follow the clipped shape.

How is this different from Lesson 7.8?

This stroke is a thin outline on the path. Lesson 7.8 will add a soft inner band that occupies a wider strip inside the shape. That band is still not physical lighting.

12 · EVIDENCE BOUNDARY

What this lesson establishes

Established

A static rim is an inset centered stroke on the panel path. Insetting by half the width keeps the full band inside the clip. The stroke is not a lighting model.

Not claimed

This is not a specular highlight, not a signed-distance inner glow, and not Apple’s private edge treatment. Lesson 7.8 will add a soft inner band as a separate object.
