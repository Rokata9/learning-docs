Chapter 7 · A soft inner band that is still not lighting

Inner highlight

Question: Lesson 7.6 left a blurred, tinted, quieter glass fill and a sharp label. Lesson 7.7 — still this course’s unresolved checkpoint — added a thin inset stroke on that panel path. That stroke is a hard outline. How do we paint a wider bright strip just inside the same path so the inner edge is soft, without a lamp?

In this lesson an inner highlight is a soft bright band of paint just inside the panel path. Soft means the band’s opacity fades across neighboring pixels. It is still one color on every side. It is not a reflection of a lamp.
Generated ahead. Lesson 7.7 is generated and is not learner-confirmed complete. 1 · THE NEW OBJECT

A band is a strip. A rim is a hairline.

Inner band

The pixels that sit in a chosen width just inside the panel path. Teaching default width: 24 CSS px so the strip is obvious. Android default: 12.dp. Those units are not interchangeable.

Softness from a later blur

The band is first a wide inset Stroke, the same inset rule as Lesson 7.7. A small blur on that stroke’s own layer then averages neighboring pixels. The glass fill already has its own 18.dp blur. These are two different BlurEffect objects.

Clip after blur

Blur spreads the band inward and outward. A later clip to the panel path discards every blurred pixel outside the rounded rectangle. The inner fade remains. That one-sided result is the new mechanism.

inset = band width ÷ 2 inner corner radius = panel corner radius − inset then blur the stroke on its own layer then clip the blurred pixels to the panel path

A blur reads neighboring pixels on both sides of the stroke. Some of those neighbors sit outside the panel path. That is the outward fade.

Clipping is a later discard. It does not change how the blur was calculated. It only refuses to show pixels outside the rounded rectangle.

4 · THE PRODUCTION RULE

After you have seen the leak

draw a wide inset stroke on its own layer
blur that layer
clip the blurred pixels to the panel path
draw the thin unblurred rim afterward

Inputs

Band width — the slider. Teaching unit: CSS pixels. Android unit: dp converted to px.

Band blur — fixed. Teaching: 8 CSS px. Android: 6.dp. This is not the glass fill’s 18.dp blur.

Panel corner radius — inherited. Teaching canvas: 36 px. Android: 14.dp.

Outputs, and who consumes them

Inset and inner corner radius are consumed by drawRoundRect for the band stroke, exactly as Lesson 7.7 consumed them for the rim.

The blurred layer is consumed by the parent Modifier.clip. The clip’s output is the visible one-sided band.

The thin rim is a later sibling. It is not fed into the band blur.

7 · ANDROID ROUTE

Own layer, small BlurEffect, parent clip

Box(Modifier.clip(ArtworkShape)) {
    GlassGroup() // Lesson 7.6 fill; not in the band blur

    Canvas(
        Modifier
            .matchParentSize()
            .graphicsLayer {
                renderEffect = BlurEffect(
                    renderEffect = null,
                    radiusX = bandBlurPx,
                    radiusY = bandBlurPx,
                    edgeTreatment = TileMode.Clamp,
                )
            },
    ) {
        val inset = bandWidthPx / 2f
        drawRoundRect(
            color = bandColor,
            topLeft = Offset(inset, inset),
            size = Size(size.width - bandWidthPx, size.height - bandWidthPx),
            cornerRadius = CornerRadius(max(0f, cornerPx - inset)),
            style = Stroke(width = bandWidthPx),
        )
    }

    Canvas(Modifier.matchParentSize()) {
        drawInsetRim() // unblurred Lesson 7.7 stroke
    }
    SharpLabel()
}

What each part changes

The frosted group from Lesson 7.6 stays underneath and keeps its own 18.dp blur. The band canvas is a sibling, so the band is neither desaturated nor given that large blur.

BlurEffect on the band’s graphicsLayer is the small softness. Parent Modifier.clip is the later discard. That order is the lesson.

TileMode.Clamp is Lesson 7.3’s already-chosen edge treatment. This lesson does not change it. The new fact is the clip after the blur, not a new tile mode.

The thin rim is drawn after the band, with no BlurEffect.

10 · EXERCISES

Answer before opening each hidden solution

What is an inner highlight in this lesson?

A soft bright band of paint just inside the panel path. Soft means the band’s opacity fades across neighboring pixels. It uses one color on every side. It is not a lamp reflection.

Why blur the band on its own layer instead of increasing the glass blur?

The glass 18.dp blur averages the navy/orange artwork. The band blur averages white stroke pixels against their neighbors. Those are two different input images and two different BlurEffect objects. Raising the glass blur would not paint a white inner strip.

If the inner edge looks hard, which step is missing?

The small blur of the band layer. An inset Stroke alone is a hard strip. Clip-after-blur is what fades the inner edge. Missing the clip instead would leave a white leak outside the panel.

How is this different from Lesson 7.9?

This lesson clips after blur so softness stays inside the panel. Lesson 7.9 will put a darker copy behind the card in a larger layer so softness can exist outside the panel.
