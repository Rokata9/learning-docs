Chapter 7 · One new edge rule

Edge treatment

A blur reads neighboring source pixels. Near the outer boundary of its source image, some requested neighbors may not exist.

The edge rule answers one question: what value should the blur use for a requested position outside its source image?
Radius stays fixed. This lesson changes only the answer for missing source positions.

2 · Two meanings of “edge”

An internal color boundary is not the end of the source

Color boundary inside the source

Blue pixels sit next to orange pixels, and both sides are inside the source image. Blur reads those real blue and orange pixels and mixes them. No source position is missing, so the edge rule is not involved.

Outer boundary of the source

The source image ends at the dashed rectangle. A blur request beyond that rectangle has no real source pixel. Only then does the edge rule provide a replacement value.

Separate operation: clipping after the blur can hide output pixels, but it cannot provide source pixels that the blur needed earlier.

5 · Why Decal does not add visible black

Transparent black has zero opacity

Definitions

Transparent black is RGBA(0, 0, 0, 0). Its RGB components are zero, and its alpha is also zero.

Premultiplied RGBA stores each RGB component already multiplied by alpha. A fully transparent pixel therefore contributes zero red, zero green, zero blue, and zero alpha.

It does not contribute visible black. It contributes nothing, which lowers the amount of opaque color in the average.

Uniform orange example

orange C = (1.00, 0.40, 0.10, 1.00) transparent T = (0.00, 0.00, 0.00, 0.00) samples = T, T, C, C, C premultiplied average = (0.60, 0.24, 0.06, 0.60) straight RGB = (0.60, 0.24, 0.06) ÷ 0.60 = (1.00, 0.40, 0.10) final straight RGBA = (1.00, 0.40, 0.10, 0.60)
The result keeps the same orange RGB values but has only 60% opacity. On screen it looks like orange fading into whatever is behind it. It does not become opaque black.
6 · What this means for a glass panel

Give the blur real backdrop pixels beyond the visible panel

larger backdrop sample
panel-sized area
shown at the end

Concrete route

  1. The visible panel needs a panel-sized result.
  2. Before blurring, read a larger rectangle from the real backdrop. The extra outer area contains real scene pixels immediately beyond the panel edges.
  3. Blur that larger rectangle.
  4. After blurring, keep only the inner rectangle matching the panel and ignore the extra outer border.
Crop means selecting a smaller rectangle from a larger image. Here, “crop after blur” means discard the extra outer border and keep the panel-sized middle.
Why: a pixel near the panel edge needs backdrop neighbors just outside the panel. Those pixels already exist in the real scene. Reading them is better than ending the blur source exactly at the panel edge and asking the edge rule to supply replacements there.
Boundary of this lesson: Core Image does not document exactly how far this Gaussian reads, so this lesson does not claim an exact size for the extra outer border.
7 · iOS route

Only the wrap changes

let radiusPx = radiusPt * displayScale let extended = extendForEdge(source, mode: selectedMode, sigma: radiusPx) let blurred = extended.applyingGaussianBlur(sigma: radiusPx) let result = blurred.cropped(to: source.extent)

Meaning of each part

radiusPt stays at 18. radiusPx is 18 × displayScale and is the CIGaussianBlur sigma in bitmap pixels. SwiftUI blur is one symmetric radius, so there is no separate horizontal and vertical sigma.

extendForEdge supplies values only for reads outside the original bitmap. Clamp repeats the edge color. Decal leaves the outside clear. Mirror places reflected copies. Repeated places translated copies.

cropped(to: source.extent) throws away the padding and keeps the original rectangle.

SwiftUI .blur(radius:) has no edge-treatment argument. This bitmap route is the closest Core Image sampler wrap. The larger-source glass-panel route from Section 6 is a separate integration step. This explorer changes only the wrap.

10 · Explain it back

Four direct checks

When is the edge rule used?

Only when the blur requests a source position outside the original input bounds.

Why is a blue-to-orange boundary inside the source different?

Both blue and orange pixels really exist inside the source. The blur mixes them normally; there is no missing source position to replace.

Why does Decal fade orange instead of adding opaque black?

Decal supplies transparent black with alpha zero. In premultiplied form it contributes zero RGB and zero alpha, so the average becomes less opaque. The surviving straight RGB can remain orange.

What does “crop after blur” mean in the panel example?

Blur a larger backdrop rectangle, then select only the smaller inner rectangle that matches the visible panel. The extra outer border is not drawn into the final panel.

12 · Evidence boundary

What this lesson establishes

Established

The edge rule supplies values for reads outside the original bitmap. Clamp, Decal, Mirror, and Repeated use different rules. The explorer applies those rules with a Core Image wrap, then CIGaussianBlur.

Not claimed

The lesson does not reveal Core Image's sample positions, weights, exact extra-margin requirement, allocation behavior, or measured GPU cost. It does not claim that this sigma matches SwiftUI .blur(radius:).
