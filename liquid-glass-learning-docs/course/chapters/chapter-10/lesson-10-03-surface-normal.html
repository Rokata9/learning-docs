Lesson 10.3 — Surface normal

Turn two surface slopes into one direction that points away from the surface. Light theme · desktop · works from file://.

A surface normal is an arrow that points straight away from a surface. This lesson builds that arrow from the x slope and y slope. We need the arrow because later lessons will measure how much the surface faces a light.

  • The violet surface: Lesson 10.1's flat top and quarter-circle rim, drawn with real heights.
  • The pink N arrow: the unit normal above W. Its length is 1, so only its direction is used later.
  • W = (0.72, 0.50): the teaching pixel. All UV positions start at the picture's top-left, and y grows down.
  • The lime cut: the horizontal pixel row y = 0.50. The side view follows this row at the same scale.

Before you start

Used from the course
  • Lesson 8.6: UV positions run from 0 to 1 across the picture.
  • Lesson 8.7: a vector is a packed group of numbers. float3 holds three numbers.
  • Lesson 9.1: length uses a right triangle. This lesson uses the same sum of squares with a third member.
  • Lesson 10.1: h is the surface height above one pixel.
  • Lesson 10.2: slopeX is height change ÷ horizontal distance.
New here
  • Surface normal N: a direction straight away from the surface. N has three members: x, y on the screen, and z away from the screen.
  • rawNormal: (−slopeX, −slopeY, 1). It has the right direction, but its length may differ from 1.
  • Unit normal: a direction whose length is 1. We divide every rawNormal member by normalLength because later light calculations need direction without the raw length.
  • Normal-map RGB: N × 0.5 + 0.5 in each channel. This is only a way to see N. It is not light on the glass.

    Why 0.5 in the color lines? N's members can be negative. Multiplying by 0.5 and adding 0.5 maps the range −1 … +1 into a display channel's range 0 … 1. The 0.5 values are chosen display constants. They do not change N.

      Section 4 · short code excerptThe iPhone shader

      The real function is in chapter10/NormalMap.metal. Four calls reuse Lesson 10.1's height. The new lines make two slopes, build rawNormal, and divide it by its length.

      float circleHeightForNormal(float2 uv, float2 center, float radius, float bevel) {
    float2 p = uv - center;
    float sd = length(p) - radius;
    float inside = clamp(-sd, 0.0, bevel);
    float leg = bevel - inside;
    return sqrt(bevel * bevel - leg * leg);
}

[[ stitchable ]] half4 normalMap(
    float2 position, half4 color, float2 resolution, float2 center,
    float radius, float bevel, float step, float scale
) {
    float2 uv = position * scale / resolution;
    float hLeft = circleHeightForNormal(uv - float2(step, 0.0), center, radius, bevel);
    float hRight = circleHeightForNormal(uv + float2(step, 0.0), center, radius, bevel);
    float hAbove = circleHeightForNormal(uv - float2(0.0, step), center, radius, bevel);
    float hBelow = circleHeightForNormal(uv + float2(0.0, step), center, radius, bevel);
    float slopeX = (hRight - hLeft) / (2.0 * step);
    float slopeY = (hBelow - hAbove) / (2.0 * step);
    float3 rawNormal = float3(-slopeX, -slopeY, 1.0);
    float normalLength = sqrt(rawNormal.x * rawNormal.x +
                              rawNormal.y * rawNormal.y +
                              rawNormal.z * rawNormal.z);
    float3 N = rawNormal / normalLength;
    return half4(half3(N * 0.5 + 0.5), 1.0);
}

      float roundedRectHeightForNormal(float2 uv, float2 center, float2 outerHalf,
                                 float cornerRadius, float bevel) {
    float2 p = uv - center;
    float2 innerHalf = outerHalf - cornerRadius;
    float2 q = abs(p) - innerHalf;
    float sdBox;
    if (q.x > 0.0 && q.y > 0.0) {
        sdBox = length(q);
    } else if (q.x > 0.0) {
        sdBox = q.x;
    } else if (q.y > 0.0) {
        sdBox = q.y;
    } else {
        sdBox = max(q.x, q.y);
    }
    float sd = sdBox - cornerRadius;
    float inside = clamp(-sd, 0.0, bevel);
    float leg = bevel - inside;
    return sqrt(bevel * bevel - leg * leg);
}

float3 roundedRectNormal(float2 uv, float2 center, float2 outerHalf,
                         float cornerRadius, float bevel, float step) {
    float hLeft = roundedRectHeightForNormal(uv - float2(step, 0.0), center, outerHalf, cornerRadius, bevel);
    float hRight = roundedRectHeightForNormal(uv + float2(step, 0.0), center, outerHalf, cornerRadius, bevel);
    float hAbove = roundedRectHeightForNormal(uv - float2(0.0, step), center, outerHalf, cornerRadius, bevel);
    float hBelow = roundedRectHeightForNormal(uv + float2(0.0, step), center, outerHalf, cornerRadius, bevel);
    float slopeX = (hRight - hLeft) / (2.0 * step);
    float slopeY = (hBelow - hAbove) / (2.0 * step);
    float3 rawNormal = float3(-slopeX, -slopeY, 1.0);
    float normalLength = sqrt(rawNormal.x * rawNormal.x +
                              rawNormal.y * rawNormal.y +
                              rawNormal.z * rawNormal.z);
    return rawNormal / normalLength;
