Lesson 10.3 — Surface normal

Turn the two slopes of a pixel into an arrow that stands straight out of the surface. Light theme · desktop · works from file://.

Lesson 10.2 measured how steep the glass is along x. Light needs a different fact: which way the surface faces. This lesson builds that fact as an arrow, the surface normal. It starts on the surface and stands at a square corner (90°) to it. We need it because Lesson 10.4 will compare two directions, and Lesson 10.5 will make the glass brighter where this arrow points toward a light.

Before you start

Used from the course
  • Lesson 8.6: UV positions run from 0 to 1 across the picture. y grows toward the bottom of the picture.
  • Lesson 9.1: the long side of a right triangle is √(leg² + leg²). The countable case is 3, 4, 5.
  • Lesson 9.10: normalization. dir = p / length(p) keeps the direction of p and makes its length 1.
  • Lesson 10.1: h, the surface height above a pixel, in UV. The rim is a quarter of the rim circle with center K.
  • Lesson 10.2: slopeX = (hRight − hLeft) ÷ (2 × step). At W = (0.72, 0.50) it is −1.
New here
  • Surface normal: an arrow that starts on the surface and stands at a square corner to it, pointing out of the glass. Section 1.
  • The quarter turn: turning a slope triangle by 90° gives the arrow (−slope, 1). Section 1.
  • slopeY: Lesson 10.2's slope, measured along y. Section 2.
  • Length of a 3D arrow: Lesson 9.1's triangle used twice, √(x² + y² + z²). Section 2.
  • N, the unit normal: the normal divided by its own length, so its length is 1. Section 2.
  • float3 (Metal): one value that holds three numbers. Section 5.

        Section 5 · short code excerptThe iPhone shader

        The real code is in chapter10/NormalMap.metal. The helper is Lesson 10.1's height. The shader asks it for four heights, makes the two slopes, then the new lines build N. The last two lines only make N visible as a color.

        float circleHeightForNormal(float2 uv, float2 center, float radius, float bevel) {
    float2 p = uv - center;
    float sd = length(p) - radius;
    float inside = clamp(-sd, 0.0, bevel);
    float leg = bevel - inside;
    return sqrt(bevel * bevel - leg * leg);
}

[[ stitchable ]] half4 normalMap(
    float2 position, half4 color, float2 resolution, float2 center,
    float radius, float bevel, float step, float scale
) {
    float2 uv = position * scale / resolution;
    float hLeft  = circleHeightForNormal(uv - float2(step, 0.0), center, radius, bevel);
    float hRight = circleHeightForNormal(uv + float2(step, 0.0), center, radius, bevel);
    float hD     = circleHeightForNormal(uv - float2(0.0, step), center, radius, bevel);
    float hE     = circleHeightForNormal(uv + float2(0.0, step), center, radius, bevel);
    float slopeX = (hRight - hLeft) / (2.0 * step);
    float slopeY = (hE - hD) / (2.0 * step);
    float3 rawNormal = float3(-slopeX, -slopeY, 1.0);
    float normalLength = length(rawNormal);
    float3 N = rawNormal / normalLength;
    float3 rgb = N * 0.5 + 0.5;
    return half4(rgb.x, rgb.y, rgb.z, 1.0);
}

        float3 unitNormalFromSlopes(float slopeX, float slopeY) {
    float3 rawNormal = float3(-slopeX, -slopeY, 1.0);
    float normalLength = sqrt(rawNormal.x * rawNormal.x
                            + rawNormal.y * rawNormal.y
                            + rawNormal.z * rawNormal.z);
    return rawNormal / normalLength;
}

float3 buttonNormal(float2 uv, float2 center, float2 outerHalf,
                    float cornerRadius, float bevel, float step) {
    float hLeft  = buttonHeightForNormal(uv - float2(step, 0.0), center, outerHalf, cornerRadius, bevel);
    float hRight = buttonHeightForNormal(uv + float2(step, 0.0), center, outerHalf, cornerRadius, bevel);
    float hD     = buttonHeightForNormal(uv - float2(0.0, step), center, outerHalf, cornerRadius, bevel);
    float hE     = buttonHeightForNormal(uv + float2(0.0, step), center, outerHalf, cornerRadius, bevel);
    float slopeX = (hRight - hLeft) / (2.0 * step);
    float slopeY = (hE - hD) / (2.0 * step);
    return unitNormalFromSlopes(slopeX, slopeY);
}
