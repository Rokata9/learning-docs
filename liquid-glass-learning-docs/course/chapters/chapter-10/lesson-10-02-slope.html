Lesson 10.2 — Slope

Measure how the surface height changes as x grows. Generated, not complete · light theme · desktop · works from file://.

Slope is a height change divided by the horizontal distance over which that change happens. This lesson measures the x slope: it reads the surface height one small step left and one small step right of a pixel. We need that number because Lesson 10.3 will use x and y slopes to make a surface direction, and later lessons will shine light on that direction.

  • The violet surface: Lesson 10.1's flat top and quarter-circle rim, seen along the horizontal line through W.
  • A and B: the pixels one step left and right of W. Their heights are hLeft and hRight.
  • W = (0.72, 0.50): the pixel whose x slope the page estimates. Drag A, W, B, or C in either map to move the glass or the sample positions.
  • The pink line: the straight join between the surface above A and the surface above B. Its slope is the average slope between A and B, an estimate at W.

Before you start

Used from the course
  • Lesson 8.6: UV means positions from 0 to 1 across the picture.
  • Lesson 9.1: length(p) is the long side of a right triangle.
  • Lesson 9.2: sd is minus inside the glass and plus outside.
  • Lesson 10.1: h is the surface height above one pixel. A = (0.71, 0.50) has h = 0.08; B = (0.73, 0.50) has h = 0.06.
New here
  • x slope: height change ÷ horizontal distance. A plus sign means the surface rises to the right; a minus sign means it falls to the right.
  • step = 0.01 UV: a chosen small distance, not a property of glass. Smaller steps measure a smaller part of the surface.
  • Average slope: the slope of the straight join between two surface points. This lesson uses it as an estimate at W. A curved rim can change steepness between A and B, so this number does not claim an exact slope at one point.

      Section 4 · short code excerptThe iPhone shader

      The real functions are in chapter10/SlopeMap.metal. The helper repeats Lesson 10.1 at one UV position. The shader calls the helper twice, then computes the new x slope. The last three lines only make the number visible.

      float circleHeightForSlope(float2 uv, float2 center, float radius, float bevel) {
    float2 p = uv - center;
    float sd = length(p) - radius;
    float inside = clamp(-sd, 0.0, bevel);
    float leg = bevel - inside;
    return sqrt(bevel * bevel - leg * leg);
}

[[ stitchable ]] half4 slopeMap(
    float2 position, half4 color, float2 resolution, float2 center,
    float radius, float bevel, float step, float slopeRange, float scale
) {
    float2 uv = position * scale / resolution;
    float hLeft = circleHeightForSlope(uv - float2(step, 0.0), center, radius, bevel);
    float hRight = circleHeightForSlope(uv + float2(step, 0.0), center, radius, bevel);
    float deltaH = hRight - hLeft;
    float deltaX = 2.0 * step;
    float slopeX = deltaH / deltaX;
    float red = clamp(0.15 + slopeX / slopeRange, 0.15, 1.0);
    float blue = clamp(0.15 - slopeX / slopeRange, 0.15, 1.0);
    return half4(red, 0.15, blue, 1.0);
}

      float roundedRectHeightForSlope(float2 uv, float2 center, float2 outerHalf,
                                float cornerRadius, float bevel) {
    float2 p = uv - center;
    float2 innerHalf = outerHalf - cornerRadius;
    float2 q = abs(p) - innerHalf;
    float sdBox;
    if (q.x > 0.0 && q.y > 0.0) {
        sdBox = length(q);
    } else if (q.x > 0.0) {
        sdBox = q.x;
    } else if (q.y > 0.0) {
        sdBox = q.y;
    } else {
        sdBox = max(q.x, q.y);
    }
    float sd = sdBox - cornerRadius;
    float inside = clamp(-sd, 0.0, bevel);
    float leg = bevel - inside;
    return sqrt(bevel * bevel - leg * leg);
}

float roundedRectSlopeX(float2 uv, float2 center, float2 outerHalf,
                        float cornerRadius, float bevel, float step) {
    float2 leftUv = uv - float2(step, 0.0);
    float2 rightUv = uv + float2(step, 0.0);
    float hLeft = roundedRectHeightForSlope(leftUv, center, outerHalf, cornerRadius, bevel);
    float hRight = roundedRectHeightForSlope(rightUv, center, outerHalf, cornerRadius, bevel);
    float deltaH = hRight - hLeft;
    float deltaX = 2.0 * step;
    return deltaH / deltaX;
}
