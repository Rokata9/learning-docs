Lesson 10.1 — Height-map idea

Give every pixel of the glass a height: 0 at the outline, 0.10 on the flat top. The first lesson of Chapter 10. Light theme · desktop · works from file://.

In Chapter 9 the glass was flat. A pixel was glass or not: the mask of Lesson 9.14. Real glass, like a wide drop of water on a table, is a raised shape: it is thin at its edge and thicker inside. This lesson gives every pixel a surface height h: how high the glass stands above that pixel. We need it because the next lessons measure how the surface tilts (Lessons 10.2 and 10.3), and light reacts to the tilt (Lesson 10.5).

  • The violet circle (left): the outline of the glass. Center C = (0.50, 0.50), radius 0.25. In the right picture, the rows are violet where they cross the glass.
  • Gray (left): the surface height h of each pixel, from 0 (black) to the flat top, 0.10 (white).
  • W = (0.71, 0.50): one pixel of the screen, near the outline. The page traces it to the end.
  • H (right): the surface straight above W, height 0.08. The angle 0° looks straight down: then the glass looks flat, as in Chapter 9.

    Section 2 · the new linesThe height in the code

    The shader of Lesson 9.2 already computes sd. Four new lines turn it into a height, and the shader stores the height as a gray so we can see it:

    p = uv − C d = length(p) sd = d − radius Lesson 9.2: minus inside the glass, plus outside inside = clamp(−sd, 0, bevel) new: how far the pixel is inside the outline, limited to 0 … bevel leg = bevel − inside new: how far the pixel is from K, the center of the rim circle h = √(bevel² − leg²) new: the surface height, the missing leg of the right triangle gray = h ÷ bevel new: the height as a part of the top height, 0 … 1, stored as a gray
    • bevel = 0.10 is the width of the rounded rim. The rim is a quarter of the rim circle, whose radius is also bevel, so the flat top is bevel high.
    • −sd is plus inside the glass because sd is minus there (Lesson 9.2). clamp limits it to 0 … bevel. So outside the glass inside = 0, and on the flat top inside = bevel.
    • h = √(bevel² − leg²) is the right triangle of Lesson 9.1: the long side is bevel, one leg is leg, and h is the other leg.
    • gray is only for seeing the heights. The height map is a number per pixel. Later lessons use h, not the gray.
    • Heights are in UV, the same unit as positions. So the side view draws x and height at one scale.

    Why a round rim?

    A round rim is not the simplest choice. Two simpler shapes exist. Switch between them: the side view and the height map change in place.

    Rim shape

      Why the quarter circle. The glass copies a drop of liquid, and a drop has a round rim and a flat top. The shape matters later: Lesson 10.5 lights the surface. There a corner shows as a sharp line of light (at F for the ramp), and a wall shows as a line one pixel wide (at O for the slab). This lesson does not need the light. It only picks the shape.

        Section 5 · short code excerptThe iPhone shader

        The real Metal function from the LiquidGlassLab app: chapter10/HeightMap.metal (explorer screen: chapter10/HeightMapExplorer.swift). The parameter list is packed onto fewer lines here, and the comments on the right were added for the lesson. The new lines are green.

        [[ stitchable ]] half4 heightMap(
    float2 position, half4 color, float2 resolution,
    float2 center, float radius, float bevel, float scale
) {
    float2 fragCoord = position * scale;
    float2 uv = fragCoord / resolution;
    float2 p = uv - center;
    float sd = length(p) - radius;                     // Lesson 9.2
    float inside = clamp(-sd, 0.0, bevel);             // new: 0 outside, bevel on the flat top
    float leg = bevel - inside;                        // new: from K, the rim circle's center
    float h = sqrt(bevel * bevel - leg * leg);         // new: the surface height
    float gray = h / bevel;                            // new: 0 at the outline, 1 on the flat top
    return half4(gray, gray, gray, 1.0);
}
        • clamp keeps leg between 0 and bevel. So bevel * bevel - leg * leg is never below 0, because leg² is at most bevel². Without the clamp, a pixel outside the glass would get a leg longer than bevel, and sqrt of a number below 0 has no answer.
        • half4(gray, gray, gray, 1.0): the same number in red, green and blue is a gray (Lesson 3.1).
        • color is not used. A colorEffect function must still take it (Lesson 8.3).
        Browser and iPhone. On this page, JavaScript runs the same lines for every pixel of a canvas. On iPhone, the explorer passes center = (0.50, 0.50), radius = 0.25 and the bevel slider to the shader, and Metal runs heightMap for every pixel of a 360-pt square. There the default rim is 0.10 × 360 = 36 pt wide. The screen stays flat in both: h is a number, and the pictures at an angle are drawn by this page only.

        float roundedRectSd(float2 p, float2 outerHalf, float cornerRadius) {
    float2 innerHalf = outerHalf - cornerRadius;
    float2 q = abs(p) - innerHalf;
    float sdBox;
    if (q.x > 0.0 && q.y > 0.0) {
        sdBox = length(q);                 // a corner
    } else if (q.x > 0.0) {
        sdBox = q.x;                       // a side
    } else if (q.y > 0.0) {
        sdBox = q.y;                       // the top or the bottom
    } else {
        sdBox = max(q.x, q.y);             // inside the inner box
    }
    return sdBox - cornerRadius;
}

float surfaceHeight(float sd, float bevel) {
    float inside = clamp(-sd, 0.0, bevel);
    float leg = bevel - inside;
    return sqrt(bevel * bevel - leg * leg);
}
