Exercise 3 · Diagnostic

Does progress 0.5 mean the current width is half of 320 pt?

Show answer

No. Progress 0.5 means halfway between the start and end in normalized timing. Lesson 5.4 defines how that fraction maps to width.

The raw ratio exceeds 1, so clamped progress is 1.

8 · Sources and evidence

Primary iOS contracts used by the lesson

  • Apple Developer, SwiftUI Animation — later animation APIs consume a 0-through-1 fraction. This lesson calculates that fraction from elapsed time and duration before any geometry mapping.
  • Apple Developer, SwiftUI TimelineView — a live clock can supply elapsed time. The explorer uses sliders so both inputs stay independently inspectable.
Evidence boundary: the browser is a teaching model. The iOS app is the source of truth for the slider-driven ratio. Progress 0.5 is halfway in time, not a claim about current width.
