Lesson 5.5 — Easing

Lesson 5.4 maps progress directly into values at a constant rate. This lesson inserts one inspectable function between raw progress and interpolation so the same duration can begin slowly or finish slowly.

Practical goal

Keep raw progress, eased progress, and interpolated values separate, then prove that easing changes pace without changing endpoints or duration.

Eased progress

How quickly the current value changes during different parts of the duration.

Easing changes the progress supplied to interpolation. It does not change the start value, end value, or selected duration.

2 · Trace one value

Exact input → operation → intermediate → output

Ease-in at raw progress 0.25

raw progress p = 0.25 eased progress = p × p = 0.25 × 0.25 = 0.0625

Interpolation consumes the eased result

width = 64 + (320 − 64) × 0.0625 = 64 + 256 × 0.0625 = 64 + 16 = 80 dp

Linear at the same raw progress would use 0.25 and produce 128 dp.

6 · Exercises

Answer before opening the hidden result

Exercise 1 · Ease-in midpoint

For p², what is eased progress at raw progress 0.5?

Show answer
0.5 × 0.5 = 0.25
Exercise 2 · Endpoint preservation

Why do start and end remain unchanged for p²?

Show answer

Because 0² = 0 and 1² = 1.

Exercise 3 · Diagnostic

Does ease-in make the total duration longer?

Show answer

No. It changes how progress is distributed during the same duration.

Exercise 4 · Ease-out at 0.25

Calculate 1 − (1 − 0.25)².

Show answer
1 − 0.75² = 1 − 0.5625 = 0.4375
