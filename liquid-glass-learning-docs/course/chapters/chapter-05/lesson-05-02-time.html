6 · Difference

Produces elapsed nanoseconds and milliseconds.

// TimeExplorer.kt — frame loop excerpt
val frameTimeNanos = withFrameNanos { it }
val start = firstFrameNanos ?: frameTimeNanos
elapsedTimeNanos = frameTimeNanos - start
The frame timestamp comes from the Compose frame clock. Android's value-based animation documentation also shows manual play-time control by subtracting a start timestamp from later withFrameNanos values.

6 · Exercises

Answer before opening the hidden result

Exercise 1 · Which timestamp stays fixed?

During one uninterrupted run, which value remains fixed?

Show answer

The start timestamp remains fixed. The current frame timestamp changes on later frames.

Exercise 2 · Convert units

How many milliseconds are 125,000,000 ns?

Show answer
125,000,000 ÷ 1,000,000 = 125 ms
Exercise 3 · Diagnostic

Does a current frame timestamp of 12,350,000,000 ns mean the animation has run for that long?

Show answer

No. Elapsed time requires subtracting the start timestamp from the current timestamp.

Exercise 4 · Pause

What changes while the timing loop is paused?

Show answer

No new current timestamp is consumed. The last displayed timing snapshot remains available.
