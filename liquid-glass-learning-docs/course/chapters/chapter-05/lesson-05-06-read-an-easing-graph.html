Lesson 5.6 — Read an easing graph

Lesson 5.5 already gave you raw progress, eased progress, and three inspectable easing rules. This lesson teaches how the graph displays those same numbers so you can read an easing curve instead of treating it as a decorative line.

Practical goal

Given one raw-progress value on the horizontal axis, find the curve, read the eased-progress value on the vertical axis, and feed that output into the unchanged interpolation formula.

Boundary: this lesson does not calculate velocity or graph slope. Those belong to Lesson 5.7.

Lesson 5.6 stays complete as Chapter 5 motion math.

0 · PREREQUISITE LEDGER

Name the graph objects before reading them

Only graph-reading vocabulary is new.

Raw progress

The normalized fraction of planned duration that has passed. It becomes the graph’s horizontal coordinate.

Eased progress

The fraction of the endpoint value change that interpolation should use. It becomes the graph’s vertical coordinate.

Axis

One numbered direction in a graph. The horizontal axis reads left to right. The vertical axis reads bottom to top.

Coordinate pair

Two numbers that identify one graph point. This lesson writes the pair as (raw progress, eased progress).

3 · TRACE ONE GRAPH READING

Raw 0.25 becomes eased 0.0625 on the ease-in curve

Every value remains visible.

Input X
raw progress = 0.2500

Twenty-five percent of the planned duration has passed.

Curve operation
ease-in output = p × p = 0.25 × 0.25 = 0.0625
Graph point
(X, Y) = (0.2500, 0.0625)

The first field is the input. The second is the output.

Next consumer
width = 64 + 256 × 0.0625 = 80 pt

Interpolation consumes Y, not X.

Do not read “below” as reverse movement. At the same raw time, below the diagonal means the easing has returned a smaller value-change fraction than linear. Above means it has returned a larger fraction.
5 · THE LINEAR DIAGONAL

Use it as a visual equality reference

No velocity calculation is required.

Below the diagonal

eased progress < raw progress

At that raw time, interpolation uses less of the endpoint difference than linear would.

On the diagonal

eased progress = raw progress

The easing behaves linearly at that point.

Above the diagonal

eased progress > raw progress

At that raw time, interpolation uses more of the endpoint difference than linear would.

Deferred: the steepness of the curve and movement per unit time belong to Lesson 5.7 — Velocity. Lesson 5.6 reads coordinates only.

9 · EXERCISES

Answer before opening the hidden result

Exercise 1 · Name both axes

What does X store? What does Y store?

Show answer

X stores raw normalized progress. Y stores the eased progress returned for that X.

Exercise 2 · Ease-out at raw 0.50

Use 1 − (1 − p)². What point appears?

Show answer
Y = 1 − (1 − 0.50)² = 1 − 0.25 = 0.75 point = (0.50, 0.75)
Exercise 3 · Diagnostic: below the diagonal

Does a point below the linear diagonal mean the animation is reversing?

Show answer

No. It means the easing output is smaller than the raw input at that X. Interpolation has used less of the endpoint difference than linear would at the same raw time.

Exercise 4 · Which value enters interpolation?

At graph point (0.25, 0.0625), which number is passed as interpolation progress?

Show answer

The Y value, 0.0625. X is the raw timing input. Y is the easing output consumed by interpolation.

11 · SOURCES AND EVIDENCE

Primary iOS contracts used by the lesson

  • Apple Developer, SwiftUI UnitCurve — defines the fraction-to-fraction transform contract used by production animations. The explorer plots three explicit teaching functions instead.
  • Apple Developer, SwiftUI Animation — can consume a timing curve. This lesson keeps a manual slider so every graph coordinate remains inspectable.
Evidence boundary: the browser and iOS graph draw the three explicit teaching functions from Lesson 5.5. They do not infer the curve of an arbitrary easing object through reflection. They evaluate known easing functions at many raw-progress inputs and plot the returned outputs.
