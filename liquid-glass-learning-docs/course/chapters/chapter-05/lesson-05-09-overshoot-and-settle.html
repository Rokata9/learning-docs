Chapter 5 · Motion without mystery

Lesson 5.9 — Overshoot and settle

Lesson 5.8 established that a spring carries velocity from one update into the next. This lesson names what happens when that velocity carries the value beyond its target and measures whether the correction is controlled or excessive.

One new diagnostic

Measure target crossings, maximum overshoot, and a clear settle rule instead of judging motion only with adjectives such as “bouncy.”

0 · WHERE THIS LESSON FITS

From spring updates to measurable motion quality

Crossing

The position moves from one side of the target to the other.

Overshoot

The amount by which a value passes beyond its target.

Peak

A local farthest point, where velocity changes direction around the peak.

Settled

The value is near the target and moving slowly enough under a stated rule.

1 · SYMBOLIC DIAGNOSTIC CONTRACT

Name the trace values and tests before calculating them

These formulas measure a completed spring trace; they do not generate the spring motion.

TTarget position

Course value 1.0000.

xᵢPosition at tick i

The subscript i identifies which recorded tick supplies the value.

vᵢVelocity at tick i

Positive moves toward larger positions; negative moves toward smaller positions.

εxPosition tolerance

Maximum allowed position error. Course value 0.0100.

εvSpeed tolerance

Maximum allowed velocity magnitude. Course value 0.0100.

NConfirmation count

Required consecutive qualifying ticks. Course value 2.

1 · Which side of the target?

sᵢ = xᵢ − T

sᵢ is a signed side value. Negative means below the target; positive means beyond it.

2 · Did the trace cross?

crossing between i−1 and i when sᵢ₋₁ and sᵢ have opposite signs

The sign change says the two consecutive positions lie on opposite sides of the target.

3 · How much overshoot exists?

oᵢ = max(0, xᵢ − T)

This opening example moves toward larger values. Positions below the target produce zero overshoot.

4 · What is the maximum?

o_max = maximum of all oᵢ values

The tick that produces o_max is the overshoot peak for this trace.

5 · How close and how slow?

position error eᵢ = |T − xᵢ| speed magnitude qᵢ = |vᵢ|

Absolute value removes direction because the settle test needs magnitudes.

6 · Does one tick qualify?

qualifiesᵢ = (eᵢ ≤ εx) AND (qᵢ ≤ εv)

Both conditions must be true during the same tick.

Lesson settle rule:
settled at tick i when qualifies is true for N consecutive ticks course values: εx = 0.0100 εv = 0.0100 N = 2

This is an explicit teaching diagnostic. It is not Compose's internal spring-termination rule.

2 · WHY CROSSING HAPPENS

Reaching the target does not automatically erase velocity

Before crossing

Tick 5 position = 0.9387 Tick 5 velocity = +0.1210

The value is below the target and still moving toward larger values.

After the next update

Tick 6 position = 1.0102 Target = 1.0000 position − target = 1.0102 − 1.0000 = +0.0102

The value crossed because positive velocity remained when it reached the target.

Important distinction: the target tells the spring where to pull. It is not a wall that clamps the position.

Which quantities change sign?

Target crossing and direction reversal are different events. Displacement d = T − x and spring pull S = k × d change sign when position crosses the target. Velocity changes sign later, at a peak or trough where the position reverses direction.

Motion phasePosition relative to targetVelocity vDisplacement d = T − xSpring pull S = k × dVisible result
Approach from belowx < TpositivepositivepositivePosition grows toward the target.
Beyond target, before first peakx > Tstill positivenegativenegativePosition still grows, but the reversed pull slows it.
First peakx > Tzero at the turning pointnegativenegativePosition stops growing and starts returning.
Crossing back belowx < Tstill negativepositivepositivePosition still falls, but the reversed pull slows it.
Trough below targetx < Tzero at the turning pointpositivepositivePosition stops falling and starts growing again.
Precise answer: in an underdamped spring, d and S alternate sign at every target crossing. Velocity alternates sign at every peak and trough. Speed, meaning |v|, usually grows after a turning point, becomes large near a crossing, then shrinks to zero at the next turning point. Damping makes each later cycle smaller. The controlled preset has one obvious overshoot and then tiny residual cycles; the Too bouncy preset makes the repeated cycles visually obvious.

5 · WHY THE SPRING RETURNS

After crossing, the spring pull reverses direction

Beyond the target

position = 1.0532 target = 1.0000 displacement = target − position = −0.0532

The negative displacement creates a spring pull back toward smaller values.

Damping removes motion

Spring pull changes direction around the target. Damping reduces the current velocity in whichever direction it is moving. Together they reduce later oscillations.

5A · THE REPEATING SIGN CYCLE

Displacement and spring pull alternate at crossings; velocity alternates at turning points

Target crossing

x moves from below T to above T or from above T to below T therefore: d = T − x changes sign S = k × d changes sign

The restoring pull always points back toward the target.

Peak or trough

velocity reaches 0 then changes sign

The position changes direction at a peak or trough, not at the target crossing itself. That delay is exactly what creates overshoot.

Why velocity seems to become slower and faster: within each half-cycle, the speed magnitude |v| is zero at a peak or trough, grows as the value moves away from that turning point, and later falls back to zero at the next turning point. Damping reduces the maximum speed and position excursion in each successive cycle.
6 · DEFINE SETTLED

Near the target is not sufficient while movement remains large

Position error

abs(target − position)

How far the value is from the target, without a direction sign.

Speed magnitude

abs(velocity)

How strongly the value is still moving, without the direction sign.

Consecutive confirmation

Require both limits for two ticks so one brief pass through the tolerance band does not count as settled.

settled for this lesson = position error ≤ 0.0100 AND speed magnitude ≤ 0.0100 for 2 consecutive teaching ticks
This is a chosen lesson diagnostic. It is not a claim about Compose’s exact internal completion threshold.

10 · CODING CHALLENGE

Require both position and velocity limits

A value can pass near the target while still moving quickly.

Required rule

abs(position − target) ≤ positionTolerance AND abs(velocity) ≤ velocityTolerance
11 · EXERCISES

Answer before opening the solutions

1 · Is the first target crossing the overshoot peak?

No. The value can cross the target with outward velocity and continue farther before reaching its peak.

2 · Why does the spring pull reverse after crossing?

target − position changes sign when position passes the target.

3 · Diagnostic: why check velocity when settling?

Because a value can be inside the position tolerance while moving quickly enough to leave it immediately.

4 · Does no overshoot automatically mean the fastest motion?

No. High damping can eliminate overshoot but may approach the target more slowly.
