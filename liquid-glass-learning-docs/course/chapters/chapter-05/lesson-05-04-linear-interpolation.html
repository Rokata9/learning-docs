2 · Trace one value

Exact input → operation → intermediate → output

Width at progress 0.25

start width = 64 pt end width = 320 pt progress = 0.25 difference = 320 − 64 = 256 pt selected change = 256 × 0.25 = 64 pt current width = 64 + 64 = 128 pt

Equivalent compact form

current = start + (end − start) × progress = 64 + (320 − 64) × 0.25 = 64 + 256 × 0.25 = 128 pt

// LinearInterpolationExplorer.swift — linear interpolation
func lerp(
    _ start: CGFloat,
    _ end: CGFloat,
    progress: CGFloat
) -> CGFloat {
    start + (end - start) * progress
}

Exercise 2 · Menu alpha

Show answer

Exercise 3 · Diagnostic

Why is end × progress insufficient when the start is not zero?

Show answer

It selects a fraction measured from zero. Interpolation must select a fraction of end − start and add it to the actual start.

Exercise 4 · Decreasing value

Dots alpha starts at 1 and ends at 0. What is it at progress 0.75?

Show answer
1 + (0 − 1) × 0.75 = 0.25
