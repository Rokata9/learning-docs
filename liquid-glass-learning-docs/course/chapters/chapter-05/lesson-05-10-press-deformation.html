Chapter 5 · Motion without mystery

Lesson 5.10 — Press deformation

A button already knows where the pointer went down and whether that press is still active. This lesson turns those two inputs into a small contact-centered deformation: the control spreads sideways, compresses vertically, and slightly flattens its corners while the contact point stays fixed.

Practical problem

A center-based scale makes every press look identical. How can the same control react around the actual local contact point without changing its measured layout size?

Terminology boundary

Pressed state is a Boolean interaction state: active or inactive.

It is not a measurement of finger force. The pointer-down coordinate supplies position. The Boolean supplies the requested endpoint. The spring supplies the current intermediate amount.

0 · OBJECTS AND CONTRACT

Name every object before the first formula

All later symbols refer to these exact objects.

Measured control

One local rectangle with width W and height H. Its local origin is the top-left corner.

Pointer-down point P

The pointer position measured in that control’s local point coordinate system.

Pivot O

The point around which scale is applied. This lesson derives O from P.

Press amount q

The current animated value from 0 through 1. It controls the visible deformation.

Button color used by the teaching scene: straight sRGB RGBA(0.1176, 0.2510, 0.6863, 1.0000). The color is fixed. Only geometry changes.
1 · ALL FORMULAS

Keep the complete value path visible

Each card names its inputs, output, and next consumer.

Pointer points → pivot fractions

fₓ = clamp(pₓ ÷ W, 0, 1) fᵧ = clamp(pᵧ ÷ H, 0, 1)

Output: two fractions consumed by UnitPoint.

Interaction state → target amount

q_target = if b then 1 else 0

The animation system moves current q toward this target.

Current q → deformation values

sₓ = 1 + (1.04 − 1) × q sᵧ = 1 + (0.90 − 1) × q r = 32 + (24 − 32) × q

Outputs: horizontal scale, vertical scale, and local corner radius.

Scale one local point around O

x′ = Oₓ + (x − Oₓ) × sₓ y′ = Oᵧ + (y − Oᵧ) × sᵧ

Output: the point’s transformed drawing position. Layout bounds remain unchanged.

5 · iOS VALUE PATH

Map the browser objects to SwiftUI

1 · Measure

GeometryReader supplies the control’s runtime width and height in points.

2 · Press

DragGesture(minimumDistance: 0) supplies one position relative to the containing view and waits for release or cancellation.

3 · Normalize

Divide local pointer X/Y by measured width/height and clamp to 0..1.

4 · Animate q

Animation.spring moves current q toward 1 while pressed and toward 0 after release/cancel.

5 · Derive shape

Current q produces scale X, scale Y, and corner radius.

6 · Draw

scaleEffect applies pivoted scale. Canvas draws the current rounded shape.

Teaching implementation

One view uses DragGesture, GeometryReader, and scaleEffect. It exposes every value for inspection.

Production design-system boundary

For a reusable press effect across many controls, a SwiftUI ButtonStyle can read configuration.isPressed. The press gesture includes the local press position, while release and cancel end the effect.

Evidence boundary: the browser reproduces the lesson formulas. It does not reproduce SwiftUI’s internal spring solver. The iOS explorer executes the actual SwiftUI animation and scaleEffect APIs.

8 · EXERCISES

Answer before opening the details

Exercise 1 · Right-side pointer fraction

For pₓ = 240 pt and W = 320 pt, calculate fₓ.

Show answer
fₓ = 240 ÷ 320 = 0.7500
Exercise 2 · Half press amount

At q = 0.50, calculate sᵧ and r.

Show answer
sᵧ = 1 + (0.90 − 1) × 0.50 = 0.9500 r = 32 + (24 − 32) × 0.50 = 28 pt
Exercise 3 · Layout versus drawing

Why can the transformed right edge extend beyond 320 pt while the measured width remains 320 pt?

Show answer

scaleEffect applies a draw-phase transformation. It does not remeasure or replace the view’s layout bounds.

Exercise 4 · Release and cancellation

Why must both endings clear the pressed state?

Show answer

Either ending means the active press no longer exists. If cancellation is ignored, the control can remain stuck with q targeting 1.
