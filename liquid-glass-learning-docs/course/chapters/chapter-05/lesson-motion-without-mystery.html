3 · NEW VOCABULARY

Words this chapter will define before use

Endpoint snapshot

One complete resting result or one complete expanded result, stored as numbers before any clock starts.

Elapsed time

How long one timing run has lasted, measured from repeated frame-clock timestamps.

Progress

Elapsed time divided by one planned duration, then clamped to the closed range 0 through 1.

Linear interpolation

Current value = start + (end − start) × progress. Every property uses the same progress.

Easing

A function that turns raw progress into a different fraction before interpolation. Endpoints and duration stay unchanged.

Average velocity

Change in one UI property divided by the length of one named time interval, in points per second.

Teaching Euler spring

One tick updates velocity, then position, from inspectable stiffness, damping, and mass. These are not SwiftUI spring constants.

Play-time clock

A local debug clock that can slow, pause, step, or reverse animation time without changing endpoint formulas.
