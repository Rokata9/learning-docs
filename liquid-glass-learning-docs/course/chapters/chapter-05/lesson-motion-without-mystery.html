3 · CHAPTER VOCABULARY

Terms introduced before use

State

Data that describes the UI at one instant.

Time

A measured duration or instant used to place an animation in its sequence.

Progress

A normalized value, usually 0 through 1, that says how far a transition has advanced.

Interpolation

A calculation that produces a value between a start value and an end value.

Easing

A rule that changes how progress advances without changing the endpoints.

Velocity

How quickly a value changes and in which direction.

Spring

A motion model that reacts using stiffness and damping instead of a fixed timing curve.

Interruption

A new input received before the previous motion has finished.
