Chapter 1 · Diagnose before adding more

Explain what the material still lacks

The current result is useful because it is incomplete. You can now separate what the code visibly produces from what a complete Liquid Glass material will need later.

One new idea

A diagnosis is a conclusion supported by specific evidence. “It does not look like glass” is vague. “The line remains sharp and unmoved, so blur and refraction are absent” is a diagnosis.

1 · Where this lesson fits

Stop before adding another effect

Lessons 1.1–1.7 gave you vocabulary, an observation method, Android code, a study background, translucency, one formula, and five controlled device states.

Visible result

A white rounded panel changes the colors of the background underneath it.

Diagnostic task

For every claimed ingredient, name the exact visual clue that supports or rejects the claim.

Why stop here

Adding blur now would make it harder to prove what plain alpha did by itself.

2 · Terms

Evidence, claim, and diagnosis

These terms keep observation separate from implementation guesses.

Claim

A claim is a statement that may be true or false. Example: “The panel blurs the background.”

Evidence

Evidence is an observed result that supports or rejects a claim. Example: a thin line remains sharp.

Diagnosis

A diagnosis joins a claim to evidence and states the conclusion.

Absent

An effect is absent when the current code and visible result do not contain that operation. “Absent” does not mean impossible.

Translucency · present

White color influence is present. The panel uses a translucent white source, so colors underneath move toward white. This is a fixed neutral tint. It is not adaptive tint, because the source color does not react to the background.

package com.example.liquidglasslab.chapter01

import androidx.compose.foundation.background
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.unit.dp

private val PanelShape = RoundedCornerShape(32.dp)

@Composable
internal fun TranslucentRoundedPanel(
    alpha: Float,
    modifier: Modifier = Modifier,
) {
    Box(
        modifier = modifier.background(
            color = Color.White.copy(
                alpha = alpha.coerceIn(0f, 1f),
            ),
            shape = PanelShape,
        ),
    )
}

10 · Exercises
Use evidence, not labels
The diagnostic question asks you to reject a plausible but unsupported conclusion.

    
  1. The background is lighter under the panel. Which present ingredient does this support?
  2. A thin line remains sharp but lower in contrast. Which missing ingredient does this evidence reject?
  3. A circle remains circular and at the same position. Does that prove refraction?
  4. Write one sentence that distinguishes the present fixed white tint from a future adaptive tint.
Answer 1
Translucency from the white foreground fill.
Answer 2
Blur. Blur would spread the line boundary into nearby positions.
Answer 3 · Diagnostic
No. It is evidence against visible refraction in this result. Refraction would move, bend, or resize background detail.
Answer 4
The current white source is fixed; adaptive tint would change its material response after measuring or otherwise reacting to the background or environment.
