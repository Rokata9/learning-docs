Chapter 1 · Build reliable visual evidence

Build a study background

A future glass effect can only be judged when the content behind it contains visible clues. This lesson builds those clues before it adds any glass panel.

The iOS result will contain a gradient, four solid color regions, circles, sharp lines, and text. Each clue reveals a different kind of change.

Small goal

  • Explain why one flat color is a weak graphics test.
  • Name what each clue can reveal.
  • Add StudyBackground.swift.
  • Run the result on the iPhone 16 Pro.

Deliberately absent: no translucency, blur, refraction, highlight, shadow, or animation is implemented yet.

1 · The main graphics idea

A useful background exposes change

No new mathematical formula is required in this lesson.

Study background

A study background is a deliberately designed image placed behind an effect so that the effect is easier to inspect.

It is not decoration. It is measurement support for your eyes.

Visual clue

A visual clue is one recognizable part of the background whose change can be noticed. A sharp line is a clue because softness or bending is easy to see.

An edge is the visible boundary where one region changes into another region.

Likely misconception: a beautiful background is not automatically a useful study background. A smooth photograph can look good while hiding small blur or distortion changes. We want known shapes and known edges.

4 · Trace one real value

Follow sharpLineCount = 11 into the screen

This is a value trace. It names the exact input, operation, and output.

Inputprivate let sharpLineCount = 11

The Swift integer value is eleven.

OperationForEach(0..<sharpLineCount, id: \.self)

ForEach runs the block eleven times. The supplied indexes are 0 through 10.

OutputRectangle()

Each run emits one line-shaped view. The line field therefore contains eleven separate line children.

Deferred detail: the code uses points, SwiftUI's layout unit. Chapter 2 explains how a point becomes physical pixels. For this lesson, treat 1 point and 3 points as two deliberately different line thicknesses.

import SwiftUI

private let sharpLineCount = 11

private let studyGradientColors: [Color] = [
    Color(hex: 0xE0F2FE),
    Color(hex: 0xBAE6FD),
    Color(hex: 0xC4B5FD),
    Color(hex: 0xFED7AA),
]

private struct ColorRegion {
    let label: String
    let backgroundColor: Color
    let contentColor: Color
}

private let colorRegions: [ColorRegion] = [
    ColorRegion(label: "RED", backgroundColor: Color(hex: 0xDC2626), contentColor: .white),
    ColorRegion(label: "AMBER", backgroundColor: Color(hex: 0xF59E0B), contentColor: Color(hex: 0x422006)),
    ColorRegion(label: "GREEN", backgroundColor: Color(hex: 0x059669), contentColor: .white),
    ColorRegion(label: "BLUE", backgroundColor: Color(hex: 0x2563EB), contentColor: .white),
]

private extension Color {
    init(hex: UInt32) {
        self.init(
            red: Double((hex >> 16) & 0xFF) / 255,
            green: Double((hex >> 8) & 0xFF) / 255,
            blue: Double(hex & 0xFF) / 255
        )
    }
}

struct StudyBackground: View {
    var body: some View {
        ZStack {
            LinearGradient(
                colors: studyGradientColors,
                startPoint: .topLeading,
                endPoint: .bottomTrailing
            )
            .ignoresSafeArea()

            VStack(alignment: .leading, spacing: 16) {
                StudyHeader()
                ColorRegionStrip()

                HStack(spacing: 14) {
                    CircleClues()
                        .frame(maxWidth: .infinity, maxHeight: .infinity)
                    SharpLineClues()
                        .frame(maxWidth: .infinity, maxHeight: .infinity)
                }
                .frame(maxWidth: .infinity, maxHeight: .infinity)

                TextClues()
            }
            .padding(.horizontal, 20)
            .padding(.vertical, 18)
            .safeAreaPadding()
        }
        .frame(maxWidth: .infinity, maxHeight: .infinity)
    }
}

private struct StudyHeader: View {
    var body: some View {
        VStack(alignment: .leading, spacing: 2) {
            Text("LIQUID GLASS LAB")
                .font(.system(size: 30, weight: .black))
                .tracking(1.2)
                .foregroundStyle(Color(hex: 0x0F172A))
            Text("Lesson 1.4 · Study background")
                .font(LabType.titleMedium)
                .foregroundStyle(Color(hex: 0x334155))
        }
    }
}

private struct ColorRegionStrip: View {
    var body: some View {
        HStack(spacing: 0) {
            ForEach(colorRegions, id: \.label) { region in
                region.backgroundColor
                    .overlay {
                        Text(region.label)
                            .font(.system(size: 12, weight: .black))
                            .tracking(0.7)
                            .foregroundStyle(region.contentColor)
                            .multilineTextAlignment(.center)
                    }
                    .frame(maxWidth: .infinity, maxHeight: .infinity)
            }
        }
        .frame(maxWidth: .infinity)
        .frame(height: 76)
        .clipShape(RoundedRectangle(cornerRadius: 18, style: .circular))
    }
}

9 · Final exercises
Answer before opening the hidden answers

      
The first question targets the most likely misconception.

    

    
Exercise 1 · Diagnostic: Which exposes a small blur more reliably: a flat blue area or alternating sharp lines? Explain why.
Answer: alternating sharp lines. A blur changes the narrow boundaries into wider soft bands. A uniform blue area contains no internal edge, so nearby blue values still look blue.

    
Exercise 2 · A future effect makes a known circle look wider than it is tall. Which clue changed, and what kind of visible behavior does that suggest?
Answer: the circle silhouette changed. It suggests uneven geometric distortion or refraction. Tint alone changes color but does not turn a circle into an oval.

    
Exercise 3 · With sharpLineCount = 11, which indexes does ForEach(0..<sharpLineCount, id: \.self) provide, and how many line children are emitted?
Answer: indexes 0 through 10. The block runs eleven times, so it emits eleven line children.

    
Exercise 4 · Why does the gradient fill the complete app window while safeAreaPadding() applies only to the clue-content column?
Answer: the visual background is allowed to continue behind system bars. The important text, shapes, and lines must remain inside the safe area so the system interface and display cutout do not cover them.
