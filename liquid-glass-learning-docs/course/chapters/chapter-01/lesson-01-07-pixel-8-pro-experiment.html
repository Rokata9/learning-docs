Lesson 1.7 · Device experiment
Chapter 1 · One controlled variable

Run a controlled opacity experiment

You will compare the same panel at five exact opacity values. Everything else stays fixed. This lets you connect one code value to one visible change without mixing in blur, refraction, shadow, or motion.

One new idea

A controlled experiment changes one chosen input while keeping the other inputs unchanged.

  • Changed input: panel alpha.
  • Fixed inputs: background, panel bounds, corner shape, and white fill color.
  • Measured output: what remains visible under the panel.
1 · Where this lesson fits

From one calculation to five device states

Lesson 1.6 followed one channel at one image position. Lesson 1.7 changes alpha across five exact states and compares the complete visible panel on the Pixel 8 Pro.

Already known

Alpha controls the source weight in the simplified opaque-background mixture.

New in this lesson

You will collect comparable observations instead of relying on memory.

Still absent

No neighboring or shifted background position is read. The panel still has no blur or refraction.

2 · Terms

Words used by the experiment

Each word names one concrete part of the procedure.

Variable

A variable is an input that can hold different values. Here the variable is panelAlpha.

Constant during the experiment

A constant during the experiment is an input that you deliberately do not change while comparing states.

Preset

A preset is one named, exact value that can be selected again. The five presets are 0%, 25%, 50%, 75%, and 100%.

Observation

An observation is a statement about what is visibly present. It does not guess how the renderer is implemented.

Percentage and alpha: divide the percentage by 100. Therefore 25% becomes 0.25, 75% becomes 0.75, and 100% becomes 1.00.
3 · Interactive explanation

Change only alpha

The browser scene is a teaching model. The Pixel 8 Pro run is the Android result.

What changes

The white panel contributes 25%. The background remains visible with 75% of the simplified weight.

What stays fixed

Panel size, position, corner radius, white source color, study background, and draw order.

Sharp-edge check

The line under the panel has lower contrast, but its boundary remains sharp and stays at the same position.

Keep all five states visible

Do not compare by memory alone. The five small views preserve the other inputs and differ only in alpha. Your Pixel screenshots serve the same purpose.

package com.example.liquidglasslab.chapter01

import androidx.compose.foundation.background
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.unit.dp

private val PanelShape = RoundedCornerShape(32.dp)

@Composable
internal fun TranslucentRoundedPanel(
    alpha: Float,
    modifier: Modifier = Modifier,
) {
    Box(
        modifier = modifier.background(
            color = Color.White.copy(
                alpha = alpha.coerceIn(0f, 1f),
            ),
            shape = PanelShape,
        ),
    )
}


    
package com.example.liquidglasslab.chapter01

import androidx.compose.foundation.layout.Arrangement
import androidx.compose.foundation.layout.Column
import androidx.compose.foundation.layout.PaddingValues
import androidx.compose.foundation.layout.Row
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.foundation.layout.padding
import androidx.compose.material3.Button
import androidx.compose.material3.MaterialTheme
import androidx.compose.material3.OutlinedButton
import androidx.compose.material3.Slider
import androidx.compose.material3.Surface
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import java.util.Locale
import kotlin.math.abs
import kotlin.math.roundToInt

private val OpacityPresets = listOf(
    0f,
    0.25f,
    0.50f,
    0.75f,
    1f,
)

@Composable
internal fun OpacityExperimentControls(
    alpha: Float,
    onAlphaChange: (Float) -> Unit,
    modifier: Modifier = Modifier,
) {
    val percentLabel = "${(alpha * 100).roundToInt()}%"
    val decimalLabel = String.format(Locale.US, "%.2f", alpha)

    Surface(
        modifier = modifier.fillMaxWidth(),
        tonalElevation = 3.dp,
        shadowElevation = 8.dp,
    ) {
        Column(
            modifier = Modifier.padding(
                horizontal = 16.dp,
                vertical = 12.dp,
            ),
            verticalArrangement = Arrangement.spacedBy(6.dp),
        ) {
            Row(
                modifier = Modifier.fillMaxWidth(),
                horizontalArrangement = Arrangement.SpaceBetween,
                verticalAlignment = Alignment.CenterVertically,
            ) {
                Text(
                    text = "Panel opacity",
                    style = MaterialTheme.typography.titleMedium,
                )
                Text(
                    text = "$percentLabel · alpha $decimalLabel",
                    style = MaterialTheme.typography.labelLarge,
                )
            }

            Slider(
                value = alpha,
                onValueChange = onAlphaChange,
                valueRange = 0f..1f,
                steps = 3,
            )

            Row(
                modifier = Modifier.fillMaxWidth(),
                horizontalArrangement = Arrangement.spacedBy(6.dp),
            ) {
                OpacityPresets.forEach { preset ->
                    val label = "${(preset * 100).roundToInt()}%"
                    val selected = abs(alpha - preset) < 0.001f

                    if (selected) {
                        Button(
                            onClick = { onAlphaChange(preset) },
                            modifier = Modifier.weight(1f),
                            contentPadding = PaddingValues(
                                horizontal = 4.dp,
                                vertical = 8.dp,
                            ),
                        ) {
                            Text(label)
                        }
                    } else {
                        OutlinedButton(
                            onClick = { onAlphaChange(preset) },
                            modifier = Modifier.weight(1f),
                            contentPadding = PaddingValues(
                                horizontal = 4.dp,
                                vertical = 8.dp,
                            ),
                        ) {
                            Text(label)
                        }
                    }
                }
            }
        }
    }
}


    
State owner
Chapter01Screen owns panelAlpha. One current value prevents the panel and controls from disagreeing.
Discrete slider
steps = 3 places three intermediate notches between the two endpoints. Together with 0 and 1, that produces five selectable values.

    
Renderer boundary: the Kotlin source proves which alpha is supplied. It does not expose the exact internal blending instructions executed by the device GPU. Framework source, graphics tracing, or a captured frame would be needed for that deeper claim. This unknown does not change the experiment because the supplied alpha and visible result are directly observable.

  


  

    
7 · Predict, then run on the Pixel 8 Pro
Write the prediction before touching the preset
A prediction makes a mistaken mental model visible. That is useful evidence.

    

      
Prediction prompts
  1. At 0%, will any panel fill remain visible?
  2. At 50%, will a straight line move?
  3. At 100%, will the background remain visible inside the panel?
  4. Will the panel bounds change between presets?

      
Device procedure
  1. Build and run the cumulative project on the Pixel 8 Pro.
  2. Select 0%. Wait until the screen is still. Save a screenshot.
  3. Repeat for 25%, 50%, 75%, and 100%.
  4. Inspect the same sharp line, circle edge, text edge, and solid color region in every screenshot.
  5. Do not change display brightness, orientation, app window size, or background code during the set.

9 · Exercises
Answer before opening the details
One question deliberately targets the blur misconception.

    
  1. Convert 75% to an alpha fraction.
  2. At 0%, what foreground contribution does the white panel make?
  3. A line becomes lighter at 50% but remains sharp and unmoved. Does that prove blur?
  4. Name three inputs that must stay unchanged for this experiment to isolate alpha.
Answer 1
75 ÷ 100 = 0.75.
Answer 2
Zero. The source weight is 0.00.
Answer 3 · Diagnostic
No. Lower contrast is evidence of color mixing. Blur would spread the edge using nearby positions.
Answer 4
Any three of these are sufficient: study background, panel size, panel position, corner radius, source color, draw order, device orientation, and app window size.
