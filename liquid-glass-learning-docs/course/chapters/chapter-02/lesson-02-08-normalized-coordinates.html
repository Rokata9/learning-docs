Chapter 2 · Lesson 2.8

Normalized coordinates

Describe a point by its fraction of the drawing area instead of by one fixed pixel distance.

Lesson 2.7 changed the origin used to measure a position. Lesson 2.8 keeps one local origin and changes the numeric scale. A local pixel point such as (160, 270) can become the normalized point (0.25, 0.75).

The word normalized means that a value has been converted into a chosen standard range. This lesson uses the range from 0 through 1.

One new mathematical idea

  • Divide a local X position by the drawing width.
  • Divide a local Y position by the drawing height.
  • Multiply by the size to convert back to local pixels.
  • Keep the same relative point when the drawing area changes size.
After completion: 16 of 216 lessons
1 · Name the two descriptions

One point, two numeric scales

The coordinate-system origin stays at the rectangle’s top-left corner.

Local pixels

Distance in px

x = 160 px means the point is 160 pixels to the right of the local origin. y = 270 px means the point is 270 pixels below the local origin.

The values depend on the current rectangle size.

Normalized

Fraction of the size

normalizedX = 0.25 means the point is 25% of the width from the left edge. normalizedY = 0.75 means the point is 75% of the height from the top edge.

The values describe the relative position.

normalizedX = localX ÷ width
normalizedY = localY ÷ height
localX = normalizedX × width
localY = normalizedY × height

0

The left edge for X. The top edge for Y.

0.5

Halfway across the width or height. This is the center along that axis.

1

The right edge for X. The bottom edge for Y.

Important limit: division produces a value from 0 to 1 only when the local point is inside the rectangle or on its boundary. The Android lesson uses coerceIn(0f, 1f) to enforce that inside-rectangle range. Division performs the normalization. Clamping only limits the result.

3 · Why normalize?

The same relative point survives a size change

Pixel coordinates change. The normalized pair stays fixed.

Inputone normalized pair and two rectangle sizes
Operationmultiply the same pair by each size
Outputdifferent local pixel pairs at the same relative position
This is why normalized coordinates are useful for graphics. A material feature can remain at “25% from the left and 75% from the top” even when the component becomes larger.
4 · Boundary diagnostic

Normalized 1 is an edge, not the last pixel index

This reuses the edge-versus-cell distinction from Lesson 2.4.

For a width of 8 pixels, the right boundary is at local X = 8. Dividing by the width gives 8 ÷ 8 = 1.

The last pixel index is 7. Its center is at 7.5 in this boundary-based diagram. That center normalizes to 7.5 ÷ 8 = 0.9375, not 1.

Do not replace width with the last pixel index. Width is the distance from the left edge to the right edge.

@Composable
internal fun NormalizedCoordinatesExplorer(
    modifier: Modifier = Modifier,
) {
    var sizePresetName by rememberSaveable {
        mutableStateOf(DrawingSizePreset.Wide.name)
    }
    val sizePreset = DrawingSizePreset.valueOf(sizePresetName)

    var normalizedX by rememberSaveable {
        mutableFloatStateOf(0.25f)
    }
    var normalizedY by rememberSaveable {
        mutableFloatStateOf(0.75f)
    }
    var measuredSizePx by remember {
        mutableStateOf(IntSize.Zero)
    }

    val localXpx = normalizedX * measuredSizePx.width.toFloat()
    val localYpx = normalizedY * measuredSizePx.height.toFloat()

    Column(
        modifier = modifier.fillMaxWidth(),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.spacedBy(14.dp),
    ) {
        Text(
            text = "The green point stores a relative position from 0 to 1.",
            color = Color(0xFF4338CA),
            style = MaterialTheme.typography.titleLarge,
            fontWeight = FontWeight.Black,
        )
        Text(
            text = "Tap inside the rectangle, move the sliders, or select a preset. Then resize " +
                "the rectangle. The local pixel position changes, but the normalized position " +
                "stays the same.",
            style = MaterialTheme.typography.bodyLarge,
        )

        CoordinateReadout(
            measuredSizePx = measuredSizePx,
            normalizedX = normalizedX,
            normalizedY = normalizedY,
            localXpx = localXpx,
            localYpx = localYpx,
        )

        Box(
            modifier = Modifier
                .size(
                    width = sizePreset.widthDp.dp,
                    height = sizePreset.heightDp.dp,
                )
                .background(
                    color = Color.White,
                    shape = DrawingShape,
                )
                .border(
                    width = 3.dp,
                    color = Color(0xFF1E40AF),
                    shape = DrawingShape,
                )
                .onSizeChanged { measuredSizePx = it }
                .pointerInput(measuredSizePx) {
                    detectTapGestures { localOffset ->
                        if (measuredSizePx.width > 0 && measuredSizePx.height > 0) {
                            normalizedX = (
                                localOffset.x / measuredSizePx.width.toFloat()
                            ).coerceIn(0f, 1f)
                            normalizedY = (
                                localOffset.y / measuredSizePx.height.toFloat()
                            ).coerceIn(0f, 1f)
                        }
                    }
                }
                .semantics {
                    contentDescription =
                        "Normalized coordinate drawing area. Size ${measuredSizePx.width} by " +
                        "${measuredSizePx.height} pixels. Selected normalized point " +
                        "${formatNormalized(normalizedX)}, ${formatNormalized(normalizedY)}."
                },
        ) {
            Canvas(
                modifier = Modifier.matchParentSize(),
            ) {
                val gridFractions = listOf(0.25f, 0.5f, 0.75f)
                val gridStrokePx = 1.dp.toPx()

                gridFractions.forEach { fraction ->
                    drawLine(
                        color = Color(0xFFC7D2FE),
                        start = Offset(
                            x = size.width * fraction,
                            y = 0f,
                        ),
                        end = Offset(
                            x = size.width * fraction,
                            y = size.height,
                        ),
                        strokeWidth = gridStrokePx,
                    )
                    drawLine(
                        color = Color(0xFFC7D2FE),
                        start = Offset(
                            x = 0f,
                            y = size.height * fraction,
                        ),
                        end = Offset(
                            x = size.width,
                            y = size.height * fraction,
                        ),
                        strokeWidth = gridStrokePx,
                    )
                }

                val marker = Offset(
                    x = normalizedX * size.width,
                    y = normalizedY * size.height,
                )

                drawLine(
                    color = Color(0xFFBE185D),
                    start = Offset(
                        x = 0f,
                        y = marker.y,
                    ),
                    end = marker,
                    strokeWidth = 2.dp.toPx(),
                )
                drawLine(
                    color = Color(0xFF1E40AF),
                    start = Offset(
                        x = marker.x,
                        y = 0f,
                    ),
                    end = marker,
                    strokeWidth = 2.dp.toPx(),
                )
                drawCircle(
                    color = Color(0xFF059669),
                    radius = 10.dp.toPx(),
                    center = marker,
                )
                drawCircle(
                    color = Color.White,
                    radius = 4.dp.toPx(),
                    center = marker,
                )
            }

            Text(
                text = "(0, 0)",
                modifier = Modifier
                    .align(Alignment.TopStart)
                    .padding(8.dp),
                color = Color(0xFF1E3A8A),
                style = MaterialTheme.typography.labelMedium,
                fontWeight = FontWeight.Black,
            )
            Text(
                text = "(1, 1)",
                modifier = Modifier
                    .align(Alignment.BottomEnd)
                    .padding(8.dp),
                color = Color(0xFF1E3A8A),
                style = MaterialTheme.typography.labelMedium,
                fontWeight = FontWeight.Black,
            )
        }

        Text(
            text = "At normalized 1.0, the point lies on the right or bottom boundary. Part of " +
                "the circular marker can be clipped because its center is exactly on that edge.",
            style = MaterialTheme.typography.bodySmall,
            color = Color(0xFF5C687A),
        )

        Text(
            text = "Drawing-area size",
            style = MaterialTheme.typography.titleMedium,
            fontWeight = FontWeight.Black,
        )
        Column(
            modifier = Modifier.fillMaxWidth(),
            verticalArrangement = Arrangement.spacedBy(8.dp),
        ) {
            DrawingSizePreset.entries.forEach { candidate ->
                val selected = candidate == sizePreset
                val onClick = {
                    sizePresetName = candidate.name
                }

                if (selected) {
                    Button(
                        modifier = Modifier.fillMaxWidth(),
                        onClick = onClick,
                    ) {
                        Text(candidate.buttonLabel)
                    }
                } else {
                    OutlinedButton(
                        modifier = Modifier.fillMaxWidth(),
                        onClick = onClick,
                    ) {
                        Text(candidate.buttonLabel)
                    }
                }
            }
        }

        NormalizedSlider(
            label = "Normalized X",
            value = normalizedX,
            onValueChange = { normalizedX = it.coerceIn(0f, 1f) },
        )
        NormalizedSlider(
            label = "Normalized Y",
            value = normalizedY,
            onValueChange = { normalizedY = it.coerceIn(0f, 1f) },
        )

        Text(
            text = "Exact point presets",
            style = MaterialTheme.typography.titleMedium,
            fontWeight = FontWeight.Black,
        )
        Column(
            modifier = Modifier.fillMaxWidth(),
            verticalArrangement = Arrangement.spacedBy(8.dp),
        ) {
            NormalizedPointPreset.entries.forEach { preset ->
                OutlinedButton(
                    modifier = Modifier.fillMaxWidth(),
                    onClick = {
                        normalizedX = preset.normalizedX
                        normalizedY = preset.normalizedY
                    },
                ) {
                    Text(preset.buttonLabel)
                }
            }
        }
    }
}

@Composable
private fun CoordinateReadout(
    measuredSizePx: IntSize,
    normalizedX: Float,
    normalizedY: Float,
    localXpx: Float,
    localYpx: Float,
) {
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .background(
                color = Color(0xFFEEF2FF),
                shape = RoundedCornerShape(16.dp),
            )
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(6.dp),
    ) {
        Text(
            text = "Measured rectangle: ${measuredSizePx.width} × ${measuredSizePx.height} px",
            fontWeight = FontWeight.Black,
        )
        Text(
            text = "Normalized point: (${formatNormalized(normalizedX)}, " +
                "${formatNormalized(normalizedY)})",
            color = Color(0xFF3730A3),
            fontWeight = FontWeight.Black,
        )
        Text(
            text = "Local point: (${formatPixels(localXpx)}, ${formatPixels(localYpx)}) px",
            fontWeight = FontWeight.SemiBold,
        )
        Text(
            text = "X: ${formatPixels(localXpx)} ÷ ${measuredSizePx.width} = " +
                formatNormalized(normalizedX),
            style = MaterialTheme.typography.bodyMedium,
        )
        Text(
            text = "Y: ${formatPixels(localYpx)} ÷ ${measuredSizePx.height} = " +
                formatNormalized(normalizedY),
            style = MaterialTheme.typography.bodyMedium,
        )
    }
}

@Composable
private fun NormalizedSlider(
    label: String,
    value: Float,
    onValueChange: (Float) -> Unit,
) {
    Column(
        modifier = Modifier.fillMaxWidth(),
    ) {
        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.SpaceBetween,
        ) {
            Text(
                text = label,
                fontWeight = FontWeight.SemiBold,
            )
            Text(
                text = formatNormalized(value),
                color = Color(0xFF4338CA),
                fontWeight = FontWeight.Black,
            )
        }
        Slider(
            value = value,
            onValueChange = onValueChange,
            valueRange = 0f..1f,
            steps = 19,
        )
    }
}

private fun formatNormalized(value: Float): String =
    String.format(Locale.US, "%.2f", value)

private fun formatPixels(value: Float): String =
    String.format(Locale.US, "%.1f", value)

10 · Exercises
Answer before opening the solutions
Exercise 4 targets the most likely edge-versus-index misconception.


Exercise 1 · Normalize one local point
A rectangle is 640 px wide and 360 px high. A local point is (160, 270) px. What is the normalized pair?
Answer: 160 ÷ 640 = 0.25 and 270 ÷ 360 = 0.75. The pair is (0.25, 0.75).


Exercise 2 · Convert back to pixels
A rectangle is 800 px wide and 500 px high. The normalized point is (0.25, 0.60). What is the local pixel point?
Answer: x = 0.25 × 800 = 200 px. y = 0.60 × 500 = 300 px. The local point is (200, 300) px.


Exercise 3 · Resize diagnosis
A point is normalized (0.5, 0.25). A rectangle changes from 400 × 200 px to 800 × 400 px. Which values stay unchanged, and what are the two local pixel pairs?
Answer: the normalized pair stays (0.5, 0.25). The first local point is (200, 50) px. The second is (400, 100) px. Both pixel components double because both dimensions double.


Exercise 4 · Diagnostic: edge or last index?
A one-row raster is 8 px wide. What local X gives normalized X = 1? Is that value the last pixel index?
Answer: localX = 1 × 8 = 8. This is the right boundary. It is not the last pixel index. The indexes are 0 through 7.
