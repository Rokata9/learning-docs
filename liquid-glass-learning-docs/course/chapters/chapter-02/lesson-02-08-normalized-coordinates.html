Normalized coordinates

Describe a point by its fraction of the drawing area instead of by one fixed local distance.

Lesson 2.7 changed the origin used to measure a position. Lesson 2.8 keeps one local origin and changes the numeric scale. A local point such as (160, 270) can become the normalized point (0.25, 0.75).

The word normalized means that a value has been converted into a chosen standard range. This lesson uses the range from 0 through 1.

One new mathematical idea

  • Divide a local X position by the drawing width.
  • Divide a local Y position by the drawing height.
  • Multiply by the size to convert back to local points.
  • Keep the same relative point when the drawing area changes size.
1 · Name the two descriptions

One point, two numeric scales

The coordinate-system origin stays at the rectangle’s top-left corner.

Local points

Distance in pt

x = 160 pt means the point is 160 points to the right of the local origin. y = 270 pt means the point is 270 points below the local origin.

The values depend on the current rectangle size. SwiftUI Canvas and tap locations use this unit.

Normalized

Fraction of the size

normalizedX = 0.25 means the point is 25% of the width from the left edge. normalizedY = 0.75 means the point is 75% of the height from the top edge.

The values describe the relative position.

normalizedX = localX ÷ width
normalizedY = localY ÷ height
localX = normalizedX × width
localY = normalizedY × height

0

The left edge for X. The top edge for Y.

0.5

Halfway across the width or height. This is the center along that axis.

1

The right edge for X. The bottom edge for Y.

Important limit: division produces a value from 0 to 1 only when the local point is inside the rectangle or on its boundary. The iOS lesson uses clamped(to: 0...1) to enforce that inside-rectangle range. Division performs the normalization. Clamping only limits the result.

3 · Why normalize?

The same relative point survives a size change

Local point coordinates change. The normalized pair stays fixed.

Inputone normalized pair and two rectangle sizes
Operationmultiply the same pair by each size
Outputdifferent local point pairs at the same relative position
This is why normalized coordinates are useful for graphics. A material feature can remain at “25% from the left and 75% from the top” even when the component becomes larger.
4 · Boundary diagnostic

Normalized 1 is an edge, not the last pixel index

This reuses the edge-versus-cell distinction from Lesson 2.4.

For a width of 8 pixels, the right boundary is at local X = 8. Dividing by the width gives 8 ÷ 8 = 1.

The last pixel index is 7. Its center is at 7.5 in this boundary-based diagram. That center normalizes to 7.5 ÷ 8 = 0.9375, not 1.

Do not replace width with the last pixel index. Width is the distance from the left edge to the right edge.

import SwiftUI

private enum DrawingSizePreset: String, CaseIterable {
    case compact
    case wide
    case square

    var buttonLabel: String {
        switch self {
        case .compact: return "Compact 220 × 150 pt"
        case .wide: return "Wide 320 × 160 pt"
        case .square: return "Square 240 × 240 pt"
        }
    }

    var widthPt: CGFloat {
        switch self {
        case .compact: return 220
        case .wide: return 320
        case .square: return 240
        }
    }

    var heightPt: CGFloat {
        switch self {
        case .compact: return 150
        case .wide: return 160
        case .square: return 240
        }
    }
}

private enum NormalizedPointPreset: String, CaseIterable {
    case topLeft
    case center
    case quarterThreeQuarter
    case bottomRight

    var buttonLabel: String {
        switch self {
        case .topLeft: return "Top-left (0, 0)"
        case .center: return "Center (0.5, 0.5)"
        case .quarterThreeQuarter: return "Quarter / three-quarter"
        case .bottomRight: return "Bottom-right (1, 1)"
        }
    }

    var normalizedX: CGFloat {
        switch self {
        case .topLeft: return 0
        case .center: return 0.5
        case .quarterThreeQuarter: return 0.25
        case .bottomRight: return 1
        }
    }

    var normalizedY: CGFloat {
        switch self {
        case .topLeft: return 0
        case .center: return 0.5
        case .quarterThreeQuarter: return 0.75
        case .bottomRight: return 1
        }
    }
}

struct NormalizedCoordinatesExplorer: View {
    @State private var sizePreset = DrawingSizePreset.wide
    @State private var normalizedX: CGFloat = 0.25
    @State private var normalizedY: CGFloat = 0.75
    @State private var measuredSizePt = CGSize.zero

    private var localXPt: CGFloat { normalizedX * measuredSizePt.width }
    private var localYPt: CGFloat { normalizedY * measuredSizePt.height }

    var body: some View {
        VStack(spacing: 14) {
            Text("The green point stores a relative position from 0 to 1.")
                .font(.system(size: 22, weight: .black))
                .foregroundStyle(Color(hex: 0x4338CA))
            Text(
                "Tap inside the rectangle, move the sliders, or select a preset. Then resize " +
                "the rectangle. The local point position changes, but the normalized position " +
                "stays the same."
            )
            .font(LabType.bodyLarge)

            CoordinateReadout(
                measuredSizePt: measuredSizePt,
                normalizedX: normalizedX,
                normalizedY: normalizedY,
                localXPt: localXPt,
                localYPt: localYPt
            )

            ZStack(alignment: .topLeading) {
                Canvas { context, size in
                    let gridFractions: [CGFloat] = [0.25, 0.5, 0.75]
                    for fraction in gridFractions {
                        var vertical = Path()
                        vertical.move(to: CGPoint(x: size.width * fraction, y: 0))
                        vertical.addLine(to: CGPoint(x: size.width * fraction, y: size.height))
                        context.stroke(vertical, with: .color(Color(hex: 0xC7D2FE)), lineWidth: 1)

                        var horizontal = Path()
                        horizontal.move(to: CGPoint(x: 0, y: size.height * fraction))
                        horizontal.addLine(to: CGPoint(x: size.width, y: size.height * fraction))
                        context.stroke(horizontal, with: .color(Color(hex: 0xC7D2FE)), lineWidth: 1)
                    }

                    let marker = CGPoint(
                        x: normalizedX * size.width,
                        y: normalizedY * size.height
                    )

                    var fromLeft = Path()
                    fromLeft.move(to: CGPoint(x: 0, y: marker.y))
                    fromLeft.addLine(to: marker)
                    context.stroke(fromLeft, with: .color(Color(hex: 0xBE185D)), lineWidth: 2)

                    var fromTop = Path()
                    fromTop.move(to: CGPoint(x: marker.x, y: 0))
                    fromTop.addLine(to: marker)
                    context.stroke(fromTop, with: .color(Color(hex: 0x1E40AF)), lineWidth: 2)

                    context.fill(
                        Path(ellipseIn: CGRect(x: marker.x - 10, y: marker.y - 10, width: 20, height: 20)),
                        with: .color(Color(hex: 0x059669))
                    )
                    context.fill(
                        Path(ellipseIn: CGRect(x: marker.x - 4, y: marker.y - 4, width: 8, height: 8)),
                        with: .color(.white)
                    )
                }

                Text("(0, 0)")
                    .font(LabType.label)
                    .fontWeight(.black)
                    .foregroundStyle(Color(hex: 0x1E3A8A))
                    .padding(8)

                Text("(1, 1)")
                    .font(LabType.label)
                    .fontWeight(.black)
                    .foregroundStyle(Color(hex: 0x1E3A8A))
                    .frame(maxWidth: .infinity, maxHeight: .infinity, alignment: .bottomTrailing)
                    .padding(8)
            }
            .frame(width: sizePreset.widthPt, height: sizePreset.heightPt)
            .background(Color.white)
            .clipShape(RoundedRectangle(cornerRadius: 22, style: .continuous))
            .overlay(
                RoundedRectangle(cornerRadius: 22, style: .continuous)
                    .strokeBorder(Color(hex: 0x1E40AF), lineWidth: 3)
            )
            .contentShape(RoundedRectangle(cornerRadius: 22, style: .continuous))
            .background {
                GeometryReader { proxy in
                    Color.clear.preference(key: DrawingSizeKey.self, value: proxy.size)
                }
            }
            .onPreferenceChange(DrawingSizeKey.self) { measuredSizePt = $0 }
            .onTapGesture(coordinateSpace: .local) { location in
                guard measuredSizePt.width > 0, measuredSizePt.height > 0 else { return }
                normalizedX = (location.x / measuredSizePt.width).clamped(to: 0...1)
                normalizedY = (location.y / measuredSizePt.height).clamped(to: 0...1)
            }
            .accessibilityLabel(
                "Normalized coordinate drawing area. Size \(formatPixels(measuredSizePt.width)) by " +
                "\(formatPixels(measuredSizePt.height)) points. Selected normalized point " +
                "\(formatNormalized(normalizedX)), \(formatNormalized(normalizedY))."
            )

            Text(
                "At normalized 1.0, the point lies on the right or bottom boundary. Part of " +
                "the circular marker can be clipped because its center is exactly on that edge."
            )
            .font(.system(size: 12))
            .foregroundStyle(Color(hex: 0x5C687A))

            Text("Drawing-area size")
                .font(LabType.titleMedium)
                .fontWeight(.black)
            VStack(spacing: 8) {
                ForEach(DrawingSizePreset.allCases, id: \.self) { candidate in
                    let selected = candidate == sizePreset
                    if selected {
                        Button {
                            sizePreset = candidate
                        } label: {
                            Text(candidate.buttonLabel)
                                .frame(maxWidth: .infinity)
                        }
                        .buttonStyle(.borderedProminent)
                    } else {
                        Button {
                            sizePreset = candidate
                        } label: {
                            Text(candidate.buttonLabel)
                                .frame(maxWidth: .infinity)
                        }
                        .buttonStyle(.bordered)
                    }
                }
            }

            NormalizedSlider(
                label: "Normalized X",
                value: $normalizedX
            )
            NormalizedSlider(
                label: "Normalized Y",
                value: $normalizedY
            )

            Text("Exact point presets")
                .font(LabType.titleMedium)
                .fontWeight(.black)
            VStack(spacing: 8) {
                ForEach(NormalizedPointPreset.allCases, id: \.self) { preset in
                    Button {
                        normalizedX = preset.normalizedX
                        normalizedY = preset.normalizedY
                    } label: {
                        Text(preset.buttonLabel)
                            .frame(maxWidth: .infinity)
                    }
                    .buttonStyle(.bordered)
                }
            }
        }
        .frame(maxWidth: .infinity)
    }
}

private struct CoordinateReadout: View {
    var measuredSizePt: CGSize
    var normalizedX: CGFloat
    var normalizedY: CGFloat
    var localXPt: CGFloat
    var localYPt: CGFloat

    var body: some View {
        VStack(alignment: .leading, spacing: 6) {
            Text(
                "Measured rectangle: \(formatPixels(measuredSizePt.width)) × " +
                "\(formatPixels(measuredSizePt.height)) pt"
            )
            .fontWeight(.black)
            Text(
                "Normalized point: (\(formatNormalized(normalizedX)), " +
                "\(formatNormalized(normalizedY)))"
            )
            .fontWeight(.black)
            .foregroundStyle(Color(hex: 0x3730A3))
            Text(
                "Local point: (\(formatPixels(localXPt)), \(formatPixels(localYPt))) pt"
            )
            .fontWeight(.semibold)
            Text(
                "X: \(formatPixels(localXPt)) ÷ \(formatPixels(measuredSizePt.width)) = " +
                formatNormalized(normalizedX)
            )
            .font(.system(size: 14))
            Text(
                "Y: \(formatPixels(localYPt)) ÷ \(formatPixels(measuredSizePt.height)) = " +
                formatNormalized(normalizedY)
            )
            .font(.system(size: 14))
        }
        .padding(16)
        .frame(maxWidth: .infinity, alignment: .leading)
        .background(
            RoundedRectangle(cornerRadius: 16, style: .continuous)
                .fill(Color(hex: 0xEEF2FF))
        )
    }
}

private struct NormalizedSlider: View {
    var label: String
    @Binding var value: CGFloat

    var body: some View {
        VStack(alignment: .leading, spacing: 2) {
            HStack {
                Text(label)
                    .fontWeight(.semibold)
                Spacer()
                Text(formatNormalized(value))
                    .fontWeight(.black)
                    .foregroundStyle(Color(hex: 0x4338CA))
            }
            Slider(
                value: Binding(
                    get: { Double(value) },
                    set: { value = CGFloat($0).clamped(to: 0...1) }
                ),
                in: 0...1,
                step: 0.05
            )
        }
    }
}

private struct DrawingSizeKey: PreferenceKey {
    static var defaultValue = CGSize.zero

    static func reduce(value: inout CGSize, nextValue: () -> CGSize) {
        value = nextValue()
    }
}

private extension Comparable {
    func clamped(to range: ClosedRange<Self>) -> Self {
        min(max(self, range.lowerBound), range.upperBound)
    }
}

private func formatNormalized(_ value: CGFloat) -> String {
    String(format: "%.2f", Double(value))
}

private func formatPixels(_ value: CGFloat) -> String {
    String(format: "%.1f", Double(value))
}

            red: Double((hex >> 16) & 0xFF) / 255,
            green: Double((hex >> 8) & 0xFF) / 255,
            blue: Double(hex & 0xFF) / 255
        )
    }
}

10 · Exercises
Answer before opening the solutions
Exercise 4 targets the most likely edge-versus-index misconception.


Exercise 1 · Normalize one local point
A rectangle is 640 pt wide and 360 pt high. A local point is (160, 270) pt. What is the normalized pair?
Answer: 160 ÷ 640 = 0.25 and 270 ÷ 360 = 0.75. The pair is (0.25, 0.75).


Exercise 2 · Convert back to points
A rectangle is 800 pt wide and 500 pt high. The normalized point is (0.25, 0.60). What is the local point?
Answer: x = 0.25 × 800 = 200 pt. y = 0.60 × 500 = 300 pt. The local point is (200, 300) pt.


Exercise 3 · Resize diagnosis
A point is normalized (0.5, 0.25). A rectangle changes from 400 × 200 pt to 800 × 400 pt. Which values stay unchanged, and what are the two local point pairs?
Answer: the normalized pair stays (0.5, 0.25). The first local point is (200, 50) pt. The second is (400, 100) pt. Both point components double because both dimensions double.


Exercise 4 · Diagnostic: edge or last index?
A one-row raster is 8 px wide. What local X gives normalized X = 1? Is that value the last pixel index?
Answer: localX = 1 × 8 = 8. This is the right boundary. It is not the last pixel index. The indexes are 0 through 7.
