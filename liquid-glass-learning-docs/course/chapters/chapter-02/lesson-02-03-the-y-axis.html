Chapter 2 · Vertical position

A larger Y value moves downward

The Y axis is the vertical reference line used to describe top-to-bottom position. In iOS screen coordinates, Y starts at the top and increases as a position moves down.

This lesson keeps X fixed at 4. Only Y changes. That lets you see one coordinate direction at a time.

By the end

  • Explain why the top row is Y = 0.
  • Predict whether Y increases or decreases after an up or down movement.
  • Separate grid Y from browser SVG pixels, iOS points, and physical display pixels.
  • Trace selectedY = 5 into row 5 of the iOS grid.

2 · Terms and visible result

Vertical, Y axis, and coordinate system

Each term names a specific rule or direction.

Vertical

Vertical means the top-to-bottom direction on the screen.

Visible test: the selected cell changes row but stays in the same column.

Y axis

The Y axis is the reference axis used to measure vertical position.

iOS rule: larger Y values are lower on the screen.

Coordinate system

A coordinate system is a set of rules that assigns numbers to positions. The rules include the origin, directions, and units.

This lesson: the grid origin is at its top-left position.

This direction is not a universal law of mathematics. Some mathematical graphs make Y increase upward. iOS screen and SwiftUI Canvas coordinates normally place the origin at the top-left and make Y increase downward. Always identify the coordinate system before interpreting a Y value.

private let defaultSelectedRow = 3

    "00111100",
    "01222210",
    "12233221",
    "12333321",
    "12333321",
    "12233221",
    "01222210",
    "00111100",
]

private let pixelPalette: [Character: Color] = [
    "0": Color(hex: 0xE2E8F0),
    "1": Color(hex: 0x1E40AF),
    "2": Color(hex: 0x7DD3FC),
    "3": Color(hex: 0xF8FAFC),
]

struct EnlargedPixelGrid: View {
    var selectedColumn: Int
    var selectedRow: Int = defaultSelectedRow

    var body: some View {
        VStack(spacing: 0) {
            ForEach(Array(pixelArt.enumerated()), id: \.offset) { rowIndex, row in
                HStack(spacing: 0) {
                    ForEach(Array(row.enumerated()), id: \.offset) { columnIndex, sampleCode in
                        PixelCell(
                            color: pixelPalette[sampleCode]!,
                            selected: rowIndex == selectedRow &&
                                columnIndex == selectedColumn
                        )
                    }
                }
            }
        }
        .border(Color(hex: 0x0F172A), width: 2)
    }
}

private struct PixelCell: View {
    let color: Color
    let selected: Bool

    var body: some View {
        color
            .frame(width: 34, height: 34)
            .border(
                selected ? Color(hex: 0xDC2626) : Color(hex: 0x64748B),
                width: selected ? 4 : 0.5
            )
    }
}

private extension Color {

            red: Double((hex >> 16) & 0xFF) / 255,
            green: Double((hex >> 8) & 0xFF) / 255,
            blue: Double(hex & 0xFF) / 255
        )
    }
}


    
import SwiftUI

private let firstY = 0
private let lastY = pixelGridRowCount - 1
private let fixedColumn = 4

struct YAxisExplorer: View {
    @State private var selectedY = firstY

    var body: some View {
        VStack(spacing: 12) {
            Text("Selected grid position: X = \(fixedColumn), Y = \(selectedY)")
                .font(.system(size: 22, weight: .black))
            Text("Y increases downward ↓")
                .font(LabType.bodyLarge)
                .fontWeight(.bold)
                .foregroundStyle(Color(hex: 0x1E40AF))

            EnlargedPixelGrid(
                selectedColumn: fixedColumn,
                selectedRow: selectedY
            )

            Slider(
                value: Binding(
                    get: { Double(selectedY) },
                    set: { selectedY = Int($0.rounded()) }
                ),
                in: Double(firstY)...Double(lastY),
                step: 1
            )

            HStack(spacing: 12) {
                Button {
                    selectedY = max(selectedY - 1, firstY)
                } label: {
                    Text("Move up")
                        .frame(maxWidth: .infinity)
                }
                .buttonStyle(.bordered)
                .disabled(selectedY <= firstY)

                Button {
                    selectedY = min(selectedY + 1, lastY)
                } label: {
                    Text("Move down")
                        .frame(maxWidth: .infinity)
                }
                .buttonStyle(.borderedProminent)
                .disabled(selectedY >= lastY)
            }

            Text("Top row: Y = \(firstY) · Bottom row: Y = \(lastY)")
                .font(LabType.bodyLarge)
        }
        .frame(maxWidth: .infinity)
    }
}

private extension Color {
    init(hex: UInt32) {
        self.init(
            red: Double((hex >> 16) & 0xFF) / 255,
            green: Double((hex >> 8) & 0xFF) / 255,
            blue: Double(hex & 0xFF) / 255
        )
    }
}

9 · Coding challenge
Repair the Move down operation
The starting code subtracts 1 and clamps against the lower boundary. That operation moves up, not down.

    

      

        
Editable Swift teaching fragment

        
Make the operation increase Y and stop at lastY.

      

      

        
Clickable code-driven previewY = 3

        

      

    

    
Reference answer
return min(selectedY + 1, lastY)
Adding 1 moves to the next row below. min(..., lastY) prevents a result larger than the last valid row index.

  


  

    
10 · Exercises
Use the vertical direction rule consistently
The diagnostic question separates a coordinate from a drawing measurement.

    

      
  1. Starting at Y = 2, move down three rows. What is the result?
  2. Starting at Y = 5, move up one row. What is the result?
  3. The browser axis draws Y = 3 at 252 SVG-local pixels. Does that mean the iOS selection is at physical display pixel 252?
  4. Why is Y = 7 the bottom valid row in an eight-row zero-indexed grid?

      
Answer 1
2 + 3 = 5. Moving down increases Y.
Answer 2
5 − 1 = 4. Moving up decreases Y.
Answer 3 · Diagnostic
No. 252 is an SVG-local position created by this browser diagram’s 96-pixel top margin and 52-pixel spacing. The iOS grid uses points, and the physical display uses physical pixels. Those values are not interchangeable.
Answer 4
Indexing starts at 0. Eight indexes are 0 through 7, so 7 is the eighth and last row.
