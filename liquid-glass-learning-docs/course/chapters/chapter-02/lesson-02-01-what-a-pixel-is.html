Lesson 2.1 · What a pixel is
Chapter 2 · The screen is a grid

Treat an image as a rectangular grid of samples

A detailed image can be inspected as many small positions arranged in rows and columns. Each position stores the information used to produce one small part of the image.

One new idea

A pixel is one addressable position in a raster image. A sample is the stored value read at that position. People often use “pixel” for both the position and its stored color.

2 · Terms

Pixel, raster, row, and column

These definitions apply to the teaching grid and to ordinary raster images.

Raster image

A raster image is a rectangular collection of sample positions. Screenshots and decoded photographs are common raster images.

Pixel

A pixel is one smallest addressable position in that raster image.

Row

A row is one horizontal sequence of pixel positions.

Column

A column is one vertical sequence of pixel positions.

Important device boundary: the large squares in this lesson are enlarged teaching cells. Each square occupies many physical display pixels on the Pixel 8 Pro. It is not one physical screen pixel.

4 · Clarify the earlier 0.40 value

One channel number is not a complete color

This directly answers the question raised after Lesson 1.6.

Red0.40102 / 255
Green0.65166 / 255
Blue0.90230 / 255
Alpha1.00255 / 255

Same RGBA representation

(0.40, 0.65, 0.90, 1.00) is RGBA written with normalized fractions. The approximate 8-bit form is (102, 166, 230, 255).

What 0.40 alone means

0.40 describes one selected channel at one image position. It becomes a gray only when red, green, and blue are all set to 0.40. With alpha 1, that gray is approximately #666666 in 8-bit sRGB code values.

Precision boundary: multiplying by 255 and rounding explains the common 8-bit code-value representation. It does not mean that 0.40 produces exactly 40% of the display’s physical light. Color spaces and transfer functions are taught in Chapter 3.

Why use Row and Column here?
The lesson needs a visibly enlarged grid, not one-square-per-physical-pixel rendering. Compose layout makes every teaching cell easy to inspect.
What the code does not prove
A 34.dp square is not 34 physical pixels. Android converts density-independent layout units to physical pixels. Lesson 2.5 explains that conversion.

10 · Exercises
Separate a pixel position from its color data
The diagnostic question returns to the Lesson 1.6 channel value.
  1. An image has 12 columns and 5 rows. How many pixel positions does it contain?
  2. What is the difference between a pixel position and a sample value?
  3. Does the single number 0.40 describe a complete RGBA color?
  4. If red, green, and blue are all 0.40 and alpha is 1.00, what approximate 8-bit gray value results?
Answer 1
12 × 5 = 60 positions.
Answer 2
The position identifies where the cell is in the raster grid. The sample value is the stored information read at that position, commonly including color channels.
Answer 3 · Diagnostic
No. It is one channel value unless the other channels are also supplied.
Answer 4
0.40 × 255 = 102, so the approximate opaque sRGB gray is RGBA(102, 102, 102, 255), commonly written #666666.
