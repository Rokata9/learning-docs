Chapter 2 · Android measurement units

Pixels, dp, and density

Android layout code usually expresses intended size in dp. A Compose drawing surface uses px. Density is the runtime scale that converts between those two units.

One graphics idea: layout and drawing can describe the same distance using different units. One math idea: converting dp to px is multiplication by density.

By the end

  • Define px, dp, and density.
  • Calculate px = dp × density.
  • Convert px back with dp = px ÷ density.
  • Explain why Canvas.size.width is not a dp value.
  • Read the real runtime density on the Pixel 8 Pro.

1 · Three separate terms

Name the unit before using the number

The number 96 is incomplete until its unit is known.

dp

Density-independent pixel

A dp is an abstract Android layout unit. Android changes the number of px used for one dp according to the current density.

Concrete object: Modifier.size(96.dp) requests a layout size.

px

Pixel coordinate unit

In this lesson, px is one coordinate unit in the app's raster drawing surface. Compose Canvas sizes, coordinates, and stroke widths use px.

Concrete object: size.width inside a Canvas draw block is a px value.

density

Conversion scale

Density tells Compose how many px correspond to one dp in the current configuration.

Example: density 2.75 means 1 dp → 2.75 px before integer layout rounding.

Not covered yet: physical OLED subpixels, display-compositor scaling, and text unit sp. Those topics do not change today's dp-to-px conversion rule.

3 · Why dp exists

Keep layout intent, not a fixed px count

The diagram uses a fixed teaching scale of three SVG units for one dp. SVG units here are only diagram coordinates.

Same layout intent

At density 1, 96.dp uses 96 px. At density 3, the same 96.dp uses 288 px. The dp width remains the same in the Android layout model.

96 dp × 1 = 96 px · 96 dp × 3 = 288 px

Common mistake

Using 96f as a Canvas distance fixes the value at 96 px. On a density-3 display, that distance represents only 96 ÷ 3 = 32 dp.

private const val InitialSampleDp = 96
private val SampleSizesDp = listOf(48, 72, 96, 120)

@Composable
internal fun DensityExplorer(
    modifier: Modifier = Modifier,
) {
    val density = LocalDensity.current
    var selectedDp by rememberSaveable {
        mutableIntStateOf(InitialSampleDp)
    }
    var measuredSquarePx by remember {
        mutableStateOf(IntSize.Zero)
    }
    var measuredCanvasPx by remember {
        mutableStateOf(IntSize.Zero)
    }

    val requestedSize = selectedDp.dp
    val densityScale = density.density
    val calculatedSizePx = with(density) {
        requestedSize.toPx()
    }
    val roundedSizePx = with(density) {
        requestedSize.roundToPx()
    }
    val oneDpPx = with(density) {
        1.dp.toPx()
    }
    val canvasInsetPx = with(density) {
        16.dp.toPx()
    }

    Column(
        modifier = modifier.fillMaxWidth(),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.spacedBy(14.dp),
    ) {
        Text(
            text = "Runtime density = ${formatNumber(densityScale, 2)} px per dp",
            color = Color(0xFF1E40AF),
            style = MaterialTheme.typography.titleLarge,
            fontWeight = FontWeight.Black,
        )
        Text(
            text = "$selectedDp dp × ${formatNumber(densityScale, 2)} = " +
                "${formatNumber(calculatedSizePx, 2)} px",
            style = MaterialTheme.typography.titleMedium,
            fontWeight = FontWeight.Bold,
        )
        Text(
            text = "Layout needs a whole-pixel size, so this request rounds to $roundedSizePx px.",
            style = MaterialTheme.typography.bodyLarge,
        )

        Box(
            modifier = Modifier
                .size(requestedSize)
                .onSizeChanged { measuredSquarePx = it }
                .background(
                    color = Color(0xFFDBEAFE),
                    shape = RoundedCornerShape(16.dp),
                )
                .border(
                    width = 2.dp,
                    color = Color(0xFF1E40AF),
                    shape = RoundedCornerShape(16.dp),
                )
                .semantics {
                    contentDescription =
                        "Square requested as $selectedDp density-independent pixels, " +
                        "measured as ${measuredSquarePx.width} by ${measuredSquarePx.height} pixels"
                },
            contentAlignment = Alignment.Center,
        ) {
            Text(
                text = "$selectedDp dp",
                color = Color(0xFF1E3A8A),
                style = MaterialTheme.typography.titleMedium,
                fontWeight = FontWeight.Black,
            )
        }

        Text(
            text = "Measured square = ${measuredSquarePx.width} × ${measuredSquarePx.height} px",
            color = Color(0xFF059669),
            style = MaterialTheme.typography.bodyLarge,
            fontWeight = FontWeight.Bold,
        )

        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.spacedBy(8.dp),
        ) {
            SampleSizesDp.forEach { sizeDp ->
                val selected = selectedDp == sizeDp
                if (selected) {
                    Button(
                        onClick = { selectedDp = sizeDp },
                        modifier = Modifier.weight(1f),
                    ) {
                        Text("$sizeDp dp")
                    }
                } else {
                    OutlinedButton(
                        onClick = { selectedDp = sizeDp },
                        modifier = Modifier.weight(1f),
                    ) {
                        Text("$sizeDp dp")
                    }
                }
            }
        }

        Column(
            modifier = Modifier
                .fillMaxWidth()
                .background(
                    color = Color.White,
                    shape = RoundedCornerShape(18.dp),
                )
                .border(
                    width = 1.dp,
                    color = Color(0xFFCBD5E1),
                    shape = RoundedCornerShape(18.dp),
                )
                .padding(16.dp),
            verticalArrangement = Arrangement.spacedBy(8.dp),
        ) {
            Text(
                text = "Canvas drawing space",
                style = MaterialTheme.typography.titleMedium,
                fontWeight = FontWeight.Black,
            )
            Text(
                text = "The Canvas is requested in dp. Its draw coordinates and stroke widths are px.",
                style = MaterialTheme.typography.bodyMedium,
            )

            Canvas(
                modifier = Modifier
                    .fillMaxWidth()
                    .height(132.dp)
                    .onSizeChanged { measuredCanvasPx = it }
                    .semantics {
                        contentDescription =
                            "Canvas measured as ${measuredCanvasPx.width} by ${measuredCanvasPx.height} pixels, " +
                            "with a sixteen density-independent pixel inset converted to " +
                            "${formatNumber(canvasInsetPx, 2)} pixels"
                    },
            ) {
                drawRect(
                    color = Color(0xFFF8FAFC),
                )

                drawRect(
                    color = Color(0xFFE0E7FF),
                    topLeft = Offset(canvasInsetPx, canvasInsetPx),
                    size = Size(
                        width = size.width - (canvasInsetPx * 2f),
                        height = size.height - (canvasInsetPx * 2f),
                    ),
                )
                drawRect(
                    color = Color(0xFF4338CA),
                    topLeft = Offset(canvasInsetPx, canvasInsetPx),
                    size = Size(
                        width = size.width - (canvasInsetPx * 2f),
                        height = size.height - (canvasInsetPx * 2f),
                    ),
                    style = Stroke(width = oneDpPx),
                )

                val firstLineY = size.height * 0.43f
                val secondLineY = size.height * 0.68f
                val lineStartX = canvasInsetPx * 1.6f
                val lineEndX = size.width - (canvasInsetPx * 1.6f)

                drawLine(
                    color = Color(0xFFDC2626),
                    start = Offset(lineStartX, firstLineY),
                    end = Offset(lineEndX, firstLineY),
                    strokeWidth = 1f,
                )
                drawLine(
                    color = Color(0xFF059669),
                    start = Offset(lineStartX, secondLineY),
                    end = Offset(lineEndX, secondLineY),
                    strokeWidth = oneDpPx,
                )
            }

            Text(
                text = "Canvas size = ${measuredCanvasPx.width} × ${measuredCanvasPx.height} px",
                style = MaterialTheme.typography.bodyMedium,
                fontWeight = FontWeight.Bold,
            )
            Text(
                text = "Red line = 1 px · Green line = 1 dp = " +
                    "${formatNumber(oneDpPx, 2)} px · Inner inset = 16 dp = " +
                    "${formatNumber(canvasInsetPx, 2)} px",
                style = MaterialTheme.typography.bodyMedium,
            )
        }

        Text(
            text = "Use dp for layout intent. Convert dp to px before supplying a Canvas or shader distance.",
            style = MaterialTheme.typography.bodyLarge,
            fontWeight = FontWeight.Bold,
        )
    }
}

private fun formatNumber(
    value: Float,
    decimalPlaces: Int,
): String = String.format(
    Locale.US,
    "%.${decimalPlaces}f",
    value,
)

9 · Exercises
Predict before opening the answers
At least one question targets the most common unit mistake.

    
Exercise 1 · A component is 96.dp wide and density is 2.75 px per dp. What is its converted width?
Answer: 96 × 2.75 = 264 px.

    
Exercise 2 · A measured Canvas distance is 220 px and density is 2.75. What is the equivalent dp distance?
Answer: 220 ÷ 2.75 = 80 dp.

    
Exercise 3 · Diagnostic: inside a Compose Canvas, size.width is 600f. Is that 600.dp?
Answer: no. Inside the Canvas draw block, size.width is 600 px. Convert it with the current density only when you specifically need an equivalent dp value.

    
Exercise 4 · A design radius is 24.dp. Density is 3. Why is radius = 24f wrong in a Canvas or shader?
Answer: 24f supplies 24 px, which is only 24 ÷ 3 = 8 dp at density 3. The intended radius is 24.dp.toPx() = 72 px.
