Chapter 2 · The screen is a grid

Build a coordinate inspector

A coordinate inspector is a diagnostic view that shows one selected point together with the exact coordinate system and unit used by each number. You will combine the nine Chapter 2 ideas into one Android tool.

one visible point → several named descriptions

Lesson goal

  • Draw a grid, local origin, bounds, center, crosshair, and point marker.
  • Read the point as local px, local dp, normalized coordinates, parent px, window px, and screen px.
  • Explain why the numbers differ without saying that the point moved.
  • Trace the real Pixel 8 Pro values from input to drawing.
16 of 216 lessons were complete before this lesson.
1 · New input words

Define the objects before using them

The tool needs one small amount of pointer vocabulary.

Pointer

A pointer is a physical object that can point at a screen coordinate. On the Pixel 8 Pro, the pointer is normally your finger. A stylus or mouse can also be a pointer.

Pointer event

A pointer event is one data record produced when a pointer goes down, moves, or goes up. The event contains a position relative to the element receiving it.

Crosshair

A crosshair is one horizontal guide and one vertical guide that meet at the selected point. It makes the point’s X and Y distances visible.

Inspector bounds

The inspector bounds are the rectangle occupied by the diagnostic drawing area. Its local left and top are 0. Its local right and bottom equal its measured width and height.

Evidence limit: the browser laboratory below uses teaching coordinates. The Android readout uses the size, density, and placement measured by Compose on your Pixel 8 Pro.

4 · One number can refer to different objects

Name the value before reading it

The label is part of the data.

160 px

This is the local horizontal distance from the inspector’s left edge to the point.

64 dp

This is the same local horizontal distance after division by the teaching density 2.5 px per dp.

0.25

This is the unitless horizontal fraction of the inspector width.

500 px

This is the point’s horizontal screen-relative position in the default nested example.

Diagnostic question: is 0.25 “smaller” than 160 px? That comparison has no useful meaning. The two values use different numeric scales and describe the distance in different ways.

6 · Android value trace
Follow one finger position to every readout
The code stores immutable numbers, not a long-lived LayoutCoordinates object.
1 · Read density
LocalDensity.current supplies the current px-per-dp conversion scale.
val density = LocalDensity.current
2 · Measure geometry
onGloballyPositioned copies size and three origins into InspectorGeometry.
sizePx = coordinates.size
originInWindowPx = coordinates.positionInWindow()
3 · Receive pointer input
awaitFirstDown receives the first pressed pointer inside the inspector.
val down = awaitFirstDown(...)
4 · Clamp to bounds
The point is restricted to local X from 0 through width and local Y from 0 through height.
down.position.clampTo(geometry.sizePx)
5 · Store normalized state
Division converts local pixels into a pair that survives a later size change.
normalizedX = value / width
normalizedY = value / height
6 · Rebuild local px
The current width and height convert the stored fractions back into drawing coordinates.
Offset(
 x = normalizedX * widthPx,
 y = normalizedY * heightPx,
)
7 · Derive other spaces
Density division produces dp. Origin addition produces parent, window, and screen positions.
localPx / density
originInWindowPx + localPointPx
8 · Draw the evidence
The Canvas consumes the grid, bounds, center, and point values. The text rows consume the same state.
drawInspectorGrid(
 localPointPx,
 localCenterPx,
 pointerPressed,
)
pointer event → local px → normalized state → current local px → dp and larger spaces → Canvas + text readouts
Why raw pointer input is used here: this teaching tool needs the exact down position and every movement position. The implementation uses one custom pointer handler and consumes its active changes so dragging inside the inspector does not become vertical page scrolling. Gesture design in a production control requires additional accessibility and interaction semantics; this diagnostic surface is not a general-purpose button.

@Composable
internal fun CoordinateInspector(
    modifier: Modifier = Modifier,
) {
    val density = LocalDensity.current
    val densityScale = density.density

    var geometry by remember {
        mutableStateOf(InspectorGeometry())
    }
    var normalizedX by rememberSaveable {
        mutableFloatStateOf(0.25f)
    }
    var normalizedY by rememberSaveable {
        mutableFloatStateOf(0.75f)
    }
    var pointerPressed by remember {
        mutableStateOf(false)
    }

    val widthPx = geometry.sizePx.width.toFloat()
    val heightPx = geometry.sizePx.height.toFloat()
    val localPointPx = Offset(
        x = normalizedX * widthPx,
        y = normalizedY * heightPx,
    )
    val localCenterPx = Offset(
        x = widthPx / 2f,
        y = heightPx / 2f,
    )
    val localPointDp = Offset(
        x = divideByDensity(localPointPx.x, densityScale),
        y = divideByDensity(localPointPx.y, densityScale),
    )
    val pointInParentPx = geometry.originInParentPx + localPointPx
    val pointInWindowPx = geometry.originInWindowPx + localPointPx
    val pointOnScreenPx = geometry.originOnScreenPx?.plus(localPointPx)

    Column(
        modifier = modifier.fillMaxWidth(),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.spacedBy(14.dp),
    ) {
        Text(
            text = "One point. Several descriptions.",
            color = Color(0xFF4338CA),
            style = MaterialTheme.typography.titleLarge,
            fontWeight = FontWeight.Black,
        )
        Text(
            text = "Touch or drag inside the rectangle. The crosshair marks one point. Every " +
                "readout below describes that same point from a named origin or with a named unit.",
            style = MaterialTheme.typography.bodyLarge,
        )

        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(340.dp)
                .background(
                    color = Color.White,
                    shape = InspectorShape,
                )
                .border(
                    width = 1.dp,
                    color = Color(0xFFCBD5E1),
                    shape = InspectorShape,
                )
                .onGloballyPositioned { coordinates ->
                    geometry = InspectorGeometry(
                        sizePx = coordinates.size,
                        originInParentPx = coordinates.positionInParent(),
                        originInWindowPx = coordinates.positionInWindow(),
                        originOnScreenPx = coordinates
                            .positionOnScreen()
                            .toFiniteOffsetOrNull(),
                    )
                }
                .pointerInput(geometry.sizePx) {
                    awaitEachGesture {
                        val down = awaitFirstDown(requireUnconsumed = false)
                        val downPoint = down.position.clampTo(geometry.sizePx)
                        normalizedX = normalize(downPoint.x, geometry.sizePx.width)
                        normalizedY = normalize(downPoint.y, geometry.sizePx.height)
                        pointerPressed = true
                        down.consume()

                        try {
                            var anyPointerPressed = true
                            while (anyPointerPressed) {
                                val event = awaitPointerEvent()
                                val trackedChange = event.changes.firstOrNull {
                                    it.id == down.id
                                }

                                if (trackedChange != null) {
                                    val trackedPoint = trackedChange.position
                                        .clampTo(geometry.sizePx)
                                    normalizedX = normalize(
                                        value = trackedPoint.x,
                                        size = geometry.sizePx.width,
                                    )
                                    normalizedY = normalize(
                                        value = trackedPoint.y,
                                        size = geometry.sizePx.height,
                                    )
                                    trackedChange.consume()
                                }

                                anyPointerPressed = event.changes.any { it.pressed }
                            }
                        } finally {
                            pointerPressed = false
                        }
                    }
                }
                .semantics {
                    contentDescription =
                        "Coordinate inspector. Local point ${formatOffset(localPointPx)} pixels. " +
                        "Normalized point ${formatNormalizedPair(normalizedX, normalizedY)}."
                },
        ) {
            Canvas(
                modifier = Modifier.matchParentSize(),
            ) {
                drawInspectorGrid(
                    localPointPx = localPointPx,
                    localCenterPx = localCenterPx,
                    pointerPressed = pointerPressed,
                )
            }

            Text(
                text = "origin (0, 0)",
                modifier = Modifier
                    .align(Alignment.TopStart)
                    .padding(10.dp),
                color = Color(0xFF1E3A8A),
                style = MaterialTheme.typography.labelMedium,
                fontWeight = FontWeight.Black,
            )
            Text(
                text = "right = ${formatCoordinate(widthPx)} px",
                modifier = Modifier
                    .align(Alignment.TopEnd)
                    .padding(10.dp),
                color = Color(0xFF92400E),
                style = MaterialTheme.typography.labelMedium,
                fontWeight = FontWeight.Black,
            )
            Text(
                text = "bottom = ${formatCoordinate(heightPx)} px",
                modifier = Modifier
                    .align(Alignment.BottomStart)
                    .padding(10.dp),
                color = Color(0xFF92400E),
                style = MaterialTheme.typography.labelMedium,
                fontWeight = FontWeight.Black,
            )
        }

        Text(
            text = if (pointerPressed) {
                "Pointer state: pressed. The inspector is receiving movement events."
            } else {
                "Pointer state: released. Touch inside the rectangle to update the point."
            },
            color = if (pointerPressed) Color(0xFFBE185D) else Color(0xFF5C687A),
            style = MaterialTheme.typography.bodyMedium,
            fontWeight = FontWeight.SemiBold,
        )

        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.spacedBy(8.dp),
        ) {
            InspectorPointPreset.entries.take(2).forEach { preset ->
                InspectorPresetButton(
                    preset = preset,
                    selected = normalizedX == preset.normalizedX &&
                        normalizedY == preset.normalizedY,
                    modifier = Modifier.weight(1f),
                    onClick = {
                        normalizedX = preset.normalizedX
                        normalizedY = preset.normalizedY
                    },
                )
            }
        }
        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.spacedBy(8.dp),
        ) {
            InspectorPointPreset.entries.drop(2).forEach { preset ->
                InspectorPresetButton(
                    preset = preset,
                    selected = normalizedX == preset.normalizedX &&
                        normalizedY == preset.normalizedY,
                    modifier = Modifier.weight(1f),
                    onClick = {
                        normalizedX = preset.normalizedX
                        normalizedY = preset.normalizedY
                    },
                )
            }
        }

        InspectorReadouts(
            geometry = geometry,
            densityScale = densityScale,
            localPointPx = localPointPx,
            localPointDp = localPointDp,
            localCenterPx = localCenterPx,
            normalizedX = normalizedX,
            normalizedY = normalizedY,
            pointInParentPx = pointInParentPx,
            pointInWindowPx = pointInWindowPx,
            pointOnScreenPx = pointOnScreenPx,
        )

        Text(
            text = "The parent, window, and screen calculations below assume this lesson's " +
                "inspector is not rotated or scaled. A later transform would require a coordinate " +
                "conversion API instead of simple addition.",
            style = MaterialTheme.typography.bodySmall,
            color = Color(0xFF5C687A),
        )
    }
}

private fun androidx.compose.ui.graphics.drawscope.DrawScope.drawInspectorGrid(
    localPointPx: Offset,
    localCenterPx: Offset,
    pointerPressed: Boolean,
) {
    val gridSpacingPx = 32.dp.toPx()
    val gridStrokePx = 1.dp.toPx()
    val centerStrokePx = 2.dp.toPx()
    val pointerStrokePx = 2.dp.toPx()
    val boundaryStrokePx = 3.dp.toPx()
    val dashEffect = PathEffect.dashPathEffect(
        intervals = floatArrayOf(10.dp.toPx(), 7.dp.toPx()),
    )

    var gridX = gridSpacingPx
    while (gridX < size.width) {
        drawLine(
            color = Color(0xFFDCE6F5),
            start = Offset(gridX, 0f),
            end = Offset(gridX, size.height),
            strokeWidth = gridStrokePx,
        )
        gridX += gridSpacingPx
    }

    var gridY = gridSpacingPx
    while (gridY < size.height) {
        drawLine(
            color = Color(0xFFDCE6F5),
            start = Offset(0f, gridY),
            end = Offset(size.width, gridY),
            strokeWidth = gridStrokePx,
        )
        gridY += gridSpacingPx
    }

    drawLine(
        color = Color(0xFF4338CA),
        start = Offset(localCenterPx.x, 0f),
        end = Offset(localCenterPx.x, size.height),
        strokeWidth = centerStrokePx,
        pathEffect = dashEffect,
    )
    drawLine(
        color = Color(0xFF4338CA),
        start = Offset(0f, localCenterPx.y),
        end = Offset(size.width, localCenterPx.y),
        strokeWidth = centerStrokePx,
        pathEffect = dashEffect,
    )

    drawLine(
        color = Color(0xFFBE185D),
        start = Offset(0f, localPointPx.y),
        end = localPointPx,
        strokeWidth = pointerStrokePx,
    )
    drawLine(
        color = Color(0xFF1E40AF),
        start = Offset(localPointPx.x, 0f),
        end = localPointPx,
        strokeWidth = pointerStrokePx,
    )

    val inset = boundaryStrokePx / 2f
    drawRect(
        color = Color(0xFFD97706),
        topLeft = Offset(inset, inset),
        size = Size(
            width = (size.width - boundaryStrokePx).coerceAtLeast(0f),
            height = (size.height - boundaryStrokePx).coerceAtLeast(0f),
        ),
        style = Stroke(width = boundaryStrokePx),
    )

    drawCircle(
        color = if (pointerPressed) Color(0xFFBE185D) else Color(0xFF059669),
        radius = 12.dp.toPx(),
        center = localPointPx,
    )
    drawCircle(
        color = Color.White,
        radius = 5.dp.toPx(),
        center = localPointPx,
    )
    drawCircle(
        color = Color(0xFF4338CA),
        radius = 5.dp.toPx(),
        center = localCenterPx,
    )
}

private fun normalize(
    value: Float,
    size: Int,
): Float = if (size > 0) {
    (value / size.toFloat()).coerceIn(0f, 1f)
} else {
    0f
}

private fun divideByDensity(
    valuePx: Float,
    densityScale: Float,
): Float = if (densityScale > 0f) {
    valuePx / densityScale
} else {
    0f
}

private fun Offset.clampTo(size: IntSize): Offset = Offset(
    x = x.coerceIn(0f, size.width.toFloat()),
    y = y.coerceIn(0f, size.height.toFloat()),
)

private fun Offset.toFiniteOffsetOrNull(): Offset? =
    takeIf { it.x.isFinite() && it.y.isFinite() }

private fun formatOffset(offset: Offset): String =
    "(${formatCoordinate(offset.x)}, ${formatCoordinate(offset.y)})"

private fun formatNormalizedPair(
    x: Float,
    y: Float,
): String = "(${formatNormalized(x)}, ${formatNormalized(y)})"

private fun formatCoordinate(value: Float): String =
    String.format(Locale.US, "%.1f", value)

private fun formatNormalized(value: Float): String =
    String.format(Locale.US, "%.3f", value)

private fun formatDensity(value: Float): String =
    String.format(Locale.US, "%.3f px/dp", value)

10 · Exercises
Answer before opening the solutions
Exercise 4 targets the most likely unit-mixing mistake.
Exercise 1 · Bounds, center, and normalized point
An inspector measures 640 × 360 px. The pointer-local point is (160, 270) px. State the local bounds, local center, and normalized point.
Answer: bounds are left 0, top 0, right 640, bottom 360 px. Center is (320, 180) px. Normalized point is (160 ÷ 640, 270 ÷ 360) = (0.25, 0.75).
Exercise 2 · Convert local pixels to dp
The pointer-local point is (180, 270) px. Density is 3 px per dp. What is the local dp pair?
Answer: (180 ÷ 3, 270 ÷ 3) = (60, 90) dp.
Exercise 3 · Move through the larger coordinate systems
Inspector origin in parent is (120, 80) px. Parent origin in window is (180, 100) px. Window origin on screen is (40, 60) px. Pointer local is (160, 270) px. Find pointer in parent, window, and screen.
Answer: parent is (120, 80) + (160, 270) = (280, 350) px. Window is (180, 100) + (280, 350) = (460, 450) px. Screen is (40, 60) + (460, 450) = (500, 510) px.
Exercise 4 · Diagnostic: which pair may be added?
An inspector origin on screen is (40, 60) px. The point is local (160, 270) px and normalized (0.25, 0.75). Which pair must be added to the screen origin, and why?
Answer: add the local pixel pair: (40, 60) + (160, 270) = (200, 330) px. Both operands are pixel offsets. The normalized pair is unitless and cannot be added directly to a pixel origin.



11 · Evidence and deferrals
What this checkpoint proves
Keep the design conclusion separate from framework details that were not measured.
The running app can prove
It can prove the inspector’s measured pixel size, runtime density, pointer-local positions, normalized results, and the positions returned by the Compose coordinate APIs on your current device and window configuration.
This lesson does not prove
It does not prove how Android converts physical touch-sensor data into app-window coordinates, how the system compositor places every surface, or how transformed descendants should be mapped. Those questions require framework source, tracing, or later transform APIs.
Design conclusion: later blur, refraction, and shader sampling code must name its coordinate system and unit. The inspector gives us a reusable way to verify that mapping before blaming a shader formula.
