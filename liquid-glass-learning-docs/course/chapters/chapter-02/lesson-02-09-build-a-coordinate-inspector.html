Build a coordinate inspector

A coordinate inspector is a diagnostic view that shows one selected point together with the exact coordinate system and unit used by each number. You will combine the nine Chapter 2 ideas into one iOS tool.

one visible point → several named descriptions

Lesson goal

  • Draw a grid, local origin, bounds, center, crosshair, and point marker.
  • Read the point as local pt, local px, normalized coordinates, parent pt, window pt, and screen pt.
  • Explain why the numbers differ without saying that the point moved.
  • Trace the real iPhone 16 Pro values from input to drawing.
1 · New input words

Define the objects before using them

The tool needs one small amount of pointer vocabulary.

Pointer

A pointer is a physical object that can point at a screen coordinate. On the iPhone 16 Pro, the pointer is normally your finger. A stylus or mouse can also be a pointer.

Pointer event

A pointer event is one data record produced when a pointer goes down, moves, or goes up. The event contains a position relative to the element receiving it.

Crosshair

A crosshair is one horizontal guide and one vertical guide that meet at the selected point. It makes the point’s X and Y distances visible.

Inspector bounds

The inspector bounds are the rectangle occupied by the diagnostic drawing area. Its local left and top are 0. Its local right and bottom equal its measured width and height.

Evidence limit: the browser laboratory below uses teaching coordinates. The iOS readout uses the size, scale, and placement measured by SwiftUI on your iPhone 16 Pro.

4 · One number can refer to different objects

Name the value before reading it

The label is part of the data.

160 pt

This is the local horizontal distance from the inspector’s left edge to the point.

400 px

This is the same local horizontal distance after multiplication by the teaching scale 2.5 px per pt.

0.25

This is the unitless horizontal fraction of the inspector width.

500 pt

This is the point’s horizontal screen-relative position in the default nested example.

Diagnostic question: is 0.25 “smaller” than 160 px? That comparison has no useful meaning. The two values use different numeric scales and describe the distance in different ways.

6 · iOS value trace
Follow one finger position to every readout
The code stores immutable numbers, not a long-lived geometry object.
1 · Read scale
displayScale supplies the current px-per-pt conversion scale.
@Environment(\.displayScale)
private var displayScale
2 · Measure geometry
GeometryReader copies size and the parent origin into InspectorGeometry. Window and screen origins come from UIView.convert.
sizePt = proxy.size
originInParentPt = proxy.frame(
  in: .named("inspectorParent")
).origin
3 · Receive pointer input
DragGesture(minimumDistance: 0) receives the first press and every movement inside the inspector.
DragGesture(minimumDistance: 0)
  .onChanged { value in
    updateNormalized(from: value.location)
  }
4 · Clamp to bounds
The point is restricted to local X from 0 through width and local Y from 0 through height.
location.x.clamped(
  to: 0...widthPt
)
5 · Store normalized state
Division converts local points into a pair that survives a later size change.
normalizedX = value / width
normalizedY = value / height
6 · Rebuild local pt
The current width and height convert the stored fractions back into drawing coordinates.
CGPoint(
 x: normalizedX * widthPt,
 y: normalizedY * heightPt
)
7 · Derive other spaces
Scale multiplication produces px. Origin addition produces parent, window, and screen positions.
localPt * displayScale
originInWindowPt + localPointPt
8 · Draw the evidence
The Canvas consumes the grid, bounds, center, and point values. The text rows consume the same state.
drawInspectorGrid(
 localPointPt,
 localCenterPt,
 pointerPressed
)
pointer event → local pt → normalized state → current local pt → px and larger spaces → Canvas + text readouts
Why a high-priority drag is used here: this teaching tool needs the exact down position and every movement position. The implementation uses one drag gesture with highPriorityGesture so dragging inside the inspector does not become vertical page scrolling. Gesture design in a production control requires additional accessibility and interaction semantics; this diagnostic surface is not a general-purpose button.

private struct InspectorGeometry {
    var sizePt: CGSize = .zero
    var originInParentPt: CGPoint = .zero
    var originInWindowPt: CGPoint?
    var originOnScreenPt: CGPoint?
}

private enum InspectorPointPreset: String, CaseIterable {
    case origin
    case center
    case quarterThreeQuarter
    case bottomRight

    var buttonLabel: String {
        switch self {
        case .origin: return "Origin"
        case .center: return "Center"
        case .quarterThreeQuarter: return "Quarter / three-quarter"
        case .bottomRight: return "Bottom-right boundary"
        }
    }

    var normalizedX: CGFloat {
        switch self {
        case .origin: return 0
        case .center: return 0.5
        case .quarterThreeQuarter: return 0.25
        case .bottomRight: return 1
        }
    }

    var normalizedY: CGFloat {
        switch self {
        case .origin: return 0
        case .center: return 0.5
        case .quarterThreeQuarter: return 0.75
        case .bottomRight: return 1
        }
    }
}

struct CoordinateInspector: View {
    @Environment(\.displayScale) private var displayScale
    @State private var geometry = InspectorGeometry()
    @State private var normalizedX: CGFloat = 0.25
    @State private var normalizedY: CGFloat = 0.75
    @State private var pointerPressed = false

    private var widthPt: CGFloat { geometry.sizePt.width }
    private var heightPt: CGFloat { geometry.sizePt.height }
    private var localPointPt: CGPoint {
        CGPoint(x: normalizedX * widthPt, y: normalizedY * heightPt)
    }
    private var localCenterPt: CGPoint {
        CGPoint(x: widthPt / 2, y: heightPt / 2)
    }
    private var localPointPx: CGPoint {
        CGPoint(
            x: multiplyByScale(localPointPt.x, displayScale),
            y: multiplyByScale(localPointPt.y, displayScale)
        )
    }
    private var pointInParentPt: CGPoint {
        addPoints(geometry.originInParentPt, localPointPt)
    }
    private var pointInWindowPt: CGPoint? {
        addOrNil(geometry.originInWindowPt, localPointPt)
    }
    private var pointOnScreenPt: CGPoint? {
        addOrNil(geometry.originOnScreenPt, localPointPt)
    }

    var body: some View {
        VStack(spacing: 14) {
            Text("One point. Several descriptions.")
                .font(.system(size: 22, weight: .black))
                .foregroundStyle(Color(hex: 0x4338CA))
            Text(
                "Touch or drag inside the rectangle. The crosshair marks one point. Every " +
                "readout below describes that same point from a named origin or with a named unit."
            )
            .font(LabType.bodyLarge)

            ZStack(alignment: .topLeading) {
                Canvas { context, size in
                    drawInspectorGrid(
                        context: context,
                        size: size,
                        localPointPt: localPointPt,
                        localCenterPt: localCenterPt,
                        pointerPressed: pointerPressed
                    )
                }

                Text("origin (0, 0)")
                    .font(LabType.label)
                    .fontWeight(.black)
                    .foregroundStyle(Color(hex: 0x1E3A8A))
                    .padding(10)

                Text("right = \(formatCoordinate(widthPt)) pt")
                    .font(LabType.label)
                    .fontWeight(.black)
                    .foregroundStyle(Color(hex: 0x92400E))
                    .frame(maxWidth: .infinity, maxHeight: .infinity, alignment: .topTrailing)
                    .padding(10)

                Text("bottom = \(formatCoordinate(heightPt)) pt")
                    .font(LabType.label)
                    .fontWeight(.black)
                    .foregroundStyle(Color(hex: 0x92400E))
                    .frame(maxWidth: .infinity, maxHeight: .infinity, alignment: .bottomLeading)
                    .padding(10)
            }
            .frame(maxWidth: .infinity)
            .frame(height: 340)
            .background(Color.white)
            .clipShape(RoundedRectangle(cornerRadius: 22, style: .continuous))
            .overlay(
                RoundedRectangle(cornerRadius: 22, style: .continuous)
                    .strokeBorder(Color(hex: 0xCBD5E1), lineWidth: 1)
            )
            .contentShape(RoundedRectangle(cornerRadius: 22, style: .continuous))
            .background {
                GeometryReader { proxy in
                    Color.clear
                        .preference(
                            key: InspectorSizeKey.self,
                            value: proxy.size
                        )
                        .preference(
                            key: InspectorParentOriginKey.self,
                            value: proxy.frame(in: .named("inspectorParent")).origin
                        )
                        .background {
                            WindowScreenProbe { inWindow, onScreen in
                                geometry.originInWindowPt = inWindow
                                geometry.originOnScreenPt = onScreen
                            }
                        }
                }
            }
            .onPreferenceChange(InspectorSizeKey.self) { geometry.sizePt = $0 }
            .onPreferenceChange(InspectorParentOriginKey.self) { geometry.originInParentPt = $0 }
            .highPriorityGesture(
                DragGesture(minimumDistance: 0)
                    .onChanged { value in
                        updateNormalized(from: value.location)
                        pointerPressed = true
                    }
                    .onEnded { _ in
                        pointerPressed = false
                    }
            )
            .accessibilityLabel(
                "Coordinate inspector. Local point \(formatOffset(localPointPt)) points. " +
                "Normalized point \(formatNormalizedPair(normalizedX, normalizedY))."
            )

            Text(
                pointerPressed
                    ? "Pointer state: pressed. The inspector is receiving movement events."
                    : "Pointer state: released. Touch inside the rectangle to update the point."
            )
            .font(.system(size: 14, weight: .semibold))
            .foregroundStyle(pointerPressed ? Color(hex: 0xBE185D) : Color(hex: 0x5C687A))

            HStack(spacing: 8) {
                ForEach(Array(InspectorPointPreset.allCases.prefix(2)), id: \.self) { preset in
                    InspectorPresetButton(
                        preset: preset,
                        selected: normalizedX == preset.normalizedX &&
                            normalizedY == preset.normalizedY
                    ) {
                        normalizedX = preset.normalizedX
                        normalizedY = preset.normalizedY
                    }
                }
            }
            HStack(spacing: 8) {
                ForEach(Array(InspectorPointPreset.allCases.dropFirst(2)), id: \.self) { preset in
                    InspectorPresetButton(
                        preset: preset,
                        selected: normalizedX == preset.normalizedX &&
                            normalizedY == preset.normalizedY
                    ) {
                        normalizedX = preset.normalizedX
                        normalizedY = preset.normalizedY
                    }
                }
            }

            InspectorReadouts(
                geometry: geometry,
                displayScale: displayScale,
                localPointPt: localPointPt,
                localPointPx: localPointPx,
                localCenterPt: localCenterPt,
                normalizedX: normalizedX,
                normalizedY: normalizedY,
                pointInParentPt: pointInParentPt,
                pointInWindowPt: pointInWindowPt,
                pointOnScreenPt: pointOnScreenPt
            )

            Text(
                "The parent, window, and screen calculations below assume this lesson's " +
                "inspector is not rotated or scaled. A later transform would require a coordinate " +
                "conversion API instead of simple addition."
            )
            .font(.system(size: 12))
            .foregroundStyle(Color(hex: 0x5C687A))
        }
        .frame(maxWidth: .infinity)
        .coordinateSpace(.named("inspectorParent"))
    }

    private func updateNormalized(from location: CGPoint) {
        let clamped = CGPoint(
            x: location.x.clamped(to: 0...max(widthPt, 0)),
            y: location.y.clamped(to: 0...max(heightPt, 0))
        )
        normalizedX = normalize(clamped.x, size: widthPt)
        normalizedY = normalize(clamped.y, size: heightPt)
    }
}

private func drawInspectorGrid(
    context: GraphicsContext,
    size: CGSize,
    localPointPt: CGPoint,
    localCenterPt: CGPoint,
    pointerPressed: Bool
) {
    let gridSpacingPt: CGFloat = 32
    var gridX = gridSpacingPt
    while gridX < size.width {
        var vertical = Path()
        vertical.move(to: CGPoint(x: gridX, y: 0))
        vertical.addLine(to: CGPoint(x: gridX, y: size.height))
        context.stroke(vertical, with: .color(Color(hex: 0xDCE6F5)), lineWidth: 1)
        gridX += gridSpacingPt
    }

    var gridY = gridSpacingPt
    while gridY < size.height {
        var horizontal = Path()
        horizontal.move(to: CGPoint(x: 0, y: gridY))
        horizontal.addLine(to: CGPoint(x: size.width, y: gridY))
        context.stroke(horizontal, with: .color(Color(hex: 0xDCE6F5)), lineWidth: 1)
        gridY += gridSpacingPt
    }

    var centerVertical = Path()
    centerVertical.move(to: CGPoint(x: localCenterPt.x, y: 0))
    centerVertical.addLine(to: CGPoint(x: localCenterPt.x, y: size.height))
    context.stroke(
        centerVertical,
        with: .color(Color(hex: 0x4338CA)),
        style: StrokeStyle(lineWidth: 2, dash: [10, 7])
    )

    var centerHorizontal = Path()
    centerHorizontal.move(to: CGPoint(x: 0, y: localCenterPt.y))
    centerHorizontal.addLine(to: CGPoint(x: size.width, y: localCenterPt.y))
    context.stroke(
        centerHorizontal,
        with: .color(Color(hex: 0x4338CA)),
        style: StrokeStyle(lineWidth: 2, dash: [10, 7])
    )

    var fromLeft = Path()
    fromLeft.move(to: CGPoint(x: 0, y: localPointPt.y))
    fromLeft.addLine(to: localPointPt)
    context.stroke(fromLeft, with: .color(Color(hex: 0xBE185D)), lineWidth: 2)

    var fromTop = Path()
    fromTop.move(to: CGPoint(x: localPointPt.x, y: 0))
    fromTop.addLine(to: localPointPt)
    context.stroke(fromTop, with: .color(Color(hex: 0x1E40AF)), lineWidth: 2)

    let inset: CGFloat = 1.5
    let bounds = CGRect(
        x: inset,
        y: inset,
        width: max(size.width - 3, 0),
        height: max(size.height - 3, 0)
    )
    context.stroke(
        Path(roundedRect: bounds, cornerRadius: 0),
        with: .color(Color(hex: 0xD97706)),
        lineWidth: 3
    )

    let markerColor = pointerPressed ? Color(hex: 0xBE185D) : Color(hex: 0x059669)
    context.fill(
        Path(ellipseIn: CGRect(
            x: localPointPt.x - 12,
            y: localPointPt.y - 12,
            width: 24,
            height: 24
        )),
        with: .color(markerColor)
    )
    context.fill(
        Path(ellipseIn: CGRect(
            x: localPointPt.x - 5,
            y: localPointPt.y - 5,
            width: 10,
            height: 10
        )),
        with: .color(.white)
    )
    context.fill(
        Path(ellipseIn: CGRect(
            x: localCenterPt.x - 5,
            y: localCenterPt.y - 5,
            width: 10,
            height: 10
        )),
        with: .color(Color(hex: 0x4338CA))
    )
}

private struct WindowScreenProbe: UIViewRepresentable {
    var onChange: (CGPoint?, CGPoint?) -> Void

    func makeCoordinator() -> Coordinator {
        Coordinator(onChange: onChange)
    }

    func makeUIView(context: Context) -> ProbeView {
        let view = ProbeView()
        view.isUserInteractionEnabled = false
        view.backgroundColor = .clear
        view.onLayout = { [weak view] in
            guard let view else { return }
            context.coordinator.report(from: view)
        }
        return view
    }

    func updateUIView(_ uiView: ProbeView, context: Context) {
        context.coordinator.onChange = onChange
        uiView.onLayout = { [weak uiView] in
            guard let uiView else { return }
            context.coordinator.report(from: uiView)
        }
        DispatchQueue.main.async {
            context.coordinator.report(from: uiView)
        }
    }

    final class Coordinator {
        var onChange: (CGPoint?, CGPoint?) -> Void
        private var lastWindow: CGPoint?
        private var lastScreen: CGPoint?

        init(onChange: @escaping (CGPoint?, CGPoint?) -> Void) {
            self.onChange = onChange
        }

        func report(from view: UIView) {
            let inWindow: CGPoint?
            let onScreen: CGPoint?
            if let window = view.window {
                inWindow = view.convert(.zero, to: nil)
                if let screen = window.windowScene?.screen {
                    onScreen = view.convert(.zero, to: screen.coordinateSpace)
                } else {
                    onScreen = nil
                }
            } else {
                inWindow = nil
                onScreen = nil
            }

            guard inWindow != lastWindow || onScreen != lastScreen else { return }
            lastWindow = inWindow
            lastScreen = onScreen
            onChange(inWindow, onScreen)
        }
    }

    final class ProbeView: UIView {
        var onLayout: (() -> Void)?

        override func layoutSubviews() {
            super.layoutSubviews()
            onLayout?()
        }

        override func didMoveToWindow() {
            super.didMoveToWindow()
            onLayout?()
        }
    }
}

private func normalize(_ value: CGFloat, size: CGFloat) -> CGFloat {
    guard size > 0 else { return 0 }
    return (value / size).clamped(to: 0...1)
}

private func multiplyByScale(_ valuePt: CGFloat, _ scale: CGFloat) -> CGFloat {
    guard scale > 0 else { return 0 }
    return valuePt * scale
}

private func addPoints(_ first: CGPoint, _ second: CGPoint) -> CGPoint {
    CGPoint(x: first.x + second.x, y: first.y + second.y)
}

private func addOrNil(_ first: CGPoint?, _ second: CGPoint) -> CGPoint? {
    guard let first else { return nil }
    return addPoints(first, second)
}

private func formatOffset(_ offset: CGPoint) -> String {
    "(\(formatCoordinate(offset.x)), \(formatCoordinate(offset.y)))"
}

private func formatOptionalOffset(_ offset: CGPoint?) -> String {
    guard let offset else { return "not available" }
    return "\(formatOffset(offset)) pt"
}

private func formatNormalizedPair(_ x: CGFloat, _ y: CGFloat) -> String {
    "(\(formatNormalized(x)), \(formatNormalized(y)))"
}

private func formatCoordinate(_ value: CGFloat) -> String {
    String(format: "%.1f", Double(value))
}

private func formatNormalized(_ value: CGFloat) -> String {
    String(format: "%.3f", Double(value))
}

private func formatScale(_ value: CGFloat) -> String {
    String(format: "%.3f px/pt", Double(value))
}

private extension Comparable {
    func clamped(to range: ClosedRange<Self>) -> Self {
        min(max(self, range.lowerBound), range.upperBound)
    }
}

private extension Color {
    init(hex: UInt32) {
        self.init(
            red: Double((hex >> 16) & 0xFF) / 255,
            green: Double((hex >> 8) & 0xFF) / 255,
            blue: Double(hex & 0xFF) / 255
        )
    }
}

10 · Exercises
Answer before opening the solutions
Exercise 4 targets the most likely unit-mixing mistake.
Exercise 1 · Bounds, center, and normalized point
An inspector measures 640 × 360 pt. The pointer-local point is (160, 270) pt. State the local bounds, local center, and normalized point.
Answer: bounds are left 0, top 0, right 640, bottom 360 pt. Center is (320, 180) pt. Normalized point is (160 ÷ 640, 270 ÷ 360) = (0.25, 0.75).
Exercise 2 · Convert local points to pixels
The pointer-local point is (180, 270) pt. Scale is 3 px per pt. What is the local px pair?
Answer: (180 × 3, 270 × 3) = (540, 810) px.
Exercise 3 · Move through the larger coordinate systems
Inspector origin in parent is (120, 80) pt. Parent origin in window is (180, 100) pt. Window origin on screen is (40, 60) pt. Pointer local is (160, 270) pt. Find pointer in parent, window, and screen.
Answer: parent is (120, 80) + (160, 270) = (280, 350) pt. Window is (180, 100) + (280, 350) = (460, 450) pt. Screen is (40, 60) + (460, 450) = (500, 510) pt.
Exercise 4 · Diagnostic: which pair may be added?
An inspector origin on screen is (40, 60) pt. The point is local (160, 270) pt and normalized (0.25, 0.75). Which pair must be added to the screen origin, and why?
Answer: add the local point pair: (40, 60) + (160, 270) = (200, 330) pt. Both operands are point offsets. The normalized pair is unitless and cannot be added directly to a point origin.



11 · Evidence and deferrals
What this checkpoint proves
Keep the design conclusion separate from framework details that were not measured.
The running app can prove
It can prove the inspector’s measured point size, runtime scale, pointer-local positions, normalized results, and the positions returned by the SwiftUI and UIKit coordinate APIs on your current device and window configuration.
This lesson does not prove
It does not prove how iOS converts physical touch-sensor data into app-window coordinates, how the system compositor places every surface, or how transformed descendants should be mapped. Those questions require framework source, tracing, or later transform APIs.
Design conclusion: later blur, refraction, and shader sampling code must name its coordinate system and unit. The inspector gives us a reusable way to verify that mapping before blaming a shader formula.
Official references used for the iOS behavior: DragGesture, GeometryReader, displayScale, and UIView.convert(_:to:).
