Chapter 2 · Rectangle measurements

Width, height, edges, and center

A rectangle has four boundary lines. Those lines are its edges. Its width is the horizontal distance between the left and right edges. Its height is the vertical distance between the top and bottom edges. The center is halfway between each opposing pair of edges.

One graphics idea: bounds describe the rectangular area occupied by an object. One math idea: halfway means divide a distance by 2.

By the end

  • Name all four edges.
  • Calculate width and height from edge positions.
  • Calculate centerX and centerY.
  • Explain why a right edge at 8 does not create a cell with index 8.
  • Run the matching explorer on the Pixel 8 Pro.

1 · Name the rectangle

Five terms describe the object

Each term refers to a specific part or measurement.

Bounds

The bounds are the rectangular area enclosed by the four edges.

Edge

An edge is one boundary line: left, top, right, or bottom.

Width

Width is the horizontal distance from the left edge to the right edge.

Height

Height is the vertical distance from the top edge to the bottom edge.

Center

The center is halfway across the width and halfway down the height.

width = right − left · height = bottom − top

In the first model, the left and top edges are both at 0. That makes width = right and height = bottom. Later lessons will move the rectangle away from the origin.

3 · Diagnostic distinction

An edge coordinate is not a cell index

This is the most likely mistake in this lesson.

Width = 8 units

The boundary coordinates are 0 through 8. The eight cell indexes are 0 through 7.

right edge = 8 · last cell index = 8 − 1 = 7

Why?

A cell occupies the interval between two boundaries. Cell 0 lies between edge 0 and edge 1. Cell 7 lies between edge 7 and edge 8. The edge at 8 closes the last cell. It is not another cell.

@Composable
internal fun BoundsCenterExplorer(
    modifier: Modifier = Modifier,
) {
    var widthUnits by rememberSaveable {
        mutableIntStateOf(8)
    }
    var heightUnits by rememberSaveable {
        mutableIntStateOf(6)
    }

    val centerX = widthUnits / 2f
    val centerY = heightUnits / 2f
    val drawingWidth = (widthUnits * DrawingUnitDp).dp
    val drawingHeight = (heightUnits * DrawingUnitDp).dp

    Column(
        modifier = modifier.fillMaxWidth(),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.spacedBy(14.dp),
    ) {
        Text(
            text = "Width = $widthUnits units · Height = $heightUnits units",
            style = MaterialTheme.typography.titleLarge,
            fontWeight = FontWeight.Black,
        )
        Text(
            text = "Bounds: left = 0 · top = 0 · right = $widthUnits · bottom = $heightUnits",
            style = MaterialTheme.typography.bodyLarge,
        )
        Text(
            text = "Center = (${formatHalfUnit(centerX)}, ${formatHalfUnit(centerY)})",
            color = Color(0xFF059669),
            style = MaterialTheme.typography.titleMedium,
            fontWeight = FontWeight.Black,
        )

        Box(
            modifier = Modifier
                .width(drawingWidth + 92.dp)
                .height(drawingHeight + 72.dp),
            contentAlignment = Alignment.Center,
        ) {
            Canvas(
                modifier = Modifier
                    .size(
                        width = drawingWidth,
                        height = drawingHeight,
                    )
                    .semantics {
                        contentDescription =
                            "Rectangle $widthUnits units wide and $heightUnits units high, " +
                            "with center at ${formatHalfUnit(centerX)}, ${formatHalfUnit(centerY)}"
                    },
            ) {
                drawRect(
                    color = Color(0xFFEFF6FF),
                )

                val cellWidth = size.width / widthUnits
                val cellHeight = size.height / heightUnits

                for (column in 1 until widthUnits) {
                    val x = column * cellWidth
                    drawLine(
                        color = Color(0xFFCBD5E1),
                        start = Offset(x, 0f),
                        end = Offset(x, size.height),
                        strokeWidth = 1.dp.toPx(),
                    )
                }

                for (row in 1 until heightUnits) {
                    val y = row * cellHeight
                    drawLine(
                        color = Color(0xFFCBD5E1),
                        start = Offset(0f, y),
                        end = Offset(size.width, y),
                        strokeWidth = 1.dp.toPx(),
                    )
                }

                drawRect(
                    color = Color(0xFF1E40AF),
                    style = Stroke(width = 3.dp.toPx()),
                )

                val center = Offset(
                    x = size.width / 2f,
                    y = size.height / 2f,
                )
                val dash = PathEffect.dashPathEffect(
                    intervals = floatArrayOf(10.dp.toPx(), 7.dp.toPx()),
                )

                drawLine(
                    color = Color(0xFFBE185D),
                    start = Offset(center.x, 0f),
                    end = Offset(center.x, size.height),
                    strokeWidth = 2.dp.toPx(),
                    pathEffect = dash,
                )
                drawLine(
                    color = Color(0xFFBE185D),
                    start = Offset(0f, center.y),
                    end = Offset(size.width, center.y),
                    strokeWidth = 2.dp.toPx(),
                    pathEffect = dash,
                )
                drawCircle(
                    color = Color(0xFF059669),
                    radius = 8.dp.toPx(),
                    center = center,
                )
                drawCircle(
                    color = Color(0xFF064E3B),
                    radius = 8.dp.toPx(),
                    center = center,
                    style = Stroke(width = 2.dp.toPx()),
                )
            }

            Text(
                text = "top = 0",
                modifier = Modifier.align(Alignment.TopCenter),
                color = Color(0xFF1E40AF),
                style = MaterialTheme.typography.labelLarge,
                fontWeight = FontWeight.Bold,
            )
            Text(
                text = "bottom = $heightUnits",
                modifier = Modifier.align(Alignment.BottomCenter),
                color = Color(0xFF1E40AF),
                style = MaterialTheme.typography.labelLarge,
                fontWeight = FontWeight.Bold,
            )
            Text(
                text = "left\n0",
                modifier = Modifier.align(Alignment.CenterStart),
                color = Color(0xFF1E40AF),
                style = MaterialTheme.typography.labelLarge,
                fontWeight = FontWeight.Bold,
            )
            Text(
                text = "right\n$widthUnits",
                modifier = Modifier.align(Alignment.CenterEnd),
                color = Color(0xFF1E40AF),
                style = MaterialTheme.typography.labelLarge,
                fontWeight = FontWeight.Bold,
            )
        }

        Text(
            text = "centerX = $widthUnits ÷ 2 = ${formatHalfUnit(centerX)} · " +
                "centerY = $heightUnits ÷ 2 = ${formatHalfUnit(centerY)}",
            style = MaterialTheme.typography.bodyLarge,
            fontWeight = FontWeight.Bold,
        )

        DimensionSlider(
            label = "Width",
            value = widthUnits,
            valueRange = FirstWidth..LastWidth,
            onValueChange = { widthUnits = it },
        )
        DimensionSlider(
            label = "Height",
            value = heightUnits,
            valueRange = FirstHeight..LastHeight,
            onValueChange = { heightUnits = it },
        )

        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.spacedBy(8.dp),

            RectanglePresets.forEach { preset ->
                val selected = widthUnits == preset.width &&
                    heightUnits == preset.height

                if (selected) {
                    Button(
                        onClick = {
                            widthUnits = preset.width
                            heightUnits = preset.height
                        },
                        modifier = Modifier.weight(1f),

                        Text(preset.label)
                    }
                } else {
                    OutlinedButton(
                        onClick = {
                            widthUnits = preset.width
                            heightUnits = preset.height
                        },
                        modifier = Modifier.weight(1f),
                    ) {
                        Text(preset.label)
                    }
                }
            }
        }

        Text(
            text = "A width of 8 has a right edge at X = 8, but its eight cell indexes are 0 through 7.",
            style = MaterialTheme.typography.bodyMedium,
        )
    }
}

@Composable
private fun DimensionSlider(
    label: String,
    value: Int,
    valueRange: IntRange,
    onValueChange: (Int) -> Unit,
) {
    Column(
        modifier = Modifier.fillMaxWidth(),
        verticalArrangement = Arrangement.spacedBy(2.dp),
    ) {
        Text(
            text = "$label: $value units",
            style = MaterialTheme.typography.labelLarge,
            fontWeight = FontWeight.Bold,
        )
        Slider(
            value = value.toFloat(),
            onValueChange = { newValue ->
                onValueChange(newValue.roundToInt())
            },
            valueRange = valueRange.first.toFloat()..valueRange.last.toFloat(),
            steps = valueRange.count() - 2,
        )
    }
}

private fun formatHalfUnit(value: Float): String {
    val wholeNumber = value.toInt()
    return if (value == wholeNumber.toFloat()) {
        wholeNumber.toString()
    } else {
        "$wholeNumber.5"
    }
}

9 · Exercises
Answer before opening the hidden solutions
At least one question targets the edge-versus-index misconception.

    
Exercise 1 · A rectangle starts at left 0 and top 0. Its width is 10 and height is 6. What is its center?
Answer: (5, 3). Calculate 10 ÷ 2 = 5 and 6 ÷ 2 = 3.

    
Exercise 2 · A rectangle has left 3, right 11, top 4, and bottom 10. What are its width and height?
Answer: width is 11 − 3 = 8. Height is 10 − 4 = 6. The rectangle does not start at the origin, so right and bottom are not equal to width and height.

    
Exercise 3 · Diagnostic: an 8-cell row has a right edge at X = 8. Does it contain a cell with index 8?
Answer: no. Its cell indexes are 0..7. Edge 8 is the boundary after cell 7.

    
Exercise 4 · Why can the center contain .5 even when width and height are whole numbers?
Answer: an odd whole number divided by 2 produces a half. For width 7, 7 ÷ 2 = 3.5. A center is a position, not necessarily a cell index.
