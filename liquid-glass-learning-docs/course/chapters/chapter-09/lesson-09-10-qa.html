Question 1 · walkthrough step 3

“Length 1 means one whole image width here.”

After dir = p / d, the pair dir has UV length 1. In this square, x = 0 is the left edge and x = 1 is the right edge, so a UV length of 1 equals the picture’s width.

That is only the unit. We do not draw a full-width arrow on the checker. The next step multiplies by dispLen (default 0.10), which is one tenth of that width.

dir has UV length 1 picture width, in UV = 1 ← left edge to right edge dispLen = 0.10 ← the walk we actually use 0.10 = one tenth of the picture width

Question 4 · section 4 opening

“Here every pixel, outside a tiny skip at C, takes an extra walk of length dispLen along its own ray from C.”

The skip is the Metal line if (d > 0.0001). If a pixel is closer to C than 0.0001 UV, the shader does not divide. disp stays (0, 0). That pixel reads itself and keeps its own color.

Why: at C, d is 0. Dividing p / d would be division by zero. Those positions are not deleted. On a 400-pixel picture the radius is 0.04 pixels. You cannot see a hole.

if (d > 0.0001) { disp = (p / d) * dispLen; } // else disp stays (0, 0) // readUv = uv − disp = uv

Changed in the lesson. Section 4 opening plus the magnified skip diagram.

Question 7 · imagination step 3

“nearest input = (0.50, 0.25)” — why is x = 0.50? The green point looks like 0.25 + 0.10 = 0.35 from the origin.

C is at (0.50, 0.50). The closest point on the horizontal line y = 0.25 is directly above C, so it keeps C’s x. That input point is Q = (0.50, 0.25).

The green mark is the landing, not Q. Distance from C to Q is 0.25. Add the extra walk 0.10 and the landing is 0.35 away from C. That 0.35 is a distance, not a y coordinate. The landing’s y is 0.50 − 0.35 = 0.15. x stays 0.50 because the spoke is vertical.

C = (0.50, 0.50) Q = (0.50, 0.25) ← on the line, same x as C landing = (0.50, 0.15) ← extra walk straight up distance C → Q = 0.25 extra walk Q → land = 0.10 distance C → landing = 0.35 ← not a coordinate landing y = 0.50 − 0.35 = 0.15

Changed in the lesson. Step 3 labels white Q on the line and lime landing above it, and writes distance versus coordinate.

Question 9 · x/y split

“Off to the right. Part of the stick is sideways, so the up/down leg is shorter than dispLen.” — isn’t that always the case?

Yes. In any right triangle the two short sides are shorter than the long side, except when one short side is 0 (then the other equals the long side).

The new fact is which short side shrinks. The long side stays dispLen. Directly above C, sideways = 0 and up/down = dispLen. Off to the right, sideways is some positive amount, so up/down is less than dispLen. Further from x = 0.50, more of the stick is spent sideways, so the landing cannot rise as far.

Changed in the lesson. The live callout under the x/y split now says that, with the two current lengths.

Question 10 · Test 1

“The two ends of the picture have the same |x − 0.50|, so the same d, so the same landing y. Cyan through those ends is therefore level. The peak leaves that height. That only rules out one straight line.”

Left end x = 0 and right end x = 1 are both 0.50 away from C’s x. Same distance from C means the same upward part, so both landings have the same y. A line through two points at the same height is horizontal. That is all “cyan is level” means.

“The peak leaves that height” means the peak’s landing y is a smaller number (higher on the screen), so it is not on that horizontal.

That kills only the unique straight line through the two ends. A tent — two straight halves that meet at the peak — also misses cyan, so Test 1 cannot tell a tent from a curve.

Changed in the lesson. Two drawn tests: horizontal cyan with the peak off it, then a tent that still fits.

Question 12 · slope

“There is no ridge: as x slides, d changes a little every time, so the upward part changes a little every time, so the slope turns continuously.”

Move x a little to the right. Then d grows a little. Then the upward part shrinks a little. Then the landing is a little less high. The amount of height change per step of x is the slope.

On a tent that amount is one fixed number on the whole right half. Here it is not one number, because d is different at every x. The left of C is the same story with x decreasing. No sharp corner at the peak.

Changed in the lesson. Three short blue ticks on the pink curve versus one violet tent slope, plus that paragraph split into short sentences.

Question 13 · recap

“The formula is not linear on either side of C, and the landing only rises toward C then falls away… so it is a curve.”

Both a tent and this curve go up toward C and down away from C. That shared shape is not the proof.

A tent’s right half is y = a + b × x, with one pair (a, b) for the whole half. The actual formula is landing y = 0.25 − (0.25 / d) × dispLen, and d = sqrt((x − 0.50)² + 0.25²) is not of the form a + b × x. So already on the right of C the landings are not a straight line. The meeting at the peak is rounded, not a ridge.

Changed in the lesson. The recap is now two blocks: what this does not prove, then what it does.

Question 14 · removed section

“The extra upward part fades.” — is that the stick that is 0.10 in the center?

No. The extra walk is still length dispLen (the 0.10 stick). Far from C, most of that stick is spent sideways, so the upward piece (0.25 / d) × dispLen gets small. That upward piece is what “fades,” not the stick itself.

Changed in the lesson. That flattening section was removed. The meaning is here only.

Question 15 · removed section

“Their output y values no longer match, so even the corner-to-corner join tilts.”

Point 1 sits directly above C. Its whole stick goes up, so it rises a full dispLen. Point 3 is the top-right corner. Its stick splits, so it rises less. A straight line between those two new points is no longer horizontal: it slants. That slanted join is still not the real edge.

Changed in the lesson. Removed with the three-points block.

Question 18 · practice details

“If instead disp = p × dispLen, then readUv = C + p × (1 − dispLen). At 0.10, read distances are 90% of output distances. This is uniform scaling, so straight sides remain straight.”

Three different formulas, three different pictures, same dispLen = 0.10.

Real: disp = (p / length(p)) × dispLen → stick length is always dispLen disp = p → readUv = C disp = p × dispLen → readUv = C + p × (1 − dispLen) → at 0.10, a uniform 90% scale around C

Question 19 · replacement for the removed end of section 4

Replace the navy-into-orange / flattening / three-points block with a section that helps imagine moving in different quadrants.

The stick length is always dispLen. Quadrant does not change the length. Quadrant only changes the signs of the two legs, and how the stick is split between them.

p.x = x − 0.50 positive → extra walk has a rightward piece negative → extra walk has a leftward piece zero → extra walk is purely vertical (stays straight) p.y = y − 0.50 positive → extra walk has a downward piece negative → extra walk has an upward piece zero → extra walk is purely horizontal (stays straight)

Changed in the lesson. Section 4 now ends on a clickable four-quadrant explorer. Practice exercise 4 is a top-left quadrant question.
