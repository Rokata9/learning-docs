Lesson 9.10 · visual Q&A

See the walk. Inspect the point.

The checkerboard from Lesson 9.9 is the input image. The shader reads a color from that image and copies it into the output image.

W is a fixed output position. R is the input position it reads. C is the picture center. In UV coordinates, x is a fraction of the image width and y is a fraction of its height. x increases rightward; y increases downward.

Click any plotted point to open its coordinates. Use Tab then Enter or Space with a keyboard. Escape, the × button, or an outside click closes the tooltip.

The fixed worked examples use dispLen = 0.10, a chosen read distance in UV units. Question 8 lets you change it.

For the curve questions, Q names an input point. Its landing is an output position that copies Q. We draw the outward construction after the inward read is understood.

Two final exercises

1. Can the point on the violet join use the original input x?

Use the actual output landing’s x. The input x changes during the outward walk. At input x = 0.65, the output x is about 0.70145. Compare Q′ and T at that same output x.

2. At exactly d = 0.0001, does this shader divide?

No. Select “Exactly at cutoff.” The condition uses >, so equality skips the division. The read stays at the output position.
