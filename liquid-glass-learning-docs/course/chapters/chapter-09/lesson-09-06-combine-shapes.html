Chapter 9 · One pixel, two signed distances, one pick

Combine shapes

Question: Lesson 9.2 gives one circle a signed distance: minus inside, zero on the boundary, plus outside. Production then stores orange when that one number is less than 0. How do you paint a blob made from two circles — the combined shape, only the overlap, or one circle with the other cut out — still using one sd and the same hard if?

Compute both signed distances at this pixel. min keeps the smaller number (more inside) and paints the combined blob. max keeps the larger number (more outside) and paints only the overlap. Negate one field, then max, to cut that circle out of the other.

Canonical wording: min, max, union, intersection, subtraction, signed distance.

Complete. Two Lesson 9.2 circles. radiusA = radiusB = 0.25. Circle B’s center is B = (0.20, 0). Teaching left-only pixel T has p = (−0.10, 0). Then sdA = length(p) − radiusA = 0.10 − 0.25 = −0.15 and sdB = length(pB) − radiusB = 0.30 − 0.25 = +0.05. Lesson 9.7 is the unresolved checkpoint.
1 · THE NEW QUESTION

Each leftover field already answers one circle. The new pick answers both.

Circle A leftover

Center at C, the origin of p. radiusA = 0.25, the Lesson 9.2 default. sdA = length(p) − radiusA. At T, length(p) = 0.10, so sdA = length(p) − radiusA = 0.10 − 0.25 = −0.15.

Circle B leftover

radiusB = 0.25. Center B = (0.20, 0). To measure this pixel from B, subtract B’s center: pB = p − B. That is Lesson 8.8’s subtract, now from a second origin. At T, pB = p − B = (−0.10, 0) − (0.20, 0) = (−0.30, 0), length(pB) = 0.30, sdB = length(pB) − radiusB = 0.30 − 0.25 = +0.05.

New pick

min(sdA, sdB) returns the smaller leftover. max(sdA, sdB) returns the larger leftover. For signed distance, smaller means more inside. One pick at this pixel becomes the combined sd that the hard if already knows.

2 · MIN, MAX, AND A SIGN FLIP

Smaller is more inside. Larger is more outside.

On a number line, minus sits to the left of plus. min(sdA, sdB) = min(−0.15, +0.05) = −0.15 because −0.15 is the smaller number. max(sdA, sdB) = max(−0.15, +0.05) = +0.05 because +0.05 is the larger number. Production still stores orange when the picked sd is less than 0.

Union · combined blob

A pixel is inside the union if it is inside at least one circle. That is true when the smaller signed distance is negative. sd = min(sdA, sdB). At T, sd = min(sdA, sdB) = min(−0.15, +0.05) = −0.15, so union stores orange.

Intersection · only the overlap

A pixel is inside the intersection only if it is inside both circles. That is true when the larger signed distance is still negative. sd = max(sdA, sdB). At T, sd = max(sdA, sdB) = max(−0.15, +0.05) = +0.05, so intersection stores navy.

B minus A · cut A out of B

Negating sdA flips A: inside A becomes plus, outside A becomes minus. Then sd = max(sdB, −sdA) keeps pixels that are inside B and outside A. At T, −sdA = −(−0.15) = +0.15, so sd = max(sdB, −sdA) = max(+0.05, +0.15) = +0.15, navy. T was never in B.

union sd = min(sdA, sdB) = min(−0.15, +0.05) = −0.15 orange intersection sd = max(sdA, sdB) = max(−0.15, +0.05) = +0.05 navy B minus A −sdA = −(−0.15) = +0.15 sd = max(sdB, −sdA) = max(+0.05, +0.15) = +0.15 navy

5 · ANDROID ROUTE
Two leftover lengths, one mode uniform, one pick

    

      
private const val Radius = 0.25f
private const val OffsetX = 0.20f
private const val TeachPx = -0.10f
private const val TeachPy = 0.00f

uniform float2 resolution;
uniform float combineMode;

half4 main(float2 fragCoord) {
    float2 uv = fragCoord / resolution;
    float2 p = uv - float2(0.5, 0.5);
    float sdA = length(p) - 0.25;
    float2 pB = p - float2(0.20, 0.0);
    float sdB = length(pB) - 0.25;
    float sd;
    if (combineMode < 0.5) {
        sd = min(sdA, sdB);
    } else if (combineMode < 1.5) {
        sd = max(sdA, sdB);
    } else {
        sd = max(sdB, -sdA);
    }
    ...
}

      

        
What each part changes

        
Radius is Lesson 9.2’s default, used twice: radiusA = radiusB = Radius = 0.25. OffsetX is how far B sits to the right of C, so B = (OffsetX, 0) = (0.20, 0).

        
pB = p − B asks “which way from B?” The visual center C stays the origin of p.

        
combineMode is 0 for union, 1 for intersection, 2 for B minus A. The three buttons write that one float. They do not rebuild the program.

        
TeachPx = −0.10 so the printed teaching pixel is only in A: p = (TeachPx, TeachPy) = (−0.10, 0), sdA = length(p) − radiusA = 0.10 − 0.25 = −0.15, sdB = length(pB) − radiusB = 0.30 − 0.25 = +0.05.

8 · EXERCISES
Answer before opening each hidden solution

    
At C, p = (0, 0), what are sdA and sdB, and which colors do union and intersection store?
length(p) = 0. sdA = length(p) − radiusA = 0 − 0.25 = −0.25. pB = p − B = (0, 0) − (0.20, 0) = (−0.20, 0). length(pB) = 0.20. sdB = length(pB) − radiusB = 0.20 − 0.25 = −0.05. Both minus, so C sits in the overlap. Union sd = min(sdA, sdB) = min(−0.25, −0.05) = −0.25, orange. Intersection sd = max(sdA, sdB) = max(−0.25, −0.05) = −0.05, orange.

    
Diagnostic: someone writes sd = sdA + sdB for the union. At T that sum is still minus. Which nearby pixel goes the wrong color?
At T, sdA + sdB = −0.15 + 0.05 = −0.10, still orange by luck. Take a pixel inside A and far outside B, say sdA = −0.04 and sdB = +0.20. Union should use sd = min(sdA, sdB) = min(−0.04, +0.20) = −0.04, orange. The sum is −0.04 + 0.20 = +0.16, navy. Addition lets a far-outside second field cancel an inside first field. min(sdA, sdB) does not.

    
The overlap pixel p = (0.10, 0) is inside both. What is B minus A, and which color?
length(p) = 0.10. sdA = length(p) − radiusA = 0.10 − 0.25 = −0.15. pB = p − B = (0.10, 0) − (0.20, 0) = (−0.10, 0). length(pB) = 0.10. sdB = length(pB) − radiusB = 0.10 − 0.25 = −0.15. −sdA = −(−0.15) = +0.15. B minus A sd = max(sdB, −sdA) = max(−0.15, +0.15) = +0.15. Plus means outside the cut shape, so navy. The overlap is exactly what B minus A removes.

    
The right-only pixel p = (0.30, 0) is inside B and outside A. What is B minus A?
length(p) = 0.30. sdA = length(p) − radiusA = 0.30 − 0.25 = +0.05. pB = p − B = (0.30, 0) − (0.20, 0) = (0.10, 0). length(pB) = 0.10. sdB = length(pB) − radiusB = 0.10 − 0.25 = −0.15. −sdA = −(+0.05) = −0.05. B minus A sd = max(sdB, −sdA) = max(−0.15, −0.05) = −0.05. Minus, orange. That is the part of B that survives the cut.
