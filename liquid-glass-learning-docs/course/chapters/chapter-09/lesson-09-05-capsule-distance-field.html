Chapter 9 · Grow a line segment by the end radius

Capsule distance field

Question: Lesson 4.3 named a capsule: a rounded rectangle whose short ends are semicircles. Height owns the radius: radius = height ÷ 2. Width owns the straight span between those ends. Lesson 9.4 grew an inner box. When that inner height hits 0, the inner box is a horizontal line segment. How do you measure signed distance to that capsule from p?

Find the nearest point on the inner segment, take length to it, then subtract the radius. clamp picks the nearest segment x: if p.x sits between the endpoints it stays; if it sits past an end it becomes that end. Production then uses if (sd < 0.0) on this sd.

1 · THE NEW QUESTION

A box grow still has vertical leftovers. A capsule does not.

4.3 leftover

A horizontal capsule has width at least as large as height. Radius equals height ÷ 2, so the left and right vertical flats have length zero. Each end is one semicircle. Width only moves the two end centers apart.

9.4 leftover

Growing an inner box by r keeps vertical flats when inner height is greater than 0. At r = half-height, inner height is 0 and that inner box is a horizontal segment. This lesson starts from that segment.

New nearest point

The new number is distance to the nearest point on that segment, minus r. Teaching outer half-size is (0.40, 0.20) so the pill is clearly wider than a circle.

outerHalf = (0.40, 0.20) radius = 0.20 ← half of the height, p units innerHalfW = 0.40 − 0.20 = 0.20 inner segment: x from −0.20 to +0.20, y = 0 nearestX = clamp(p.x, −innerHalfW, innerHalfW) sd = length(p − (nearestX, 0)) − radius
Teaching cap-boundary pixel p = (0.32, −0.16) ← right end (0.20, 0) plus 0.20 × (0.6, −0.8) ← 0.6² + 0.8² = 1 nearestX = clamp(0.32, −0.20, 0.20) = 0.20 length((0.12, −0.16)) = 0.20 sd = 0.20 − 0.20 = 0
2 · GROW THE INNER SEGMENT

The middle stays a flat band. Each end is a semicircle.

The dashed indigo line is the inner segment. The two green circles are Lesson 4.3’s construction circles, now with the same center as each segment end. The orange outline is the capsule: every point whose signed distance to the segment equals the radius.

Why the radius equals the half-height

Lesson 4.3 solved height − radius − radius = 0. In p units the half-height is 0.20, so radius is 0.20. The top and bottom of the capsule then sit at y = ±0.20.

Why a segment, not a box

There is no leftover vertical inner edge. Every pixel’s nearest inner point lies on this one horizontal segment: either between the ends, or at an end.

Width owns the middle

Raising half-width lengthens the segment and the top and bottom flats. Radius stays 0.20. At half-width 0.20 the segment length is 0 and the capsule is a circle.

3 · NEAREST POINT ON THE SEGMENT

clamp picks the x. length measures the rest.

Lesson 8.11’s clamp(x, lo, hi) returns x when it already sits in the interval, lo when x is below, and hi when x is above. Here the interval is the inner segment’s x range, and the input is this pixel’s p.x. The five steps walk one pixel through that pick, then the grow.

8 · EXERCISES
Answer before opening each hidden solution

    
At the visual center, r = 0.20, what is sd, and which color does production store?
nearestX = clamp(0, −0.20, 0.20) = 0. length to (0, 0) is 0. sd = 0 − 0.20 = −0.20. Minus means inside, so the hard if stores orange.

    
Diagnostic: someone writes float sd = length(p) − radius. What silhouette do you get, and what happens to the top flat at p = (0, −0.20)?
sd = 0 is a circle of radius 0.20 around the visual center. The teaching capsule’s top flat sits at y = −0.20 only between x = −0.20 and x = 0.20. On that circle, p = (0, −0.20) happens to be on the boundary too, but p = (0.10, −0.20) has circle length 0.2236 and sd = +0.0236 (navy), while the capsule stores sd = 0 (still on the flat).

    
The top-flat pixel p = (0.00, −0.20) is not at an end. Why is sd still 0?
p.x = 0 already sits on the segment, so nearestX stays 0. Distance to (0, 0) is |−0.20| = 0.20, equal to the radius. The grow subtract lands on 0. The pixel sits on the outer top flat.

    
If half-width equals the radius 0.20, what is the inner segment, and what silhouette do you get?
innerHalfW = 0. The segment is one point: the visual center. nearestX is always 0. sd = length(p) − 0.20, which is Lesson 9.2’s circle. That is Lesson 4.3’s circle limit.
