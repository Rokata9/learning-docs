Scale around the center

Question: Lesson 9.8 subtracted the same offset at every pixel, so the whole picture slid. How do you keep the center copying itself, while a far pixel stores a color that lived closer to the center, so the middle looks larger?

1 · THE WALK

Reach a neighbor twice as close to C. Paint that color here.

Lesson 9.8 already split two jobs. This pixel stores. eval asks a possibly different pixel. The write pixel does not slide. Canvas does not scale. The input picture does not move.

The new choice is how far from C we ask. Measure the distance from C to this write pixel. Divide that distance by scale. Ask the neighbor that sits that new distance from C, on the same ray. Copy its color onto this pixel.

scale = 2

Ask a point half as far from C — twice as close to the center. W stores that nearer color. Nearer content is dragged onto farther seats. The middle looks twice as large.

scale = 1

Ask the same distance. W reads W. Identity. Nothing is dragged.

scale = 0.5

Ask twice as far from C. W stores a farther color. More of the input is squeezed in. Cells look smaller. Edge writes can ask past the square. That edge is Lesson 9.12. This lab paints those asks gray.

2 · WHY DIVIDE BY SCALE

Twice as large means the walk is half as long.

The slash is the walk. We first choose the stored picture: the inner half of the input should fill the whole square. That picture looks twice as large. The number of that choice is scale = 2.

Prove it on the right edge, as a distance from C. The right edge is half a square from C. The right edge of the inner half is a quarter-square from C. For that inner-half edge to be painted on the square’s edge, a walk of 0.50 must become a walk of 0.25.

right-edge write is 0.50 from C we want to ask the inner-half edge, 0.25 from C 0.50 / 2 = 0.25 that 2 is the enlargement we chose

The left edge is the mirror. Every store pixel then asks somewhere in the inner half. That band stretches across the whole square. That is magnification by 2. A teaching write 0.30 of the square right of C uses the same shorten: 0.30 / 2 = 0.15 from C.

4 · ANDROID ROUTE
One new uniform: scale. The divide is the walk.

    

      
private const val DefaultScale = 2.00f

uniform shader background;
uniform float2 resolution;
uniform float scale;

half4 main(float2 fragCoord) {
    float2 uv = fragCoord / resolution;
    float2 p = uv - float2(0.5, 0.5);
    float2 readUv = p / scale + 0.5;
    return background.eval(readUv * resolution);
}

      

        
What each part does

        
p is this pixel measured from C. You already convert that pair for eval. The leftover − 0.5 and + 0.5 are that convert, not the new idea.

        
p / scale is the walk. Default 2 asks a neighbor half as far from C. Right-edge proof: 0.50 / 2 = 0.25 from C.

        
Lesson 9.8 subtracted the same offset at every write. This divide is 0 at C and larger farther out, so C still copies C.

        
The checker is four cells across. Orange when column plus row is even.

7 · EXERCISES
Answer before opening each hidden solution

    

      At scale = 1, how far from C do we ask, and what color does the teaching write store?
      
The same distance as W, so W reads W. The teaching write sits in a navy input cell, so it stores navy. Nothing is dragged.

    

    

      Why divide the right-edge walk by 2, not by some other number, when the inner half should fill the square?
      
The right edge is 0.50 from C. The inner-half’s right edge is 0.25 from C. The unique number that turns 0.50 into 0.25 is 2. That 2 is the enlargement we chose: twice as large means the walk is half as long. A teaching write 0.30 from C uses the same shorten: 0.30 / 2 = 0.15 from C.

    

    

      At scale = 0.50, the teaching write is still 0.30 from C. How far from C is the ask, and why can the store be gray?
      
0.30 / 0.50 = 0.60 from C, which is past the right edge (the edge is only 0.50 from C). This HTML stand-in stores gray for an ask outside the square. Android’s out-of-range eval is Lesson 9.12. Minification is still “walk farther on the input.” W still sits 0.30 from C.
