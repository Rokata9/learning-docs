1 · THE NEW QUESTION

A circle signed distance cannot draw Lesson 4.2’s flats and quarter-circles.

4.2 leftover

A rounded rectangle keeps the same outer bounds as a sharp rectangle. The corner radius is the distance from one construction-circle center to that corner’s quarter-circle. Join points are where a straight edge ends and the arc begins.

9.2 leftover

A circle is a point grown by a radius: sd = length(p) − radius. Minus still means inside. That formula’s zero contour is always a circle. Lesson 4.2’s shape has long flat sides.

New grow

Grow an inner sharp box by the same corner radius. The zero contour becomes Lesson 4.2’s rounded rectangle. Teaching outer half-size is (0.30, 0.20) so the shape is clearly wider than it is tall.

Not those later tools

A capsule is Lesson 9.5. Combining two complete signed-distance fields with min or max is Lesson 9.6. This lesson picks the larger of two leftover numbers only inside the inner box, as a comparison, not as a shape union.

2 · GROW THE INNER BOX

Flat sides move out by r. Corners swing through a quarter-circle.

The dashed indigo rectangle is the inner box. The four green circles are Lesson 4.2’s construction circles. The orange outline is the rounded rectangle: the set of points whose signed distance to the inner box equals zero after subtracting r.

Why subtract r from the outer half

Lesson 4.2 placed each construction-circle center one corner radius in from both meeting edges. In p units that center sits at (outerHalf.x − r, outerHalf.y − r) in the right-and-bottom quarter after abs. That is the inner-box corner.

Why subtract r a second time

Signed distance to the inner box is zero on the inner box’s own boundary. Subtracting r moves that zero out by r. A point grown by r is Lesson 9.2. A box grown by r is this lesson.

The AABB corner pocket

The outer sharp box’s top-right corner is p = (0.30, −0.20). The quarter-circle does not reach it. That leftover square is outside the rounded rectangle, the same pocket Lesson 7.9 showed around a shadow card. Production stores navy there.

3 · ABS, THEN FOUR REGIONS

Solve one quarter. The other three match by symmetry.

AGSL abs(p) is the non-negative version of each member. After that, both members are zero or greater. A pixel in the left half is treated like its mirror in the right half. A pixel in the top half is treated like its mirror in the bottom half. The rounded rectangle looks the same in all four quarters.

q = abs(p) − innerHalf qx > 0 → past the inner right edge qy > 0 → past the inner bottom edge (after abs) qx ≤ 0 → still inside that inner edge qy ≤ 0 → still inside that inner edge Both positive: nearest inner point is the inner corner sdBox = length(q) ← Lesson 9.1 at that corner Only qx positive: nearest is the inner right flat sdBox = qx Only qy positive: nearest is the inner bottom flat sdBox = qy Both ≤ 0: inside the inner box sdBox = the larger leftover (the one nearer zero)

7 · ANDROID ROUTE
Three uniforms, four branches, one subtract

    

      
private const val PanelSizeDp = 360
private const val HalfWidth = 0.30f
private const val HalfHeight = 0.20f
private const val DefaultCornerRadius = 0.10f
private const val TeachPx = 0.26f
private const val TeachPy = -0.18f

uniform float2 resolution;
uniform float halfWidth;
uniform float halfHeight;
uniform float cornerRadius;

half4 main(float2 fragCoord) {
    float2 uv = fragCoord / resolution;
    float2 p = uv - float2(0.5, 0.5);
    float2 q = abs(p) - float2(
        halfWidth - cornerRadius,
        halfHeight - cornerRadius
    );
    float sdBox;
    if (q.x > 0.0) {
        if (q.y > 0.0) {
            sdBox = length(q);
        } else {
            sdBox = q.x;
        }
    } else {
        if (q.y > 0.0) {
            sdBox = q.y;
        } else {
            sdBox = q.x > q.y ? q.x : q.y;
        }
    }
    float sd = sdBox - cornerRadius;
    ...
}

10 · EXERCISES
Answer before opening each hidden solution

    
At the visual center, r = 0.10, what is sd, and which color does production store?
q = (−0.20, −0.10). Both leftovers are negative, so sdBox is the larger, −0.10. sd = −0.10 − 0.10 = −0.20. Minus means inside, so the hard if stores orange. That −0.20 is also minus the outer half-height, the nearer outer flat.

    
Diagnostic: someone writes float sd = length(p) − cornerRadius. What shape is sd = 0, and why is the AABB pocket then wrong?
sd = 0 is a circle of radius 0.10. The teaching shape’s outer flats sit at 0.30 and 0.20, so that circle is much smaller than the rounded rectangle. The AABB pocket pixel would be classified by circle distance, not by distance to the quarter-circle from the inner corner.

    
The AABB pocket pixel is inside the outer sharp box. Why does production store navy?
Inside the outer sharp box is not the test. The test is sd of the rounded rectangle. q = (0.10, 0.10), length(q) = 0.14142, sd = +0.04142. Plus means outside the quarter-circle. The leftover square between the sharp corner and the arc is outside the shape.

    
If corner radius is 0, what is the inner box, and what silhouette do you get?
innerHalf = outerHalf. The inner box is the outer sharp box. Growing by 0 leaves that sharp rectangle. Production stores orange inside that rectangle, including the four corner squares that a positive radius would leave as navy pockets.
