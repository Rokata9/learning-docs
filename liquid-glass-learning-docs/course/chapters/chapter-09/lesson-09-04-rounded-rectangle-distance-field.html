1 · THE NEW QUESTION

A circle signed distance cannot keep long flats.

4.2 leftover

A rounded rectangle keeps the same outer bounds as a sharp rectangle. The corner radius is the distance from one construction-circle center to that corner’s quarter-circle. Join points are where a straight edge ends and the arc begins.

9.2 leftover

A circle is a point grown by a radius: sd = length(p) − radius. Minus still means inside. That formula’s zero contour is always a circle. Lesson 4.2’s shape has long flat sides.

New grow

Grow an inner sharp box by the same corner radius. The zero contour becomes Lesson 4.2’s rounded rectangle. Teaching outer half-size is (0.30, 0.20) so the shape is clearly wider than it is tall.

2 · GROW THE INNER BOX

Flat sides move out by r. Corners swing through a quarter-circle.

The dashed indigo rectangle is the inner box. The four green circles are Lesson 4.2’s construction circles. The orange outline is the rounded rectangle: every point whose signed distance to the inner box equals the corner radius.

Why subtract r from the outer half

Lesson 4.2 placed each construction-circle center one corner radius in from both meeting edges. In p units that center sits at (outerHalf.x − r, outerHalf.y − r) in the right-and-bottom quarter after abs. That is the inner-box corner.

Why subtract r a second time

Signed distance to the inner box is zero on the inner box’s own boundary. Subtracting r moves that zero out by r. A point grown by r is a circle. A box grown by r is this rounded rectangle.

The leftover square at the sharp corner

The outer sharp box’s top-right corner is p = (0.30, −0.20). The quarter-circle does not reach it. That leftover square is outside the rounded rectangle. Production stores navy there.

5 · ANDROID ROUTE
Three uniforms, four branches, one subtract

    

      
private const val PanelSizeDp = 360
private const val HalfWidth = 0.30f
private const val HalfHeight = 0.20f
private const val DefaultCornerRadius = 0.10f
private const val TeachPx = 0.26f
private const val TeachPy = -0.18f

uniform float2 resolution;
uniform float halfWidth;
uniform float halfHeight;
uniform float cornerRadius;

half4 main(float2 fragCoord) {
    float2 uv = fragCoord / resolution;
    float2 p = uv - float2(0.5, 0.5);
    float2 q = abs(p) - float2(
        halfWidth - cornerRadius,
        halfHeight - cornerRadius
    );
    float sdBox;
    if (q.x > 0.0) {
        if (q.y > 0.0) {
            sdBox = length(q);
        } else {
            sdBox = q.x;
        }
    } else {
        if (q.y > 0.0) {
            sdBox = q.y;
        } else {
            sdBox = q.x > q.y ? q.x : q.y;
        }
    }
    float sd = sdBox - cornerRadius;
    ...
}

      

        
What each part changes

        
halfWidth and halfHeight are the outer half-size. Their subtract of cornerRadius is the inner box. q is the leftover pair after abs.

        
The nested if picks one nearest inner-box point. Both leftovers positive uses length(q). Only one leftover positive uses that leftover. Both negative uses the larger leftover.

        
DefaultCornerRadius = 0.10 so the teaching corner pixel’s sd is exactly 0. PanelSizeDp = 360 stays square so one UV step right equals one UV step down in pixels. The two half-sizes still differ, so the silhouette is a rectangle.

        
The green overlay is Compose drawRoundRect, not a second shader.

8 · EXERCISES
Answer before opening each hidden solution

    
At the visual center, r = 0.10, what is sd, and which color does production store?
q = (−0.20, −0.10). Both leftovers are negative, so sdBox is the larger, −0.10. sd = −0.10 − 0.10 = −0.20. Minus means inside, so the hard if stores orange. That −0.20 is also minus the outer half-height, the nearer outer flat.

    
Diagnostic: someone writes float sd = length(p) − cornerRadius. What shape is sd = 0, and why is the leftover square then wrong?
sd = 0 is a circle of radius 0.10. The teaching shape’s outer flats sit at 0.30 and 0.20, so that circle is much smaller than the rounded rectangle. The leftover-square pixel would be classified by circle distance, not by distance to the quarter-circle from the inner corner.

    
The leftover-square pixel is inside the outer sharp box. Why does production store navy?
Inside the outer sharp box is not the test. The test is sd of the rounded rectangle. q = (0.10, 0.10), length(q) = 0.14142, sd = +0.04142. Plus means outside the quarter-circle. The leftover square between the sharp corner and the arc is outside the shape.

    
If corner radius is 0, what is the inner box, and what silhouette do you get?
innerHalf = outerHalf. The inner box is the outer sharp box. Growing by 0 leaves that sharp rectangle. Production stores orange inside that rectangle, including the four corner squares that a positive radius would leave as navy leftovers.
