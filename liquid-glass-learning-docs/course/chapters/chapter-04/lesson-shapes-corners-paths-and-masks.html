3 · NEW VOCABULARY

Words this chapter will define before use

Bounds

Four edges that enclose a rectangular area.

Radius

One distance from a circle center to its boundary.

Path

An ordered set of drawing instructions that builds a shape boundary.

Mask

A separate value field that controls where another drawing or effect is visible.
