Lesson 4.10 — Transform origin

Lesson 4.9 explained how a boundary becomes pixel contributions. This lesson keeps one already-drawn rectangle and asks one new question: when that rectangle rotates or scales, which point should stay fixed?

Visible result first: the same rotation can look like a card spinning in place, swinging from one corner, or opening like a door. The angle is unchanged. Only the pivot point changes.

One new idea

A transform origin, also called a pivot, is the local point around which rotation and scale are applied.

The pivot remains stationary during pure rotation and scaling. Other points move around it.

2 · TERMS BEFORE FORMULAS

Name every object in the scene

Transform

A draw-time change such as rotation or scaling applied to an already measured view.

Transform origin

The local point that stays fixed while pure rotation or scale moves the rest of the drawing around it.

Origin fraction

A normalized number from 0 through 1 locating the pivot across the view's width or height.

Tracked point

One known point whose before-and-after coordinates reveal exactly what the transform did.

SwiftUI contract: UnitPoint(x: 0.5, y: 0.5) means the center. UnitPoint(x: 0, y: 0) means the top-left corner. The values are fractions of the transformed view's own measured size.

4 · TRACE ONE ACTUAL POINT

Course state: origin 0.25 / 0.75, rotation 90°, scale 1

The fixed teaching rectangle uses local width 360 and local height 200. The tracked point is its top-right corner.

Find the pivot O

pivot X = width × origin fraction X = 360 × 0.25 = 90 pivot Y = height × origin fraction Y = 200 × 0.75 = 150 O = (90, 150)

Move one point around O

P = top-right = (360, 0) Delta = P − O = (270, −150) scale 1.00 → (270, −150) rotate 90° clockwise → (150, 270) add O back → P′ = (240, 420)
Why subtract and add O? Rotation and scale are easiest around coordinate zero. Subtracting O temporarily makes the pivot zero. Adding O afterward returns the result to the rectangle's local coordinate system.
5 · SAME TRANSFORM, DIFFERENT ORIGIN

The pivot changes motion even when angle and scale do not

Top-left · (0, 0)

The top-left corner stays fixed. The card swings around that corner.

Center · (0.5, 0.5)

The center stays fixed. The card spins in place.

Left-center · (0, 0.5)

The middle of the left edge stays fixed. The result resembles a door hinge.

The pivot does not move the view in layout. It changes the draw-time transform. The transformed drawing can extend outside the original measured bounds and overlap nearby content.
6 · iOS CONNECTION

Map fractions into rotationEffect and scaleEffect

Complete source remains in Xcode and LiquidGlassLab-iOS.

Short attributed excerpt

// TransformOriginExplorer.swift — transformed teaching card
let origin = UnitPoint(x: originFractionX, y: originFractionY)
teachingCard
    .background {
        GeometryReader { proxy in
            Color.clear.preference(key: CardSizeKey.self, value: proxy.size)
        }
    }
    .onPreferenceChange(CardSizeKey.self) { measuredSize = $0 }
    .scaleEffect(uniformScale, anchor: origin)
    .rotationEffect(.degrees(rotationDegrees), anchor: origin)

Exact value path

originFractionX / originFractionY → UnitPoint fractions → measured view width / height → pivot points inside that view → scaleEffect then rotationEffect → transformed drawing measured layout size → unchanged

SwiftUI documents rotationEffect and scaleEffect as draw-time transforms. They do not change the view's measured size or placement because they affect rendering, not layout.

9 · EXERCISES

Answer before opening the details

Exercise 1 · Center pivot

A view measures 300 pt × 180 pt. What pivot points does UnitPoint.center use?

Show answer

(150 pt, 90 pt), because both fractions are 0.5.

Exercise 2 · Left-center hinge

Which fractions keep the center of the left edge fixed?

Show answer

UnitPoint(x: 0, y: 0.5).

Exercise 3 · Diagnostic: layout or drawing?

A 280 pt card is scaled to 1.4 with scaleEffect. Does SwiftUI remeasure it as 392 pt?

Show answer

No. The measured layout size stays 280 pt. The drawing becomes larger and may overlap surrounding content.

Exercise 4 · Local point to fractions

A touch point is at local (72 pt, 40 pt) inside 240 pt × 160 pt. What origin fractions represent that point?

Show answer

(72 ÷ 240, 40 ÷ 160) = (0.30, 0.25).

11 · SOURCES AND EVIDENCE

What the SwiftUI documentation supports

  • SwiftUI rotationEffect(_:anchor:) — rotates a view around a UnitPoint without changing layout size.
  • SwiftUI scaleEffect(_:anchor:) — scales a view around the same kind of fractional origin.
  • SwiftUI UnitPoint — defines origin fractions such as .center and .topLeading.
Evidence boundary: the browser reproduces the transform math for one local rectangle. The iOS experiment is the source of truth for SwiftUI behavior. This lesson does not yet animate the values over time.
