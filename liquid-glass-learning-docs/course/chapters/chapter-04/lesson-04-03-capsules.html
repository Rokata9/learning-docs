Lesson 4.3 — Capsules

Lesson 4.2 ended with a 260-unit-high rounded rectangle whose corner radius was 130. At that radius, its left and right straight sides had length zero. This lesson gives that boundary a name: a capsule.

Practical question

Why does a horizontal capsule—one whose width is at least its height—use a corner radius equal to half its height, and which parts of its boundary remain straight?

One new geometry contract

The height determines the diameter of both rounded ends. The radius is therefore calculated from height. Width only changes the straight span between the two ends.

Lesson 4.4 will use this exact relationship when it starts nesting rounded shapes.

1 · WHERE THIS LESSON FITS

Turn Lesson 4.2's maximum radius into a reusable rule

No new color or compositing operation is added.

Known input object

One rounded rectangle has a width, a height, and one equal corner radius at all four corners.

New output description

The boundary becomes a horizontal capsule when the two short vertical straight sides disappear and the left and right ends become semicircles, meaning half-circle boundaries.

2 · WHAT YOU WILL SEE

Two rounded ends stay fixed while the middle grows or shrinks

The controlled shape keeps height at 260. Its end radius therefore stays 130. Changing width moves only the right rounded end and changes the top and bottom straight spans.

Visible clue: there is no straight vertical boundary at either short end. Each end is one continuous half-circle boundary.
3 · TERMS

Define the new words before the first formula

Capsule

A rounded-rectangle boundary whose two short ends are semicircles. The course uses a horizontal capsule, so width is at least as large as height.

Semicircle

One half of a circle boundary. Its full circle has diameter equal to the capsule height.

Derived value

A value calculated from another input instead of controlled independently. Capsule radius is derived from height.

Circle limit

The boundary reached when capsule width becomes equal to capsule height. The middle straight span becomes zero and the result is a circle.

5 · TRACE ONE VALUE

Make the vertical straight side equal zero

The first formula reuses the completed Lesson 4.2 side-span calculation.

Inputs and requested output

input height = 260 input radius = unknown requested vertical straight side = 0

The output we need is one radius that removes the remaining straight boundary between the top-left and bottom-left corner curves.

Solve the known side-span calculation

vertical straight side = height − radius − radius 0 = 260 − radius − radius radius + radius = 260 2 × radius = 260 radius = 260 ÷ 2 radius = 130

The left curve centers meet

top-left center = (120 + 130, 80 + 130) = (250, 210) bottom-left center = (120 + 130, 340 − 130) = (250, 210)

The two quarter-circle corners share one center. Together, their boundary pieces form the left semicircle.

The right curve centers meet

right = 120 + 520 = 640 right end center = (640 − 130, 210) = (510, 210)

The top-right and bottom-right quarter-circle corners share this same center.

The long straight span remains

top straight span = width − radius − radius = 520 − 130 − 130 = 260 because 2 × radius = height: top straight span = width − height

5B · THREE BOUNDARIES

Rounded rectangle, capsule, and circle limit are not the same state

Classification rule for this controlled horizontal case: radius below half the height leaves a vertical straight side, so the shape is an ordinary rounded rectangle. Radius equal to half the height removes that side and creates a capsule. If width also equals height, the capsule construction reaches the circle limit.

9 · EXPLAIN THE RESULT

Height owns the rounded ends; width owns the middle

Height controls diameter

Each rounded end is half of a circle whose diameter equals the capsule height. Radius must therefore equal height divided by two.

Width controls separation

The two end centers are separated by width − height. That same number is the top and bottom straight span.

Width equals height

The two end centers meet. The straight span reaches zero. The boundary is a circle, which is the circle limit of this controlled construction.

Do not derive a horizontal capsule radius from width. Width may change while the end diameter stays fixed. Recalculate radius only when height changes.

11 · EXERCISES

Answer before opening each hidden solution

Exercise 1 · Radius from height

A horizontal capsule has height 96. What radius must it use?

Show answer
radius = height ÷ 2 = 96 ÷ 2 = 48
Exercise 2 · Remaining straight span

Width is 240. Height is 96. Calculate the top straight span.

Show answer
radius = 96 ÷ 2 = 48 straight span = width − 2 × radius = 240 − 96 = 144
Exercise 3 · Diagnostic: width equals height

Width and height are both 96. What boundary is produced? What is the radius?

Show answer

The radius is 48. Both long and short straight spans are zero. The construction reaches the circle limit, so the boundary is a circle.

Exercise 4 · Which value stays unchanged?

Height remains 96. Width grows from 240 to 300. State the new radius and top straight span.

Show answer
radius = 96 ÷ 2 = 48 (unchanged) straight span = 300 − 96 = 204

Radius stays unchanged because height did not change.
