Lesson 4.11 — Shape laboratory

Lessons 4.2, 4.3, and 4.4 established three completed geometry rules. This lesson combines them into one nested control and asks one practical question: which radius rule should run when the control changes size?

Visible result first: the same outer bounds can produce a fixed rounded rectangle or a capsule. After that choice, subtracting the same padding from the outer radius keeps the inner and outer corner arcs centered on the same points.

One integration idea

A shape contract is the rule that converts the current bounds into the radius used by one shape.

The outer contract runs first. The inner geometry is derived afterward.

2 · EXACT FIXED-RADIUS TRACE

Reuse the completed concentric-corner values

The default input comes from Lesson 4.4.

Outer geometry

outer left = 110 outer top = 35 outer width = 600 outer height = 360 fixed outer radius = 90

The fixed rounded-rectangle contract consumes the chosen radius after checking the maximum valid radius.

Inner geometry

padding = 30 inner left = 110 + 30 = 140 inner top = 35 + 30 = 65 inner width = 600 − 60 = 540 inner height = 360 − 60 = 300 inner radius = 90 − 30 = 60
outer top-left curve center = (110 + 90, 35 + 90) = (200, 125) inner top-left curve center = (140 + 60, 65 + 60) = (200, 125) result: both arcs use the same center
3 · CAPSULE TRACE

The same padding subtraction preserves an inner capsule

Outer capsule

outer height = 360 outer radius = height ÷ 2 = 360 ÷ 2 = 180

Inner capsule

inner height = 360 − 2 × 30 = 300 inner radius = outer radius − padding = 180 − 30 = 150 inner height ÷ 2 = 300 ÷ 2 = 150
Integration result: subtracting padding from the outer capsule radius produces exactly half of the inner height. The inner shape is therefore another capsule, and the rounded ends remain concentric.
4 · DEFECT DIAGNOSTIC

Copying the outer radius moves the inner curve center

Copied-radius defect

inner left = outer left + padding wrong inner radius = outer radius wrong inner center X = outer left + padding + outer radius outer center X = outer left + outer radius center shift = padding

Correct concentric rule

inner radius = outer radius − padding inner center X = outer left + padding + outer radius − padding = outer left + outer radius = outer center X
Capsule boundary: copying a capsule’s outer radius can exceed the inner shape’s maximum valid radius. A renderer or teaching model may clamp the request. That clamp can hide the original mistake, so use the fixed rounded-rectangle preset when diagnosing copied-radius center shift.

6 · iOS CONNECTION

The same derived values feed direct SwiftUI drawing

Complete source remains in Xcode and LiquidGlassLab-iOS.

Outer contract

// ShapeLaboratory.swift — calculateShapeGeometry
let outerRadius: CGFloat
switch contract {
case .fixedRoundedRectangle:
    outerRadius = min(max(fixedRadius, 0), maximumOuterRadius)
case .horizontalCapsule:
    outerRadius = height / 2
}

Concentric inner rule

let innerWidth = width - 2 * padding
let innerHeight = height - 2 * padding
let innerRadius = max(outerRadius - padding, 0)

Direct drawing

let outerPath = Path(
    roundedRect: outerRect,
    cornerRadius: outerRadius
)
let innerPath = Path(
    roundedRect: innerRect,
    cornerRadius: innerRadius
)
context.fill(outerPath, with: .color(outerColor))
context.fill(innerPath, with: .color(innerColor))

Optional inspection transform

.rotationEffect(
    .degrees(inspectionRotationDegrees),
    anchor: selectedOrigin
)

The transform changes only the inspection drawing. It does not change the shape-contract arithmetic. SwiftUI Canvas drawing is already in points.

Exercise 1 · Fixed rounded rectangle

Outer radius is 72 and padding is 18. What is the concentric inner radius?

Show answer

Exercise 2 · Capsule

Outer height is 160 and padding is 20. Calculate outer radius, inner height, and inner radius.

Show answer
outer radius = 160 ÷ 2 = 80 inner height = 160 − 40 = 120 inner radius = 80 − 20 = 60 check: 120 ÷ 2 = 60
Exercise 3 · Diagnostic defect

Why does copying outer radius to the inner fixed rounded rectangle shift the inner corner center?

Show answer

The inner edge already moved inward by padding. Keeping the same radius moves the inner curve center inward by that padding as well. Subtracting padding from radius cancels the edge movement and preserves the center.

Exercise 4 · Name absent operations

Which Path and mask are used by the controlled laboratory result?

Show answer

None. It uses direct rounded-rectangle drawing. There is no oversized content to clip and no independent visibility field to apply as a mask.
