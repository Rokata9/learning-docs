Lesson 4.7 — Clipping

Lesson 4.5 gave you one closed badge Path. This lesson uses that same boundary as a yes-or-no drawing permission. The selected draw calls may change positions inside the badge. The same draw calls may not change positions outside it.

Practical problem

A color pattern is intentionally larger than the badge. How can the program keep the pattern visible inside the badge without resizing, trimming, or rebuilding the pattern itself?

One new idea

Clipping limits where later drawing commands may write.

The path stays the same. The oversized pattern stays the same. Only the allowed output region changes.

Lesson 4.8 will introduce masks. Lesson 4.9 will explain the soft transition at a rendered edge.

1 · WHERE THIS LESSON FITS

Reuse a completed closed Path

No new curve formula is needed.

Completed object

The badge boundary uses the Lesson 4.5 command sequence:

move(to: A) addLine(to: B) addLine(to: C) addLine(to: D) addLine(to: E) closeSubpath()

The final closeSubpath() stores the segment from E back to A, so the path encloses one region.

New use of that object

The closed path is supplied to clip(to:) on a GraphicsContext copy. Draw calls on that copy are restricted to the region enclosed by the path.

The lesson does not change the path commands or the content commands.

2 · WHAT YOU WILL SEE

The same pattern either leaks or stays inside

First identify the visible problem.

Clipping off

The four opaque color bands cover their complete oversized drawing area. They remain visible beyond the badge outline.

Clipping on

The same four band draw calls run. Only the portions inside the badge remain visible.

After the clipped copy

A separate ring drawn on the original GraphicsContext is visible outside the badge. This proves that clip(to:) affected only the copy.

3 · TERMS

Define every object before the interaction

Clip region

The area in which the current clipped drawing commands are allowed to change the output.

Candidate drawing

The color or shape a draw call would write at a position before the clip decision is applied.

Discarded draw

A current draw command that is prevented from replacing the existing destination at an outside position. Existing content is not erased.

Scope

The exact block of code affected by one operation. Here, the clip affects only draw calls on the GraphicsContext copy that received clip(to:).

10 · EXPLAIN THE RESULT

Clipping changes permission, not geometry

What changes

The set of drawing positions where commands inside the clip block may replace the destination.

What does not change

The badge Path, the band rectangles, their colors, and their original coordinates.

What outside means

The current clipped draw is rejected at that position. Previously drawn background remains.

Why Q is visible

Q is drawn on the original GraphicsContext. clip(to:) affected only the copy, so the outside ring is permitted.

Deliberate boundary: this lesson treats positions as clearly inside or clearly outside. The renderer's multi-pixel transition at the path edge is antialiasing, taught in Lesson 4.9. A mask that supplies gradual visibility values is a different object, taught in Lesson 4.8.

12 · EXERCISES

Answer before opening the hidden solutions

Exercise 1 · Inside point I

Clipping is on. Point I = (300, 230) is inside the badge. The candidate band is opaque amber. What final color reaches I?

Show answer

The opaque amber candidate reaches I because the clip allows the draw there. The final output is straight sRGB RGBA(0.8510, 0.4667, 0.0235, 1.0000).

Exercise 2 · Outside point O

Clipping is on. Point O = (720, 230) is outside the badge. Does O become transparent, or does the earlier background remain?

Show answer

The earlier background remains. Clipping rejects the current band draw at O. It does not erase the destination or replace it with transparent black.

Exercise 3 · Diagnostic: clip or mask?

A designer wants visibility values such as 0.00, 0.25, 0.70, and 1.00 across a soft field. Is the yes-or-no clip model from this lesson sufficient?

Show answer

No. This lesson's clip region answers whether the current draw may proceed at clearly inside or outside positions. A separate field containing gradual visibility values is a mask, introduced in Lesson 4.8.

Exercise 4 · Scope

A blue circle is drawn outside the badge on the original GraphicsContext after the clipped copy is discarded. Is it still clipped by the badge?

Show answer

No. clip(to:) affected only the copy. A later circle drawn on the original context is not restricted by that finished clip.

14 · SOURCES AND EVIDENCE

What the iOS contract supports

  • SwiftUI GraphicsContext.clip(to:) — adds a clipping path to that context. Subsequent drawing on that context is clipped to the intersection of the current clip and the given path.
  • SwiftUI GraphicsContext — a value type. Copying it and clipping the copy leaves the original context's clip unchanged.
  • SwiftUI Canvas — drawing is in points, origin top-left, y down.
Evidence boundary: the browser uses SVG clipping as a teaching model. The iOS experiment executes SwiftUI GraphicsContext.clip(to:). Neither experiment reads physical display pixels back from the renderer. Lesson 4.9 will study the rendered transition around a mathematical boundary.
