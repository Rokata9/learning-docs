Chapter 4 · Shapes, corners, paths, and masks

Lesson 4.4 — Concentric corners

Lesson 4.2 gave each rounded corner one center and one radius. This lesson places one smaller rounded rectangle inside another and keeps the matching corner curves centered on the same point. Curves that share one center are called concentric.

Practical question

When every inner edge moves inward by the same padding distance—the gap between matching outer and inner edges—what inner corner radius keeps both corner curves centered on the same point?

Controlled lesson boundary

The outer shape uses one equal radius at all four corners. The inner edges move inward by the same amount on the left, top, right, and bottom.

The padding stays between 0 and the outer radius. Different horizontal and vertical padding, elliptical radii, and per-corner values remain outside this lesson.

1 · WHERE THIS LESSON FITS

Nest two known rounded rectangles

No path, mask, clipping, or image operation is added.

Known outer object

One rounded rectangle has fixed bounds and a fixed radius. Its top-left curve center is found by adding the radius to the outer left and top edges.

New inner object

A second rounded rectangle sits inside the first. Its bounds come from moving each matching edge inward by one uniform padding distance.

2 · WHAT YOU WILL SEE

The wrong radius makes the corner band drift

The two examples use the same outer shape and the same 30-unit padding.

The corner band is the visible region between the outer and inner corner boundaries.

Visible clue: the correct inner curve follows the outer curve around one center, so the corner band keeps a consistent direction around the corner. Copying the outer radius moves the inner curve center down and right, so that region no longer follows one shared center.
3 · TERMS

Define every object before the calculation

Outer rounded rectangle

The larger boundary. Its bounds and radius are the starting inputs.

Inner rounded rectangle

The smaller boundary created after all four outer edges move inward.

Uniform padding

One distance used equally between the outer and inner left, top, right, and bottom edges.

Concentric corner curves

Two circular corner curves that use the same center point but different radii.

Inner bounds: the inner rectangle's four edges after padding is removed from both sides of each dimension. For example, inner width equals outer width minus left padding minus right padding.

5 · TRACE ONE VALUE

Find the inner radius from one actual top-left corner

The formula appears only after its inputs and output are named.

Inputs

Outer left = 110 Outer top = 35 Outer radius = 90 Uniform padding = 30

The outer top-left curve center is already known from Lesson 4.2.

outer center X = 110 + 90 = 200 outer center Y = 35 + 90 = 125 outer center = (200, 125)

Move the inner edges

inner left = 110 + 30 = 140 inner top = 35 + 30 = 65

The inner radius is the distance from those new inner edges to the same center.

horizontal inner radius = 200 − 140 = 60 vertical inner radius = 125 − 65 = 60
Now the reusable rule is justified:
inner radius = outer radius − uniform padding = 90 − 30 = 60
Output object: one inner rounded rectangle with bounds (140, 65) .. (680, 365) and radius 60. Its top-left corner curve uses the same center (200, 125) as the outer curve.

10 · EXPLAIN THE RESULT

Padding moves the edge; radius subtraction cancels that move

Correct cancellation

inner center X = inner left + inner radius = (outer left + padding) + (outer radius − padding) = outer left + outer radius

The added padding and subtracted padding cancel. The center stays fixed.

Copied-radius defect

inner center X = inner left + outer radius = outer left + padding + outer radius = outer center X + padding

The center moves right by the padding. The same error moves it downward by the padding.

Validity contract: this circular concentric rule requires equal left and top padding and a non-negative result. At padding = outer radius, the inner radius reaches zero and the inner corner becomes sharp. For padding larger than the outer radius, the required radius would be negative, so a concentric circular inner corner does not exist under this model. Clamping to zero creates valid geometry, but it no longer preserves a curved concentric pair.

12 · EXERCISES

Answer before opening each hidden solution

Exercise 1 · Direct calculation

An outer radius is 72. Uniform padding is 18. What inner radius keeps the corners concentric?

Show answer
inner radius = 72 − 18 = 54
Exercise 2 · Diagnostic: copied radius

Outer left is 20, outer radius is 48, and padding is 12. Compare the outer center X with the inner center X if the inner radius is incorrectly copied as 48.

Show answer
outer center X = 20 + 48 = 68 inner left = 20 + 12 = 32 wrong inner center X = 32 + 48 = 80 center shift = 80 − 68 = 12

The inner center moves right by exactly the padding. The correct inner radius is 36.

Exercise 3 · Radius-zero boundary

What happens when padding equals the outer radius?

Show answer

The calculated inner radius is zero. The inner boundary is still a valid rectangle, but its corners are sharp. There is no inner circular corner curve to pair concentrically with the outer curve.

Exercise 4 · Unequal left and top padding

Outer radius is 90. Left padding is 20, but top padding is 30. Can one circular inner radius preserve the same top-left center in both directions?

Show answer
horizontal radius needed = 90 − 20 = 70 vertical radius needed = 90 − 30 = 60

No single circular radius can be both 70 and 60. This lesson's formula requires uniform padding. Elliptical or asymmetric corner geometry is a separate contract.

14 · SOURCES AND EVIDENCE

What the Android documentation supports

  • AndroidX Compose exposes RoundedCornerShape for rounded rectangular shapes.
  • Compose drawing APIs expose drawRoundRect and CornerRadius for direct Canvas drawing.
  • Compose layout padding moves child content inward, but the concentric-radius subtraction is a geometry relationship derived in this lesson. It is not automatically inferred from two unrelated shape objects.

AndroidX RoundedCornerShape reference · Compose graphics modifiers and drawRoundRect · Compose constraints and padding

Evidence boundary: the browser and Kotlin calculate the controlled circular geometry. They do not prove how every design system defines “concentric,” how asymmetric padding should be resolved, or how physical display pixels are antialiased.
