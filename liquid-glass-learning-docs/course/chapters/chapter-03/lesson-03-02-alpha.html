Chapter 3 · Color, opacity, and compositing

Alpha

Alpha is a fourth color channel. In this lesson, alpha is the source-opacity number that controls how strongly a fixed RGB source participates when it is drawn over a background.

This lesson isolates one idea. Red, green, and blue stay fixed at (0.80, 0.25, 0.60). Only alpha changes. Lesson 3.3 calculates the complete source-over result.

Lesson goal

By the end, you should be able to:

  • read RGBA(0.80, 0.25, 0.60, 0.50) as four separate channel values;
  • explain alpha = 0, 0.5, and 1;
  • explain why lower alpha reveals more background rather than directly making the source darker;
  • map one alpha value to Compose Color(alpha = ...) without reversing it.

1 · Vocabulary

One new channel and three related words

These words are related, but they are not interchangeable labels.

Alpha

Alpha is the numeric channel used here to store source opacity. The normalized range is 0.00 through 1.00.

Opacity

Opacity is how strongly the source is allowed to contribute. In this lesson, opacity equals alpha.

Transparency

Transparency describes how much background is left open. In this simple lesson, the transparent share is 1 − alpha.

RGBA

RGBA is an ordered tuple containing red, green, blue, and alpha. One tuple describes one source color value.

RGBA(red, green, blue, alpha) = RGBA(0.80, 0.25, 0.60, 0.50)
Scope limit: real renderers can also use alpha to represent partial pixel coverage at antialiased edges. Lesson 3.5 returns to that case. For this lesson, treat alpha as source opacity.

3 · Separate the four channel slots

Three values stay fixed; one value changes

The tuple position tells you which channel a number belongs to.

Red · fixed
0.80

No alpha control changes this number.

Green · fixed
0.25

No alpha control changes this number.

Blue · fixed
0.60

No alpha control changes this number.

Alpha · changing
0.50

This is the only channel controlled by the slider.

RGBA(0.80, 0.25, 0.60, 0.00)

At alpha 0, the RGB data does not become black

The tuple can still contain red 0.80, green 0.25, and blue 0.60. Alpha 0.00 prevents that source color from making a visible contribution when the source is drawn.

The checkerboard therefore looks unchanged. This does not prove that the stored RGB numbers were erased.

Diagnostic misconception: “alpha 0 turns the source RGB into (0, 0, 0)” is false for ordinary straight RGBA data. Premultiplied storage is introduced in Lesson 3.5 because its stored numbers follow an additional rule.
4 · Alpha is not a brightness control

Use the background to test the claim

A statement about “brighter” or “darker” is incomplete until the background is named.

Over dark navy

Lower alpha reveals more dark navy. The visible result can become darker.

Over pale yellow

Lower alpha reveals more pale yellow. The visible result can become lighter or more yellow.

Conclusion

Lower alpha means “less source and more background.” It does not mean one guaranteed brightness direction.

alpha ↓ ⇒ source contribution ↓ and visible background influence ↑

@Composable
internal fun AlphaExplorer(
    modifier: Modifier = Modifier,
) {
    var alpha by rememberSaveable {
        mutableFloatStateOf(InitialAlpha)
    }

    val colorScheme = MaterialTheme.colorScheme
    val sourceColor = Color(
        red = SourceRed,
        green = SourceGreen,
        blue = SourceBlue,
        alpha = alpha,
    )
    val transparency = 1f - alpha
    val alpha8Bit = (alpha * 255f).roundToInt()

    Surface(
        modifier = modifier.fillMaxWidth(),
        shape = ExplorerShape,
        color = colorScheme.surface,
        contentColor = colorScheme.onSurface,
        border = BorderStroke(
            width = 1.dp,
            color = colorScheme.outlineVariant,
        ),
    ) {
        Column(
            modifier = Modifier.padding(18.dp),
            verticalArrangement = Arrangement.spacedBy(16.dp),
        ) {
            Text(
                text = "One fixed RGB color, one changing alpha channel",
                style = MaterialTheme.typography.titleLarge,
                fontWeight = FontWeight.Black,
            )
            Text(
                text = "The source RGB values remain (0.80, 0.25, 0.60). " +
                    "Only the alpha value changes.",
                style = MaterialTheme.typography.bodyMedium,
            )

            CheckerboardAlphaSwatch(
                sourceColor = sourceColor,
                alpha = alpha,
            )

            Surface(
                modifier = Modifier.fillMaxWidth(),
                color = colorScheme.surfaceVariant,
                contentColor = colorScheme.onSurfaceVariant,
                shape = CardShape,
            ) {
                Column(
                    modifier = Modifier.padding(14.dp),
                    verticalArrangement = Arrangement.spacedBy(5.dp),
                ) {
                    Text(
                        text = "RGBA(0.80, 0.25, 0.60, ${alpha.twoDecimals()})",
                        fontWeight = FontWeight.Black,
                    )
                    Text(
                        text = "Opacity = ${alpha.asPercent()} · " +
                            "transparent share = ${transparency.asPercent()}",
                    )
                    Text(
                        text = "Approximate 8-bit alpha = $alpha8Bit of 255",
                    )
                }
            }

            Text(
                text = "Alpha channel",
                style = MaterialTheme.typography.titleMedium,
                fontWeight = FontWeight.Black,

                modifier = Modifier.fillMaxWidth(),

                    value = alpha,
                    onValueChange = { alpha = it.coerceIn(0f, 1f) },
                    valueRange = 0f..1f,

                        .weight(1f)
                        .semantics {
                            contentDescription = "Source alpha ${alpha.asPercent()}"

                        thumbColor = colorScheme.primary,
                        activeTrackColor = colorScheme.primary,
                        inactiveTrackColor = colorScheme.surfaceVariant,

@Composable
private fun CheckerboardAlphaSwatch(
    sourceColor: Color,
    alpha: Float,
) {
    val colorScheme = MaterialTheme.colorScheme

    Box(
        modifier = Modifier
            .fillMaxWidth()
            .height(190.dp)
            .clip(SwatchShape)
            .border(
                width = 1.dp,
                color = colorScheme.outline,
                shape = SwatchShape,
            ),
        contentAlignment = Alignment.Center,
    ) {
        Canvas(
            modifier = Modifier
                .fillMaxWidth()
                .height(190.dp),
        ) {
            drawCheckerboard(cellSizePx = 24.dp.toPx())
            drawRect(color = sourceColor)
        }

        Surface(
            color = colorScheme.surface.copy(alpha = 0.94f),
            contentColor = colorScheme.onSurface,
            shape = RoundedCornerShape(10.dp),
        ) {
            Text(
                text = "Alpha ${alpha.twoDecimals()} · ${alpha.asPercent()}",
                style = MaterialTheme.typography.titleMedium,
                fontWeight = FontWeight.Black,
                modifier = Modifier.padding(
                    horizontal = 12.dp,
                    vertical = 8.dp,
                ),
            )
        }
    }
}

@Composable

private fun DrawScope.drawCheckerboard(cellSizePx: Float) {
    val columnCount = ceil(size.width / cellSizePx).toInt()
    val rowCount = ceil(size.height / cellSizePx).toInt()

    repeat(rowCount) { row ->
        repeat(columnCount) { column ->
            val cellColor = if ((row + column) % 2 == 0) {
                CheckerLight
            } else {
                CheckerDark
            }

            drawRect(
                color = cellColor,
                topLeft = Offset(
                    x = column * cellSizePx,
                    y = row * cellSizePx,
                ),
                size = androidx.compose.ui.geometry.Size(
                    width = cellSizePx,
                    height = cellSizePx,
                ),
            )
        }
    }
}

private fun Float.twoDecimals(): String =
    String.format(Locale.US, "%.2f", this)

private fun Float.asPercent(): String =
    "${(this * 100f).roundToInt()}%"

10 · Exercises
Answer before opening the details
At least one question targets the most likely misconception.
Exercise 1 — Which channel changed?
The source changes from RGBA(0.80, 0.25, 0.60, 0.25) to RGBA(0.80, 0.25, 0.60, 0.75). Which channel values changed?
Answer: Only alpha changed, from 0.25 to 0.75. Red, green, and blue stayed fixed.
Exercise 2 — Alpha 0 diagnostic
At alpha 0.00, must the stored straight-RGBA values red 0.80, green 0.25, and blue 0.60 become zero?
Answer: No. The tuple can retain those RGB numbers. Alpha zero prevents the source from contributing visibly when drawn. Premultiplied storage follows an additional rule and is taught in Lesson 3.5.
Exercise 3 — Is lower alpha always brighter?
You reduce alpha from 0.75 to 0.25. Can you conclude that the visible result becomes brighter?
Answer: No. Lower alpha reveals more background. A dark background can make the result darker. A light background can make it lighter.
Exercise 4 — Convert alpha to 8-bit
What is the approximate 8-bit alpha for normalized alpha 0.75?
Answer: round(0.75 × 255) = round(191.25) = 191.



11 · Evidence and deferrals
What this lesson proves
Keep the observed API behavior separate from renderer details not inspected here.
The browser and Android app can prove
They can prove that one alpha input reaches the matching Color argument, that RGB values can remain fixed while alpha changes, and that different backgrounds produce different visible results at the same source alpha.
This lesson does not fully calculate
It does not yet calculate each final red, green, blue, and output-alpha value. Lesson 3.3 performs the source-over arithmetic one channel at a time.
Renderer limit: exact device pixel values can also be affected by color spaces, quantization, display conversion, and later compositor stages. Those unknowns do not change the code-level conclusion that the lesson varies the source alpha while keeping source RGB fixed.
