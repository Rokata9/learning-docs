Chapter 3 · Color, opacity, and compositing

Lesson 3.9 — Saturation

You already know this final opaque color from Lesson 3.8: straight sRGB RGBA(0.65, 0.35, 0.70, 1.00). This lesson answers one new question: how can the program reduce or enlarge the differences among its red, green, and blue channel values without drawing a second tint color over it?

Saturation in this lesson: one numeric factor used by AndroidX ColorMatrix.setToSaturation. The helper first calculates a gray reference, meaning one channel value that becomes the red, green, and blue value of the gray reference color. The factor then reduces, preserves, or enlarges each channel's difference from that value. A factor below 1 moves the channels closer to the gray reference. A factor above 1 moves them farther from it. Other tools may use the word saturation for a different operation.
By the end

You will be able to calculate the gray reference, transform red, green, and blue separately, prove what factors below and above 1 do, distinguish the gray reference from relative luminance, and explain where AndroidX stores the same calculation inside a color matrix.

1 · Start with one known color

No new layer is added

The input is already the final opaque output of Lesson 3.8.

Known input object

Input straight sRGB RGBA = (0.65, 0.35, 0.70, 1.00)

Alpha is 1.00. The color is already opaque. The main saturation calculation therefore does not need a destination or source-over compositing.

New operation

one input Color + one numeric factor ↓ channel transformation one output Color

The operation changes the input red, green, and blue fields. It leaves alpha unchanged. Section 7 later shows how AndroidX stores this same transformation in a ColorMatrix, which is a table of multipliers.

Important boundary: if a later input has alpha below 1, the matrix can still transform its RGB and leave its alpha unchanged. That translucent result is not yet the final visible color. It must still be composited over its real destination before visible-output luminance or contrast is calculated.
2 · Control the exact inputs

One color and one factor

The browser and Kotlin use the same normalized channel range from 0 through 1.

The saturation factor is one number that controls the size of the differences between the input channels and the gray reference defined above. Factor 0 removes those differences. Factor 1 preserves them. A factor above 1 enlarges them. Sections 3 and 4 calculate those statements instead of asking you to accept the words.

3 · Calculate one shared gray reference

Calculate the value shared by gray red, green, and blue

The gray reference is an intermediate number created by the saturation transform.

A gray RGB color has equal red, green, and blue channel values. The AndroidX saturation helper calculates one number from the input channels. The lesson calls that number the gray reference. Setting all three output channels to the gray reference produces a gray color.

The numbers 0.213, 0.715, and 0.072 are fixed multipliers used by this AndroidX helper. A multiplier scales one input before the three results are added. The current color does not generate these constants.

Pure red input

RGB(1, 0, 0) → gray reference 0.213

Pure green input

RGB(0, 1, 0) → gray reference 0.715

Pure blue input

RGB(0, 0, 1) → gray reference 0.072
Why this demonstration matters: the helper does not give red, green, and blue one-third each. It maps the three pure primary inputs to different gray values. AndroidX fixes the exact multipliers. Section 6 explains why this calculation must still not be called relative luminance.
gray reference = 0.213 × input red + 0.715 × input green + 0.072 × input blue
Why the fixed multipliers add to 1: 0.213 + 0.715 + 0.072 = 1.000. If the input is already gray, such as RGB(0.40, 0.40, 0.40), the result remains 0.40 because 1.000 × 0.40 = 0.40.
4 · Transform one channel at a time

Scale its signed distance from gray

The same operation runs independently for red, green, and blue.

A signed distance is the input channel minus the gray reference. A positive result means the input channel is above gray on the 0-to-1 number line. A negative result means it is below gray.

signed distance = input channel − gray reference scaled distance = saturation factor × signed distance raw output channel = gray reference + scaled distance
Exact meaning of closer to gray and farther from gray: a factor below 1 reduces the absolute distance between every channel and the gray reference. A factor above 1 increases that distance. The lesson proves the claim with the live signed distances above; it does not rely on the words alone.
5 · Read the factor by region

Zero, below one, one, and above one do different things

Clamping: a factor above 1 can create a raw channel below 0 or above 1. Clamping means restricting that raw value to the nearest allowed boundary. The browser and Kotlin show both the raw value and the displayed clamped value.
6 · Separate the gray reference from relative luminance

Similar coefficients do not make the operations identical

This is the most likely misconception in this lesson.

Saturation gray reference

The input is the stored straight sRGB channels. The operation combines those stored numbers directly. The output is one reference value used by all three output-channel equations in this saturation transform.

≠

Relative luminance from Lesson 3.6

The input sRGB channels are decoded into linear-light values first. The output is one unitless measurement used by contrast calculations.

Why this matters: do not call the gray reference “luminance,” and do not use input.luminance() as the gray reference for this AndroidX matrix. The two calculations answer different questions.
7 · Inspect the AndroidX ColorMatrix

The API stores the same calculation as four rows

A color matrix is a table of multipliers that calculates output channels from input channels.

ColorMatrix.setToSaturation(factor) first calculates 1 − factor. It then creates the three RGB rows with fixed weights 0.213, 0.715, and 0.072. The alpha row is [0, 0, 0, 1, 0]. It multiplies input alpha by 1 and adds 0, so output alpha equals input alpha.

Output× input R× input G× input B× input A+ offset

Apply the rows to the current input

The current lesson uses normalized 0-to-1 channels. A draw-time color filter later applies the matrix to every affected pixel. This lesson applies the same rows to one known color so every intermediate number remains visible.

8 · Apply one factor to several fixed colors

Each input receives its own gray reference

The factor is shared. The input RGB, gray reference, and output differ per color.

9 · Recalculate luminance and contrast from the output RGB

A saturation transform creates a new measurement input

Wrong after RGB changes

The old values still describe the input RGB. They become stale when attached to a different output RGB.

Correct

Calculate relative luminance from the transformed output. Then calculate black and white contrast from that new luminance.

No promise of luminance preservation: this AndroidX saturation matrix operates directly on channel values. It does not promise that the WCAG relative-luminance number remains unchanged.
10 · Keep alpha and compositing in the correct order

The matrix leaves alpha unchanged

Main lesson case

input alpha = 1.00 matrix alpha row = [0, 0, 0, 1, 0] output alpha = 1.00

The input is already opaque. No destination is needed to know the visible output.

Translucent future case

translucent source RGBA ↓ saturation transform transformed source RGBA ↓ source-over with destination final visible RGB

The transform changes source RGB and keeps source alpha. Compositing is still required afterward.

Measurement consumer

final visible opaque RGB ↓ sRGB decoding relative luminance ↓ contrast formula foreground contrast

Luminance does not receive alpha as a fourth channel.

private data class SaturationResult(
    val matrix: ColorMatrix,
    val grayReference: Float,
    val rawRed: Float,
    val rawGreen: Float,
    val rawBlue: Float,
    val rawAlpha: Float,
    val outputColor: Color,

@Composable
private fun BeforeAfterCard(
    inputColor: Color,
    outputColor: Color,
    saturation: Float,
) {
    Surface(
        shape = CardShape,
        color = MaterialTheme.colorScheme.surfaceContainer,
        border = BorderStroke(1.dp, MaterialTheme.colorScheme.outlineVariant),
    ) {
        Column(
            modifier = Modifier.padding(14.dp),
            verticalArrangement = Arrangement.spacedBy(10.dp),
        ) {
            Row(
                modifier = Modifier.fillMaxWidth(),
                horizontalArrangement = Arrangement.spacedBy(10.dp),
            ) {
                ColorSwatch(
                    modifier = Modifier.weight(1f),
                    label = "Input",
                    color = inputColor,
                )
                ColorSwatch(
                    modifier = Modifier.weight(1f),
                    label = "Output",
                    color = outputColor,
                )
            }
            Text(
                text = "Saturation factor = ${saturation.f2()}",
                fontFamily = FontFamily.Monospace,
                fontWeight = FontWeight.Black,
            )
            Text(
                text = when {
                    saturation < 0.9995f -> {
                        "The output keeps ${(saturation * 100f).f0()}% of each original " +
                            "signed distance from the gray reference."
                    }
                    saturation > 1.0005f -> {
                        "The output keeps 100% of each original distance and adds " +
                            "${((saturation - 1f) * 100f).f0()}% more in the same direction."
                    }
                    else -> "The factor is 1. The output RGB equals the input RGB."
                },
            )
        }
    }
}

private fun applySaturationMatrix(
    input: Color,
    saturation: Float,
): SaturationResult {
    val matrix = ColorMatrix().apply {
        setToSaturation(saturation)
    }

    fun rawChannel(row: Int): Float {
        return matrix[row, 0] * input.red +
            matrix[row, 1] * input.green +
            matrix[row, 2] * input.blue +
            matrix[row, 3] * input.alpha +
            matrix[row, 4]
    }

    val rawRed = rawChannel(0)
    val rawGreen = rawChannel(1)
    val rawBlue = rawChannel(2)
    val rawAlpha = rawChannel(3)
    val grayReference = MatrixRedWeight * input.red +
        MatrixGreenWeight * input.green +
        MatrixBlueWeight * input.blue

    return SaturationResult(
        matrix = matrix,
        grayReference = grayReference,
        rawRed = rawRed,
        rawGreen = rawGreen,
        rawBlue = rawBlue,
        rawAlpha = rawAlpha,
        outputColor = Color(
            red = rawRed.coerceIn(0f, 1f),
            green = rawGreen.coerceIn(0f, 1f),
            blue = rawBlue.coerceIn(0f, 1f),
            alpha = rawAlpha.coerceIn(0f, 1f),
        ),
    )
}

private fun contrastRatio(
    foreground: Color,
    background: Color,
): Float {
    val foregroundLuminance = foreground.luminance()
    val backgroundLuminance = background.luminance()
    val lighter = max(foregroundLuminance, backgroundLuminance)
    val darker = minOf(foregroundLuminance, backgroundLuminance)
    return (lighter + ContrastOffset) / (darker + ContrastOffset)
}

private fun readableLabelColor(background: Color): Color {
    return if (contrastRatio(Color.Black, background) >= contrastRatio(Color.White, background)) {
        Color.Black
    } else {
        Color.White
    }
}

private fun Color.hasSameRgb(other: Color): Boolean {
    val tolerance = 0.00005f
    return abs(red - other.red) <= tolerance &&
        abs(green - other.green) <= tolerance &&
        abs(blue - other.blue) <= tolerance
}

private fun Color.rgbText(): String {
    return "RGB(${red.f4()}, ${green.f4()}, ${blue.f4()})"
}

private fun Color.rgbaText(): String {
    return "RGBA(${red.f4()}, ${green.f4()}, ${blue.f4()}, ${alpha.f4()})"
}

private fun Float.f0(): String = String.format(Locale.US, "%.0f", this)
private fun Float.f1(): String = String.format(Locale.US, "%.1f", this)
private fun Float.f2(): String = String.format(Locale.US, "%.2f", this)
private fun Float.f4(): String = String.format(Locale.US, "%.4f", this)

private fun Float.signed4(): String {
    val normalized = if (abs(this) < 0.00005f) 0f else this
    return String.format(Locale.US, "%+.4f", normalized)
