Chapter 3 · Color, opacity, and compositing

Lesson 3.11 — Compositing laboratory

Lessons 3.3 and 3.4 already gave you one source, one destination, and one output at one drawing position. This lesson keeps that same kind of drawing position and adds more operations above it. The new task is to preserve the exact order and pass each output into the next operation.

Practical question

When several translucent layers, one saturation transform, and one opaque blend-mode layer affect the same position, which value does each operation consume, and what final straight sRGB color does the ordered calculation produce?

Chapter 3 completed

This laboratory does not introduce another color formula. It combines formulas you already completed.

The one new idea is a running composite: the current RGBA result after every operation completed so far. That result becomes the destination for the next draw operation.

3 · TERMS

Name the ordered objects before calculating them

These labels are used throughout the laboratory.

Layer

One drawable source with a color, an alpha value, a draw position, and a blend operation.

Layer stack

The ordered list of layers from the opaque base at the bottom to the last source drawn at the top.

Running composite

The current straight RGBA result after all stages completed so far. The next draw treats this result as its destination.

Stage

One named operation in the sequence. A stage consumes one input color and produces one output color.

Bypass

Skipping an optional stage. Its output is then exactly equal to its input.

Inspection position

The one drawing-target position whose values are followed. Every enabled shape fully covers this position in the lesson model.

Bottom to top

The draw order. The base exists first. Every later layer is drawn over the result below it.

Final displayed color

The opaque straight sRGB output after the last enabled stage. This is the color consumed by luminance and contrast calculations.

9 · EXPLAIN THE RESULT

The final value is a chain of dependencies

A later stage cannot safely reuse a value that belonged to an earlier input.

One output replaces one destination

After Layer A, its output becomes the destination for Layer B. After Layer B, that output becomes the input of the saturation transform.

Order changes causality

Reversing A and B changes which source sees which destination. The same two alpha values can therefore produce a different running composite.

Derived measurements come last

Relative luminance and contrast belong to the final RGB only. Measurements from the base or an intermediate stage become stale when a later stage changes RGB.

Chapter 3 checkpoint answer: two panels with the same alpha can look different because alpha does not determine the destination color. Source-over combines the source with the actual destination already present at that position. Different destinations produce different output RGB values.
10 · CODING CHALLENGE

Stop reusing the original base

The defective loop ignores every earlier layer when it calculates the next layer.

Edit the destination argument or use the buttons, then check the repair.

Default red-channel consequence

The correct path draws Layer A over the base, then draws Layer B over the Layer A output. The defective path draws both sources independently over the original base and returns only the last result.

11 · EXERCISES AND HIDDEN ANSWERS

Use the reset course values

Answer first. Open each nested answer only afterward.

Exercise 1 · Layer A red

Base red is 0.22. Layer A red is 0.90 with alpha 0.50. Calculate the output straight red.

Show answer
output premultiplied red = 0.90 × 0.50 + 0.22 × 1.00 × (1 − 0.50) = 0.45 + 0.11 = 0.56 output alpha = 0.50 + 1.00 × 0.50 = 1.00 output straight red = 0.56 ÷ 1.00 = 0.56
Exercise 2 · Layer B receives the new destination

Layer B red is 0.20 with alpha 0.25. Its destination is the opaque Layer A output, whose straight red is 0.56 and alpha is 1.00. Calculate the new output straight red.

Show answer
output premultiplied red = 0.20 × 0.25 + 0.56 × 1.00 × (1 − 0.25) = 0.05 + 0.42 = 0.47 output alpha = 0.25 + 1.00 × 0.75 = 1.00 output straight red = 0.47 ÷ 1.00 = 0.47
Exercise 3 · Diagnostic: may Layer B reuse base red 0.22?

Explain whether the Layer B calculation may use the original base red after Layer A has already been drawn.

Show answer

No. Layer A replaced the drawing-target value at the inspected position. Layer B is drawn later, so its destination is the Layer A output. Reusing the original base removes Layer A from the causal chain.

Exercise 4 · Why is the short Multiply formula valid at the top stage?

Name every condition that makes final red = top source red × running destination red complete in the reset state.

Show answer

The inspected position is fully covered by the top source; top source alpha is 1.00; the running destination alpha is 1.00 because the stack began with an opaque base; the running destination is drawn first; and the opaque top source is drawn second. Changing alpha or partial coverage would restore omitted terms.
