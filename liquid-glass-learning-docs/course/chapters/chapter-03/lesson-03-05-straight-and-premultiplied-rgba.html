Color, opacity, and compositing

Straight and premultiplied RGBA

Lesson 3.3 already combined a translucent source over a translucent destination. This lesson gives precise names to the two RGB forms that appeared in that calculation. It then shows when each form is used.

One rule for the whole lesson: a bare RGB(...) triplet does not tell you whether the values are straight or premultiplied. Every triplet on this page is labelled.
By the end, you will be able to explain:
  • what straight RGBA stores;
  • what premultiplied RGBA stores;
  • how both relate to Lesson 3.3;
  • why destination alpha belongs in the general source-over formula;
  • when SwiftUI Color expects straight values and when a premultiplied buffer expects premultiplied values.
1 · The exact objects

One source, one destination, and one output at one image position

No circle, edge, filtering, image resizing, or opaque background is assumed.

Source · drawn now
source over checkerboard

The source is the new translucent color being drawn.

Destination · already present
destination over checkerboard

The destination is the translucent color already stored at the same image position.

Output · source over destination
output over checkerboard

The output is still translucent unless its calculated alpha equals 1.

The checkerboard is a third layer used only to make transparency visible. It is not the destination in the source-over calculation above.
2 · Two representations

The same translucent source can be stored in two numerical forms

Change alpha and watch the straight RGB stay fixed while premultiplied RGB changes.

0.50
0.60
Straight RGBA is also called unassociated RGBA. Premultiplied RGBA is also called associated RGBA.

Straight RGBA

The red, green, and blue fields store the color components independently from alpha.

Premultiplied RGBA

The red, green, and blue fields store alpha-weighted color contributions. Alpha itself is stored unchanged.

These tuples are not numerically equal, but they represent the same translucent source. Converting the representation does not change what the source means.
3 · When each representation is used

The API contract decides which numbers a function expects

Do not infer the representation from the word RGB.

SwiftUI Color

The public Color(red:green:blue:opacity:) components are kept separate. The lab helper Color.compositeOver applies the same straight-RGBA source-over formula: both input colors and the returned color are not premultiplied.

Use straight RGBA at this API boundary.

Premultiplied buffers or math

Some renderer data and image buffers define their RGB fields as already multiplied by alpha. Core Graphics requires an alpha-bearing bitmap context that it draws to be premultiplied (CGImageAlphaInfo.premultipliedLast).

Use premultiplied RGBA only when the contract says so.

Your own code

Use different types such as StraightRgba and PremultipliedRgba. Convert once where data crosses from one contract to the other.

Do not manually premultiply a SwiftUI Color before calling compositeOver.

Why premultiplied values are useful here: each RGB field already says how much color that layer contributes. Source-over can add those contributions directly. A later image-sampling lesson will cover another reason premultiplied values are useful.

5 · The complete source-over calculation

Two valid paths start with different input representations

Both paths calculate the same output premultiplied RGBA and the same output straight RGBA.

Path A · start with straight RGBA

Because the RGB fields are not alpha-weighted yet, the formula includes both source alpha and destination alpha.

output premultiplied RGB = source straight RGB × source alpha + destination straight RGB × destination alpha × (1 − source alpha)

Path B · start with premultiplied RGBA

Each input RGB tuple already includes its own alpha. Do not multiply either tuple by its own alpha again.

output premultiplied RGB = source premultiplied RGB + destination premultiplied RGB × (1 − source alpha)
drawn using straight output for display

Output premultiplied RGBA

The source-over addition naturally produces this representation.

same translucent output

Output straight RGBA

Divide output premultiplied RGB by output alpha when alpha is greater than zero.

compositeOver result

Color.compositeOver

The helper accepts straight inputs and returns this straight output.

6 · The opaque-destination special case

The shorter formula is valid only after stating that destination alpha equals 1

Your correction was right: the general formula contains destination alpha.

General case

destination contribution = destination straight RGB × destination alpha × (1 − source alpha)

The current destination alpha is .

When destination alpha = 1

destination straight RGB × 1 × (1 − source alpha) = destination straight RGB × (1 − source alpha)

Output alpha then becomes 1. Straight and premultiplied output RGB are numerically equal because dividing by 1 changes nothing.

7 · Why keep two representations?

The fields have different meanings even when both paths produce the same visual output

The equality is in the final represented color, not in every intermediate tuple.

QuestionStraight RGBAPremultiplied RGBA
What does stored red mean?The red component before alpha weighting.The red contribution after alpha weighting.
Source tuple at alpha 0.50Straight RGBA(0.90, 0.10, 0.80, 0.50)Premultiplied RGBA(0.45, 0.05, 0.40, 0.50)
Must source RGB be multiplied by source alpha during source-over?Yes. The tuple has not done it yet.No. The tuple already contains that multiplication.
Natural output of contribution additionOutput premultiplied RGB. The addition sums alpha-weighted color contributions.
How to obtain output straight RGB?Divide output premultiplied RGB by output alpha, only when output alpha is greater than zero.
The two formulas are not two arbitrary ways to do the same multiplications. One formula performs alpha weighting during compositing. The other consumes values that were alpha-weighted earlier.

private struct StraightRgba {
    let red: CGFloat
    let green: CGFloat
    let blue: CGFloat
    let alpha: CGFloat

    func toPremultiplied() -> PremultipliedRgba {
        PremultipliedRgba(
            red: red * alpha,
            green: green * alpha,
            blue: blue * alpha,
            alpha: alpha
        )
    }

    func toColor() -> Color {
        Color(
            red: min(max(red, 0), 1),
            green: min(max(green, 0), 1),
            blue: min(max(blue, 0), 1),
            opacity: min(max(alpha, 0), 1)
        )
    }

    func asTuple() -> String {
        "Straight RGBA(\(threeDecimals(red)), \(threeDecimals(green)), " +
            "\(threeDecimals(blue)), \(twoDecimals(alpha)))"
    }

    func rgbTuple() -> String {
        "(\(threeDecimals(red)), \(threeDecimals(green)), \(threeDecimals(blue)))"
    }
}

private struct PremultipliedRgba {
    let red: CGFloat
    let green: CGFloat
    let blue: CGFloat
    let alpha: CGFloat

    func toStraight() -> StraightRgba {
        if alpha <= 0 {
            return StraightRgba(
                red: 0,
                green: 0,
                blue: 0,
                alpha: 0
            )
        }
        return StraightRgba(
            red: red / alpha,
            green: green / alpha,
            blue: blue / alpha,
            alpha: alpha
        )
    }

    func asTuple() -> String {
        "Premultiplied RGBA(\(threeDecimals(red)), \(threeDecimals(green)), " +
            "\(threeDecimals(blue)), \(twoDecimals(alpha)))"
    }

    func rgbTuple() -> String {
        "(\(threeDecimals(red)), \(threeDecimals(green)), \(threeDecimals(blue)))"
    }
}

private struct SourceOverCalculation {
    let sourceStraight: StraightRgba
    let destinationStraight: StraightRgba
    let sourcePremultiplied: PremultipliedRgba
    let destinationPremultiplied: PremultipliedRgba
    let destinationOpening: CGFloat
    let destinationAfterSource: PremultipliedRgba
    let outputPremultiplied: PremultipliedRgba
    let outputStraight: StraightRgba
}

private func calculateSourceOver(
    source: StraightRgba,
    destination: StraightRgba
) -> SourceOverCalculation {
    let sourcePremultiplied = source.toPremultiplied()
    let destinationPremultiplied = destination.toPremultiplied()
    let destinationOpening = 1 - source.alpha

    let destinationAfterSource = PremultipliedRgba(
        red: destinationPremultiplied.red * destinationOpening,
        green: destinationPremultiplied.green * destinationOpening,
        blue: destinationPremultiplied.blue * destinationOpening,
        alpha: destination.alpha * destinationOpening
    )

    let outputPremultiplied = PremultipliedRgba(
        red: sourcePremultiplied.red + destinationAfterSource.red,
        green: sourcePremultiplied.green + destinationAfterSource.green,
        blue: sourcePremultiplied.blue + destinationAfterSource.blue,
        alpha: source.alpha + destinationAfterSource.alpha
    )

    return SourceOverCalculation(
        sourceStraight: source,
        destinationStraight: destination,
        sourcePremultiplied: sourcePremultiplied,
        destinationPremultiplied: destinationPremultiplied,
        destinationOpening: destinationOpening,
        destinationAfterSource: destinationAfterSource,
        outputPremultiplied: outputPremultiplied,
        outputStraight: outputPremultiplied.toStraight()
    )
}

private func drawCheckerboard(
    context: GraphicsContext,
    size: CGSize
) {
    let cellSize: CGFloat = 20
    let columnCount = Int(ceil(size.width / cellSize))
    let rowCount = Int(ceil(size.height / cellSize))
    for row in 0..<rowCount {
        for column in 0..<columnCount {
            let cellColor = (row + column).isMultiple(of: 2) ? checkerLight : checkerDark
            let rect = CGRect(
                x: CGFloat(column) * cellSize,
                y: CGFloat(row) * cellSize,
                width: cellSize,
                height: cellSize
            )
            context.fill(Path(rect), with: .color(cellColor))
        }
    }
}

private func twoDecimals(_ value: CGFloat) -> String {
    String(format: "%.2f", Double(value))
}

private func threeDecimals(_ value: CGFloat) -> String {
    String(format: "%.3f", Double(value))
}

private extension Color {
    init(hex: UInt32) {
        self.init(
            red: Double((hex >> 16) & 0xFF) / 255,
            green: Double((hex >> 8) & 0xFF) / 255,
            blue: Double(hex & 0xFF) / 255
        )
    }

    func toStraightRgba() -> StraightRgba {
        var red: CGFloat = 0
        var green: CGFloat = 0
        var blue: CGFloat = 0
        var alpha: CGFloat = 0
        guard UIColor(self).getRed(&red, green: &green, blue: &blue, alpha: &alpha) else {
            return StraightRgba(red: 0, green: 0, blue: 0, alpha: 0)
        }
        return StraightRgba(red: red, green: green, blue: blue, alpha: alpha)
    }

    func compositeOver(_ destination: Color) -> Color {
        let source = toStraightRgba()
        let dest = destination.toStraightRgba()
        return calculateSourceOver(source: source, destination: dest)
            .outputStraight
            .toColor()
    }
}

private struct OverSourceOverCalculation {
    let sourceContributionAlpha: CGFloat
    let destinationContributionAlpha: CGFloat
    let outputPremultipliedRed: CGFloat
    let outputPremultipliedGreen: CGFloat
    let outputPremultipliedBlue: CGFloat
    let outputStraight: OverStraightRgba
}

private func calculateSourceOver(
    source: OverStraightRgba,
    destination: OverStraightRgba
) -> OverSourceOverCalculation {
    let sourceContributionAlpha = source.alpha
    let destinationContributionAlpha = destination.alpha * (1 - source.alpha)
    let outputAlpha = sourceContributionAlpha + destinationContributionAlpha

    let outputPremultipliedRed =
        source.red * sourceContributionAlpha +
        destination.red * destinationContributionAlpha
    let outputPremultipliedGreen =
        source.green * sourceContributionAlpha +
        destination.green * destinationContributionAlpha
    let outputPremultipliedBlue =
        source.blue * sourceContributionAlpha +
        destination.blue * destinationContributionAlpha

    let outputStraight: OverStraightRgba
    if outputAlpha <= 0 {
        outputStraight = OverStraightRgba(
            red: 0,
            green: 0,
            blue: 0,
            alpha: 0
        )
    } else {
        outputStraight = OverStraightRgba(
            red: outputPremultipliedRed / outputAlpha,
            green: outputPremultipliedGreen / outputAlpha,
            blue: outputPremultipliedBlue / outputAlpha,
            alpha: outputAlpha
        )
    }

    return OverSourceOverCalculation(
        sourceContributionAlpha: sourceContributionAlpha,
        destinationContributionAlpha: destinationContributionAlpha,
        outputPremultipliedRed: outputPremultipliedRed,
        outputPremultipliedGreen: outputPremultipliedGreen,
        outputPremultipliedBlue: outputPremultipliedBlue,
        outputStraight: outputStraight
    )
}

private func drawCheckerboard(
    context: GraphicsContext,
    size: CGSize,
    cellSize: CGFloat
) {
    let columnCount = Int(ceil(size.width / cellSize))
    let rowCount = Int(ceil(size.height / cellSize))
    for row in 0..<rowCount {
        for column in 0..<columnCount {
            let cellColor = (row + column).isMultiple(of: 2) ? checkerLight : checkerDark
            let rect = CGRect(
                x: CGFloat(column) * cellSize,
                y: CGFloat(row) * cellSize,
                width: cellSize,
                height: cellSize
            )
            context.fill(Path(rect), with: .color(cellColor))
        }
    }
}

private func twoDecimals(_ value: CGFloat) -> String {
    String(format: "%.2f", Double(value))
}

private extension Color {
    init(hex: UInt32) {
        self.init(
            red: Double((hex >> 16) & 0xFF) / 255,
            green: Double((hex >> 8) & 0xFF) / 255,
            blue: Double(hex & 0xFF) / 255
        )
    }
}

Exercise 1 · Name both representations
Source straight RGBA is (0.80, 0.20, 0.60, 0.25). Write the premultiplied RGBA tuple. Then state whether the two tuples represent the same translucent source.
Answer: Premultiplied RGBA(0.20, 0.05, 0.15, 0.25). Yes. The numerical fields differ, but both representations describe the same translucent source.

    
Exercise 2 · Diagnostic destination-alpha question
Why is destination RGB × (1 − source alpha) incomplete when destination alpha is 0.60?
Answer: the destination RGB is straight and has not yet been weighted by its own alpha. The general term is destination straight RGB × destination alpha × (1 − source alpha).

    
Exercise 3 · Link to Lesson 3.3
What precise name should replace Lesson 3.3's “weighted total”? What operation produces its “straight output”?
Answer: “output premultiplied RGB.” Divide that tuple by output alpha, when output alpha is greater than zero, to obtain output straight RGB.

    
Exercise 4 · API contract
You have a SwiftUI Color and want to call the lab helper compositeOver. Should you premultiply its RGB first?
Answer: no. The helper accepts non-premultiplied inputs and returns a non-premultiplied output, matching the SwiftUI Color component contract.
