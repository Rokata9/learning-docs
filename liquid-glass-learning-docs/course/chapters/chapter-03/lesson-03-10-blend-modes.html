Lesson 3.10 — Blend modes

You already know one source color drawn second over one destination color from Lessons 3.3 and 3.4. This lesson keeps those two objects, their opaque alpha values, their shape, and their draw order fixed. It changes only the arithmetic used where the source circle covers the destination.

Practical question

What visible output does Android produce when the same opaque source and destination use Normal, Multiply, Screen, or Plus?

0 · PREREQUISITE LEDGER

Name every object before the first formula

The new term is defined here. The other objects come from completed lessons.

Source

The opaque color drawn now. In the scene, it is the circle drawn second.

Destination

The opaque color already in the Canvas. It fills the entire drawing area before the source is drawn.

Output

The new color calculated at a drawing position covered by the source circle.

Blend mode

The rule that combines matching source and destination channels to calculate the output channel.

Important boundary: both alpha values stay at 1.00. The formulas in this lesson describe a fully covered position inside the solid circle. They do not yet describe translucent inputs or boundary positions where the source covers only part of one drawing position. That coverage calculation is taught later.

2 · NORMAL / SRCOVER

With an opaque source, Normal outputs the source

Start with the operation already known from Lesson 3.3.

Normal is the common name used by many graphics tools for ordinary source-over compositing. Compose names the mode BlendMode.SrcOver. The source is drawn over the destination.

At the solid interior of the circle, source alpha is 1.00. The source covers the destination completely. The output channel is therefore the source channel.

output channel = source channel red output = 0.8400 green output = 0.3600 blue output = 0.1800
Why the destination disappears here: the source is opaque. This statement would not be true for source alpha below 1.
3 · MULTIPLY

Multiply matching channels

Trace one channel completely before repeating the operation.

Multiply uses this opaque-input channel rule:

output channel = source channel × destination channel

Red trace

source red = 0.8400 destination red = 0.2200 output red = 0.8400 × 0.2200 = 0.1848

Why the result is lower

Both inputs are between 0 and 1. Multiplying by a number below 1 keeps only a fraction of the other input.

0.1848 < 0.8400 0.1848 < 0.2200

For these inputs, the output red channel is lower than both input red channels.

Neutral source for Multiply: source channel 1. The proof is 1 × destination = destination. An opaque white source therefore leaves an opaque destination unchanged under Multiply.
4 · SCREEN

Multiply the distances that remain before white

This construction explains the formula instead of presenting it without a cause.

For one normalized channel, white is the value 1. The distance before white is 1 − channel.

Red distances before white

source distance = 1 − 0.8400 = 0.1600 destination distance = 1 − 0.2200 = 0.7800

Keep the shared remaining distance

combined remaining distance = 0.1600 × 0.7800 = 0.1248 output red = 1 − 0.1248 = 0.8752

The same rule can be rearranged into the shorter formula used by Android documentation:

output = 1 − (1 − source) × (1 − destination) = source + destination − source × destination
Neutral source for Screen: source channel 0. The proof is 0 + destination − 0 × destination = destination. An opaque black source therefore leaves an opaque destination unchanged under Screen.
5 · PLUS

Add matching channels, then clamp the result

Keep this “saturating addition” separate from Lesson 3.9 color saturation.

Plus first calculates a raw sum:

raw channel = source channel + destination channel

A normalized channel must remain inside 0..1. Clamping restricts a value to the nearest allowed boundary:

output channel = clamp(raw channel, 0, 1)
Two different uses of the word “saturation”: some API documentation calls this operation saturating addition, meaning “add, but stop at the maximum representable value.” Lesson 3.9 saturation means scaling channel distances from a gray reference. They are unrelated operations.
Neutral source for Plus: source channel 0. The proof is clamp(0 + destination, 0, 1) = destination.

7 · FOUR OUTPUTS

Keep the inputs fixed and compare all four rules

The cards recalculate when you change either input color.

Draw-order reminder: for the opaque formulas taught here, swapping source and destination does not change the Multiply, Screen, or Plus overlap output. Multiplication gives the same product when its two inputs swap, and addition gives the same sum when its two inputs swap. Normal is different: the opaque source replaces the destination, so swapping the two colors changes which color is on top. Do not extend this opaque-input conclusion to translucent blend-mode compositing without the full alpha equations.

9 · DERIVED MEASUREMENTS

Recalculate luminance and contrast from each output

The mode changes RGB. A measurement derived from RGB must follow the new RGB.

The relative-luminance values belong to the exact output RGB triplets shown in the same cards. The source luminance or destination luminance cannot be reused as though it described another mode’s output.
10 · ALPHA LIMIT

Why both colors stay opaque in this lesson

One new idea is enough: the RGB blend function.

What this lesson calculates

A fully covered circle-interior position where source alpha and destination alpha are both 1.00.

The short RGB formulas are exact for that controlled case.

What this lesson defers

When alpha is below 1, a complete blend-mode compositor must also calculate how much of the position the source covers, how much destination contribution survives, the output alpha, and the blend function’s contribution.

Do not copy the opaque formulas alone into that larger case.

@Composable
private fun BlendScene(
    source: Color,
    destination: Color,
    result: Color,
    mode: LessonBlendMode,
) {
    val borderColor = MaterialTheme.colorScheme.outline
    val onResult = readableTextColor(result)

    Surface(
        shape = CardShape,
        color = MaterialTheme.colorScheme.surfaceVariant,
        border = BorderStroke(1.dp, MaterialTheme.colorScheme.outlineVariant),
    ) {
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(300.dp),
        ) {
            Canvas(
                modifier = Modifier
                    .fillMaxWidth()
                    .height(300.dp),
            ) {
                val corner = CornerRadius(
                    x = 18.dp.toPx(),
                    y = 18.dp.toPx(),
                )
                drawRoundRect(
                    color = destination,
                    cornerRadius = corner,
                )

                val radius = min(size.width, size.height) * 0.31f
                drawCircle(
                    color = source,
                    radius = radius,
                    center = Offset(
                        x = size.width * 0.60f,
                        y = size.height * 0.54f,
                    ),
                    blendMode = mode.composeMode,
                )

                drawRoundRect(
                    color = borderColor,
                    cornerRadius = corner,
                    style = Stroke(width = 1.dp.toPx()),
                )
            }

            Column(
                modifier = Modifier
                    .align(Alignment.TopStart)
                    .padding(14.dp),
            ) {
                Text(
                    text = "Destination fills the drawing area",
                    color = readableTextColor(destination),
                    style = MaterialTheme.typography.labelLarge,
                    fontWeight = FontWeight.Black,
                )
                Text(
                    text = formatStraightRgba(destination),
                    color = readableTextColor(destination),
                    style = MaterialTheme.typography.bodySmall,
                    fontFamily = FontFamily.Monospace,
                )
            }

            Surface(
                modifier = Modifier
                    .align(Alignment.Center)
                    .padding(start = 86.dp, top = 22.dp),
                shape = RoundedCornerShape(12.dp),
                color = result,
                contentColor = onResult,
                tonalElevation = 0.dp,
            ) {
                Column(
                    modifier = Modifier.padding(
                        horizontal = 12.dp,
                        vertical = 9.dp,
                    ),
                    horizontalAlignment = Alignment.CenterHorizontally,
                ) {
                    Text(
                        text = mode.label,
                        fontWeight = FontWeight.Black,
                    )
                    Text(
                        text = "solid circle interior",
                        style = MaterialTheme.typography.labelSmall,
                    )
                }
            }
        }
    }
}

private fun blendOpaqueColors(
    source: Color,
    destination: Color,
    mode: LessonBlendMode,
): OpaqueBlendResult {
    val red = blendOpaqueChannel(
        source = source.red,
        destination = destination.red,
        mode = mode,
    )
    val green = blendOpaqueChannel(
        source = source.green,
        destination = destination.green,
        mode = mode,
    )
    val blue = blendOpaqueChannel(
        source = source.blue,
        destination = destination.blue,
        mode = mode,
    )

    return OpaqueBlendResult(
        red = red,
        green = green,
        blue = blue,
        outputColor = Color(
            red = red.output,
            green = green.output,
            blue = blue.output,
            alpha = 1f,
        ),
    )
}

private fun blendOpaqueChannel(
    source: Float,
    destination: Float,
    mode: LessonBlendMode,
): ChannelBlend {
    val raw = when (mode) {
        LessonBlendMode.Normal -> source
        LessonBlendMode.Multiply -> source * destination
        LessonBlendMode.Screen -> {
            source + destination - source * destination
        }
        LessonBlendMode.Plus -> source + destination
    }

    return ChannelBlend(
        raw = raw,
        output = raw.coerceIn(0f, 1f),
    )
}

private fun channelFormula(
    mode: LessonBlendMode,
    source: Float,
    destination: Float,
    calculation: ChannelBlend,
): String {
    return when (mode) {
        LessonBlendMode.Normal -> {
            "source alpha = 1.0000\n" +
                "output = source\n" +
                "       = ${format4(source)}"
        }
        LessonBlendMode.Multiply -> {
            "output = source × destination\n" +
                "       = ${format4(source)} × ${format4(destination)}\n" +
                "       = ${format4(calculation.output)}"
        }
        LessonBlendMode.Screen -> {
            val product = source * destination
            "product = source × destination\n" +
                "        = ${format4(source)} × ${format4(destination)}\n" +
                "        = ${format4(product)}\n" +
                "output = source + destination − product\n" +
                "       = ${format4(source)} + ${format4(destination)} " +
                "− ${format4(product)}\n" +
                "       = ${format4(calculation.output)}"
        }
        LessonBlendMode.Plus -> {
            "raw sum = source + destination\n" +
                "        = ${format4(source)} + ${format4(destination)}\n" +
                "        = ${format4(calculation.raw)}\n" +
                "output = clamp(raw sum, 0, 1)\n" +
                "       = ${format4(calculation.output)}"
        }
    }
}

private fun contrastRatio(
    firstLuminance: Float,
    secondLuminance: Float,
): Float {
    val lighter = max(firstLuminance, secondLuminance)
    val darker = min(firstLuminance, secondLuminance)

    return (lighter + ContrastOffset) /
        (darker + ContrastOffset)
}

private fun readableTextColor(background: Color): Color {
    return if (background.luminance() >= 0.42f) {
        Color.Black
    } else {
        Color.White
    }
}

private fun formatStraightRgba(color: Color): String {
    return "straight sRGB RGBA(" +
        "${format4(color.red)}, " +
        "${format4(color.green)}, " +
        "${format4(color.blue)}, " +
        "${format4(color.alpha)})"
}

private fun formatStraightRgb(color: Color): String {
    return "straight sRGB RGB(" +
        "${format4(color.red)}, " +
        "${format4(color.green)}, " +
        "${format4(color.blue)})"
}

private fun format4(value: Float): String {
    return String.format(Locale.US, "%.4f", value)
}

private fun format6(value: Float): String {
    return String.format(Locale.US, "%.6f", value)
}

Exercise 3 · Diagnostic: is this Lesson 3.9 saturation?

Plus calculates red as 0.84 + 0.22 = 1.06 and displays 1.00. Why did the value become 1.00? Did a gray reference participate?

Show answer

The raw sum exceeded the allowed normalized maximum. Clamping restricted it to 1.00. No gray reference or saturation factor participated. This is saturating addition, not the Lesson 3.9 color-saturation transform.

Exercise 4 · Neutral source

Which opaque source leaves the destination unchanged for Multiply? Which opaque source does that for Screen and Plus?

Show answer

Multiply uses white, because 1 × destination = destination. Screen and Plus use black, because source channel 0 leaves the destination unchanged in each formula.
