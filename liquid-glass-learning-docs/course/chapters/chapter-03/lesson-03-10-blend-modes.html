2 · NORMAL / BLENDMODE.NORMAL

With an opaque source, Normal outputs the source

Start with the operation already known from Lesson 3.3.

Normal is the common name used by many graphics tools for ordinary source-over compositing. SwiftUI names the mode BlendMode.normal. The source is drawn over the destination.

At the solid interior of the circle, source alpha is 1.00. The source covers the destination completely. The output channel is therefore the source channel.

output channel = source channel red output = 0.8400 green output = 0.3600 blue output = 0.1800
Why the destination disappears here: the source is opaque. This statement would not be true for source alpha below 1.
3 · MULTIPLY

Multiply matching channels

Trace one channel completely before repeating the operation.

Multiply uses this opaque-input channel rule:

output channel = source channel × destination channel

Red trace

source red = 0.8400 destination red = 0.2200 output red = 0.8400 × 0.2200 = 0.1848

Why the result is lower

Both inputs are between 0 and 1. Multiplying by a number below 1 keeps only a fraction of the other input.

0.1848 < 0.8400 0.1848 < 0.2200

For these inputs, the output red channel is lower than both input red channels.

Neutral source for Multiply: source channel 1. The proof is 1 × destination = destination. An opaque white source therefore leaves an opaque destination unchanged under Multiply.
4 · SCREEN

Multiply the distances that remain before white

This construction explains the formula instead of presenting it without a cause.

For one normalized channel, white is the value 1. The distance before white is 1 − channel.

Red distances before white

source distance = 1 − 0.8400 = 0.1600 destination distance = 1 − 0.2200 = 0.7800

Keep the shared remaining distance

combined remaining distance = 0.1600 × 0.7800 = 0.1248 output red = 1 − 0.1248 = 0.8752

The same rule can be rearranged into the shorter formula used by this lesson and by SwiftUI blend documentation:

output = 1 − (1 − source) × (1 − destination) = source + destination − source × destination
Neutral source for Screen: source channel 0. The proof is 0 + destination − 0 × destination = destination. An opaque black source therefore leaves an opaque destination unchanged under Screen.
5 · PLUS

Add matching channels, then clamp the result

Keep this “saturating addition” separate from Lesson 3.9 color saturation.

Plus first calculates a sum before clamping:

pre-clamp channel sum = source channel + destination channel

A normalized channel must remain inside 0..1. Clamping restricts a value to the nearest allowed boundary:

output channel = clamp(pre-clamp channel sum, 0, 1)
Two different uses of the word “saturation”: some API documentation calls this operation saturating addition, meaning “add, but stop at the maximum representable value.” Lesson 3.9 saturation means scaling channel distances from a gray reference. They are unrelated operations.
Neutral source for Plus: source channel 0. The proof is clamp(0 + destination, 0, 1) = destination.

7 · FOUR OUTPUTS

Keep the inputs fixed and compare all four rules

The cards recalculate when you change either input color.

Draw-order reminder: for the opaque formulas taught here, swapping source and destination does not change the Multiply, Screen, or Plus overlap output. Multiplication gives the same product when its two inputs swap, and addition gives the same sum when its two inputs swap. Normal is different: the opaque source replaces the destination, so swapping the two colors changes which color is on top. Do not extend this opaque-input conclusion to translucent blend-mode compositing without the full alpha equations.

10 · ALPHA LIMIT

Why both colors stay opaque in this lesson

One new idea is enough: the RGB blend function.

The exact conditions used here

The short formulas in Sections 3–6 are complete—not approximate—because all of these conditions are true:

  1. The inspected drawing position lies fully inside the source circle, so source coverage at that position is 100%.
  2. Source alpha is 1.00.
  3. Destination alpha is 1.00.
  4. The destination is drawn first and the source is drawn second.

Because alpha is 1.00, multiplying a channel by its own alpha does not change the number. A straight channel such as 0.84 and its premultiplied contribution are therefore both 0.84 in this specific lesson.

Why the general formulas become shorter

For example, the general Multiply equation contains three contribution terms:

output contribution = source × (1 − destination alpha) + destination × (1 − source alpha) + source × destination

Substituting both alpha values:

= source × (1 − 1) + destination × (1 − 1) + source × destination = source × 0 + destination × 0 + source × destination = source × destination

If either alpha is below 1, or if the position is only partly covered at the circle boundary, the discarded terms are no longer zero. The short formula alone is then incomplete.

private enum LessonBlendMode: Int, CaseIterable, Identifiable {
    case normal
    case multiply
    case screen
    case plus

    var id: Int { rawValue }

    var label: String {
        switch self {
        case .normal: return "Normal / BlendMode.normal"
        case .multiply: return "Multiply"
        case .screen: return "Screen"
        case .plus: return "Plus"
        }
    }

    var canvasBlendMode: GraphicsContext.BlendMode {
        switch self {
        case .normal: return .normal
        case .multiply: return .multiply
        case .screen: return .screen
        case .plus: return .plusLighter
        }
    }
}

private struct ChannelBlend {
    let unclamped: CGFloat
    let output: CGFloat
}

private struct OpaqueBlendResult {
    let red: ChannelBlend
    let green: ChannelBlend
    let blue: ChannelBlend
    let outputColor: Color

    var anyChannelWasClamped: Bool {
        red.unclamped != red.output
            || green.unclamped != green.output
            || blue.unclamped != blue.output
    }
}

private struct BlendScene: View {
    let source: Color
    let destination: Color
    let result: Color
    let mode: LessonBlendMode

    var body: some View {
        ZStack(alignment: .topLeading) {
            Canvas { context, size in
                let rect = CGRect(origin: .zero, size: size)
                context.fill(
                    Path(roundedRect: rect, cornerRadius: 18),
                    with: .color(destination)
                )

                let radius = min(size.width, size.height) * 0.31
                let center = CGPoint(x: size.width * 0.60, y: size.height * 0.54)
                var circleContext = context
                circleContext.blendMode = mode.canvasBlendMode
                circleContext.fill(
                    Path(
                        ellipseIn: CGRect(
                            x: center.x - radius,
                            y: center.y - radius,
                            width: radius * 2,
                            height: radius * 2
                        )
                    ),
                    with: .color(source)
                )

                context.stroke(
                    Path(roundedRect: rect, cornerRadius: 18),
                    with: .color(Color(uiColor: .separator)),
                    lineWidth: 1
                )
            }

            VStack(alignment: .leading, spacing: 4) {
                Text("Destination fills the drawing area")
                    .font(.system(size: 14, weight: .black))
                    .foregroundStyle(readableTextColor(destination))
                Text(formatStraightRgba(destination))
                    .font(.system(size: 12, design: .monospaced))
                    .foregroundStyle(readableTextColor(destination))
            }
            .padding(14)

            VStack(spacing: 2) {
                Text(mode.label)
                    .fontWeight(.black)
                Text("solid circle interior")
                    .font(.system(size: 12))
            }
            .foregroundStyle(readableTextColor(result))
            .padding(.horizontal, 12)
            .padding(.vertical, 9)
            .background(
                RoundedRectangle(cornerRadius: 12, style: .continuous)
                    .fill(result)
            )
            .frame(maxWidth: .infinity, maxHeight: .infinity, alignment: .center)
            .padding(.leading, 86)
            .padding(.top, 22)
        }
        .frame(maxWidth: .infinity)
        .frame(height: 300)
        .clipShape(RoundedRectangle(cornerRadius: 16, style: .continuous))
        .overlay(
            RoundedRectangle(cornerRadius: 16, style: .continuous)
                .strokeBorder(Color(uiColor: .separator), lineWidth: 1)
        )
    }
}

private struct StraightRgba {
    let red: CGFloat
    let green: CGFloat
    let blue: CGFloat
    let alpha: CGFloat
}

private func blendOpaqueColors(
    source: Color,
    destination: Color,
    mode: LessonBlendMode
) -> OpaqueBlendResult {
    let sourceRgba = source.toStraightRgba()
    let destinationRgba = destination.toStraightRgba()
    let red = blendOpaqueChannel(source: sourceRgba.red, destination: destinationRgba.red, mode: mode)
    let green = blendOpaqueChannel(source: sourceRgba.green, destination: destinationRgba.green, mode: mode)
    let blue = blendOpaqueChannel(source: sourceRgba.blue, destination: destinationRgba.blue, mode: mode)
    return OpaqueBlendResult(
        red: red,
        green: green,
        blue: blue,
        outputColor: Color(
            red: red.output,
            green: green.output,
            blue: blue.output,
            opacity: 1
        )
    )
}

private func blendOpaqueChannel(
    source: CGFloat,
    destination: CGFloat,
    mode: LessonBlendMode
) -> ChannelBlend {
    let unclamped: CGFloat
    switch mode {
    case .normal:
        unclamped = source
    case .multiply:
        unclamped = source * destination
    case .screen:
        unclamped = source + destination - source * destination
    case .plus:
        unclamped = source + destination
    }
    return ChannelBlend(
        unclamped: unclamped,
        output: min(max(unclamped, 0), 1)
    )
}

private func channelFormula(
    mode: LessonBlendMode,
    source: CGFloat,
    destination: CGFloat,
    calculation: ChannelBlend
) -> String {
    switch mode {
    case .normal:
        return "source alpha = 1.0000\n" +
            "output = source\n" +
            "       = \(format4(source))"
    case .multiply:
        return "output = source × destination\n" +
            "       = \(format4(source)) × \(format4(destination))\n" +
            "       = \(format4(calculation.output))"
    case .screen:
        let product = source * destination
        return "product = source × destination\n" +
            "        = \(format4(source)) × \(format4(destination))\n" +
            "        = \(format4(product))\n" +
            "output = source + destination − product\n" +
            "       = \(format4(source)) + \(format4(destination)) " +
            "− \(format4(product))\n" +
            "       = \(format4(calculation.output))"
    case .plus:
        return "unclamped sum = source + destination\n" +
            "        = \(format4(source)) + \(format4(destination))\n" +
            "        = \(format4(calculation.unclamped))\n" +
            "displayed = clamp(unclamped sum, 0, 1)\n" +
            "       = \(format4(calculation.output))"
    }
}

private func contrastRatio(
    firstLuminance: CGFloat,
    secondLuminance: CGFloat
) -> CGFloat {
    let lighter = max(firstLuminance, secondLuminance)
    let darker = min(firstLuminance, secondLuminance)
    return (lighter + contrastOffset) / (darker + contrastOffset)
}

private func readableTextColor(_ background: Color) -> Color {
    background.luminance() >= 0.42 ? Color.black : Color.white
}

private func formatStraightRgba(_ color: Color) -> String {
    let rgba = color.toStraightRgba()
    return "straight sRGB RGBA(" +
        "\(format4(rgba.red)), " +
        "\(format4(rgba.green)), " +
        "\(format4(rgba.blue)), " +
        "\(format4(rgba.alpha)))"
}

private func formatStraightRgb(_ color: Color) -> String {
    let rgba = color.toStraightRgba()
    return "straight sRGB RGB(" +
        "\(format4(rgba.red)), " +
        "\(format4(rgba.green)), " +
        "\(format4(rgba.blue)))"
}

private func format4(_ value: CGFloat) -> String {
    String(format: "%.4f", Double(value))
}

private func format6(_ value: CGFloat) -> String {
    String(format: "%.6f", Double(value))
}

private func decodeSrgbChannel(_ encoded: CGFloat) -> CGFloat {
    let safeEncoded = min(max(encoded, 0), 1)
    if safeEncoded <= 0.04045 {
        return safeEncoded / 12.92
    }
    return CGFloat(pow(Double((safeEncoded + 0.055) / 1.055), 2.4))
}

private func calculateRelativeLuminance(red: CGFloat, green: CGFloat, blue: CGFloat) -> CGFloat {
    0.2126 * decodeSrgbChannel(red)
        + 0.7152 * decodeSrgbChannel(green)
        + 0.0722 * decodeSrgbChannel(blue)
}

private extension Color {
    init(hex: UInt32) {
        self.init(
            red: Double((hex >> 16) & 0xFF) / 255,
            green: Double((hex >> 8) & 0xFF) / 255,
            blue: Double(hex & 0xFF) / 255
        )
    }

    func toStraightRgba() -> StraightRgba {
        var red: CGFloat = 0
        var green: CGFloat = 0
        var blue: CGFloat = 0
        var alpha: CGFloat = 0
        guard UIColor(self).getRed(&red, green: &green, blue: &blue, alpha: &alpha) else {
            return StraightRgba(red: 0, green: 0, blue: 0, alpha: 0)
        }
        return StraightRgba(red: red, green: green, blue: blue, alpha: alpha)
    }

    func luminance() -> CGFloat {
        let rgba = toStraightRgba()
        return calculateRelativeLuminance(red: rgba.red, green: rgba.green, blue: rgba.blue)
    }
}

Exercise 3 · Diagnostic: is this Lesson 3.9 saturation?

Plus calculates red as 0.84 + 0.22 = 1.06 and displays 1.00. Why did the value become 1.00? Did a gray reference participate?

Show answer

The pre-clamp sum exceeded the allowed normalized maximum. Clamping restricted it to 1.00. No gray reference or saturation factor participated. This is saturating addition, not the Lesson 3.9 color-saturation transform.

Exercise 4 · Neutral source

Which opaque source leaves the destination unchanged for Multiply? Which opaque source does that for Screen and Plus?

Show answer

Multiply uses white, because 1 × destination = destination. Screen and Plus use black, because source channel 0 leaves the destination unchanged in each formula.
