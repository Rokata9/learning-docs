Chapter 3 · Color, opacity, and compositing

Red, green, and blue channels

One opaque RGB color is described by three ordered numbers. Each number controls one named color channel at one pixel.

This lesson isolates one idea. Alpha is fixed at 1.00, which means fully opaque. Lesson 3.2 studies alpha separately.

Lesson goal

By the end, you should be able to:

  • explain why one channel value is not a complete color;
  • read RGB(0.80, 0.25, 0.60) as three named values;
  • change one channel without claiming that the other two changed;
  • map the three values to SwiftUI Color arguments correctly.
Theme behavior: this page follows the operating-system light or dark preference. The surrounding interface adapts. The RGB swatches do not change because those swatches are the numeric color data being studied.
1 · Vocabulary

A channel is one named number inside a color

The channel name tells the renderer which primary color contribution the number controls.

Red channel

The red channel is the number assigned to the red primary contribution at one pixel.

R = 0.80 means 80% of the allowed numeric range in this normalized representation.

Green channel

The green channel is the number assigned to the green primary contribution at the same pixel.

G = 0.25 is independent of the red value.

Blue channel

The blue channel is the number assigned to the blue primary contribution at the same pixel.

B = 0.60 is independent of the red and green values.

complete opaque color = RGB(red, green, blue) = RGB(0.80, 0.25, 0.60)
Do not read 0.80 as a complete color. It is one channel value. The complete color requires the ordered group of red, green, and blue values.

A normalized channel value uses the range 0.00 through 1.00. The word normalized means that the numeric range has been scaled to start at 0 and end at 1. It does not mean that 0.80 is exactly 80% of the screen's physical light output or perceived brightness. Those topics are deferred to later color-space and luminance lessons.

3 · Same number, different channel

The channel name changes the visible result

All four examples use the same numeric value. The number is attached to different channel positions.

0.60

Only the red channel receives the shared value.

Only the green channel receives the shared value.

Only the blue channel receives the shared value.

All three channels receive the same value, so the result is a neutral gray.

Diagnostic rule: equal red, green, and blue values produce a neutral gray in this RGB model. Unequal values produce a color bias toward one or more channels.
4 · Two numeric scales

Normalized RGB and 8-bit RGB describe the same three channels

This is a scale conversion. It does not add or remove a color channel.

Normalized scale

Each channel is written from 0.00 through 1.00.

RGB(0.80, 0.25, 0.60)

Approximate 8-bit scale

Each channel is written as an integer from 0 through 255.

RGB(204, 64, 153)
red8 = round(0.80 × 255) = 204
green8 = round(0.25 × 255) = 64
blue8 = round(0.60 × 255) = 153

The approximate hexadecimal form is #CC4099. The first pair CC represents red, the second pair 40 represents green, and the third pair 99 represents blue. Hexadecimal is shown only as a familiar representation. A later lesson can study it in more depth if needed.

import SwiftUI

struct LabHost: View {
    @SceneStorage("lab.chapter") private var chapter = 1
    @Environment(\.colorScheme) private var colorScheme

    var body: some View {
        let background = colorScheme == .dark ? LabColor.backgroundDark : LabColor.backgroundLight
        let onBackground = colorScheme == .dark ? LabColor.onBackgroundDark : LabColor.onBackgroundLight

        VStack(spacing: 0) {
            chapterPicker(onBackground: onBackground)
                .safeAreaPadding(.top)
                .safeAreaPadding(.horizontal)
            Group {
                switch chapter {
                case 1:
                    Chapter01Screen()
                case 2:
                    Chapter02Screen()
                case 3:
                    Chapter03Screen()
                case 8:
                    ShaderSmokeView()
                case 4, 5, 6, 7, 9:
                    ChapterPlaceholder(number: chapter)
                default:
                    Chapter01Screen()
                }
            }
            .frame(maxWidth: .infinity, maxHeight: .infinity)
        }
        .background(background.ignoresSafeArea())
    }

    private func chapterPicker(onBackground: Color) -> some View {
        ScrollView(.horizontal, showsIndicators: false) {
            HStack(spacing: 8) {
                ForEach(1...9, id: \.self) { number in
                    chapterChip(number: number, onBackground: onBackground)
                }
            }
            .padding(.horizontal, 12)
            .padding(.vertical, 8)
        }
    }

    private func chapterChip(number: Int, onBackground: Color) -> some View {
        let selected = chapter == number
        return Button {
            chapter = number
        } label: {
            Text(chapterTitle(number))
                .font(LabType.label)
                .foregroundStyle(onBackground)
                .padding(.horizontal, 12)
                .padding(.vertical, 8)
                .background(
                    Capsule(style: .continuous)
                        .fill(selected ? LabColor.purple40.opacity(0.22) : Color.clear)
                )
                .overlay(
                    Capsule(style: .continuous)
                        .strokeBorder(onBackground.opacity(selected ? 0.55 : 0.28), lineWidth: 1)
                )
        }
        .buttonStyle(.plain)
    }

    private func chapterTitle(_ number: Int) -> String {
        if number == 1 {
            return "Chapter 1 · iOS baseline"
        }
        if number == 2 {
            return "Chapter 2 · The screen is a grid"
        }
        if number == 3 {
            return "Chapter 3 · Color, opacity, and compositing"
        }
        return "Chapter \(number)"
    }
}

import SwiftUI

private enum RgbPreset: String, CaseIterable {
    case mixed
    case red
    case green
    case blue
    case black
    case white

    var buttonLabel: String {
        switch self {
        case .mixed: return "Mixed"
        case .red: return "Red"
        case .green: return "Green"
        case .blue: return "Blue"
        case .black: return "Black"
        case .white: return "White"
        }
    }

    var red: CGFloat {
        switch self {
        case .mixed: return 0.80
        case .red, .white: return 1
        case .green, .blue, .black: return 0
        }
    }

    var green: CGFloat {
        switch self {
        case .mixed: return 0.25
        case .green, .white: return 1
        case .red, .blue, .black: return 0
        }
    }

    var blue: CGFloat {
        switch self {
        case .mixed: return 0.60
        case .blue, .white: return 1
        case .red, .green, .black: return 0
        }
    }
}

private let firstPresetRow: [RgbPreset] = [.mixed, .red, .green]
private let secondPresetRow: [RgbPreset] = [.blue, .black, .white]

struct RgbChannelsExplorer: View {
    @Environment(\.colorScheme) private var colorScheme
    @State private var red = RgbPreset.mixed.red
    @State private var green = RgbPreset.mixed.green
    @State private var blue = RgbPreset.mixed.blue

    private var redControlColor: Color {
        colorScheme == .dark ? Color(hex: 0xF87171) : Color(hex: 0xDC2626)
    }

    private var greenControlColor: Color {
        colorScheme == .dark ? Color(hex: 0x34D399) : Color(hex: 0x059669)
    }

    private var blueControlColor: Color {
        colorScheme == .dark ? Color(hex: 0x60A5FA) : Color(hex: 0x1E40AF)
    }

    private var finalColor: Color {
        Color(red: red, green: green, blue: blue, opacity: 1)
    }

    private var red8Bit: Int { eightBit(red) }
    private var green8Bit: Int { eightBit(green) }
    private var blue8Bit: Int { eightBit(blue) }

    private var hexadecimal: String {
        String(format: "#%02X%02X%02X", red8Bit, green8Bit, blue8Bit)
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 16) {
            Text("Three channel contributions")
                .font(.system(size: 22, weight: .black))
            Text(
                "Each small swatch keeps one channel and sets the other two to zero. " +
                "The large swatch uses all three values at the same pixel."
            )
            .font(.system(size: 15))

            HStack(spacing: 10) {
                ChannelContributionCard(
                    name: "Red",
                    value: red,
                    swatchColor: Color(red: red, green: 0, blue: 0)
                )
                ChannelContributionCard(
                    name: "Green",
                    value: green,
                    swatchColor: Color(red: 0, green: green, blue: 0)
                )
                ChannelContributionCard(
                    name: "Blue",
                    value: blue,
                    swatchColor: Color(red: 0, green: 0, blue: blue)
                )
            }

            ZStack {
                RoundedRectangle(cornerRadius: 18, style: .continuous)
                    .fill(finalColor)
                    .overlay(
                        RoundedRectangle(cornerRadius: 18, style: .continuous)
                            .strokeBorder(Color(uiColor: .separator), lineWidth: 1)
                    )
                Text(
                    "RGB(\(twoDecimals(red)), \(twoDecimals(green)), \(twoDecimals(blue)))"
                )
                .font(LabType.titleMedium)
                .fontWeight(.black)
                .padding(.horizontal, 12)
                .padding(.vertical, 8)
                .background(
                    RoundedRectangle(cornerRadius: 10, style: .continuous)
                        .fill(Color(uiColor: .systemBackground).opacity(0.92))
                )
            }
            .frame(maxWidth: .infinity)
            .frame(height: 190)
            .accessibilityLabel("Final RGB color \(hexadecimal)")

            VStack(alignment: .leading, spacing: 5) {
                Text(
                    "Normalized RGB = (\(twoDecimals(red)), \(twoDecimals(green)), \(twoDecimals(blue)))"
                )
                .fontWeight(.bold)
                Text("Approximate 8-bit RGB = (\(red8Bit), \(green8Bit), \(blue8Bit))")
                Text("Hexadecimal RGB = \(hexadecimal)")
                Text("Alpha is fixed at 1.00 in this lesson.")
            }
            .font(.system(size: 15))
            .foregroundStyle(Color.primary.opacity(0.78))
            .padding(14)
            .frame(maxWidth: .infinity, alignment: .leading)
            .background(
                RoundedRectangle(cornerRadius: 14, style: .continuous)
                    .fill(Color(uiColor: .secondarySystemFill))
            )

            ChannelSlider(
                label: "Red channel",
                value: $red,
                channelColor: redControlColor
            )
            ChannelSlider(
                label: "Green channel",
                value: $green,
                channelColor: greenControlColor
            )
            ChannelSlider(
                label: "Blue channel",
                value: $blue,
                channelColor: blueControlColor
            )

            Text("Exact presets")
                .font(LabType.titleMedium)
                .fontWeight(.black)
            PresetRow(presets: firstPresetRow, onPresetSelected: applyPreset)
            PresetRow(presets: secondPresetRow, onPresetSelected: applyPreset)
        }
        .padding(18)
        .frame(maxWidth: .infinity, alignment: .leading)
        .background(
            RoundedRectangle(cornerRadius: 22, style: .continuous)
                .fill(Color(uiColor: .systemBackground))
        )
        .overlay(
            RoundedRectangle(cornerRadius: 22, style: .continuous)
                .strokeBorder(Color(uiColor: .separator), lineWidth: 1)
        )
    }

    private func applyPreset(_ preset: RgbPreset) {
        red = preset.red
        green = preset.green
        blue = preset.blue
    }
}

private struct ChannelSlider: View {
    let label: String
    @Binding var value: CGFloat
    let channelColor: Color

    var body: some View {
        VStack(alignment: .leading, spacing: 2) {
            HStack {
                Text(label)
                    .fontWeight(.bold)
                Spacer()
                Text(twoDecimals(value))
                    .fontWeight(.black)
            }
            Slider(value: $value, in: 0...1)
                .tint(channelColor)
                .accessibilityLabel(label)
        }
    }
}

private struct PresetRow: View {
    let presets: [RgbPreset]
    let onPresetSelected: (RgbPreset) -> Void

    var body: some View {
        HStack(spacing: 8) {
            ForEach(presets, id: \.self) { preset in
                Button {
                    onPresetSelected(preset)
                } label: {
                    Text(preset.buttonLabel)
                        .frame(maxWidth: .infinity)
                }
                .buttonStyle(.bordered)
            }
        }
    }
}

private func eightBit(_ value: CGFloat) -> Int {
    Int((min(max(value, 0), 1) * 255).rounded())
}

private func twoDecimals(_ value: CGFloat) -> String {
    String(format: "%.2f", Double(value))
}

private extension Color {
    init(hex: UInt32) {
        self.init(
            red: Double((hex >> 16) & 0xFF) / 255,
            green: Double((hex >> 8) & 0xFF) / 255,
            blue: Double(hex & 0xFF) / 255
        )
    }
}

10 · Exercises
Answer before opening the solutions
Exercise 2 targets the most likely misconception.
Exercise 1 · Read the tuple
For RGB(0.20, 0.70, 0.90), state the red, green, and blue channel values separately.
Answer: red is 0.20, green is 0.70, and blue is 0.90. The position in the ordered tuple gives each number its channel name.
Exercise 2 · Diagnostic: is 0.40 a gray color?
Someone says, “The color is 0.40, so it is gray.” What is missing from that statement?
Answer: one number does not describe a complete RGB color. The statement must name the channel or provide all three channels. RGB(0.40, 0.40, 0.40) is gray because all three channels are equal. A lone 0.40 could be only red, only green, or only blue.
Exercise 3 · Change only red
Start with RGB(0.20, 0.70, 0.90). Change only red to 0.80. What is the new complete tuple, and which values remain unchanged?
Answer: the new color is RGB(0.80, 0.70, 0.90). Green remains 0.70. Blue remains 0.90.
Exercise 4 · Convert the lesson color
Convert RGB(0.80, 0.25, 0.60) to approximate 8-bit channel values using round(channel × 255).
Answer: red is round(0.80 × 255) = 204. Green is round(0.25 × 255) = 64. Blue is round(0.60 × 255) = 153. The approximate 8-bit color is RGB(204, 64, 153), or #CC4099.



11 · Evidence and deferrals
What this lesson proves
Keep the visible model separate from display-hardware details that were not measured.
The browser and iOS app can prove
They can prove that three independent numeric inputs are passed to the matching red, green, and blue arguments, and that changing those inputs changes the displayed swatch.
This lesson does not prove
It does not measure the iPhone 16 Pro panel's physical light output, subpixel layout, calibration, color-management transforms, or human perceived brightness. Those questions require display documentation and measurement tools.
Design conclusion: later tint, blur, and shader code must keep channel order correct. A green-blue swap is a data-mapping defect even when every input number is individually valid.
Theme conclusion: interface chrome may change with the OS theme. Numeric color samples must not be recolored by that theme because doing so would change the data under study.
Official Apple references: SwiftUI Color and SwiftUI Slider.
