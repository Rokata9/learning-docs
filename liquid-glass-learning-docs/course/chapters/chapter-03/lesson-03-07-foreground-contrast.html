Chapter 3 · Lesson 3.7

Foreground contrast

Lesson 3.6 gave us one final opaque background color and one relative-luminance number for that color. This lesson asks one practical question: should a three-dot icon drawn on that background be black or white?

In this lesson, a foreground is the icon drawn above the background. Contrast means the numeric separation between the foreground's relative luminance and the background's relative luminance.

One new mathematical operation

Calculate two contrast ratios

Calculate one ratio for black. Calculate one ratio for white. Choose the larger result. Keep the accessibility target as a separate check.

Known input from Lesson 3.6: background straight sRGB RGBA(0.80, 0.25, 0.60, 1.00) background relative luminance ≈ 0.187759

2 · Define the new output

What a contrast ratio is

The formula consumes two relative-luminance numbers and produces one comparison number.

Input 1

The foreground's relative luminance. Lesson 3.6 explains how that number is calculated from a final opaque color.

Input 2

The background's relative luminance. The current course background produces approximately 0.187759.

Output

One unitless contrast ratio. A larger ratio means stronger numeric separation between the two colors. For example, 4.75:1 means the adjusted lighter quantity is 4.75 times the adjusted darker quantity.

First understand the word “ratio”

A ratio compares two numbers by division.

10 ÷ 2 = 5 Written as a ratio: 5:1

This means the first value is five times the second value.

The fixed value 0.05

The contrast formula adds 0.05 to both luminance values before dividing. This number is fixed by the standard. It is not calculated from the current colors.

Its immediate mathematical role is important: black has luminance 0. Adding 0.05 keeps the denominator above zero, so the calculation never divides by zero. The standard has a deeper viewing-model history for this offset; that derivation is outside this lesson.

Now the formula has defined inputs and output.
contrast ratio = (lighter relative luminance + 0.05) ÷ (darker relative luminance + 0.05)

Lighter means the larger of the two luminance numbers. Darker means the smaller one. The foreground is not always the lighter color, so the formula names the values by size rather than by layer.

Smallest possible result

same color against itself = (L + 0.05) ÷ (L + 0.05) = 1:1

1:1 means the formula found no luminance separation.

Largest possible result

white against black = (1 + 0.05) ÷ (0 + 0.05) = 1.05 ÷ 0.05 = 21:1

21:1 is the maximum result within the 0-to-1 relative-luminance range.

4 · Compare the results

Choose the larger ratio

This is a selection rule, not yet an accessibility threshold.

Current comparison

Diagnostic: do not use a simple 0.50 luminance threshold

The course background has luminance near 0.1878, which is below 0.50. A rule that says “below 0.50 always means white” would choose white.

The two real contrast calculations show that black has the slightly larger ratio for this background. The program should compare the candidate ratios rather than guess from an unrelated 0.50 cutoff.

5 · Separate measurement from policy

“Best of two” and “meets a target” are different questions

A target is a minimum ratio required for a particular kind of content.

Choose the stronger candidate

Compare black and white. Keep the larger ratio.

Non-text icon example

The lesson uses 3.0:1 as a reference target for a meaningful non-text icon against its adjacent background. WCAG 2.2 and Material 3 guidance both use this value in relevant non-text contexts.

Normal-size text example

The lesson also displays 4.5:1 so you can see that a candidate may be the stronger of two and still miss a stricter target.

Do not round before checking a target. Displayed ratios are rounded for reading. The code compares the full calculated number with the target.

7 · Evidence limit for real Liquid Glass

One uniform background color is not a photograph or moving page

The current lesson measures one solid opaque background.

What this lesson proves

Given two final opaque sRGB colors, the lesson can calculate their relative luminances, calculate their contrast ratio, compare black and white candidates, and check fixed targets.

What it does not prove yet

A Liquid Glass icon may sit over text, photographs, gradients, or moving content. Different pixels behind the icon can have different luminance values. Choosing one safe foreground then requires access to the actual background region and a defined sampling or aggregation policy.

Backdrop access and image sampling have not been taught yet. Those operations are deferred to the later rendering and sampling chapters.

@Composable
internal fun ForegroundContrastExplorer(
    modifier: Modifier = Modifier,
) {
    var red by rememberSaveable { mutableFloatStateOf(CourseRed) }
    var green by rememberSaveable { mutableFloatStateOf(CourseGreen) }
    var blue by rememberSaveable { mutableFloatStateOf(CourseBlue) }

    val background = Color(
        red = red,
        green = green,
        blue = blue,
        alpha = 1f,
    )
    val blackMeasurement = measureContrast(
        foreground = Color.Black,
        background = background,
    )
    val whiteMeasurement = measureContrast(
        foreground = Color.White,
        background = background,
    )
    val recommendedForeground = if (
        blackMeasurement.ratio >= whiteMeasurement.ratio
    ) {
        Color.Black
    } else {
        Color.White
    }
    val recommendedLabel = if (recommendedForeground == Color.Black) {
        "black"
    } else {
        "white"
    }

    val halfOpaqueBlack = Color.Black
        .copy(alpha = HalfOpaqueForegroundAlpha)
        .compositeOver(background)
    val halfOpaqueBlackRatio = measureContrast(
        foreground = halfOpaqueBlack,
        background = background,
    )

    val scheme = MaterialTheme.colorScheme

    Surface(
        modifier = modifier.fillMaxWidth(),
        shape = ExplorerShape,
        color = scheme.surface,
        contentColor = scheme.onSurface,
        border = BorderStroke(1.dp, scheme.outlineVariant),
    ) {
        Column(
            modifier = Modifier.padding(18.dp),
            verticalArrangement = Arrangement.spacedBy(18.dp),
        ) {
            LessonSectionTitle(
                number = "1",
                title = "Start with the final opaque background color",
            )
            Text(
                text = "The background is one final visible color. Its alpha is 1.00, " +
                    "so no lower layer can still change it. The practical question is: " +
                    "should a three-dot foreground icon be black or white?",
                style = MaterialTheme.typography.bodyMedium,
            )
            BackgroundControls(
                background = background,
                red = red,
                green = green,
                blue = blue,
                onRedChange = { red = it },
                onGreenChange = { green = it },
                onBlueChange = { blue = it },
                onCourse = {
                    red = CourseRed
                    green = CourseGreen
                    blue = CourseBlue
                },
                onMixed = {
                    red = MixedRed
                    green = MixedGreen
                    blue = MixedBlue
                },
                onPaleYellow = {
                    red = PaleYellow.red
                    green = PaleYellow.green
                    blue = PaleYellow.blue
                },
                onNavy = {
                    red = Navy.red
                    green = Navy.green
                    blue = Navy.blue
                },
                onGray = {
                    red = 0.50f
                    green = 0.50f
                    blue = 0.50f
                },
            )

            LessonSectionTitle(
                number = "2",
                title = "Measure two opaque foreground candidates",
            )
            Text(
                text = "A foreground is the icon or text drawn above the background. " +
                    "This lesson tests two opaque candidates: black and white. Each " +
                    "candidate and the background has one relative-luminance value.",
                style = MaterialTheme.typography.bodyMedium,
            )
            Row(
                modifier = Modifier.fillMaxWidth(),
                horizontalArrangement = Arrangement.spacedBy(12.dp),

                    modifier = Modifier.weight(1f),
                    label = "Black foreground",

                    modifier = Modifier.weight(1f),
                    label = "White foreground",
                    background = background,
                    measurement = whiteMeasurement,
                    recommended = recommendedForeground == Color.White,
                )
            }

            LessonSectionTitle(
                number = "3",
                title = "Calculate one contrast ratio at a time",
            )
            Text(
                text = "A ratio compares two numbers by division. The contrast-ratio " +
                    "formula first names the lighter luminance and the darker " +
                    "luminance. It then adds the fixed value 0.05 to both and divides.",
                style = MaterialTheme.typography.bodyMedium,
            )
            ContrastFormulaCard(
                title = "Black foreground over the current background",
                measurement = blackMeasurement,
            )
            ContrastFormulaCard(
                title = "White foreground over the current background",
                measurement = whiteMeasurement,
            )

            LessonSectionTitle(
                number = "4",
                title = "Compare the two results",

            SelectionCard(

                recommendedLabel = recommendedLabel,

                text = "Choosing the larger ratio and checking an accessibility target " +
                    "are separate decisions. The larger ratio identifies the stronger " +
                    "of these two candidates. A target such as 3.0:1 or 4.5:1 is a " +
                    "separate policy check.",
                style = MaterialTheme.typography.bodyMedium,
            )
            TargetCard(
                black = blackMeasurement,
                white = whiteMeasurement,
            )

            LessonSectionTitle(
                number = "5",
                title = "Alpha acts before contrast measurement",
            )
            Text(
                text = "The main black and white candidates are opaque. If a foreground " +
                    "has alpha below 1.00, first composite it over the background. The " +
                    "visible foreground-region color produced by source-over is then " +
                    "compared with the unchanged background color beside it.",
                style = MaterialTheme.typography.bodyMedium,
            )
            AlphaBridgeCard(
                background = background,
                visibleHalfBlack = halfOpaqueBlack,
                opaqueBlackRatio = blackMeasurement.ratio,
                halfBlackRatio = halfOpaqueBlackRatio.ratio,
            )
        }
    }
}

private fun measureContrast(
    foreground: Color,
    background: Color,
): ContrastMeasurement {
    require(foreground.alpha >= 0.9999f) {
        "Foreground must be the final opaque visible color."
    }
    require(background.alpha >= 0.9999f) {
        "Background must be the final opaque visible color."
    }

    val foregroundLuminance = foreground.luminance()
    val backgroundLuminance = background.luminance()
    val lighter = max(foregroundLuminance, backgroundLuminance)
    val darker = min(foregroundLuminance, backgroundLuminance)
    val ratio = (lighter + ContrastOffset) / (darker + ContrastOffset)

    return ContrastMeasurement(
        foreground = foreground,
        foregroundLuminance = foregroundLuminance,
        backgroundLuminance = backgroundLuminance,
        lighterLuminance = lighter,
        darkerLuminance = darker,
        ratio = ratio,
    )
}

private fun passLabel(ratio: Float, target: Float): String =
    if (ratio >= target) {
        "passes (${ratio.f2()}:1)"
    } else {
        "does not pass (${ratio.f2()}:1)"
    }

@Composable

    Text(
        text = text,
        fontFamily = FontFamily.Monospace,
        style = MaterialTheme.typography.bodySmall,
    )
}

12 · Exercises
Answer before opening the explanations


Exercise 1 · The course background has luminance 0.187759. For a black foreground, which value is lighter and which is darker?
Answer: the background is lighter at 0.187759. Black is darker at 0. The foreground is not automatically the lighter input.


Exercise 2 · Calculate black foreground contrast for the course background.
Answer: (0.187759 + 0.05) ÷ (0 + 0.05) = 0.237759 ÷ 0.05 ≈ 4.7552:1.


Exercise 3 · Diagnostic: the background luminance is below 0.50. Is that enough information to choose white?
Answer: no. Calculate both black and white contrast ratios. For the course background, black is approximately 4.7552:1 and white is approximately 4.4162:1, so black is the stronger candidate despite the background luminance being below 0.50.


Exercise 4 · A black icon has alpha 0.50. Should the contrast calculation use black luminance 0 directly?
Answer: no. Composite the 50% black source over the actual background first. Calculate luminance from the final visible icon-region color. Compare that result with the unchanged background luminance.

What the standard and Android API establish

  • WCAG 2.2 · Understanding Non-text Contrast explains the 3:1 target for required user-interface and graphical information against adjacent colors.
    • 

  • Material Design 3 · Icon button accessibility advises at least 3:1 contrast between an icon and its surface or background.

  • AndroidX Compose · Color.kt is the implementation source for Color.luminance() and Color.compositeOver().
