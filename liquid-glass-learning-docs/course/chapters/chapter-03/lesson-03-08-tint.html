Chapter 3 · Color, opacity, and compositing

Lesson 3.8 — Tint

You already know how a translucent source color is combined with an opaque destination by the source-over operation. This lesson uses that same operation to answer one new practical question: how can a panel gain a controlled blue color influence while the original background color still contributes to the result?

Tint in this lesson: one chosen straight sRGB source color drawn over an existing opaque destination with a chosen source alpha. Other APIs may use the word tint for different blend operations. This lesson teaches one explicit model whose inputs and output are fully visible.
Checkpoint goal

Explain which object is the tint source, which object is the destination, why the tint amount is the source alpha, why the final output remains opaque, and how every output channel is calculated.

1 · Begin with the completed background

The existing color is the destination

No new formula is needed yet.

Known input from Lesson 3.7

Destination straight sRGB RGBA = (0.80, 0.25, 0.60, 1.00)

The destination is the color already present at the drawing position before the new tint layer is drawn. Its alpha is 1.00, so it is opaque.

New practical question

We want the panel to look slightly cooler and more blue. We do not want to discard the existing magenta background completely.

Therefore, the program needs a new color source that contributes only part of the output.

Do not interpret “tint” as a mysterious material property. In this lesson, the tint is a concrete RGBA source value and one source-over operation.

General source-over calculation

The first line calculates output premultiplied red. The second line calculates output alpha. Division by output alpha produces output straight red.

Why the division does not change the number here: the destination alpha is 1.00, so output alpha is also 1.00. Dividing output premultiplied red by 1.00 returns the same numeric red value.

Live proof of what “moves toward” means

For one channel, the tint operation can be written in a second form:

output = tint × amount + base × (1 − amount) = base + amount × (tint − base)

The full channel gap is tint − base. A negative gap points toward a lower channel value. A positive gap points toward a higher channel value. Multiplying that gap by an amount from 0 through 1 selects between none and all of the gap. The output therefore stays between the base value and the tint value.

Result

The output remains opaque even when the tint source is translucent. Tint amount controls the mix in this operation. It does not make the completed panel transparent.

6 · Keep nearby ideas separate

Tint changes RGB through a chosen color source

Tint

Draw a chosen color source over the destination with a chosen alpha. The output channels move toward that source color.

Replacement

At tint alpha 1.00, the destination contribution becomes zero. The tint source completely replaces the destination.

Relative luminance

Luminance is a measurement calculated after the tint output exists. Luminance does not add the tint.

Saturation

Lesson 3.9 will transform one existing color by moving its red, green, and blue channels closer to or farther from a calculated gray reference. It will not draw a tint source over a destination.

Boundary case

At tint amount 0, output RGB equals base RGB. The old and recalculated luminance values then agree because the input did not change.

What “do not reuse” means: keep the old number if you still need to describe the old base color. Do not attach that old number to the new tinted color. Calculate a new number from the new RGB input.
8 · Evidence limit

This is a uniform-color tint model

What this lesson establishes

A known straight sRGB tint source can be drawn over a known opaque destination with source-over. The browser and Swift calculate the resulting RGBA channels explicitly.

What remains later

A complete Liquid Glass material may tint a backdrop that has already been blurred, displaced, or refracted. Those backdrop operations have not been built yet. This lesson does not claim Apple's private render order or that every iOS API named “tint” uses this exact source-over model.

private struct Swatch: View {
    let title: String
    let color: Color
    let checkerboard: Bool
    let details: String

    var body: some View {
        VStack(alignment: .leading, spacing: 6) {
            Text(title)
                .fontWeight(.black)
            ZStack {
                if checkerboard {
                    Canvas { context, size in
                        let cell: CGFloat = 24
                        var y: CGFloat = 0
                        var row = 0
                        while y < size.height {
                            var x: CGFloat = 0
                            var column = 0
                            while x < size.width {
                                let light = (row + column) % 2 == 0
                                context.fill(
                                    Path(
                                        CGRect(x: x, y: y, width: cell, height: cell)
                                    ),
                                    with: .color(
                                        light
                                            ? Color(hex: 0xE2E8F0)
                                            : Color(hex: 0x94A3B8)
                                    )
                                )
                                x += cell
                                column += 1
                            }
                            y += cell
                            row += 1
                        }
                    }
                }
                color
                Text(details)
                    .font(.system(size: 13, design: .monospaced))
                    .fontWeight(.bold)
                    .padding(.horizontal, 12)
                    .padding(.vertical, 8)
                    .background(

                    )

private struct MovementProofRow: View {
    let label: String
    let base: CGFloat
    let tint: CGFloat
    let amount: CGFloat
    let output: CGFloat

    private var fullGap: CGFloat { tint - base }
    private var selectedChange: CGFloat { amount * fullGap }

private struct StraightRgba {
    let red: CGFloat
    let green: CGFloat
    let blue: CGFloat
    let alpha: CGFloat
}

private func contrastRatio(
    _ foreground: Color,
    _ background: Color
) -> CGFloat {
    let foregroundLuminance = foreground.luminance()
    let backgroundLuminance = background.luminance()
    let lighter = max(foregroundLuminance, backgroundLuminance)
    let darker = min(foregroundLuminance, backgroundLuminance)
    return (lighter + contrastOffset) / (darker + contrastOffset)
}

private func decodeSrgbChannel(_ encoded: CGFloat) -> CGFloat {
    let safeEncoded = min(max(encoded, 0), 1)
    if safeEncoded <= 0.04045 {
        return safeEncoded / 12.92
    }
    return CGFloat(pow(Double((safeEncoded + 0.055) / 1.055), 2.4))
}

private func calculateRelativeLuminance(
    red: CGFloat,
    green: CGFloat,
    blue: CGFloat
) -> CGFloat {
    0.2126 * decodeSrgbChannel(red)
        + 0.7152 * decodeSrgbChannel(green)
        + 0.0722 * decodeSrgbChannel(blue)
}

private func fourDecimals(_ value: CGFloat) -> String {
    String(format: "%.4f", Double(value))
}

private func sixDecimals(_ value: CGFloat) -> String {
    String(format: "%.6f", Double(value))
}

private func signed4(_ value: CGFloat) -> String {
    let normalized = abs(value) < 0.00005 ? 0 : value
    return String(format: "%+.4f", Double(normalized))
}

private extension Color {
    init(hex: UInt32) {
        self.init(
            red: Double((hex >> 16) & 0xFF) / 255,
            green: Double((hex >> 8) & 0xFF) / 255,
            blue: Double(hex & 0xFF) / 255
        )
    }

    func toStraightRgba() -> StraightRgba {
        var red: CGFloat = 0
        var green: CGFloat = 0
        var blue: CGFloat = 0
        var alpha: CGFloat = 0
        guard UIColor(self).getRed(&red, green: &green, blue: &blue, alpha: &alpha) else {
            return StraightRgba(red: 0, green: 0, blue: 0, alpha: 0)
        }
        return StraightRgba(red: red, green: green, blue: blue, alpha: alpha)
    }

    func rgbaText() -> String {
        let rgba = toStraightRgba()
        return "RGBA(\(fourDecimals(rgba.red)), \(fourDecimals(rgba.green)), " +
            "\(fourDecimals(rgba.blue)), \(fourDecimals(rgba.alpha)))"
    }

    func hasSameRgb(_ other: Color) -> Bool {
        let tolerance: CGFloat = 0.00005
        let lhs = toStraightRgba()
        let rhs = other.toStraightRgba()
        return abs(lhs.red - rhs.red) <= tolerance
            && abs(lhs.green - rhs.green) <= tolerance
            && abs(lhs.blue - rhs.blue) <= tolerance
    }

    func compositeOver(_ destination: Color) -> Color {
        let source = toStraightRgba()
        let dest = destination.toStraightRgba()
        let destinationOpening = 1 - source.alpha
        let outputAlpha = source.alpha + dest.alpha * destinationOpening
        let outputPremultipliedRed =
            source.red * source.alpha + dest.red * dest.alpha * destinationOpening
        let outputPremultipliedGreen =
            source.green * source.alpha + dest.green * dest.alpha * destinationOpening
        let outputPremultipliedBlue =
            source.blue * source.alpha + dest.blue * dest.alpha * destinationOpening
        if outputAlpha <= 0 {
            return Color(red: 0, green: 0, blue: 0, opacity: 0)
        }
        return Color(
            red: min(max(outputPremultipliedRed / outputAlpha, 0), 1),
            green: min(max(outputPremultipliedGreen / outputAlpha, 0), 1),
            blue: min(max(outputPremultipliedBlue / outputAlpha, 0), 1),
            opacity: min(max(outputAlpha, 0), 1)
        )
    }

    func luminance() -> CGFloat {
        let rgba = toStraightRgba()
        return calculateRelativeLuminance(
            red: rgba.red,
            green: rgba.green,
            blue: rgba.blue
        )
    }
}

13 · Sources and evidence limits
What the SwiftUI contract and lab helpers establish


    

  • Apple Developer · SwiftUI Color documents Color(red:green:blue:opacity:) as 0...1 components stored separately from opacity.
    • 

  • Apple Developer · SwiftUI BlendMode defines BlendMode.normal as drawing the source over the destination.
    • 

  • The lab helpers compositeOver() and luminance() copy the straight-RGBA source-over formula and the sRGB Rec.709 luminance path taught in Lessons 3.3 and 3.6. SwiftUI Color has no luminance API of its own.
    • 



Evidence limit: these sources establish the SwiftUI color object and the lab compositing helpers. They do not establish Apple's private Liquid Glass tint order or prove that every API named “tint” performs source-over.







14 · Exercises
Answer before opening the hidden result


Exercise 1 · Calculate the default red output
Use tint red 0.20, tint alpha 0.25, destination red 0.80, and destination alpha 1.00.
Answer: output premultiplied red is 0.20 × 0.25 + 0.80 × 1.00 × 0.75 = 0.05 + 0.60 = 0.65. Output alpha is 1.00, so output straight red is also 0.65.


Exercise 2 · Diagnostic: what is the final alpha?
The tint source alpha is 0.25. The destination alpha is 1.00. Is the output alpha 0.25 or 1.00?
Answer: 1.00. The source contributes 0.25 alpha and the opaque destination contributes the remaining 0.75. The tint amount is not the final output opacity.


Exercise 3 · Diagnostic: why is the old luminance stale?
The base RGB is (0.80, 0.25, 0.60) and its luminance is approximately 0.187759. Tinting produces output RGB (0.65, 0.35, 0.70). Why can the program not label the new output with 0.187759 without calculating again?
Answer: 0.187759 was calculated from the old RGB triplet. Relative luminance is derived from RGB, so a different RGB triplet requires a new calculation. The new output luminance is approximately 0.185009.


Exercise 4 · Prove one “moves toward” result
A base channel is 0.40, the tint channel is 0.10, and tint amount is 0.30. Does the output increase or decrease? Calculate it with output = base + amount × (tint − base).
Answer: full gap is 0.10 − 0.40 = −0.30. Selected change is 0.30 × −0.30 = −0.09. Output is 0.40 + (−0.09) = 0.31. It decreases because the selected change is negative.
