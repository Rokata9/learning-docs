Chapter 3 · Color, opacity, and compositing

Lesson 3.8 — Tint

You already know how a translucent source color is combined with an opaque destination by the source-over operation. This lesson uses that same operation to answer one new practical question: how can a panel gain a controlled blue color influence while the original background color still contributes to the result?

Tint in this lesson: one chosen straight sRGB source color drawn over an existing opaque destination with a chosen source alpha. Other APIs may use the word tint for different blend operations. This lesson teaches one explicit model whose inputs and output are fully visible.
Checkpoint goal

Explain which object is the tint source, which object is the destination, why the tint amount is the source alpha, why the final output remains opaque, and how every output channel is calculated.

1 · Begin with the completed background

The existing color is the destination

No new formula is needed yet.

Known input from Lesson 3.7

Destination straight sRGB RGBA = (0.80, 0.25, 0.60, 1.00)

The destination is the color already present at the drawing position before the new tint layer is drawn. Its alpha is 1.00, so it is opaque.

New practical question

We want the panel to look slightly cooler and more blue. We do not want to discard the existing magenta background completely.

Therefore, the program needs a new color source that contributes only part of the output.

Do not interpret “tint” as a mysterious material property. In this lesson, the tint is a concrete RGBA source value and one source-over operation.

3 · Trace one channel completely

Calculate the red output before repeating the operation

The general source-over formula is reused from Lesson 3.3.

Exact inputs for red

The tint red value and the destination red value are straight sRGB channel values. Neither has been multiplied by alpha yet.

General source-over calculation

The first line calculates output premultiplied red. The second line calculates output alpha. Division by output alpha produces output straight red.

Why the division does not change the number here: the destination alpha is 1.00, so output alpha is also 1.00. Dividing output premultiplied red by 1.00 returns the same numeric red value.
4 · Repeat the understood operation

Red, green, and blue move toward the tint color

Each channel uses its own tint value and its own destination value.

“Moves toward” has an exact channel meaning. When the tint channel is lower than the destination channel, the output channel decreases. When the tint channel is higher, the output channel increases. The output is not required to move every channel in the same direction. The empty part of each contribution track is only the remaining numeric distance up to channel value 1.00. It is not transparency.
5 · Interpret the tint amount

The tint source alpha is not the final output alpha

The opaque destination fills the portion left open by the tint source.

0% tint amount

tint contribution = 0 base contribution = 1 output = base color

25% tint amount

tint contribution = 0.25 base contribution = 0.75 both colors affect output

100% tint amount

tint contribution = 1 base contribution = 0 output = tint color

General output-alpha formula

Result

The output remains opaque even when the tint source is translucent. Tint amount controls the mix in this operation. It does not make the completed panel transparent.

6 · Keep nearby ideas separate

Tint changes RGB through a chosen color source

Tint

Draw a chosen color source over the destination with a chosen alpha. The output channels move toward that source color.

Replacement

At tint alpha 1.00, the destination contribution becomes zero. The tint source completely replaces the destination.

Relative luminance

Luminance is a measurement calculated after the tint output exists. Luminance does not add the tint.

Saturation

Lesson 3.9 will change how colorful a color is. It will not begin by drawing one chosen tint RGB source over the destination.

Order: calculate the tint output first. Then decode that output color for relative luminance. Then calculate contrast. Do not reuse the untinted luminance after the RGB values have changed.
8 · Evidence limit

This is a uniform-color tint model

What this lesson establishes

A known straight sRGB tint source can be drawn over a known opaque destination with source-over. The browser and Kotlin calculate the resulting RGBA channels explicitly.

What remains later

A complete Liquid Glass material may tint a backdrop that has already been blurred, displaced, or refracted. Those backdrop operations have not been built yet. This lesson does not claim Apple's private render order or that every Android API named “tint” uses this exact source-over model.

@Composable
internal fun TintExplorer(
    modifier: Modifier = Modifier,
) {
    var tintRed by rememberSaveable { mutableFloatStateOf(InitialTintRed) }
    var tintGreen by rememberSaveable { mutableFloatStateOf(InitialTintGreen) }
    var tintBlue by rememberSaveable { mutableFloatStateOf(InitialTintBlue) }
    var tintAmount by rememberSaveable { mutableFloatStateOf(InitialTintAmount) }

    val baseColor = Color(
        red = BaseRed,
        green = BaseGreen,
        blue = BaseBlue,
        alpha = 1f,
    )
    val opaqueTintColor = Color(
        red = tintRed,
        green = tintGreen,
        blue = tintBlue,
        alpha = 1f,
    )
    val tintSource = opaqueTintColor.copy(alpha = tintAmount)
    val outputColor = tintSource.compositeOver(baseColor)

    val blackContrastBefore = contrastRatio(Color.Black, baseColor)
    val whiteContrastBefore = contrastRatio(Color.White, baseColor)
    val blackContrastAfter = contrastRatio(Color.Black, outputColor)
    val whiteContrastAfter = contrastRatio(Color.White, outputColor)

    val scheme = MaterialTheme.colorScheme

    Surface(
        modifier = modifier.fillMaxWidth(),
        shape = ExplorerShape,
        color = scheme.surface,
        contentColor = scheme.onSurface,
        border = BorderStroke(1.dp, scheme.outlineVariant),
    ) {
        Column(
            modifier = Modifier.padding(18.dp),
            verticalArrangement = Arrangement.spacedBy(18.dp),
        ) {
            SectionTitle(
                number = "1",
                title = "Start with one final opaque background color",
            )
            Text(
                text = "The course background is straight sRGB RGBA(0.80, 0.25, " +
                    "0.60, 1.00). The new question is: how can the program give this " +
                    "background a controlled blue influence while keeping the original " +
                    "background color in the result?",
                style = MaterialTheme.typography.bodyMedium,
            )
            LayerPreviewCard(
                baseColor = baseColor,
                tintSource = tintSource,
                outputColor = outputColor,
            )

            SectionTitle(
                number = "2",
                title = "Choose the tint color and tint amount",
            )
            Text(
                text = "This lesson defines a tint layer as one source color drawn over " +
                    "the existing background with source-over. The tint amount is the " +
                    "source alpha used by that one draw operation. It is not the final " +
                    "output alpha.",
                style = MaterialTheme.typography.bodyMedium,
            )
            TintControls(
                red = tintRed,
                green = tintGreen,
                blue = tintBlue,
                amount = tintAmount,
                onRedChange = { tintRed = it },
                onGreenChange = { tintGreen = it },
                onBlueChange = { tintBlue = it },
                onAmountChange = { tintAmount = it },
                onCoolBlue = {
                    tintRed = 0.20f
                    tintGreen = 0.65f
                    tintBlue = 1.00f
                },
                onWarmAmber = {
                    tintRed = 1.00f
                    tintGreen = 0.62f
                    tintBlue = 0.20f
                },
                onGreen = {
                    tintRed = 0.16f
                    tintGreen = 0.78f
                    tintBlue = 0.46f
                },
                onWhite = {
                    tintRed = 1.00f
                    tintGreen = 1.00f
                    tintBlue = 1.00f
                },
            )

            SectionTitle(
                number = "3",
                title = "Reuse source-over for each color channel",
            )
            Text(
                text = "The destination is opaque. Therefore the output is also opaque. " +
                    "For each channel, the tint source contributes tint amount, and the " +
                    "background contributes the remaining amount.",
                style = MaterialTheme.typography.bodyMedium,
            )
            ChannelCalculationCard(
                label = "Red",
                tintChannel = tintRed,
                baseChannel = BaseRed,
                amount = tintAmount,
                outputChannel = outputColor.red,
                accent = Color(0xFFDC2626),
            )
            ChannelCalculationCard(
                label = "Green",
                tintChannel = tintGreen,
                baseChannel = BaseGreen,
                amount = tintAmount,
                outputChannel = outputColor.green,
                accent = Color(0xFF059669),
            )
            ChannelCalculationCard(
                label = "Blue",
                tintChannel = tintBlue,
                baseChannel = BaseBlue,
                amount = tintAmount,
                outputChannel = outputColor.blue,
                accent = Color(0xFF2563EB),
            )

            SectionTitle(
                number = "4",
                title = "Tint amount is not final output opacity",
            )
            Text(
                text = "The tint source can be translucent while the result remains " +
                    "opaque. The base alpha is 1.00, so it fills every part left open by " +
                    "the tint source.",
                style = MaterialTheme.typography.bodyMedium,
            )
            OutputAlphaCard(tintAmount = tintAmount)

            SectionTitle(
                number = "5",
                title = "Recalculate luminance and contrast after tinting",
            )
            Text(
                text = "Tint changes the final visible RGB channels. Relative luminance " +
                    "and foreground contrast must therefore use the tinted output color, " +
                    "not the earlier untinted background color.",
                style = MaterialTheme.typography.bodyMedium,
            )
            MeasurementCard(
                baseColor = baseColor,
                outputColor = outputColor,
                blackContrastBefore = blackContrastBefore,
                whiteContrastBefore = whiteContrastBefore,
                blackContrastAfter = blackContrastAfter,
                whiteContrastAfter = whiteContrastAfter,
            )
        }
    }
}

@Composable
private fun Swatch(
    title: String,
    color: Color,
    checkerboard: Boolean,
    details: String,
) {
    Column(verticalArrangement = Arrangement.spacedBy(6.dp)) {
        Text(title, fontWeight = FontWeight.Black)
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(112.dp),
            contentAlignment = Alignment.Center,
        ) {
            Canvas(modifier = Modifier.fillMaxSize()) {
                if (checkerboard) {
                    val cell = 24.dp.toPx()
                    var y = 0f
                    var row = 0
                    while (y < size.height) {
                        var x = 0f
                        var column = 0
                        while (x < size.width) {
                            drawRect(
                                color = if ((row + column) % 2 == 0) {
                                    Color(0xFFE2E8F0)
                                } else {
                                    Color(0xFF94A3B8)
                                },
                                topLeft = Offset(x, y),
                                size = Size(cell, cell),
                            )
                            x += cell
                            column += 1
                        }
                        y += cell
                        row += 1
                    }
                }
                drawRect(color)
            }
            Surface(
                shape = RoundedCornerShape(12.dp),
                color = MaterialTheme.colorScheme.surface.copy(alpha = 0.92f),
                contentColor = MaterialTheme.colorScheme.onSurface,
            ) {
                Text(
                    text = details,
                    modifier = Modifier.padding(horizontal = 12.dp, vertical = 8.dp),
                    fontFamily = FontFamily.Monospace,
                    fontWeight = FontWeight.Bold,
                )
            }
        }
    }
}

@Composable
private fun ChannelCalculationCard(
    label: String,
    tintChannel: Float,
    baseChannel: Float,
    amount: Float,
    outputChannel: Float,
    accent: Color,
) {
    val remaining = 1f - amount
    val tintContribution = tintChannel * amount
    val baseContribution = baseChannel * remaining
    val scheme = MaterialTheme.colorScheme

    Surface(
        shape = CardShape,
        color = scheme.surfaceContainer,
        border = BorderStroke(1.dp, scheme.outlineVariant),
    ) {
        Column(
            modifier = Modifier.padding(14.dp),
            verticalArrangement = Arrangement.spacedBy(8.dp),
        ) {
            Text(label, color = accent, fontWeight = FontWeight.Black)
            Text(
                text = "tint channel × tint amount + base channel × remaining amount",
                style = MaterialTheme.typography.bodySmall,
            )
            Text(
                text = "${tintChannel.f4()} × ${amount.f4()} + " +
                    "${baseChannel.f4()} × ${remaining.f4()}",
                fontFamily = FontFamily.Monospace,
            )
            Text(
                text = "${tintContribution.f4()} + ${baseContribution.f4()} " +
                    "= ${outputChannel.f4()}",
                fontFamily = FontFamily.Monospace,
                fontWeight = FontWeight.Black,
            )
        }
    }
}

@Composable
private fun OutputAlphaCard(tintAmount: Float) {
    val baseAlpha = 1f
    val outputAlpha = tintAmount + baseAlpha * (1f - tintAmount)
    val scheme = MaterialTheme.colorScheme

    Surface(
        shape = CardShape,
        color = scheme.primaryContainer,
        contentColor = scheme.onPrimaryContainer,
        border = BorderStroke(1.dp, scheme.primary),
    ) {
        Column(
            modifier = Modifier.padding(14.dp),
            verticalArrangement = Arrangement.spacedBy(8.dp),
        ) {
            Text("General source-over alpha", fontWeight = FontWeight.Black)
            Text(
                text = "output alpha = tint alpha + base alpha × (1 − tint alpha)",
                fontFamily = FontFamily.Monospace,
            )
            Text(
                text = "${tintAmount.f4()} + 1.0000 × (1 − ${tintAmount.f4()}) " +
                    "= ${outputAlpha.f4()}",
                fontFamily = FontFamily.Monospace,
                fontWeight = FontWeight.Black,
            )
            Text(
                text = "The output alpha stays 1.0000 because the opaque base fills " +
                    "every portion not covered by the tint source.",
            )
        }
    }
}

@Composable
private fun MeasurementCard(
    baseColor: Color,
    outputColor: Color,
    blackContrastBefore: Float,
    whiteContrastBefore: Float,
    blackContrastAfter: Float,
    whiteContrastAfter: Float,
) {
    val scheme = MaterialTheme.colorScheme
    val beforeWinner = if (blackContrastBefore >= whiteContrastBefore) "black" else "white"
    val afterWinner = if (blackContrastAfter >= whiteContrastAfter) "black" else "white"

    Surface(
        shape = CardShape,
        color = scheme.surfaceContainer,
        border = BorderStroke(1.dp, scheme.outlineVariant),
    ) {
        Column(
            modifier = Modifier.padding(14.dp),
            verticalArrangement = Arrangement.spacedBy(8.dp),
        ) {
            Text("Before tint", fontWeight = FontWeight.Black)
            Text(
                text = "luminance = ${baseColor.luminance().f6()} · " +
                    "black = ${blackContrastBefore.f4()}:1 · " +
                    "white = ${whiteContrastBefore.f4()}:1 · winner = $beforeWinner",
                fontFamily = FontFamily.Monospace,
            )
            Text("After tint", fontWeight = FontWeight.Black)
            Text(
                text = "luminance = ${outputColor.luminance().f6()} · " +
                    "black = ${blackContrastAfter.f4()}:1 · " +
                    "white = ${whiteContrastAfter.f4()}:1 · winner = $afterWinner",
                fontFamily = FontFamily.Monospace,
            )
        }
    }
}

private fun contrastRatio(
    foreground: Color,
    background: Color,
): Float {
    val foregroundLuminance = foreground.luminance()
    val backgroundLuminance = background.luminance()
    val lighter = max(foregroundLuminance, backgroundLuminance)
    val darker = minOf(foregroundLuminance, backgroundLuminance)
    return (lighter + ContrastOffset) / (darker + ContrastOffset)
}

private fun Color.rgbaText(): String {
    return "RGBA(${red.f4()}, ${green.f4()}, ${blue.f4()}, ${alpha.f4()})"
}

private fun Float.f4(): String = String.format(Locale.US, "%.4f", this)
private fun Float.f6(): String = String.format(Locale.US, "%.6f", this)

14 · Exercises
Answer before opening the hidden result


Exercise 1 · Calculate the default red output
Use tint red 0.20, tint alpha 0.25, destination red 0.80, and destination alpha 1.00.
Answer: output premultiplied red is 0.20 × 0.25 + 0.80 × 1.00 × 0.75 = 0.05 + 0.60 = 0.65. Output alpha is 1.00, so output straight red is also 0.65.


Exercise 2 · Diagnostic: what is the final alpha?
The tint source alpha is 0.25. The destination alpha is 1.00. Is the output alpha 0.25 or 1.00?
Answer: 1.00. The source contributes 0.25 alpha and the opaque destination contributes the remaining 0.75. The tint amount is not the final output opacity.


Exercise 3 · Which operation happens first?
Do we calculate relative luminance before tinting or after tinting?
Answer: after tinting. Source-over first produces the final visible output RGB. The output RGB is then decoded and measured.


Exercise 4 · Why does draw order matter?
Would background.copy(alpha = amount).compositeOver(tintColor) generally produce the same color?
Answer: no. It makes the background the source and the tint color the destination. Source-over is not commutative, so exchanging the roles generally changes the output RGB.
