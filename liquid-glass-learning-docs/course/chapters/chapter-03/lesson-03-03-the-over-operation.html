Chapter 3 · Color, opacity, and compositing

The “over” operation

The source is the color being drawn now. The destination is the color already present at the same image position. The source-over operation combines both into one output RGBA value.

This lesson calculates one image position. No neighboring position is sampled. Blur and refraction still do not occur.

Lesson goal

By the end, you should be able to:

  • name the source, destination, and output in one draw operation;
  • calculate the destination contribution weight destination alpha × (1 − source alpha);
  • calculate output alpha and all three output color channels;
  • explain why an output with alpha below 1 can still be an intermediate layer.
Theme behavior: interface chrome follows the OS setting. The source, destination, checkerboard, and calculated output remain exact teaching data in both modes.
1 · Vocabulary

Three roles in one drawing operation

The role names are relative to this specific operation.

Source

The source is the color being drawn now. In the course example it is RGBA(0.90, 0.10, 0.80, 0.50).

Destination

The destination is the color already present at the same image position. It is RGBA(0.10, 0.90, 0.40, 0.60).

Output

The output is the new RGBA value produced by combining source over destination. For the course example it becomes RGBA(0.60, 0.40, 0.65, 0.80).

source over destination → output
Role, not identity: an object is not permanently “the destination.” It is the destination only while another source is being drawn into the image that already contains it.

Main diagnostic: 1 − source alpha describes the area left open by the source. The destination can contribute only through that opening and only by its own alpha. Therefore the destination weight is destination alpha × (1 − source alpha).
Precise representation names used from Lesson 3.5 onward: the channel sums called output premultiplied RGB already include alpha weighting. Dividing those sums by output alpha produces output straight RGB. The older labels “weighted total” and “ordinary output” are no longer used.
3 · Course example

Calculate both translucent layers completely

Every number below comes from the default source and destination shown in the laboratory.

1. Contribution weights

source weight = Aₛ = 0.50
destination weight = Aᵈ × (1 − Aₛ)
= 0.60 × (1 − 0.50)
= 0.60 × 0.50
= 0.30

The source uses 0.50 of the output coverage. The destination survives through another 0.30.

2. Output alpha

output alpha = 0.50 + 0.30 = 0.80

The remaining transparent part is 1 − 0.80 = 0.20. The output of this operation is still translucent.

Red

0.90 × 0.50 + 0.10 × 0.30
= 0.45 + 0.03
= 0.48 weighted
0.48 ÷ 0.80 = 0.60

Green

0.10 × 0.50 + 0.90 × 0.30
= 0.05 + 0.27
= 0.32 weighted
0.32 ÷ 0.80 = 0.40

Blue

0.80 × 0.50 + 0.40 × 0.30
= 0.40 + 0.12
= 0.52 weighted
0.52 ÷ 0.80 = 0.65
Complete output: RGBA(0.60, 0.40, 0.65, 0.80). The approximate 8-bit tuple is (153, 102, 166, 204).

5 · Special cases
Pressure-test the formula at the boundaries
A useful formula should produce sensible results at alpha 0 and alpha 1.
Source alpha 0
The source weight is 0. The destination survives unchanged. Output equals destination.
Source alpha 1
No opening remains behind the source. Destination weight is 0. Output equals source and is opaque.
Destination alpha 1
The destination weight becomes 1 − source alpha. This is the simpler formula used with an opaque background.
Both alphas 0
Output alpha is 0. Division by output alpha is not allowed. The implementation returns transparent black as a safe result value.
Testing trap: if you test only with an opaque destination, the defective destination weight 1 − source alpha appears correct. A translucent destination is required to expose the missing destination-alpha multiplication.

3 · Source weight
The source contribution weight is its alpha.
sourceWeight =
  source.alpha
// 0.50
4 · Destination weight
The destination survives only through the source opening and by its own alpha.
destinationWeight =
  destination.alpha *
  (1 - source.alpha)
// 0.30
5 · Output alpha
Add the two surviving coverage contributions.
outputAlpha =
  sourceWeight +
  destinationWeight
// 0.80
6 · Premultiplied RGB
Each channel receives a source contribution and a destination contribution.
weightedRed =
  .90 * .50 +
  .10 * .30
// 0.48
7 · Straight RGBA
Divide premultiplied RGB by output alpha when output alpha is greater than zero.
red = .48 / .80
// 0.60
output = RGBA(
  .60, .40, .65, .80
)

private struct OverStraightRgba {
    let red: CGFloat
    let green: CGFloat
    let blue: CGFloat
    let alpha: CGFloat

    func toColor() -> Color {
        Color(red: red, green: green, blue: blue, opacity: alpha)
    }

    func asTuple() -> String {
        "RGBA(\(twoDecimals(red)), \(twoDecimals(green)), " +
            "\(twoDecimals(blue)), \(twoDecimals(alpha)))"
    }
}

private struct OverSourceOverCalculation {
    let sourceContributionAlpha: CGFloat
    let destinationContributionAlpha: CGFloat
    let outputPremultipliedRed: CGFloat
    let outputPremultipliedGreen: CGFloat
    let outputPremultipliedBlue: CGFloat
    let outputStraight: OverStraightRgba
}

private func calculateSourceOver(
    source: OverStraightRgba,
    destination: OverStraightRgba
) -> OverSourceOverCalculation {
    let sourceContributionAlpha = source.alpha
    let destinationContributionAlpha = destination.alpha * (1 - source.alpha)
    let outputAlpha = sourceContributionAlpha + destinationContributionAlpha

    let outputPremultipliedRed =
        source.red * sourceContributionAlpha +
        destination.red * destinationContributionAlpha
    let outputPremultipliedGreen =
        source.green * sourceContributionAlpha +
        destination.green * destinationContributionAlpha
    let outputPremultipliedBlue =
        source.blue * sourceContributionAlpha +
        destination.blue * destinationContributionAlpha

    let outputStraight: OverStraightRgba
    if outputAlpha <= 0 {
        outputStraight = OverStraightRgba(
            red: 0,
            green: 0,
            blue: 0,
            alpha: 0
        )
    } else {
        outputStraight = OverStraightRgba(
            red: outputPremultipliedRed / outputAlpha,
            green: outputPremultipliedGreen / outputAlpha,
            blue: outputPremultipliedBlue / outputAlpha,
            alpha: outputAlpha
        )
    }

    return OverSourceOverCalculation(
        sourceContributionAlpha: sourceContributionAlpha,
        destinationContributionAlpha: destinationContributionAlpha,
        outputPremultipliedRed: outputPremultipliedRed,
        outputPremultipliedGreen: outputPremultipliedGreen,
        outputPremultipliedBlue: outputPremultipliedBlue,
        outputStraight: outputStraight
    )
}

private func drawCheckerboard(
    context: GraphicsContext,
    size: CGSize,
    cellSize: CGFloat
) {
    let columnCount = Int(ceil(size.width / cellSize))
    let rowCount = Int(ceil(size.height / cellSize))
    for row in 0..<rowCount {
        for column in 0..<columnCount {
            let cellColor = (row + column).isMultiple(of: 2) ? checkerLight : checkerDark
            let rect = CGRect(
                x: CGFloat(column) * cellSize,
                y: CGFloat(row) * cellSize,
                width: cellSize,
                height: cellSize
            )
            context.fill(Path(rect), with: .color(cellColor))
        }
    }
}

private func twoDecimals(_ value: CGFloat) -> String {
    String(format: "%.2f", Double(value))
}

10 · Exercises
Answer before opening the details
The second question targets the most likely source-over mistake.
Exercise 1 — Course-example output alpha
Source alpha is 0.50. Destination alpha is 0.60. What are the destination contribution weight and output alpha?
Answer: Destination weight is 0.60 × (1 − 0.50) = 0.30. Output alpha is 0.50 + 0.30 = 0.80.
Exercise 2 — Diagnostic: why is 1 − source alpha incomplete?
Why is 1 − source alpha alone not the destination contribution weight when the destination is translucent?
Answer: It measures only the opening left by the source. The destination itself occupies only its alpha share of that opening. The complete weight is destination alpha × (1 − source alpha).
Exercise 3 — Opaque destination
Source alpha is 0.25 and destination alpha is 1.00. What is output alpha?
Answer: Destination weight is 1.00 × (1 − 0.25) = 0.75. Output alpha is 0.25 + 0.75 = 1.00.
Exercise 4 — Both inputs fully transparent
Why must the code check output alpha before dividing premultiplied RGB by it?
Answer: When both alphas are zero, output alpha is zero. Division by zero is undefined. The lesson implementation returns a fully transparent result instead.



11 · Evidence and deferrals
What this lesson supports
Separate the source-over structure from renderer details that are not measured here.
Supported by the code and experiment
The lesson shows the exact normalized inputs used by the Swift function, every intermediate contribution, the calculated output, and an explicit BlendMode.normal drawing of the same two layers.
Deferred details
Lesson 3.4 reverses drawing order. Lesson 3.5 names straight RGBA, premultiplied RGBA, output premultiplied RGB, and output straight RGB. The transparent-edge artifact is deferred until the course teaches the image-sampling operation that creates new edge values. Color-space transfer functions and device precision are also outside this calculation.
Evidence limit: visual agreement between the two cards is not a byte-for-byte GPU-memory test. Exact device values can be affected by color-space conversion, quantization, and later display processing. Those details do not change which source and destination contribution factors belong in source-over.
