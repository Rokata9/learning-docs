Chapter 6 · How Android draws the scene

Lesson 6.3 — Graphics layers

Lesson 6.2 gave one owner several draw commands. This lesson groups those commands into one draw layer so translation, rotation, scale, alpha, and later effects can be applied to the complete owner as one unit.

Practical problem: the panel base, stripe, status dot, and label must move and fade together. Updating every draw command separately would duplicate transformation logic and make later effects harder to attach consistently.

The boundary to keep

graphics layer = one renderer-owned group of drawing instructions not automatically = one stored pixel image not automatically = a readable copy of sibling backdrop pixels
0 · PREREQUISITE LEDGER

Name every object before the first layer property

Only the draw-layer terms are new.

Owner node

LayerArtwork is one Compose node that owns the panel base, stripe, dot, and label.

Drawing instructions

Commands such as “draw rounded rectangle” and “draw dot.” They describe what the owner paints.

Draw layer

A container owned by Android's drawing system (the renderer). It groups one node's drawing instructions so later layer properties can affect the complete group.

Offscreen buffer

Rasterize means execute drawing instructions and store their result as pixels. An offscreen buffer is that temporary pixel image before it is drawn into the final scene. A draw layer does not always require one.

4 · DRAW LAYER VERSUS OFFSCREEN PIXELS

Do not use “layer” and “bitmap” as synonyms

Draw layer exists

LayerArtwork commands → captured as one draw layer → layer properties can transform the group

This is the core graphicsLayer contract.

Auto may rasterize

alpha < 1 or RenderEffect present → Auto uses an offscreen buffer

The drawing instructions execute into temporary pixels, then those pixels are composited into the destination.

No sibling capture

Backdrop sibling ≠ automatic input image for LayerArtwork

A graphics layer groups its own content. It does not create a readable copy of unrelated siblings behind it.

Deferred: Lesson 6.4 applies a RenderEffect to the layer's own content. Lessons 6.6–6.8 create the explicit backdrop recording, coordinate mapping, and replay route.

6 · ANDROID VALUE PATH

Apply one graphicsLayer to the owner that contains every draw

1 · Layout

LayerArtwork receives one measured slot.

2 · Internal drawing

Canvas commands and label content belong to that owner.

3 · graphicsLayer

The owner content becomes one layer group.

4 · Layer properties

Translation, rotation, scale, alpha, and origin apply to the group.

5 · Parent drawing

The transformed layer is composited into the scene.

Box(
    modifier = modifier
        .size(260.dp, 150.dp)
        .graphicsLayer {
            translationX = translationXDp.dp.toPx()
            translationY = translationYDp.dp.toPx()
            rotationZ = rotationDegrees
            scaleX = uniformScale
            scaleY = uniformScale
            alpha = layerAlpha
            transformOrigin = selectedOrigin
        },
) {
    LayerArtworkContent()
}
Why the lambda form: the layer properties read current state inside the graphicsLayer block. When only those properties change, Compose can update the layer properties without changing layout geometry or rewriting each internal command.

9 · EXERCISES

Answer before opening each explanation

Exercise 1 · Layout slot

A 360 × 200 node scales to 1.2× using graphicsLayer. Does layout reserve a 432 × 240 slot?

Show answer

No. The measured slot remains 360 × 200. Only the draw result is scaled.

Exercise 2 · Whole-group alpha

Where should alpha = 0.5f be applied if the base, dot, and label must fade together?

Show answer

Apply the alpha on the graphics layer that owns the complete group, not independently to only one child.

Exercise 3 · Offscreen boundary

Does the existence of graphicsLayer prove that Compose always allocated a bitmap?

Show answer

No. The draw layer groups instructions. Rasterization to an offscreen buffer occurs when the selected properties or compositing strategy require it.

Exercise 4 · Backdrop

Does placing the glass panel in a graphics layer automatically give it a readable image of the backdrop sibling?

Show answer

No. An explicit record, mapping, crop, and replay/read route is still required.

11 · SOURCES AND EVIDENCE

What the Android documentation supports

  • Modifier.graphicsLayer makes composable content draw into a layer and can isolate drawing instructions and apply transformations to the complete group.
  • Layer transforms affect drawing but do not change measured size or layout placement.
  • With the default Auto strategy, alpha below 1 or a RenderEffect causes offscreen rasterization.
  • An explicit GraphicsLayer.record / drawLayer route is a separate mechanism for recording and replaying content; it is not created by sibling overlap.
