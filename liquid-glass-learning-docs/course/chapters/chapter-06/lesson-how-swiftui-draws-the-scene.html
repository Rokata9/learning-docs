From a placed view to a readable backdrop sample

A glass panel needs to know which view owns each pixel, and it needs a readable image of the backdrop region behind it.

3 · VOCABULARY

Words this chapter uses for the scene

View update

body decides which views exist. In Lesson 6.1 the badge exists only on the true branch.

Layout

A Layout measures and places children. The Lesson 6.1 inset is consumed while children are placed.

Rendering

A Canvas renderer paints pixels. Fill color is read there, in points.

Draw order

Sibling order and zIndex decide which draw runs later.

Ownership

The view whose code issued a draw keeps that draw. Reordering siblings leaves ownership where it was.

Owner blur

.blur(radius:opaque:) reads pixels from the selected view. The radius is in points. The explorer prints displayScale beside that radius so the blur input stays the point radius.

recordedBackdrop

The Image produced when ImageRenderer snapshots BackdropArtwork.

Panel sample

A panel-sized clip plus a negative offset of recordedBackdrop. The offset comes from frames in ParentScene.

5 · CHAPTER CHECKPOINT

The sharp two-layer scene

By Lesson 6.11, one ImageRenderer call snapshots BackdropArtwork. The visible backdrop replays that image. The panel replays the same image inside a panel-sized clip whose offset matches the panel origin in ParentScene. Tint and border are later siblings of that replay. ForegroundContent is a later child of the panel, so the label stays sharp. drawingGroup() stays off. The lesson uses that one snapshot.

The live course checkpoint is Lesson 10.1. This chapter checkpoint is the pedagogical end of Chapter 6.
