Distance fields

Lessons 9.1 – 9.6 · 9.14

All in p units: p = uv − (0.5, 0.5) on a square picture, so one step right and one step down have the same length. Sign of sd: minus inside, 0 on the boundary, plus outside.

Distance between two points

9.1
length(p) = √(p.x² + p.y²) ← the long side of a right triangle
distance(A, B) = length(B − A)
Example p = (0.30, −0.40), a 3-4-5 triangle
squares0.30 × 0.30 = 0.09 (−0.40) × (−0.40) = 0.16
sum0.09 + 0.16 = 0.25
root√0.25 = 0.50 because 0.50 × 0.50 = 0.25
Not the walk-around 0.30 + 0.40 = 0.70. Equal-length points form a circle (the walk-around gives a diamond).

Circle signed distance

9.2
sd = length(p) − radius
color = (sd < 0.0) ? orange : navy ← hard if
Example radius 0.25
outsidep = (0.30, −0.40), length 0.50 (previous card): 0.50 − 0.25 = 0.25 → navy
centerp = (0, 0), length 0: 0 − 0.25 = −0.25 → orange
boundaryp = (0.15, −0.20): 0.15 × 0.15 = 0.0225 (−0.20) × (−0.20) = 0.04 0.0225 + 0.04 = 0.0625 √0.0625 = 0.25 0.25 − 0.25 = 0

Soft mask from a distance

9.39.14
mask = 1 − smoothstep(−band, band, sd) ← 1 inside, 0 outside
color = mix(navy, orange, mask)
band half-width of the soft edge (0.10 here; 9.14 uses 0.002 ≈ one pixel). “1 −” is needed because smoothstep rises from inside (−) to outside (+).
Example p = (0.18, −0.24), radius 0.25, band 0.10
sd0.18 × 0.18 = 0.0324 (−0.24) × (−0.24) = 0.0576 0.0324 + 0.0576 = 0.09 √0.09 = 0.30 0.30 − 0.25 = 0.05
t0.05 − (−0.10) = 0.15 0.10 − (−0.10) = 0.20 0.15 ÷ 0.20 = 0.75
smoothstep0.75 × 0.75 = 0.5625 2 × 0.75 = 1.50 3 − 1.50 = 1.50 0.5625 × 1.50 = 0.844
mask1 − 0.844 = 0.156
red0.88 − 0.10 = 0.78 0.78 × 0.156 = 0.122 0.10 + 0.122 = 0.222

Rounded rectangle signed distance

9.4
innerHalf = outerHalf − r ← the smaller sharp box
q = abs(p) − innerHalf ← abs folds every quarter onto one
sdBox = length(q) if q.x > 0 and q.y > 0 ← corner
= q.x if only q.x > 0 ← side
= q.y if only q.y > 0 ← top / bottom
= max(q.x, q.y) otherwise ← inside the inner box
sd = sdBox − r
Example outerHalf (0.30, 0.20), r 0.10, p = (0.26, −0.18)
innerHalfx: 0.30 − 0.10 = 0.20 (outerHalf.x − r) y: 0.20 − 0.10 = 0.10 (outerHalf.y − r) innerHalf.y and r are both 0.10 only here; they are different lengths
qabs: (0.26, 0.18) x: 0.26 − 0.20 = 0.06 (|p.x| − innerHalf.x) y: 0.18 − 0.10 = 0.08 (|p.y| − innerHalf.y)
sdBoxboth > 0 → 0.06 × 0.06 = 0.0036 0.08 × 0.08 = 0.0064 0.0036 + 0.0064 = 0.01 √0.01 = 0.10
sd0.10 − 0.10 = 0 (sdBox − r) → on the boundary

Capsule signed distance

9.59.14
innerHalfW = outerHalfW − radius ← radius = half the height
nearestX = clamp(p.x, −innerHalfW, innerHalfW)
sd = length(p − (nearestX, 0)) − radius
Example outerHalf (0.40, 0.20), radius 0.20, p = (0.32, −0.16)
segment0.40 − 0.20 = 0.20
nearestclamp(0.32, −0.20, 0.20) = 0.20
length0.32 − 0.20 = 0.12 −0.16 − 0 = −0.16 0.12 × 0.12 = 0.0144 (−0.16) × (−0.16) = 0.0256 0.0144 + 0.0256 = 0.04 √0.04 = 0.20
sd0.20 − 0.20 = 0

Combine shapes

9.69.12
pB = p − B ← measure from a second center B
union sd = min(sdA, sdB)
intersection sd = max(sdA, sdB)
B minus A sd = max(sdB, −sdA)
Example radii 0.25, B = (0.20, 0), pixel T: p = (−0.10, 0)
sdA(−0.10) × (−0.10) = 0.01 0 × 0 = 0 0.01 + 0 = 0.01 √0.01 = 0.10 0.10 − 0.25 = −0.15
sdB−0.10 − 0.20 = −0.30 0 − 0 = 0 → pB = (−0.30, 0) (−0.30) × (−0.30) = 0.09 0 × 0 = 0 0.09 + 0 = 0.09 √0.09 = 0.30 0.30 − 0.25 = 0.05
