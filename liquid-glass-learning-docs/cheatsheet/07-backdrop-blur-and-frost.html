Backdrop, blur and frost

Lessons 6.5 – 6.11 · 7.1 – 7.12

Why blur needs the backdrop

1.66.46.56.9
alpha only: out(p) = Panel(p) over B(p) ← one position
blur: B̄(p) = [B(p − 1) + B(p) + B(p + 1)] ÷ 3 ← neighbors
frosted: out(p) = PanelMaterial(p) over B̄(p)
A view's .blur() blurs only its own pixels (6.4). The backdrop B must be recorded (ImageRenderer) and replayed as an image the panel owns.
No feedback loop (6.9): the recorded subtree must not contain the glass panel; otherwise the panel records itself.

Offscreen cost

6.104.8
Wpx = round(Wpt × scale) Hpx = round(Hpt × scale)
pixels = Wpx × Hpx
bytes = pixels × 4 ← RGBA8 estimate
MiB = bytes ÷ 1,048,576
budget = 1,000 ms ÷ frames per second
Example panel 196 × 116 pt at scale 3
size196 × 3 = 588 px 116 × 3 = 348 px
pixels588 × 348 = 204,624
memory204,624 × 4 = 818,496 818,496 ÷ 1,048,576 = 0.781 MiB
budget1,000 ÷ 120 = 8.333 ms per frame at 120 frames per second
Note: double width and height → 2 × 2 = 4 times the pixels. An estimate, not a measured GPU time.
