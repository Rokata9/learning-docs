Rectangle bounds and circle extremes

4.1
right = left + width bottom = top + height
leftmost = centerX − radius rightmost = centerX + radius
topmost = centerY − radius bottommost = centerY + radius
diameter = 2 × radius
Example circle center (520, 145), radius 75
x520 − 75 = 445 520 + 75 = 595
y145 − 75 = 70 145 + 75 = 220
Note: the enclosing 150 × 150 square is not the circle: its corners are outside.

Cubic Bézier: the halfway point

4.64.5
midpoint = ((first x + second x) ÷ 2, (first y + second y) ÷ 2)
round 1: start–c1, c1–c2, c2–end → 3 points
round 2: midpoints of those → 2 points
round 3: midpoint of those → the curve point at halfway
SwiftUI: path.addCurve(to: end, control1: c1, control2: c2); the start is the path's current point.
Example start (120, 300), c1 (280, 100), c2 (540, 100), end (700, 300)
round 1120 + 280 = 400 400 ÷ 2 = 200 300 + 100 = 400 400 ÷ 2 = 200 → (200, 200) 280 + 540 = 820 820 ÷ 2 = 410 100 + 100 = 200 200 ÷ 2 = 100 → (410, 100) 540 + 700 = 1240 1240 ÷ 2 = 620 100 + 300 = 400 400 ÷ 2 = 200 → (620, 200)
round 2200 + 410 = 610 610 ÷ 2 = 305 200 + 100 = 300 300 ÷ 2 = 150 → (305, 150) 410 + 620 = 1030 1030 ÷ 2 = 515 100 + 200 = 300 300 ÷ 2 = 150 → (515, 150)
round 3305 + 515 = 820 820 ÷ 2 = 410 150 + 150 = 300 300 ÷ 2 = 150 → (410, 150)

Move points around a pivot (scale, rotate)

4.105.106.37.4 companion
Δ = P − O ← walk from the pivot O to the point P
scale: Δ′ = Δ × s
rotate 90° clockwise on screen (y down): (Δx, Δy) → (−Δy, Δx)
P′ = O + Δ′ ← add the pivot back
one axis: x′ = Oₓ + (x − Oₓ) × sₓ
Layout is unchanged: scaleEffect and rotationEffect change the drawing only; the measured slot keeps its size (a 360 × 200 view scaled 1.2× still reserves 360 × 200). Inverse of a scale: old = O + (new − O) ÷ s.
Example
rotate 90°O = (90, 150), P = (360, 0) 360 − 90 = 270 0 − 150 = −150 → Δ = (270, −150) (270, −150) → (150, 270) 90 + 150 = 240 150 + 270 = 420 → P′ = (240, 420)
