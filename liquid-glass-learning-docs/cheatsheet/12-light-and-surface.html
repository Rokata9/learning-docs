Light and surface

Lessons 10.1–10.3

Surface height from the rim circle

10.1
sd = d − radius ← Lesson 9.2, or any shape's sd
inside = clamp(−sd, 0, bevel) ← 0 outside, bevel on the flat top
leg = bevel − inside ← from K, the rim circle's center
h = √(bevel² − leg²) ← the missing leg (Lesson 9.1)
gray = h ÷ bevel ← the height map: black 0, white 1
h the surface height above a pixel, in UV (not a box height). bevel the width of the rounded rim and the height of the flat top. The rim is a quarter of the rim circle: center K, bevel inside the outline, radius bevel.
Example W = (0.71, 0.50), C = (0.50, 0.50), radius 0.25, bevel 0.10
sd0.21 − 0.25 = −0.04
inside−(−0.04) = 0.04
leg0.10 − 0.04 = 0.06
h²0.01 − 0.0036 = 0.0064
h√0.0064 = 0.08
gray0.08 ÷ 0.10 = 0.80

X slope from two neighbor heights

10.2
A = W − (step, 0) ← one step left, the same y
B = W + (step, 0) ← one step right, the same y
deltaH = hRight − hLeft ← signed height change from A to B
deltaX = 2 × step ← horizontal distance from A to B
slopeX = deltaH ÷ deltaX ← average x slope; estimate at W
slopeX height change per horizontal UV unit. Plus rises to the right; minus falls. step a chosen small UV distance from W to each neighbor. The formula gives the average slope between A and B, not an exact derivative. It does not measure y change.
Example W = (0.72, 0.50), A = (0.71, 0.50), B = (0.73, 0.50), step 0.01
hLeft0.08
hRight0.06
deltaH0.06 − 0.08 = −0.02
deltaX2 × 0.01 = 0.02
slopeX−0.02 ÷ 0.02 = −1

Unit surface normal from two slopes

10.3
D = W − (0, step) ← one step toward the top of the picture
E = W + (0, step) ← one step toward the bottom of the picture
slopeX = (hRight − hLeft) ÷ (2 × step) ← Lesson 10.2
slopeY = (hE − hD) ÷ (2 × step) ← the same slope along y
rawNormal = (−slopeX, −slopeY, 1) ← the quarter turn of each slope triangle
normalLength = √(x² + y² + z²) ← Lesson 9.1 twice
N = rawNormal ÷ normalLength ← length 1 (Lesson 9.10)
RGB = N × 0.5 + 0.5 ← display only, not lighting
N the unit surface normal: x right, y toward the bottom of the picture, the third part the height direction, toward your eye. rawNormal the arrow at a square corner to the surface before the division. Turning “across 1” a quarter turn makes it the height part 1; turning the slope leg makes it −slope. Dividing by one positive length changes the length, not the direction.
Example W = (0.71, 0.50), slopeX −0.7595, slopeY 0
raw.x−(−0.7595) = 0.7595
raw.y−(0) = 0
x²0.7595 × 0.7595 = 0.57684025
x² + y²0.57684025 + 0 = 0.57684025
x² + y² + z²0.57684025 + 1 = 1.57684025
normalLength√1.57684025 = 1.256
N.x0.7595 ÷ 1.256 = 0.605
N.z1 ÷ 1.256 = 0.796
N.x × 0.50.605 × 0.5 = 0.3025
red0.3025 + 0.5 = 0.8025
N.z × 0.50.796 × 0.5 = 0.398
blue0.398 + 0.5 = 0.898
