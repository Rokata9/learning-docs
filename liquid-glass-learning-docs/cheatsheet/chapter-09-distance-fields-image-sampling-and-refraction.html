Ch 9

Distance fields, image sampling, and refraction

Lessons 9.1 – 9.14

Distance fields. All in p units: p = uv − (0.5, 0.5) on a square picture, so one step right and one step down have the same length. Sign of sd: minus inside, 0 on the boundary, plus outside.

Image sampling. The pixel that is written (W) and the point that is read (R) can differ. The picture then appears to move or resize — always opposite to the read move.

Displacement, refraction and the lens. Defaults: glass radius 0.25 · band 0.10 · dispLen 0.10 · spread 0.10 · maskBand 0.002 · speed 0.10 UV/s. All positions in UV (0 … 1 of a square picture). Read points are drawn on the wallpaper; the output is a separate picture.

Distance between two points

9.1
length(p) = √(p.x² + p.y²) ← the long side of a right triangle
distance(A, B) = length(B − A)
Example p = (0.30, −0.40), a 3-4-5 triangle
squares0.30 × 0.30 = 0.09 (−0.40) × (−0.40) = 0.16
sum0.09 + 0.16 = 0.25
root√0.25 = 0.50 because 0.50 × 0.50 = 0.25
Not the walk-around 0.30 + 0.40 = 0.70. Equal-length points form a circle (the walk-around gives a diamond).

Circle signed distance

9.2
sd = length(p) − radius
color = (sd < 0.0) ? orange : navy ← hard if
Example radius 0.25
outsidep = (0.30, −0.40), length 0.50 (previous card): 0.50 − 0.25 = 0.25 → navy
centerp = (0, 0), length 0: 0 − 0.25 = −0.25 → orange
boundaryp = (0.15, −0.20): 0.15 × 0.15 = 0.0225 (−0.20) × (−0.20) = 0.04 0.0225 + 0.04 = 0.0625 √0.0625 = 0.25 0.25 − 0.25 = 0

Soft mask from a distance

9.39.14

Rounded rectangle signed distance

9.4
innerHalf = outerHalf − r ← the smaller sharp box
q = abs(p) − innerHalf ← abs folds every quarter onto one
sdBox = length(q) if q.x > 0 and q.y > 0 ← corner
= q.x if only q.x > 0 ← side
= q.y if only q.y > 0 ← top / bottom
= max(q.x, q.y) otherwise ← inside the inner box
sd = sdBox − r
Example outerHalf (0.30, 0.20), r 0.10, p = (0.26, −0.18)
innerHalfx: 0.30 − 0.10 = 0.20 (outerHalf.x − r) y: 0.20 − 0.10 = 0.10 (outerHalf.y − r) innerHalf.y and r are both 0.10 only here; they are different lengths
qabs: (0.26, 0.18) x: 0.26 − 0.20 = 0.06 (|p.x| − innerHalf.x) y: 0.18 − 0.10 = 0.08 (|p.y| − innerHalf.y)
sdBoxboth > 0 → 0.06 × 0.06 = 0.0036 0.08 × 0.08 = 0.0064 0.0036 + 0.0064 = 0.01 √0.01 = 0.10
sd0.10 − 0.10 = 0 (sdBox − r) → on the boundary

Displacement field

9.109.10 Q&A
p = uv − (0.5, 0.5)
d = length(p)
dir = p ÷ d ← length 1, away from C
← skipped if d ≤ 0.0001
disp = dir × dispLen ← the same length for every pixel
readUv = uv − disp ← R lies dispLen closer to C
color = wall(readUv)
dispLen a UV read distance, not a percentage. Every read point moves the same length toward C, so the whole picture bends, even far from C.
Example W = (0.65, 0.20), dispLen 0.10
p0.65 − 0.50 = 0.15 0.20 − 0.50 = −0.30
d0.15 × 0.15 = 0.0225 (−0.30) × (−0.30) = 0.09 0.0225 + 0.09 = 0.1125 √0.1125 = 0.335
dir0.15 ÷ 0.335 = 0.448 −0.30 ÷ 0.335 = −0.896
disp0.448 × 0.10 = 0.0448 −0.896 × 0.10 = −0.0896
readUv0.65 − 0.0448 = 0.6052 0.20 − (−0.0896) = 0.2896
color0.6052 × 4 = 2.4208 → 2 0.2896 × 4 = 1.1584 → 1 2 + 1 = 3 → odd → navy (W itself sits on orange)

Refraction: push fades across the band

9.119.11 Q&A
sd = d − radius
falloff = 1 − smoothstep(−band, band, sd) ← 1 inside, 0 outside
push = dispLen × falloff
disp = dir × push ← = dir × dispLen × falloff
readUv = uv − disp
Rings: inner ring sd = −band (0.15 from C, full push 0.10) · circle sd = 0 (half push 0.05) · outer ring sd = +band (0.35 from C, no push). Outside the outer ring nothing moves: the line x = 0.90 stays straight.
Example W = (0.65, 0.30), C = (0.50, 0.50)
p0.65 − 0.50 = 0.15 0.30 − 0.50 = −0.20
d, sd0.15 × 0.15 = 0.0225 (−0.20) × (−0.20) = 0.04 0.0225 + 0.04 = 0.0625 √0.0625 = 0.25 0.25 − 0.25 = 0
falloff0 − (−0.10) = 0.10 0.10 − (−0.10) = 0.20 0.10 ÷ 0.20 = 0.50 0.50 × 0.50 = 0.25 (t²) 0.25 × 0.50 = 0.125 (t³) 3 × 0.25 = 0.75 2 × 0.125 = 0.25 0.75 − 0.25 = 0.50 1 − 0.50 = 0.50
push0.10 × 0.50 = 0.05
dir, disp0.15 ÷ 0.25 = 0.60 −0.20 ÷ 0.25 = −0.80 0.60 × 0.05 = 0.03 −0.80 × 0.05 = −0.04
readUv0.65 − 0.03 = 0.62 0.30 − (−0.04) = 0.34
color0.62 × 4 = 2.48 → 2 0.34 × 4 = 1.36 → 1 2 + 1 = 3 → navy
Why smoothstep, not a straight line: a straight falloff has corners at the two rings, so the bent lines get visible kinks there; a hard if makes a jump (lines break and pixels near the circle are never read). Compare them in the diagram below.

Edge safety: clamp the read point

9.12
p = uv − center ← the glass can sit anywhere
readUv = uv − disp ← R, may leave the wallpaper
readUv = clamp(readUv, 0.0, 1.0) ← R′: x and y clamped separately
color = checkerWithEdge(readUv) ← transparent outside 0 … 1
Without the clamp, pixels whose R leaves the picture have no color: a see-through seam (an arch along the bottom edge). R′ is not where the push arrow crosses the edge. SwiftUI's Layer.sample already clamps. With the glass in the middle the clamp changes no pixel.

Gentle chromatic separation

9.13
readRed = clamp(uv − disp × (1 − spread), 0, 1) ← shorter push
readGreen = clamp(uv − disp, 0, 1) ← the 9.12 read point
readBlue = clamp(uv − disp × (1 + spread), 0, 1) ← longer push
color = half4(colRed.r, colGreen.g, colBlue.b, 1.0) ← one channel from each
strip width = spread × push ← 0.10 × 0.10 = 0.01 UV at full push

Lens checkpoint: mask × bend

9.14
sd = length(p) − radius ← computed for every pixel
mask = 1 − smoothstep(−maskBand, maskBand, sd) ← answer 1: is it glass?
bent = the 9.13 color ← answer 2: where to read
plain = wall(uv, time) ← the wallpaper at the pixel itself
color = mix(plain, bent, mask) ← = plain + (bent − plain) × mask
wall(x, y, time) = checker(x + speed × time, y) ← moves left
maskBand 0.002 ≈ one pixel of a 520-px picture (520 × 0.002 = 1.04); iOS: 1 ÷ resolution.x. Mixing by falloff instead gives a 0.20-wide ghost ring; a hard if gives stair steps. Cost: four wallpaper reads per pixel.
