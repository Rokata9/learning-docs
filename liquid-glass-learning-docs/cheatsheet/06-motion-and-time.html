Motion and time

Lessons 5.1 – 5.12 · 8.10

Course endpoints (5.1): resting button 64 × 64 pt, radius 32 pt → expanded menu 320 × 232 pt, radius 28 pt. Duration 700 ms (5.3 – 5.7) or 800 ms (5.12).

Elapsed time and progress

5.25.3
elapsed = current timestamp − start timestamp
ms = ns ÷ 1,000,000
progress = clamp(elapsed ÷ duration, 0, 1) ← unitless
Example
elapsed12,350,000,000 − 12,000,000,000 = 350,000,000 ns 350,000,000 ÷ 1,000,000 = 350 ms
progress350 ÷ 700 = 0.50
too late800 ÷ 700 = 1.143 → clamp → 1

Linear interpolation

5.15.48.11
value = start + (end − start) × progress
mix(a, b, t) = a + (b − a) × t ← the Metal name (Lesson 8.11)
Example width 64 → 320 pt
progress 0.25320 − 64 = 256 256 × 0.25 = 64 64 + 64 = 128 pt
alpha 1 → 00 − 1 = −1 −1 × 0.75 = −0.75 1 + (−0.75) = 0.25
Why not end × progress? That measures from 0, not from the start value.

Easing

5.55.6
linear eased = p
ease in eased = p × p
ease out eased = 1 − (1 − p) × (1 − p)
value = start + (end − start) × eased
Graph: x = raw progress p, y = eased progress. Below the diagonal = a smaller part of the change so far, not backwards motion. 0 → 0 and 1 → 1 always.
Example p = 0.25
ease in0.25 × 0.25 = 0.0625
width256 × 0.0625 = 16 64 + 16 = 80 pt
ease out1 − 0.25 = 0.75 0.75 × 0.75 = 0.5625 1 − 0.5625 = 0.4375

Average velocity

5.7
velocity = value change ÷ time change ← pt per second

Δ width128 − 80 = 48 pt
Δ time350 − 175 = 175 ms 175 ÷ 1000 = 0.175 s
velocity48 ÷ 0.175 = 274.286 pt/s (closing: −274.286)

Spring (one Euler tick)

5.85.11
d = T − x ← signed distance to target
S = k × d ← spring pull
D = −c × v ← damping push
N = S + D Δv = N ÷ m
v_next = v + Δv x_next = x + v_next
overshoot o = max(0, x − T)
settled: |T − x| < 0.01 and |v| < 0.01 for 2 ticks in a row
k stiffness · c damping · m mass (teaching values, not SwiftUI constants). Interruption (5.11): a new target keeps the current x and v.
Example k 0.18, c 0.50, m 1, T 1, start x 0, v 0
tick 11 − 0 = 1 0.18 × 1 = 0.18 −0.50 × 0 = 0 0.18 + 0 = 0.18 0.18 ÷ 1 = 0.18 0 + 0.18 = 0.18 (v) 0 + 0.18 = 0.18 (x)
tick 21 − 0.18 = 0.82 0.18 × 0.82 = 0.1476 −0.50 × 0.18 = −0.09 0.1476 + (−0.09) = 0.0576 0.0576 ÷ 1 = 0.0576 0.18 + 0.0576 = 0.2376 (v) 0.18 + 0.2376 = 0.4176 (x)

Play-time clock (slow motion)

5.12
Δt_real = t_now − t_previous
Δt_sim = Δt_real × speed
p_next = clamp(p + dir × Δt_sim, 0, duration) ← dir = +1 open, −1 close
step = p + dir × h ← h = 16 ms debug step
u = p ÷ duration ← progress
Example
slow20 × 0.25 = 5 ms
step1 × 16 = 16 320 + 16 = 336 ms
progress336 ÷ 800 = 0.42
reverse−1 × 16 = −16 320 + (−16) = 304 ms

Time uniform and fract

8.109.14
trips = elapsedSeconds ÷ 4.0 ← Swift side
red = fract(uv.x − time) ← shader side
fract(x) = x − floor(x) ← floor: largest integer ≤ x
shift = speed × time ← 9.14 moving wallpaper, speed 0.10 UV/s
Example pixel x = 100 on a 400-px width, time = 0.50 trips
uv.x100 ÷ 400 = 0.25
fract0.25 − 0.50 = −0.25 floor(−0.25) = −1 −0.25 − (−1) = 0.75
9.14 shift0.10 × 2 = 0.20 UV at time = 2 s
