Image sampling

Lessons 9.7 – 9.9 (wallpaper rule used up to 9.14)

The pixel that is written (W) and the point that is read (R) can differ. The picture then appears to move or resize — always opposite to the read move.

Ask the input for a color

9.7
sampled = background(fragCoord, resolution)
← a copy of the input color at that pair
stripes input: cell = fract(uv.x × 5.0)
cell < 0.5 → orange, else navy
Example pixel T, uv.x = 0.15 on a 400-px square
pixel0.15 × 400 = 60 px
cell5.0 × 0.15 = 0.75 fract(0.75) = 0.75
color0.75 ≥ 0.5 → navy

Checkerboard wallpaper rule

9.99.109.129.13
col = floor(x × 4) row = floor(y × 4)
col + row even → orange (white) odd → navy (black)
9.12 on: col = min(floor(x × 4), 3), the same for row
← the edge 1.00 belongs to the last cell
9.12 on: outside 0 … 1 → transparent (no wallpaper)
Same test written another way (9.10): fract((col + row) × 0.5) is 0 for even, 0.5 for odd. Black and white from 9.13 on.
Example read point (0.62, 0.34)
col0.62 × 4 = 2.48 → floor → 2
row0.34 × 4 = 1.36 → floor → 1
color2 + 1 = 3 → odd → navy

Translate the read point

9.8
readCoord = fragCoord − (offsetU × resolution.x, 0)
sampled = background(readCoord, resolution)
offsetU width fraction to read to the left. The stripes appear to move right. background() does not clamp or wrap a negative read x.
Example W at x = 60 px (uv.x 0.15), offsetU 0.10, width 400
offset0.10 × 400 = 40 px
read60 − 40 = 20 px 20 ÷ 400 = 0.05
cell5.0 × 0.05 = 0.25 fract(0.25) = 0.25 → orange stored at W

Scale around the center

9.9
p = uv − 0.5
readUv = p ÷ scale + 0.5 ← scale 2 reads half as far from C: magnify
scale is the magnification, not displayScale. No “inner half” if: at scale 2 the middle 2 × 2 cells fill the picture; the outer ring is never read.
Example W = uv (0.80, 0.50), scale 2
p0.80 − 0.5 = 0.30 0.50 − 0.5 = 0
÷ scale0.30 ÷ 2 = 0.15 0 ÷ 2 = 0
+ 0.50.15 + 0.5 = 0.65 0 + 0.5 = 0.50 → R = (0.65, 0.50)
color0.65 × 4 = 2.60 → 2 0.50 × 4 = 2 → 2 2 + 2 = 4 → even → orange
