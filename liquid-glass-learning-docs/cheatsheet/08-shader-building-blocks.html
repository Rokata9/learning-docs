Shader building blocks

Lessons 8.1 – 8.12

A shader is one small function that runs once per output pixel. Swift passes arguments (uniforms) once per draw; every pixel reads the same values. Coordinates are in the Coordinates category.

One function per pixel

8.18.28.38.9
color = colorAt(column, row) ← the same function for every pixel
call number = row × width + column + 1 ← CPU loop order, 8 × 4 grid
return half4(r, g, b, a) ← channels 0 … 1
stripe: column remainder 2 = 1 → navy, 0 → orange
Example column 3, row 1 on an 8-wide grid
call1 × 8 = 8 8 + 3 = 11 11 + 1 = 12
stripe3 remainder 2 = 1 → navy

clamp

8.119.59.12
clamp(x, lo, hi) = min(max(x, lo), hi) ← both ends included
saturate(x) = clamp(x, 0.0, 1.0)
clamp(pair, 0, 1) clamps x and y separately
Example
belowmax(−0.20, 0) = 0 min(0, 1) = 0
insidemax(0.45, 0) = 0.45 min(0.45, 1) = 0.45
abovemax(1.20, 0) = 1.20 min(1.20, 1) = 1

mix

8.115.49.39.14
mix(a, b, t) = a + (b − a) × t ← t = 0 gives a, t = 1 gives b
colors: the same t for red, green and blue
Example mix(navy, orange, 0.25)
red0.88 − 0.10 = 0.78 0.78 × 0.25 = 0.195 0.10 + 0.195 = 0.295
green0.48 − 0.25 = 0.23 0.23 × 0.25 = 0.0575 0.25 + 0.0575 = 0.3075
blue0.18 − 0.40 = −0.22 −0.22 × 0.25 = −0.055 0.40 + (−0.055) = 0.345
t outside 0 … 1 walks past the colors: t = 1.50 gives red 0.78 × 1.50 = 1.17, 0.10 + 1.17 = 1.27. Clamp t first.

smoothstep

8.119.39.11
t = clamp((x − edge0) ÷ (edge1 − edge0), 0, 1) ← requires edge1 > edge0
smoothstep = t × t × (3 − 2t)
= 3t² − 2t³ ← the form used in 9.11 – 9.14
0 left of edge0, 1 right of edge1, an S-shaped rise in between (slow, fast, slow).
Example x = 0.45 (pixel 180 of 400), edges 0.40 … 0.60
t0.45 − 0.40 = 0.05 0.60 − 0.40 = 0.20 0.05 ÷ 0.20 = 0.25
curve0.25 × 0.25 = 0.0625 2 × 0.25 = 0.50 3 − 0.50 = 2.50 0.0625 × 2.50 = 0.156 (exact 0.15625)
store red0.88 − 0.10 = 0.78 0.78 × 0.156 = 0.122 0.10 + 0.122 = 0.222
