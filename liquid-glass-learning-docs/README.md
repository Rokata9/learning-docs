# Liquid Glass on iOS — learning documents

Interactive, picture-first lessons for building Liquid Glass effects on iOS from first principles. Open `liquid-glass-course.html` in a browser.

## The documents

- [Start a lesson chat](NEW_CHAT_PROMPT.md) to generate a lesson or ask about one.
- [Authoring rules](AGENTS.md) describe how to teach from zero math, show where numbers come from, explain where the result is used, and verify a lesson.
- [Current state](CURRENT_STATE.md) records the latest lessons, example inputs, and lab paths.
- [Safari menu plan](curriculum/safari_spring_menu_plan.md#4-the-new-plan) supplies the part-two lesson order, scope, and dependencies.

The [323-lesson curriculum](curriculum/liquid_glass_ios_curriculum.md) records the original sequence and course conventions. Older per-lesson notes, feedback, and handoffs are linked from [Current state](CURRENT_STATE.md).
