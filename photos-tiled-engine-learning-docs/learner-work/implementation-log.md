# Learner Implementation Log

This log records learner authorship and evidence. Add one entry for each lesson that changes the Android project.

## Assistance levels

- **0 — Contract only:** lesson behavior, invariants, and expected results.
- **1 — Concept hint:** one relevant concept or API named.
- **2 — Boundary hint:** responsible file, object, thread, or value path identified.
- **3 — Learner-code diagnosis:** the learner's submitted code reviewed and the first wrong assumption identified.
- **4 — Syntax unblock:** the smallest isolated syntax example needed to remove one block.
- **5 — Post-completion comparison:** architecture compared with the sealed baseline after independent completion.

Levels describe help, not authorship. The learner still writes every Android-project line.
