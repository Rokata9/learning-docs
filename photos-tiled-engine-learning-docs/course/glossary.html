Tiled-engine glossary

Future lessons expand this file before relying on a new term across documents.

GradleThe build-automation tool used by this project. Gradle reads configuration files, creates a build model—an in-memory description of projects and tasks—and runs requested tasks. A task is one named unit of build work.
Root projectThe top-level project in one Gradle build. In this source tree the root project is named Photos.
SubprojectOne registered build unit inside a Gradle root build. Android Studio commonly calls an Android-configured subproject a module.
Settings scriptThe root settings.gradle.kts file that declares which projects belong to the Gradle build.
Project pathGradle's identifier for a project inside one build. :tiled-engine is a project path, not a filesystem path.
Project directoryThe physical directory assigned to a Gradle project. By default, :tiled-engine maps to the child directory tiled-engine/ under the root.
Project registrationAdding a project path to Gradle's build model through the settings script. Creating a directory alone does not register it.
Kotlin DSLGradle configuration written with Kotlin script syntax. Files ending in .gradle.kts use this domain-specific language.
Gradle pluginSoftware applied to a project to add and configure capabilities and tasks. The Android library plugin is first applied in Lesson 1.2.
Build scriptA project-level file such as build.gradle.kts that applies plugins and configures that project. Lesson 1.1 does not create this file.
Application binary interface (ABI)The binary-level rules that let compiled code agree on data layout, calling conventions, and symbols. In this project, an Android ABI also names a CPU target such as arm64-v8a.
Decoded pixel bufferMemory that contains color-channel bytes for a rectangular pixel grid. It is not the compressed image file.
Row strideThe byte distance from the start of one stored pixel row to the start of the next row.
Half-open rectangleA rectangle that includes its left and top edges and excludes its right and bottom edges. Its width is right minus left.
ResamplingProducing a new pixel grid by calculating output pixels from positions in an input pixel grid.
JNIJava Native Interface: the runtime boundary used for calls and object references between Kotlin/Java and C++.
RAIIResource acquisition is initialization: a C++ ownership technique in which a resource is released by an object destructor when that object leaves its lifetime.
EGLThe API that creates graphics contexts and connects OpenGL ES rendering to an Android native window.
OpenGL ESThe embedded-device version of OpenGL used here to upload textures and draw two-dimensional triangles.
Pyramid levelOne complete version of an image reduced by a power of two. A level is introduced before it is divided into tiles.
TileOne rectangular piece cut from one pyramid level.
TextureGPU-accessible image storage sampled by a shader while drawing.
FenceA synchronization object that signals when earlier asynchronous work has completed.
