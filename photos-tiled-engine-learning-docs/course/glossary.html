Canonical terminology

Course glossary

Each recurring term has one stable definition here. Lessons still define a term at first use, then link back to this page. The glossary grows as the course progresses.

Android hardware buffer (AHardwareBuffer)

A block of image memory allocated by Android's graphics allocator so CPU and GPU components can share it under explicit synchronization rules.

Application Binary Interface (ABI)

The binary-level agreement about machine instructions, register use, data layout, and function calls. Android packages separate native libraries for each supported CPU family.

Channel

One stored component of a pixel, such as red, green, blue, or alpha. A channel value is a number, not a complete color by itself.

Decode

Convert compressed image-file data into pixel values that code or a GPU texture can use.

EGL

The platform bridge that creates an OpenGL ES context and connects it to an Android window surface.

EGLImage

A shareable image object that lets EGL-backed memory be bound to a graphics API object such as an OpenGL texture.

Fence

A completion signal. One component waits on the fence before reusing memory that another component may still read or write.

GPU

Graphics processing unit. It executes many drawing and sampling operations in parallel.

Java Native Interface (JNI)

The bridge that lets Kotlin or Java call C/C++ code and lets native code interact with Java virtual-machine objects.

Least-recently-used (LRU) eviction

A cache policy that removes the entry whose last use is oldest when the cache needs space.

Magic bytes

Format-identifying byte patterns near the beginning of a file. They are stronger evidence than a filename extension.

OpenGL ES

The mobile and embedded form of the OpenGL graphics API. This course uses it to draw image textures into an Android surface.

Pixel

One addressable position in a raster image. Its stored channels describe a sample at that position.

Pyramid level

One resolution in a set of progressively downscaled versions of the same image. The engine chooses a level whose pixels match the current screen scale.

Raster image

A rectangular grid of pixels arranged in rows and columns.

Region decode

Decode only a requested rectangular part of an image instead of decoding the complete source image.

Row stride

The number of bytes from the start of one pixel row in memory to the start of the next row. It may be larger than visible row width because of padding.

Screen-resolution transition image

The temporary detail-screen drawable requested near the destination view size. It is not necessarily the original full-resolution file.

SurfaceView

An Android view whose visible pixels come from a separate surface layer managed by the system compositor.

Texture

GPU-accessible image storage sampled by a shader while drawing.

Tile

A rectangular image region decoded, cached, uploaded, and drawn independently from other regions.

Tile pyramid

The complete set of tiles across all resolution levels of an image.

Transition overlay clone

The temporary full-window ImageView copy that moves from the tapped grid cell to the detail bounds.

Zoom-appropriate tile

A decoded tile from the pyramid level that supplies enough detail for the current zoom without decoding unnecessary source pixels.
