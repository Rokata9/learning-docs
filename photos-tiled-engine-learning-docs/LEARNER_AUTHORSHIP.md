# Learner authorship boundary

Every line added to the Android project during this course is manually authored by the learner.

This includes Kotlin, C++, JNI bridge code, CMake, Gradle, tests, tracing helpers, benchmarks, and implementation comments.

## Allowed lesson material

A lesson may provide plain-language definitions, source-derived behavior contracts, framework-required signatures, surviving call-site excerpts, diagrams, exact input/output examples, invariants, test scenarios, expected results, compiler/runtime errors to diagnose, progressively narrower hints, and review of learner-authored code.

## Disallowed lesson material

A lesson must not provide a complete project-ready implementation body, apply-ready patch, complete replacement source file, complete test body, original sealed function body before Lesson 60.13, or a near-transcribable solution disguised as a hint.

Explanation and review do not reduce authorship. Copying generated production code would.
